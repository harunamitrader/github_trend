Gemini CLI v0.51.0-nightly.20260707: macOSサンドボックス改善とエスケープシーケンス不具合修正

macOSサンドボックス下での ~/.gitconfig 読み取り専用化や、最新モデル向け文字列リテラル内エスケープシーケンス保持の修正などを実施。

リリース日 2026-07-07
バージョン v0.51.0-nightly.20260707.g15a9429b6
ツール Gemini CLI

主な変更点

Gemini CLI v0.51.0-nightly.20260707 では、macOS 環境におけるセキュリティサンドボックスの堅牢化、および最新モデルでの構文解釈の不具合修正が行われました。主な変更点は以下の通りです。

  • macOS サンドボックスにおける ~/.gitconfig 読み取り専用化: macOS 環境下での動作時において、セキュリティ保護のためユーザーのホームディレクトリ配下にある ~/.gitconfig ファイルへの書き込みを制限し、読み取り専用（read-only）に変更しました。
  • 文字列リテラル内エスケープシーケンスの保持: 最新の推論・コード生成モデル向けに、生成される文字列リテラル中のエスケープシーケンスが壊れずに正しく保持されるようパーサーおよび内部処理を修正しました。

影響や使いどころ

macOS 上で Gemini CLI を用いて自律実行を行う際、不正なスクリプトやツールコードによって Git 設定（ユーザー名やメールアドレス、グローバル設定など）が意図せず書き換えられるリスクを抑止し、安全性が高まりました。また、文字列エスケープのバグ修正は、エージェントが複雑なコード（正規表現やエスケープされた文字列を含むプログラム）を生成・修正する際の正確性を向上させます。

まとめ

macOS サンドボックスの安全性向上と、コード生成の正確性に直結する文字列処理の改善を盛り込んだ堅実なセキュリティ・機能改善リリースです。
