ChatGPT: 2026-07-16 Update

デスクトップアプリへの Chat/Work モード切り替えスイッチャーの搭載や、プロジェクトアクセスと統一された Recents ビューによるインターフェース刷新

リリース日 2026-07-19
トピック デスクトップアプリの UI 刷新と Work モードの強化
ツール ChatGPT

主な変更点

OpenAI は ChatGPT のデスクトップアプリ（Windows/macOS）をアップデートし、日常的な対話と複雑な作業セッションを分離・整理するための大幅な UI / 機能の再設計を実施しました。主な変更点は以下の通りです。

  • Chat vs. Work Switcher の導入: 簡単な質問をする通常の「Chat」モードと、ファイル操作や自律タスクを統合する「Work」モードをワンクリックで切り替えるグローバルスイッチを搭載しました。
  • 統合「Recents」ビュー: 過去のすべてのチャットセッションやプロジェクトワークスペース履歴を単一のサイドバーから管理・アクセス可能にしました。
  • Work会話のクラウド同期: デスクトップアプリ上で進行している複雑な Work セッションの状態を安全にクラウドと同期し、他のデバイスから再開できるようにしました。

影響や使いどころ

開発作業やドキュメント作成といった複雑な「仕事」と、ちょっとした調べ物の「雑談」が UI 上で明確に分離されるため、プロジェクト管理の負担が軽減されます。また、同期機能により異なる PC 間での作業引き継ぎが容易になります。

まとめ

ChatGPT デスクトップアプリの最新アップデートは、生産性向上に不可欠な「Work」としての AI 利用に特化した画面レイアウトを提供し、より仕事での常用に適したツールへと進化させました。
