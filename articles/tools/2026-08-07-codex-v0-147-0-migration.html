Codex / Product Update

OpenAI Codex CLI v0.147.0

CLIのバージョンバンプ、GPT-5.4世代からGPT-5.6世代へのモデル移行スケジュールの発表、および安定性の改善

リリース日 2026-08-07
バージョン v0.147.0
ツール Codex

主な変更点

OpenAI CodexのCLIツール「v0.147.0」がリリースされました。また、古いGPT-5.4系モデルから最新のGPT-5.6系モデルへの移行に向けたシャットダウンプランが発表されています。主な変更点は以下の通りです。

  • CLI v0.147.0のリリース: 依存関係のバンプや、特定の対話セッション起動時の初期化の高速化を含むメンテナンス更新が実施されました。
  • GPT-5.4モデルの廃止告知: Codexセッションでも使用されていたGPT-5.4系モデルが2026年8月31日をもって廃止され、今後はGPT-5.6系（Sol / Luna等）に置き換わることが発表されました。
  • セッション安定性の改善: 特に対話が長く続いた際の、CLIとモデル間の接続保持に関する挙動が最適化されました。

影響や使いどころ

8月末のGPT-5.4系廃止に伴い、Codex APIやCLIを利用して自動実行しているスクリプトのデフォルトモデル設定をGPT-5.6系に更新することが推奨されます。

まとめ

接続の安定化などを図るCLIのメンテナンスと、8月末に予定されているGPT-5.4系モデル廃止に向けた準備を求める移行期のアナウンスメントです。
