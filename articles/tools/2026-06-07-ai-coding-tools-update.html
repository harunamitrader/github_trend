2026-06-07 AIコーディングツール アップデート

Claude Code 2.1.167、GitHub Copilot の 1M token context と reasoning 更新、Gemini CLI v0.47.0-nightly.20260605、Codex v0.138.0-alpha.6 をまとめた 2026-06-07 の監視ログです。

リリース日 2026-06-07
カテゴリ Coding
ツール Claude Code, GitHub Copilot, Gemini CLI, Codex

主な変更点

2026年6月7日 JST の監視では、Claude Code が 2.1.167 まで進み、GitHub Copilot は大規模コンテキストと reasoning の制御を広げ、Gemini CLI は nightly 更新、Codex は alpha.6 の更新が入りました。Cline / Cursor / Windsurf / Antigravity は前回ログから変化なしです。

  • Claude Code v2.1.167: `fallbackModel` 設定、deny ルールの glob 対応、cross-session messaging の権限切り離し、fallback モデルへの再試行追加など、障害時の逃げ道と権限制御を同時に固めています。直前の 2.1.166〜2.1.162 も、挙動安定化と長時間セッションの耐性改善が中心でした。
  • GitHub Copilot: June 4 の changelog で 1M token context windows と configurable reasoning levels が公開され、VS Code の May releases と Visual Studio の May update も続けて出ました。長い文脈を扱う場面と、IDE ごとの agent 体験の差分が広がっています。
  • Gemini CLI v0.47.0-nightly.20260605: 6/5 の nightly でタグが更新され、直前の nightly からは release chore の差分のみでした。0.46.0-preview.2 と 0.45.2 も同日に並んでおり、現時点では安定版より nightly / preview 系の追従が先に進んでいます。
  • Codex v0.138.0-alpha.6: alpha.5 から alpha.6 への差分では、submission payload の serde 片付け、terminal turn error の goal blocking 化、legacy remote plugin startup sync の削除、Responses Lite の専用ツール化など、内部基盤の整理が進みました。公開向けの新機能より、実装面の再設計が目立つ回です。

影響や使いどころ

Claude Code と Copilot は実運用の境界条件を広げる更新、Gemini CLI と Codex は nightly / alpha 系の追跡と内部基盤の整理が中心です。特に Copilot の大規模コンテキスト、Claude Code の fallback モデル、Codex の goal blocking は、普段の使い方とエラー時の体験に直結します。

まとめ

今回は 4 ツールが更新されました。日常利用の安定性を上げる修正と、長文コンテキストや reasoning の拡張が同時に進んでいるので、次回はそれぞれの既定設定と課金・権限の扱いを見直すと差分を追いやすいです。
