2026-06-17 AIコーディングツール アップデート

Claude Code v2.1.178、Codex 0.140.0 / 0.141.0-alpha.3、GitHub Copilot usage metrics をまとめた 2026-06-17 の監視ログです。

リリース日 2026-06-17
カテゴリ Coding
ツール Claude Code, Codex, GitHub Copilot

主な変更点

2026年6月17日 JST の監視では、Claude Code、Codex、GitHub Copilot に新しい更新がありました。Antigravity / Cursor / Windsurf / Cline / Gemini CLI は前回ログから変化なしです。

  • Claude Code v2.1.178: `Tool(param:value)` 形式の権限ルール、ネストした `.claude/skills` の解決、作業ディレクトリに近い `.claude/` を優先する挙動、auto mode の事前判定、`/doctor` の見やすさ改善、skill 一覧の省略警告、workflow トリガーの判定整理、Remote Control のエラー説明強化、`/bug` の説明必須化が入りました。
  • Codex 0.140.0 / 0.141.0-alpha.3: `0.140.0` では `/usage`、`/goal` の大きな貼り付け対応、`codex delete` / `/delete`、`/import`、`@` で開くメンションメニュー、Bedrock API-key 認証、SQLite の自動復旧、`/review` の Esc 修正、MCP の再試行改善が入りました。続く `0.141.0-alpha.3` も 6 月 16 日に公開され、開発版はさらに前進しています。
  • GitHub Copilot usage metrics: サーバー側 telemetry を追加して、client 側だけでは拾い切れない active user を enterprise の日次・28日レポートに反映する更新です。usage metrics API で見える利用者数が、実際の稼働にもう少し近づきます。

影響や使いどころ

Claude Code は skill / permission / workflow の解決順が細かくなったので、既存のルールセットを持つ人ほど確認価値があります。Codex は `/usage` と `/delete`、`/import` の追加で日常運用の入り口が増え、GitHub Copilot は usage metrics の数値を以前より現実に近づけて見られるようになりました。

まとめ

今回は CLI と管理系の更新が中心です。Claude Code は権限ルールと skill 解決順、Codex は運用コマンドと安定化、GitHub Copilot は usage metrics の精度向上がポイントです。
