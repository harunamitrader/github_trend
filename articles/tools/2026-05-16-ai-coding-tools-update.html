AI Coding Tools Update: Claude Code v2.1.142, Gemini CLI, Codex v0.17.3

Claude Code が Opus 4.7 を標準採用。Gemini CLI や Codex も週末に向けた安定化アップデートを配信

更新日 2026-05-16
カテゴリー Coding
ステータス Update

アップデートの概要

2026年5月16日、主要な AI コーディングツール群に重要なアップデートが配信されました。特に Claude Code では推論モデルの刷新が行われ、開発効率のさらなる向上が期待されます。

Claude Code v2.1.142

Fast mode（--fast）のデフォルトモデルが、最新の Claude Opus 4.7 に移行されました（以前は 4.6）。これにより、高速なレスポンスを維持しつつ、より複雑なコードリファクタリングやアーキテクチャ提案の精度が向上しています。

Gemini CLI v0.44.0-nightly.20260515

GrepTool における大文字小文字判別（case-sensitivity）の不具合が修正されました。また、内部メトリクスの整合性が向上し、エージェントのトークン消費量や実行時間の統計がより正確に記録されるようになっています。

Codex (oh-my-codex) v0.17.3

マルチエージェントチームの起動時に発生していたマイナーバグを修正。さらに、MCP（Model Context Protocol）サーバー間の分離保護機能が強化され、複数のプラグインが競合する環境下での安定性が向上しました。

開発者への影響

Claude Code ユーザーは、特に設定を変更することなく、今日からより賢くなった Opus 4.7 による高速コーディングを享受できます。Gemini CLI を自動化パイプラインに組み込んでいる場合は、Grep 処理の正確性が向上した最新の nightly ビルドへの更新を推奨します。

今後の展望

Opus 4.7 への対応が各ツールで進んでおり、週末にかけて Cursor や Windsurf でも同様のモデル最適化が行われる可能性があります。引き続き、各ツールのリリースノートを注視していきます。
