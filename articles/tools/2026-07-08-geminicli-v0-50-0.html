Gemini CLI v0.50.0: ツールレジストリ・ディスカバリ機能の導入とリリースプロセスの安全対策

ツールレジストリ・ディスカバリ機能の導入、NPMインストール検証時のセキュリティ保護、CIバイナリ競合防止などを実施した正式バージョンリリース。

リリース日 2026-07-08
バージョン v0.50.0
ツール Gemini CLI

主な変更点

Gemini CLI v0.50.0 は、自律エージェントが使用する周辺ツールの管理機能強化や、本番公開プロセスでの安全性とCIプロセスの最適化を盛り込んだ正式リリースです。主な変更点は以下の通りです。

  • ツールレジストリ・ディスカバリ（Tool Registry Discovery）機能: 自律エージェントがローカルやリモートの環境から使用可能な外部ツールを発見し、自動登録するレジストリディスカバリ機能が追加されました。
  • NPM ci 検証におけるセキュリティ対策: リリースの検証ステップ（NPM ci）実行時に外部スクリプトの実行を無効化（ignore scripts）し、不審な外部コードの読み込みを遮断しました。
  • リリース検証のバイナリ衝突修正: CI上でリリース検証を行う際、ローカルワークスペース内の既存バイナリが検証対象をシャドウイング（衝突・上書き）してしまう不具合を解消しました。
  • ジョブクラッシュ防止とNPMリリース保護の強化: CI上のデプロイおよびプロモートジョブで発生する想定外のクラッシュや、壊れたパッケージがNPMへリリースされてしまうリスクを防止する安全機構が導入されました。

影響や使いどころ

「ツールレジストリ・ディスカバリ」の追加により、エージェント環境に新しいコマンドラインツールや外部API（MCPサーバー等）を追加した際、Gemini CLI が自動でそれを検出・理解してツールキットに組み込めるようになり、自律能力の柔軟性が向上します。また、NPMでの検証保護やCIシャドウイングの修正により、開発元から配布されるプロダクトパッケージのデリバリー信頼性とセキュリティが大幅に強化されています。

まとめ

ツール発見機能の強化と、リリースプロセスのセキュリティ強化を両立させた、実用度の高いメジャーマイナー（v0.50.0）正式リリースです。
