AI Tool Log

Cline: v4.0.10

SDK統合ランタイムへの移行とプロンプトキューイング・カスタマイズマーケットプレイスの導入

リリース日 2026-07-21
バージョン v4.0.10
ツール Cline

主な変更点

VS Code 向け AI コーディング拡張機能 Cline が v4.0.10 にアップデートされ、ランタイムの最適化と機能拡張が行われました。主な変更点は以下の通りです。

  • SDK 統合ランタイムへの移行: Plan/Act モード調整、MCP 統合、チェックポイント管理や履歴操作を共通 SDK 統合層経由で処理するアーキテクチャへ更新されました。
  • Customize マーケットプレイスの導入: 拡張機能内から Skills、MCP サーバー、Plugins を直接検索・発見・管理できるマーケットプレイス機能が追加されました。
  • チャットプロンプトのキューイングと再編集: エージェントが作業を行っている最中に新しい指示をキューとして追加する機能や、過去のメッセージを再編集・再生成する機能がサポートされました。

影響や使いどころ

実行中のエージェントに対して指示をスムーズに追加できるようになるほか、MCP ツールやプラグインの管理が拡張機能内で完結し、カスタマイズ性が大幅に向上します。

まとめ

Cline v4.0.10 は、SDK 統合による安定性向上とマーケットプレイス・キューイング機能による操作性・カスタマイズ性の拡張を実現した主要なマイナーアップデートです。
