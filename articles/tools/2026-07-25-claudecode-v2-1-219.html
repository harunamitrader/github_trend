Claude Code: v2.1.219

Claude Opus 5 (1Mコンテキスト・高速モード) の標準採用、自己アップデート失敗時の自動ロールバック、シンボリックリンク経由のワークスペース隔離バグ修正

リリース日 2026-07-25
バージョン v2.1.219
ツール Claude Code

主な変更点

Claude Code が v2.1.219 にアップデートされ、最新モデルである Claude Opus 5 への切り替え、実行環境の安全性とアップデート時の堅牢性向上が実施されました。主な変更点は以下の通りです。

  • Claude Opus 5 の標準採用: 最新の claude-opus-5 が Opus のデフォルトになりました。1M トークンのコンテキストウィンドウに対応し、より低遅延な「高速モード (fast mode)」を利用可能です。
  • アップデート自動復旧 (ロールバック): claude 実行バイナリの自己アップデート中に万一失敗した場合でも、以前動作していたバックアップバイナリから自動復旧する仕組みが追加され、アップデート失敗時に実行ファイルが消失する問題が解決しました。
  • シンボリックリンク経由のワークスペース隔離漏れの修正: シンボリックリンクされた作業ディレクトリが標準化（実パス解決）されず、バックグラウンドセッションが隔離用ワークスペースディレクトリの外へアクセスできてしまうセキュリティ上のバグが修正されました。
  • Bedrock / Compact コマンド修正: AWS Bedrock 上の Claude Opus 4.8 において自動コンパクトが機能しなくなる問題、および上限超過時に /compact コマンドがエラーになる不具合が解決されました。
  • TLS / Proxy 設定の適用改善: 企業の mTLS 認証、TLS 検証、OAuth スコープ、およびプロキシ設定などの一部ネットワーク環境設定が Claude Desktop セッション等で無視される挙動が修正されました。

影響や使いどころ

最新の Opus 5 による長大なコードベースの分析力と応答速度が向上するほか、アップデートやネットワーク周りのトラブルが大幅に減少し、よりエンタープライズでの使い勝手が向上します。

まとめ

Claude Code v2.1.219 は、コンテキスト 1M で高速化した「Claude Opus 5」のデフォルト化のほか、バイナリ自動復旧機能、シンボリックリンクのセキュリティ境界の修正、Bedrock や企業プロキシ動作のバグフィックスを含む安定版アップデートです。
