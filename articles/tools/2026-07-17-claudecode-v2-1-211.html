Coding Tool Log

Claude Code: v2.1.211

双方向オーバーライド等のテキストインジェクション脆弱性修正や、特定環境でのプロンプトキャッシュ課金回帰バグ修正を盛り込んだセキュリティ＆安定性アップデート

リリース日 2026-07-17
バージョン v2.1.211
ツール Claude Code

主な変更点

Anthropic の CLI コーディングツール Claude Code が v2.1.211（および v2.1.210）にアップデートされました。主な変更点は以下の通りです。

  • セキュリティ強化 (Bidirectional-override 対策): 承認プロンプトのプレビューにおいて、ゼロ幅スペースや酷似引用符、bidirectional-override などの隠し制御文字を無害化し、視覚的な騙し（テキストインジェクション）による攻撃を防ぎます。
  • 課金回帰バグの修正: Bedrock、Vertex、Mantle、Foundry 環境において、プロンプトキャッシュが機能せず末尾のシステムコンテキストブロックが毎回新規入力トークンとして課金されていた問題を解消しました。
  • サブエージェント出力フラグの追加: --forward-subagent-text フラグ（および CLAUDE_CODE_FORWARD_SUBAGENT_TEXT 環境変数）を導入し、stream-json 出力にサブエージェント of テキストや思考を含められるようになりました。
  • Git Worktree 間での承認同期: "Always allow"（常に許可）の承認ルールが、すべての Git worktree にわたって持続・同期されるよう改善されました。
  • Worktree 分離バグの解消: サブエージェントが自身の隔離されたワークツリーではなく、メインリポジトリのチェックアウトに対して誤って Git 変更コマンドを実行してしまう不具合を修正しました (v2.1.210)。
  • その他の不具合修正: コマンドストリーミング中のライブ経過時間表示、外部エディタ貼り付け時のゴミ文字（È/É等）混入の解消、スリープ復帰後のログアウト競合や MCP サーバー再接続エラーの修正。

影響や使いどころ

セキュリティ面での脆弱性（テキストインジェクション）が塞がれ、クラウドインフラ（AWS Bedrock や GCP Vertex 等）でのプロンプトキャッシュが再び正常に動作するようになったため、該当環境で運用しているユーザーはすぐにアップデートすることを推奨します。

まとめ

双方向テキストインジェクション対策やキャッシュ課金バグの修正など、エンタープライズ利用における信頼性と安全性を着実に強化したアップデートです。
