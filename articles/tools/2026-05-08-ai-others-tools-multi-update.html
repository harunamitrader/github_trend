AI Tool Log #468

AI Tools Update: GPT-5.5 Instant, Claude Managed Agents, and gemini-3.1-flash-lite

2026年5月8日の汎用AIツールの主要アップデート。OpenAI の GPT-5.5 Instant 投入、Claude の「Dreaming（自己改善）」機能、Google の Flash-lite 正式リリースなど、各社の主力モデルとエージェント機能がさらに進化しています。

リリース日 2026-05-08
カテゴリ 汎用AI・エージェント・ノートアプリ
ツール ChatGPT, Claude, Gemini, Grok, Perplexity, NotebookLM, OpenClaw

主な変更点

本日のアップデートでは、各社がモデルの刷新だけでなく、外部アプリ連携やエージェントの自律的な改善機能に注力している様子が伺えます。

  • ChatGPT: 新しいデフォルトモデル GPT-5.5 Instant を公開。過去のチャットや Gmail、ファイルから文脈を抽出するメモリ機能の強化や、Excel/Sheets 連携のグローバル展開も開始されました。
  • Claude: エージェント向けの 3 つの新機能（過去のセッションから自己改善する Dreaming、成功基準を定義する Outcomes、複数エージェントのオーケストレーション）が追加。また、Pro/Team プランのレート制限が大幅に緩和されました。
  • Gemini: 軽量かつ高性能な gemini-3.1-flash-lite が GA 到達。API では、ポーリングを不要にするイベント駆動型の Webhooks サポートが開始されました。
  • Grok (xAI): Web インターフェースに Gmail, GitHub, Notion, Drive などのコネクタを追加。また、SpaceX との提携により計算資源（Colossus 1）を強化しています。
  • Perplexity: 専用の Mac mini でローカル環境と AI を統合する「Personal Computer」を発表。また、Agent API での金融特化検索機能も導入されました。
  • NotebookLM: アップロードしたソースをトピックごとに自動クラスタリングし、編集可能なラベルを付与する「Source Organization」機能が全ユーザーに開放されました。

影響や使いどころ

Claude の Dreaming 機能は、エージェントが「過去の失敗から学ぶ」ための重要なステップであり、長期的な作業の精度向上が期待できます。また、GPT-5.5 Instant や Gemini 3.1 Flash-lite の登場により、日常的なタスクにおける「速度と精度のバランス」がさらに高いレベルで提供されるようになります。

まとめ

モデルの高性能化に加え、個人のデータや外部ツールとの「接続」がより深く、そして実用的になったアップデート群です。
