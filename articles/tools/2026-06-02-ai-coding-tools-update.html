2026-06-02 AIコーディングツール アップデート

Claude Code、Cline、Cursor、Gemini CLI、GitHub Copilot の最新更新をまとめた 2026-06-02 の監視ログです。

リリース日 2026-06-02
カテゴリ Coding
ツール Claude Code, Cline, Cursor, Gemini CLI, GitHub Copilot

主な変更点

2026年6月2日 JST の再監視では、Coding 対象の公式更新が 5 ツールで 8 件ありました。Claude Code は内部改善、Cline は @file 参照の安定化、Cursor は Auto-review Run Mode、Gemini CLI は nightly の追従、GitHub Copilot は課金と利用統計の更新が中心です。

  • Claude Code v2.1.159: 内部インフラの改善のみで、ユーザー向けの変更はありません。土台の安定化が続いています。
  • Cline v3.86.2: VS Code 1.122+ で @ file mentions と workspace file search を修正し、新しい bundled ripgrep の配置に追従しました。
  • Cline v3.86.1: 一部環境で失敗していた @ file mentions を修正し、workspace index や bundled ripgrep が無い場合の fallback を維持しました。
  • Cursor 3.6: Auto-review Run Mode を追加し、Shell / MCP / Fetch をより長く、少ない承認で安全に回せるようにしました。
  • Gemini CLI v0.45.0-nightly.20260530: preferredEditor が不正なときのスパムループを抑え、引用追加と nightly 追従が進みました。
  • Gemini CLI v0.45.0-nightly.20260529: PTY resize のネイティブクラッシュ耐性を上げ、preview 系の追従を進めました。
  • GitHub Copilot billing / plans: usage-based billing が有効化され、Copilot code review は June 1 から GitHub Actions minutes も消費するようになりました。
  • GitHub Copilot usage metrics: API に ai_adoption_phase と totals_by_ai_adoption_phase が増え、利用の成熟度を cohort で見やすくなりました。

影響や使いどころ

今回は、実行モード、ファイル検索、利用統計、課金の境界整理が目立ちました。開発現場では、エージェントの挙動を安全にする更新と、Copilot の請求・計測の見直しを同時に確認しておくと、運用差分を追いやすいです。

まとめ

大きな新機能よりも、運用のしやすさと計測の粒度を詰める更新が中心でした。CLI / IDE / 使用統計の三方向を並べて追うと、次に見るべき変更点が絞りやすくなります。
