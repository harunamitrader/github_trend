Perplexity: Website Publishing & Computer Agent Upgrade

回答結果を独自ドメインへ一発で公開できる Website Publishing 機能および Computer Agent のモデル切替・非公開企業データ連携

リリース日 2026-07-27
アップデート Website Publishing
ツール Perplexity

主な変更点

今回のアップデートでは、検索結果のパブリッシング機能の拡張や、自律操作エージェント（Computer Agent）の機能強化など、以下の重要な機能拡張が行われました。

  • Website Publishing: Perplexityの回答結果を直接 `.pplx.app` ドメインや、Vercelを経由した独自カスタムドメインへワンクリックで静的Webページとしてパブリッシュできる機能が追加されました。
  • Computer Agent のモデル切替対応: 自律操作型エージェントである Computer Agent において、タスクの実行途中に動的にモデルを切り替えられるようになり、複雑度に応じた処理の最適化と高速化が図られました。
  • 非公開企業データの検索連携: Forge Global との統合により、未公開・プライベート企業に関する信頼性の高い財務や取引データをソースとして参照できるようになりました。
  • 最新モデルのAPIサポート: Agent API において、Claude Opus 5、GPT-5.6 ファミリー（sol, terra, luna）、Grok 4.5 などの最新フロンティアモデルがサポートされました。

影響や使いどころ

Website Publishing機能により、調査・検索した結果をすぐさま外部公開用のWebページとして発信できるようになり、ナレッジの共有やコンテンツ制作の効率が飛躍的に高まります。また、Computer Agentの柔軟なモデル切替や非公開企業データ連携により、ビジネスリサーチや自律作業の精度と速度が大幅に向上します。

まとめ

Perplexity の最新アップデートは、検索結果のアウトプットの迅速化と、エージェントによるディープな自律リサーチ力を強化するものです。Web上での情報発信や、専門的な企業調査を行うビジネスユーザーにとって非常に価値のある機能拡張となっています。
