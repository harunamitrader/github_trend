Google Gemini: 3.5 Flash GA と Interactions API 更新

Gemini 3.5 Flash の一般提供（GA）と、Interactions API のレガシースキーマ廃止が完了しました。

リリース日 2026-06-18
バージョン Gemini 3.5 Flash GA
ツール Gemini

主な変更点

Google Gemini の開発者向け機能が一層刷新され、新しいAPIスキーマへの移行が完了しました。

  • Gemini 3.5 Flash の一般提供 (GA): デフォルトの思考レベル（thinking_level）がmediumに調整され、thought preservation（思考の保持）が標準有効化。
  • Interactions API のレガシースキーマ廃止: 従来のoutputs配列が廃止され、タイムライン表示に対応したsteps配列へ完全移行。
  • 音声生成ストリーミング対応: gemini-3.1-flash-tts-preview モデルにて、streamGenerateContent を用いたリアルタイム音声ストリーミングがサポート。

影響や使いどころ

Interactions API のスキーマ移行が必要となる一方、思考過程の保持によりマルチターン対話時の信頼性が増しています。

まとめ

APIの構造整理が進み、Antigravityプラットフォームへの統合に向けた準備が着々と進められています。
