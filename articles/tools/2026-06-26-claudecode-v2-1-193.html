Claude Code v2.1.193: autoMode のシェル分類設定追加と OTel 強化

自動モードでのシェルコマンド分類を制御する autoMode.classifyAllShell 設定が追加され、OpenTelemetry のロギング強化やバグ修正が行われました。

リリース日 2026-06-26
バージョン v2.1.193
ツール Claude Code

主な変更点

Claude Code v2.1.193 では、主に以下の機能強化とバグ修正が行われました。

  • autoMode.classifyAllShell 設定の導入: Bash や PowerShell を含むすべてのシェルコマンド実行を自動分類器経由にする設定が追加されました。
  • OpenTelemetry のロギング強化: 内部の観測性とパフォーマンス監視のためのトレースロギングが強化されました。
  • バグ修正と安定性向上: 一部環境でのエージェント動作および軽微なエラーが修正されました。

影響や使いどころ

自動モード（auto-mode）での安全なコマンド実行分類がシェル全般に拡張されたことで、よりきめ細やかな実行制御が可能となります。CI/CDなどの非インタラクティブ環境や、PowerShell等を利用するWindows環境での実行監視において、安全性がより高まります。

まとめ

今回のリリースは自動モードの安全性と観測性をさらに前進させるアップデートです。
