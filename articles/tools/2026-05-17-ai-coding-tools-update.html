AI Coding Tools Update: Claude Code v2.1.143, Copilot Memory, Gemini CLI

Claude Code v2.1.143 でプラグインコスト表示を強化。GitHub Copilot Memory のユーザー設定対応や Gemini CLI の機能改善。

リリース日 2026-05-17
カテゴリ AIコーディング (CLI本体・拡張機能)
ツール Claude Code, Gemini CLI, Copilot

主な変更点

本日確認された AI コーディングツールの主要なアップデートは以下の通りです。

  • Claude Code v2.1.143: /plugin マーケットプレイスにて、インストール前に予測されるコンテキストコストを表示する機能が追加されました。また、プラグインの依存関係強制や worktree.bgIsolation 設定の拡充、PowerShell 実行時のポリシーバイパス対応など、実用的な改善が多数含まれています。
  • GitHub Copilot Memory: Pro および Pro+ ユーザー向けに、ユーザーごとのパーソナライズ設定（Memory）が正式にサポートされました。これにより、プロジェクトを跨いだコーディングスタイルや好みのライブラリ指定などがより定着しやすくなります。
  • Gemini CLI: RAG（検索拡張生成）で使用されたスニペットをローカルログに出力するオプションが追加されました。また、プロキシ環境下での NO_PROXY 設定が正しく尊重されるよう修正されています。

影響や使いどころ

Claude Code のコスト表示機能は、大規模なリポジトリでプラグインを多用する際の API 消費管理に非常に役立ちます。また、GitHub Copilot の Memory 機能強化は、長期的には開発者個々の文脈を汲み取った精度の高いコード生成に寄与するでしょう。

まとめ

本日のアップデートは、派手な新機能よりも「実運用での利便性と透明性」を重視したものが目立ちます。特に CLI ツール群の細かな不具合修正と設定の拡充により、プロフェッショナルな開発環境での安定性がさらに向上しています。
