Devin Desktop (Windsurf) / Product Update

Devin Desktop (Windsurf) Agent Update

Agent Command Centerへのリスト表示・ソート・フィルタ追加、Devin Review全員開放、およびIDE의各種バグ修正を含むアップデート

リリース日 2026-08-01
バージョン August 2026 Update
ツール Windsurf

主な変更点

Cognition AI傘下となりDevinエコシステムへ移行中のDevin Desktop (旧Windsurf) において、自律エージェントの操作性向上を主眼としたアップデートが配信されました。主な変更点は以下の通りです。

  • エージェント・インボックスのUI改善: エージェント進行タスクを表示するインボックスにリスト表示オプションが追加され、進行中セッションのソート・フィルタリングが容易になりました。
  • Devin Review / Quick Reviewの開放: すべての購読ユーザーに対して、自律エージェントのコードレビュー結果を容易に把握・修正承認できる「Devin Review」機能へのフルアクセスを提供。
  • Windows版ショートカットの修正: Windows環境において、チャット画面とコードエディタ間のショートカットキーによる往復操作が正常に行えない問題を修正。
  • IDEフリーズの修正: 診断データや大規模なログファイルをダウンロードする際に、エディタ全体が応答なし（フリーズ）になる不具合を修正。

影響や使いどころ

エージェントとの協調による「Vibe Coding」や自律開発プロセスをサイドバーから高速に切り替え・監視可能になり、Windows環境特有の挙動の引っ掛かりが解消されます。

まとめ

Devin製品群への統合を推し進めつつ、複数のセッションやレビュー管理を効率化するための実用的なUI/UXアップデートです。
