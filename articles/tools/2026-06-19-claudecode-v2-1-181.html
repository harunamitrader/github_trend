Claude Code v2.1.181 リリース

fallbackModel 解決動作の安定化と、内部インフラのバグ修正を含むアップデートです。

リリース日 2026-06-19
バージョン v2.1.181
ツール Claude Code

主な変更点

今回のアップデートでは、主に動作の堅牢性とインフラのバグフィックスが行われています。

  • fallbackModel の安定化: 実行時のフォールバックモデル選択に関する動作が改善され、意図しない接続エラーが低減しました。
  • 内部インフラのバグ修正: プラグイン依存関係や解決処理における軽微な不具合が解消されています。
  • 例外処理の強化: エラー発生時のログ保存や復帰処理の堅牢性が向上しました。

影響や使いどころ

フォールバックモデル解決の安定化により、APIエラーが一時的に発生した際にもエージェントがクラッシュしにくくなり、バックグラウンドでの長時間実行がより安定します。

まとめ

大規模な新機能の追加はありませんが、実行の安定性を底上げするための重要な品質改善アップデートです。
