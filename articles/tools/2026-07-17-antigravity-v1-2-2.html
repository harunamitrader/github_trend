Coding Tool Log

Antigravity: v1.2.2

ワークスペース内のコードベースを高速に正規表現検索できる /codesearch コマンドの追加や、大規模会話におけるCPU負荷の大幅な軽減などを施した TUI アップデート

リリース日 2026-07-17
バージョン v1.2.2
ツール Antigravity

主な変更点

Google の CLI コーディングエージェント Antigravity (agy) が v1.2.2（内部の agy CLI バージョン v1.1.3 および v1.1.2）にアップデートされました。主な変更点は以下の通りです。

  • /codesearch コマンドの追加: ワークスペース全体を対象にコードを対話検索できる /codesearch (エイリアス /cs, /search) を導入。正規表現による検索や、-F オプションによる完全一致、f: プレフィックスによるパスのグロブ指定に対応しました。
  • 大規模セッションのパフォーマンス劇的向上: no-flickering（フリッカーなし）モードにおけるインデックス再構築や行数計算のホットパスを最適化し、5,000ステップを超える巨大な会話でも CPU 使用率や入力遅延が大幅に削減されました。
  • TUI での選択範囲コピペ改善: no-flickering モードにおいて、マウスによるドラッグ選択時に ANSI 制御文字を自動除去した状態でクリップボードへコピーする機能を追加し、仮想スクロールバーがコピペの邪魔にならないよう改善されました。
  • 非同期スキルロードによる起動短縮: 起動時のスキルディスカバリを非同期化し、ファイルアクセスの重いパスでの CLI 起動遅延を解消しました。
  • ヘッドレス実行時の安全強化: ヘッドレス (-p) 実行時に確認プロンプトが必要になった場合、サイレントに自動承認（またはハング）するのではなく、適切にソフト拒否して stderr に allow-rule の警告を出力するようになりました。
  • その他: 新規ファイル作成時の full diff プレビュー表示 (f ショートカット)、OS キーリング競合時の認証ハングバグの修正、コンテキスト圧縮境界のインジケーター表示などを搭載。

影響や使いどころ

コード検索のネイティブコマンドが実装されたことで、ワークスペース内の調査効率が大幅に向上しました。また、長時間に及ぶセッションで発生していた文字入力の遅延が解消されているため、よりスムーズな対話が行えるようになります。

まとめ

ワークスペース内のコード検索コマンドの追加や、巨大な履歴セッションでの負荷削減など、開発者が快適に長時間使い続けるための最適化と機能追加を行ったアップデートです。
