AI Tool Log

2026-06-08 AIコーディングツール アップデート

Claude Code 2.1.168、Antigravity 2.0.11、GitHub Copilot の GPT-5.2 / GPT-5.2-Codex deprecated、Cline v3.88.1 をまとめた 2026-06-08 の監視ログです。

リリース日 2026-06-08
カテゴリ Coding
ツール Claude Code, Antigravity, GitHub Copilot, Cline

主な変更点

2026年6月8日 JST の監視では、Claude Code / Antigravity / GitHub Copilot / Cline に新しい更新がありました。Cursor / Windsurf / Gemini CLI / Codex は前回ログから変化なしです。

  • Claude Code v2.1.168: 変更内容は `Bug fixes and reliability improvements` のみのメンテナンス更新です。前回の 2.1.167 と同様に、派手な新機能よりも日常運用の安定化を優先しています。
  • Antigravity 2.0.11: 起動時に暗転する問題と Open IDE ボタン周りの不具合を修正しました。起動直後の見た目と IDE 連携の導線が整っています。
  • GitHub Copilot: 6/5 の changelog で GPT-5.2 と GPT-5.2-Codex が多くの Copilot 体験から deprecated になりました。モデル選定や組織ポリシーの見直しが必要になる更新です。
  • Cline v3.88.1: テスター向けの debug section を設定画面に追加し、初回ウォークスルーの markdown ファイルも拡張機能パッケージへ含めるようになりました。初回導線の欠落が潰されています。

影響や使いどころ

今回の変更は、機能追加よりも安定性と運用ルールの調整が中心です。特に GitHub Copilot のモデル deprecated は、利用中の既定モデルや組織ポリシーと直結するため、早めの確認が必要です。Antigravity と Cline は、導入直後の体験を崩しやすい起動・初回導線を固める更新として効いています。

まとめ

今回は 4 ツールが更新されました。Claude Code と Cline は軽微な安定化、Antigravity は起動修正、Copilot はモデル整理が中心です。Cursor / Windsurf / Gemini CLI / Codex は前回ログから変化なしでした。
