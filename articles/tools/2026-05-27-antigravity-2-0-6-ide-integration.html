Antigravity 2.0.6: IDE 連携を追加

Antigravity 2.0.6 は、Antigravity IDE との往復をしやすくする導線を追加した小規模更新です。

リリース日 2026-05-22
バージョン 2.0.6
ツール Antigravity

主な変更点

2026年5月22日の公式 changelog では、Antigravity 2.0.6 に Antigravity IDE 連携が追加されました。

  • IDE 未導入時の導線: Antigravity IDE が入っていない場合に、インストール用のボタンを表示するようになりました。
  • 現在のプロジェクトを IDE で開く: IDE がインストール済みなら、現在のプロジェクトを Antigravity IDE で開くボタンを出せるようになりました。
  • 作業の切り替えを短縮: standalone 側で進めた作業を、そのまま IDE 側へつなげやすくなりました。

影響や使いどころ

Antigravity を agent の実行面として使い、細かい編集や確認は IDE で続けたい場合に効く更新です。大きな機能追加ではありませんが、作業場所の切り替えを少しでも減らせるのは実務では重要です。

まとめ

2.0.6 は、Antigravity を単独の agent アプリとして使うだけでなく、IDE と組み合わせた運用に寄せた改善です。見た目は地味でも、日常利用の摩擦を減らすタイプのアップデートだと見てよいです。
