Claude Code: v2.1.214

会話を複製・並行進行させる /fork コマンドの追加や、コマンド・表記を /subtask へ統一、WebSearch 等のセッションレベル予算 (Session budgets) 管理機能を盛り込んだ機能アップデート

リリース日 2026-07-19
バージョン v2.1.214
ツール Claude Code

主な変更点

Anthropic の CLI コーディングエージェント Claude Code が v2.1.214 にアップデートされ、より複雑な開発フローを安全かつ効率的に並行処理するための機能が追加されました。主な変更点は以下の通りです。

  • /fork コマンドの導入: 現在の対話セッションを複製し、バックグラウンドの別セッションとして並行進行させることができるようになりました。
  • /subtask への統一: インセッション内で動作するサブエージェントの呼び出しコマンドおよび表記を /subtask へ改称・統一しました。
  • Session-level budgets の実装: WebSearchツール呼び出しやサブタスクの起動に対して、セッションごとの最大予算を設定してトークン消費や意図しないコスト増を防止可能になりました。

影響や使いどころ

/fork を使用することで、元の作業コンテキストを維持したまま、別の試験的実装やデバッグを非同期に進めることが容易になります。また、セッション予算制限によって、エージェントが自律ループした際の思わぬ出費を未然に防ぐことができます。

まとめ

Claude Code v2.1.214 は、マルチタスクや予算管理など、大規模で複雑なプロジェクト開発を CLI から安全かつ効率的にオーケストレーションするための重要な機能強化となっています。
