AI Tools Update

Cline v4.0.1 (VS Code Extension)

v4.0.0 で実施した Cline SDK 移行に伴うユーザー報告の不具合や回帰問題に対応するため、安定版拡張機能を従来の v3.89.2 ベースへと一時的にロールバック（差し戻し）したアップデート。

リリース日 2026-06-29
バージョン v4.0.1
ツール Cline

主な変更点

2026年6月27日に公開されたメジャーアップデート v4.0.0 のリリース直後、多くのユーザーから発生した不具合報告を受け、急遽安定版 VS Code 拡張機能のロールバックが実施されました。

  • コードベースのロールバック: 新しい「Cline SDK」によるセッション・ランタイム管理を導入した v4.0.0 から、安定性が確立されている従来の v3.89.2 ベースのコードベースへと差し戻されました。
  • ユーザー報告の不具合解消: v4.0.0 へのアップデート後に発生していた動作不良、エージェントターンのフリーズ、および各種コマンド実行の回帰バグが、今回のロールバックにより一時的に回避されます。
  • 今後のSDK展開: 今回のロールバックはあくまで安定版に向けた一時的な措置であり、開発チームはバグを修正した上で再度SDK移行を進める方針をとっています。

影響や使いどころ

v4.0.0 への更新後に動作の不安定化やハングに悩まされていたユーザーは、今回の v4.0.1 へのアップデートにより、使い慣れた安定した従来の Cline 環境へとシームレスに戻ることができます。新規で導入を考えていた方も、安心して利用開始できる状態となっています。

まとめ

Cline v4.0.1 は、野心的な「Cline SDK」移行を伴った v4.0.0 にて顕在化した不具合を迅速に解消するため、あえて動作実績のある前バージョン系統（v3.89.2ベース）へと差し戻しをかけた、迅速かつ賢明なホットフィックスリリースです。
