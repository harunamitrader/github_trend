Claude Code v2.1.146: プラグイン依存関係解決と /code-review コマンド

Claude Code v2.1.146がリリース。プラグインの依存関係解決、/code-reviewコマンドの導入、およびバックグラウンドセッションの/resume対応が含まれています。

リリース日 2026-05-21
バージョン v2.1.146
ツール Claude Code

主な変更点

Anthropic から Claude Code v2.1.146 が公開されました。今回のアップデートはプラグイン管理の強化とコマンド体験の改善が中心です。

  • プラグイン依存関係の強制: `claude plugin disable` 時に依存する他プラグインがある場合は無効化を防ぎ、`enable` 時には推移的依存も強制的に有効化されるようになりました。
  • /code-review コマンド: 従来の `/simplify` がリネームされ、`/code-review high` のようにエフォートレベル（労力）を指定可能になりました。
  • バックグラウンドセッションの /resume: `claude --bg` やエージェントビューで開始されたバックグラウンドセッションがインタラクティブセッションと並んで表示され（bgマーク付）、途中復帰が可能になりました。
  • Windows PowerShell ツール: `-ExecutionPolicy Bypass` が付与され、Bedrock, Vertex, Foundry ユーザー向けにデフォルトで有効化。コマンドライン無効エラーも修正されました。
  • コスト見積もり表示: `/plugin marketplace` 画面にて、ターンごとおよび呼び出しごとのコンテキストコスト見積もりが表示されるようになりました。

影響や使いどころ

サードパーティ製プラグインのエコシステムが拡大する中、依存関係の破壊を防ぐ安全策が導入されたことで、より安定して拡張機能を活用できるようになります。また、Windows 環境での PowerShell 実行エラーの解消や、バックグラウンド実行後のセッション再開（/resume）など、日常的な開発ワークフローの堅牢性が着実に高まっています。

まとめ

v2.1.146 は、プラグイン管理の成熟と PowerShell 対応の修正、ならびにバックグラウンド実行をより扱いやすくするための実用的なアップデートです。
