Grok: Voice Agent Builder のベータ公開と Microsoft 365 アドイン展開

ノーコードで本番運用可能な音声エージェントを構築する「Voice Agent Builder」のベータ公開と、Microsoft Word / PowerPoint への公式アドイン提供。

リリース日 2026-07-05
トピック 音声ビルダー & M365統合
ツール Grok

主な変更点

xAIは、Grokのエコシステムを急速に拡大し、音声エージェントの作成機能（Voice Agent Builder）および Microsoft 365 オフィススイート（Word, PowerPoint）との深い統合アドインを正式に提供開始しました。

  • Voice Agent Builder のベータ提供（7月1日）: 顧客対応や予約受付などの音声電話応答タスクをノーコードで設計・デプロイできるプラットフォームを公開。低遅延な音声対話モデル Grok Voice Think Fast 1.0 を搭載し、API連携やガードレールを1パスで統合。音声クローン機能（2分以上の音声データが必要）もサポートします。
  • Microsoft PowerPoint アドイン（6月16日）: プロンプトからスライド資料全体を直接生成したり、アウトラインの拡張やプレゼン用スクリプトの自動生成・リファインをOffice内で完結させることができます。
  • Microsoft Word アドイン（6月20日）: ドキュメントのドラフト作成、推敲・編集、フォーマット変更などをサポートするサイドパネル型の連携機能を追加しました。

影響や使いどころ

企業はコールセンターの自動応答やカスタマーサポート用の音声エージェントをAPI経由（$0.05 / 分 ＋ 電話通信費）で即座に検証・導入できるようになります。また、オフィスワーカーは外部ツールとのコピペ作業をなくし、Word や PowerPoint 上から直接 Grok のエージェント能力を呼び出してドキュメント作成やプレゼン資料構築を大幅に効率化できます。

まとめ

音声対話の商業化を促すノーコードビルダーの提供と、Microsoft 365 への直接進出により、ビジネス実務エージェントとしての実用性を飛躍的に高めた大型アップデートです。
