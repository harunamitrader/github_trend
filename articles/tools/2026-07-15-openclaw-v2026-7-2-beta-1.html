OpenClaw: v2026.7.2-beta.1 リリース、Cloud Worker リモートセッションとモバイル自動化・Voice Wake 対応

自律型インテグレーションフレームワークのOpenClawは最新の開発プレビュー版であるv2026.7.2-beta.1を公開し、クラウドワーカーによるリモートコーディングセッション実行や、モバイル版での自動化・音声起動対応などを果たしました。

リリース日 2026-07-15
バージョン v2026.7.2-beta.1
ツール OpenClaw

主な変更点

今回のアップデートは、遠隔マシン上での開発タスク実行力（リモート開発サポート）と、モバイル・外部統合時の自動化・安全性が重点的に強化されています。

  • Remote coding sessionsの搭載: クラウドワーカー上での Control UI セッション実行に対応しました。これにより、Codex や Claude のカタログセッションをホストのターミナル上でストリーミング CLI として継続したり、Pi/OpenCode セッションを直接復元することが可能になります。
  • モバイル自動化と Voice Wake (Android): モバイルアプリに Automations の機能を完全移植。Android でフォアグラウンド時に動作する Voice Wake（音声による起動）機能を搭載しました。また、ヘッドレスな Linux ノードからカメラや位置情報、通知機能を取り扱えるように拡張されました。
  • チャネル接続の安全性向上: システム再起動後に Telegram の durable-ingress が消失する問題が防止されました。また Signal 連携時にアクション中であっても停止・承認コマンドのレスポンスが維持されるように改善。allowlist の誤判定によるアクセス制限の不具合も修正されています。
  • Guided Control UI Onboarding: 設定（Settings）画面から各種モデルプロバイダー（API）を直接構成できるようになり、チャネルごとのセットアップをガイド付きページでわかりやすく案内する仕組みが追加されました。

影響や使いどころ

Cloud Worker 上で Control UI のセッションが直接動作するようになったため、手元のマシンスペックが低い場合やオフライン状態であっても、リモートの安全なサンドボックス上で重たい自律型エージェントの実行タスクを継続・完了できるようになります。また Android 上で音声によるコントロールがスムーズになったため、ハンズフリーのオペレーションもより現実的になりました。

まとめ

OpenClaw v2026.7.2-beta.1 は、マルチデバイス・マルチチャネルをまたいだ自律エージェント基盤としての機能を順調に拡充しています。遠隔実行やモバイル連携の洗練により、活用の幅がさらに広がりました。
