AI Tool Log

Cursor: v3.12

ローカルに複製（クローン）することなく GitHub や GitLab のリモートリポジトリを直接インデックス化してコンテキストとして利用できる機能や、Window 復元設定の整理を盛り込んだアップデート

リリース日 2026-07-19
バージョン v3.12
ツール Cursor

主な変更点

AIコードエディター Cursor が v3.12（およびパッチビルド）にアップデートされ、リモート連携機能の大幅な強化と、起動時のウィンドウ状態管理の改善が行われました。主な変更点は以下の通りです。

  • Remote Repository Indexing の追加: GitHub や GitLab にホストされているリモートリポジトリを、ローカルにクローンすることなくエディター内の AI が直接インデックス化し、開発コンテキストとして読み込めるようになりました。
  • 起動時設定の整理 (Window Restoration): 起動時に常に Agents 画面が開いてしまう挙動の混乱を避けるため、設定項目「Open Agents Window on Startup」を、最後のセッション状態を復元する「Window Restoration」へ改名し調整しました。

影響や使いどころ

リモートインデックスにより、ローカルディスク容量を節約しつつ、組織内の巨大な共有コードベースや外部のライブラリリポジトリを手軽に参照してコード生成の精度を高めることが可能です。また、起動時にエージェント画面が勝手に開くなどのストレスが軽減されます。

まとめ

Cursor v3.12 は、リモートワークスペースとローカルエディターのシームレスな融合を進め、コンテキスト供給源としての実用性を飛躍的に高めたメジャーアップデートです。
