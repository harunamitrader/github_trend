主な変更点

2026年6月13日 JST の監視では、Claude Code と Codex に新しい更新がありました。Cursor / Windsurf / Cline / Gemini CLI / GitHub Copilot / Antigravity は前回ログから変化なしです。

  • Claude Code v2.1.175: `enforceAvailableModels` の管理設定が追加されました。2.1.174 では `wheelScrollAccelerationEnabled` の追加に加えて、`/model`、usage banner、Bedrock GovCloud、background sessions、skill hot-reload まわりの修正が入り、管理設定と実行体験の見直しが同時に進んでいます。
  • Codex v0.140.0-alpha.15: alpha.13 から alpha.15 の連続差分で、古い Windows sandbox 依存の整理、plugin app category の伝播、MCP tool call analytics の改善、`codex exec` の runtime warning、managed Bedrock auth の優先、workspace restriction の厳格化などが進みました。基盤整備が一気に進んだ alpha 群です。

影響や使いどころ

Claude Code は管理設定とスクロール系の体験改善が中心で、Codex は sandbox / plugin / auth の土台が固まっています。実運用では、アップデート後に managed setting と認証経路を一度確認しておくと安全です。

まとめ

今回は 2 ツールだけが更新されました。Claude Code は運用設定の追加、Codex は alpha.13〜15 の積み上げで内部基盤の整理が進んだ回です。次回は Cursor / GitHub Copilot / Gemini CLI の継続監視を見れば、日常利用に効く変化を追いやすくなります。
