AI Tool Log

2026-05-20 AI一般ツール アップデート

Google I/O 2026で発表された Gemini 3.5 Flash や Gemini Spark などの最新AIエージェント情報に加え、ChatGPT の金融機関アカウント連携プレビュー、NotebookLM のマインドマッププロンプト制御機能、OpenClaw のバージョン更新情報をまとめてお届けします。

リリース日 2026-05-20
カテゴリ Others
ツール ChatGPT, Gemini, Perplexity, NotebookLM, OpenClaw

主な変更点

2026年5月20日に確認された、各AI一般ツールの主なアップデートは以下の通りです。

  • ChatGPT: 米国の Pro ユーザー向けに Plaid 経由で銀行口座やクレジットカード、投資ポートフォリオと直結した予算・資産インサイトを提供するプレビュー機能を追加。さらに Box、Notion、Linear、Dropbox との連携アプリで書き込み機能を強化、File Library やパーソナライズメモリ機能を改善。
  • Gemini (Google I/O 2026発表): 出力4倍速で長期タスク向けに最適化された「Gemini 3.5 Flash」、物理世界のシミュレーションが可能な世界モデル「Gemini Omni」、24時間自律的にタスクを処理するパーソナルエージェント「Gemini Spark」、および月額100ドルの新プラン「AI Ultra」を発表。
  • Perplexity: iOSアプリでの画像生成、F1レースのライブ順位および実況表示に対応。さらにフォルダーのドラッグ＆ドロップによるファイルアップロード改善などを実施。
  • NotebookLM: 生成されるマインドマップの構成やロジック（例: 緊張関係マップ、意思決定アーキテクチャなど）を、ユーザーがプロンプトで細かく指定・制御できる「Mind Maps Prompt Steering」機能を導入。
  • OpenClaw (v2026.5.19-beta.1): 修正時のシンプルなリファクタ原則の明示、API非推奨化プロセスの導入。プロキシラインや Pi パッケージのアップデート、Node.js 22 の最小サポートライン引き上げ。

影響や使いどころ

Google I/O 2026での発表（Gemini Spark や Gemini Omni）が示すように、AI は「チャットで受け答えするアシスタント」から「裏で自律的にタスクを巡回処理するエージェント」へと進化を遂げています。ChatGPT が提供を開始した Plaid によるリアルタイム金融データとの直接連携も、その流れを汲む実用的な一歩です。さらに NotebookLM のように、要約したドキュメントをマインドマップなどの構造化ビジュアルに変換する際、より人間の意図（プロンプト）通りに制御できるようになったことで、リサーチや意思決定の効率が大幅に向上しています。

まとめ

今回のアップデートは、単なる機能改善にとどまらず、自律型エージェントの本格的な社会実装と、コンテキスト指向の情報処理の進化を象徴しています。ユーザーはAIに対し、明確な目標を指示してバックグラウンドで働かせたり、パーソナライズされたインサイトをリアルタイムデータから引き出したりすることが日常的になりつつあります。
