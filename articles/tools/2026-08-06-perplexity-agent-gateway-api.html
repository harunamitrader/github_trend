Perplexity Agent API & Gateway Update

Agent APIのGPT-5.6-luna採用・インライン引用の改善、および複数モデルを統合するUnified Gateway API of 提供

リリース日 2026-08-06
バージョン API Update
ツール Perplexity

主な変更点

Perplexityは、開発者向けの検索・推論インフラを強化するため、Agent APIのチューニングおよび統合プロキシである「Unified Gateway API」を新たに発表しました。主な更新点は以下の通りです。

  • Agent APIにおけるGPT-5.6-luna採用: 開発者向けAgent APIの「low」プリセットにおいて openai/gpt-5.6-luna モデルをバックエンドに採用。出力上限を32,768トークンへと大幅に拡張し、長い調査ドキュメントの生成が可能になりました。
  • インライン引用（Structured Inline Citations）の改善: 調査追従（Research-backed）プリセットにおいて、これまでのシンプルな数値引用（例: [1]）に加え、引用元のタイプを明示した詳細な引用形式（例: [web:1]）の出力をサポート。信頼性とトレーサビリティを高めました。
  • Unified Gateway API の提供開始: 複数のオープンウェイトモデルに対して、単一のAPIキーおよび単一のエンドポイント（OpenAI互換・Anthropic互換）でアクセス可能な統合ゲートウェイ機能を公開。モデルごとの稼働状況に応じた自動フェールオーバーやヘルスルーティングが機能します。
  • ホスト型（リモート）MCPサーバー: ローカルにMCPサーバーをインストールすることなく、リモート上で管理・利用可能なホスト型のPerplexity MCP Serverの提供を開始しました。

影響や使いどころ

AIアプリケーション開発において、モデルの可用性を高めるマルチモデル冗長化を容易に実装できるほか、PerplexityのWeb検索を活用した情報収集エージェントの引用処理や最大出力文字数を大幅に改善できます。

まとめ

Agent APIのGPT-5.6-lunaバックエンド採用と詳細インライン引用の追加、およびAPI呼び出しの耐障害性を向上させるUnified Gateway APIの提供を含む、デベロッパー向けの大規模なインフラ更新です。
