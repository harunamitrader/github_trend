Grok CLI v0.2.116

Grok CLI (Grok Build) v0.2.116がリリース。セッション巻き戻し用の/undoコマンド追加、ヘッドレス出力の改善、再ログインループの解消や視認性の向上

更新日 2026-07-29
対象ツール Grok CLI
バージョン v0.2.116

新機能・追加点

  • /undo コマンドの追加: セッション内の会話状態や、変更されたローカルファイルを直前のチェックポイントに巻き戻して復元できる `/undo` （`/rewind` のエイリアス）コマンドが導入されました。
  • ヘッドレスストリーミング出力の改善: バックグラウンド実行やヘッドレスセッション時において、ツール呼び出しのログ出力や実行ごとの正確な利用トークン・コストなどのメタデータがストリーム出力内に詳細に表示されるようになりました。
  • MCPサーバー切り替えコマンド (v0.2.113以降): ターミナルから直接 `grok mcp enable ` または `grok mcp disable ` を実行して、利用するMCPサーバーをオンデマンドで制御できるようになりました。
  • セッション削除コマンドの導入 (v0.2.114以降): 不要になった古いセッションとそのローカルデータを即座にクリーンアップできる `/delete` コマンドが追加されました。

バグ修正・改善点

  • 再ログインループの解消 (Fix): PCのスリープ復帰や一時的なネットワークの瞬断によって、強制的に再ログインを繰り返させられる認証バグが修正されました。
  • チャット履歴の破損バグの修正 (v0.2.115以降): 特定のやり取りでツール呼び出しが重複し、APIから400エラーが返される状態管理の競合が解消されました。また、長文会話時のプロンプトキャッシュ効率が改善されました。
  • UIの視認性向上: ターミナルの最小表示モードや全画面表示モードにおいて、スラッシュコマンド一覧の候補ウィンドウの描画領域と視認性が最適化されました。

開発者への影響

指示を誤ったりエージェントが暴走したりした際に `/undo` で手軽に以前の状態に戻せるようになったため、CLI経由での開発・試行錯誤が格段に安全になります。また、スリープ復帰時のログインエラーや状態破損などの不安定さが解消され、長時間立ち上げっぱなしで作業する際の堅牢性が増しています。
