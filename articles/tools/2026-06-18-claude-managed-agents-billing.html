Claude: Managed Agents (Beta) と課金体系の更新

定期実行や安全な認証情報管理を行える「Managed Agents」の公開と、自動化ツールのクレジット課金移行が発表されました。

リリース日 2026-06-18
バージョン Managed Agents
ツール Claude

主な変更点

Claudeの機能構成において、エージェント運用の幅を広げるプラットフォームの強化が行われました。

  • Managed Agents (Public Beta): ユーザーがスケジュールを設定して自動的にエージェントを動かし、Secure Vaultで認証情報を安全に保管する機能。
  • 自動化ツール向けクレジット課金への移行: Claude Code 等の自動実行機能について、クレジットベースの新課金体系へ変更。
  • 旧世代モデル（Sonnet 4/Opus 4）のAPI廃止: APIにおける Sonnet 4 および Opus 4 の提供が正式に終了。

影響や使いどころ

Managed Agentsのベータ公開によって、自動監視や定期バッチ処理などの自律タスクの設計がより安全に行えるようになります。

まとめ

安全な認証情報管理と課金体系の整理を通じ、エンタープライズや自動実行での安定利用が進んでいます。
