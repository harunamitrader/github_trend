Claude Code: v2.1.217

サブエージェントの同時並行数（fan-out）上限設定、絵文字ショートコード入力機能、MCPツールメモリリークやWindows環境での安定性向上

リリース日 2026-07-23
バージョン v2.1.217
ツール Claude Code

主な変更点

Claude Code が v2.1.217 にアップデートされ、並行実行制御の強化やユーザー体験の改善、メモリ管理の最適化が行われました。主な変更点は以下の通りです。

  • 並行処理（fan-out）制限の導入: バックグラウンドで動作するサブエージェントが際限なく増殖するのを防ぐため、同時に実行できるサブエージェント数（fan-out）に上限（デフォルトで最大20）が設定されました。
  • 絵文字ショートコード機能: プロンプト入力で絵文字ショートコード（例: :heart: と入力して ❤️ を挿入）が使用可能になりました。不要な場合は設定 emojiCompletionEnabled で無効化できます。
  • メモリリークの解消と安定性向上: 大容量の MCP ツール出力を処理する際のメモリリークを修正。さらに Windows 環境で自動アップデートを実行した際、実行ファイルの引き継ぎが正常に行われないバグが解消されました。
  • 警告・ネットワーク周りの改善: ディスク容量不足などによるトランスクリプト書き込み失敗時の警告表示を追加。また、 corporate proxy や mTLS, TLS-verify, OAuth 認証スコープが一部セッションで無視される不具合が修正されました。

影響や使いどころ

大規模なバックグラウンドタスクや複数エージェント協調時の安定性が劇的に向上し、意図しない予算消費やシステムリソースの過負荷を防ぎます。

まとめ

Claude Code v2.1.217 は、無制限な並行エージェント実行の制御、絵文字サポートといったUX面の機能追加、そしてMCP・Windows周りの複数の重要なバグ修正を含む安定化マイナーアップデートです。
