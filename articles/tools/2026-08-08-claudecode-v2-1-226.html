Claude Code / Product Update

Claude Code v2.1.226

使用量警告におけるゲートウェイ限度額サポート、信頼できないディレクトリへのワークスペース信頼プロンプト追加、およびセルフホスト型実行環境（self-hosted-runner）の追加

リリース日 2026-08-08
バージョン v2.1.226
ツール Claude Code

主な変更点

Claude Codeのマイナーバージョン「v2.1.226」がリリースされました。今回のアップデートでは、主にセキュリティ機能の強化、使い勝手の向上、およびセルフホスト型環境への対応などが含まれています。主な変更点は以下の通りです。

  • ゲートウェイ限度額のサポート: 使用量警告において、新しく設定されたゲートウェイの利用限度額（spend-limit）がサポートされ、予算管理が容易になりました。
  • ワークスペース信頼プロンプト: 信頼できないディレクトリを操作する際、ワークスペースに対する信頼を確認する明示的な確認プロンプトが表示されるようになり、安全性が向上しました。
  • セルフホスト型ランナーの追加: 新たに claude self-hosted-runner コマンドが導入され、自己ホストされたインフラ上での実行に対応しました。
  • ペースト確認ステップの追加: クリップボードからのペースト操作において、意図しない実行を防ぐためのキャンセル・確認ステップが追加されました。
  • バグ修正と信頼性向上: 401トークンエラーやmacOS上でのMCPサーバーの動作問題、ワークツリー分離セッション周りのセキュリティ修正など、多くの不具合が解消されました。

影響や使いどころ

利用制限を意識した予算管理や、セルフホスト型環境での実行が可能になり、企業の開発環境やクローズドなネットワークでの利用が容易になります。

まとめ

今回のアップデートでは、利用限度額のサポートやワークスペース信頼機能などの安全対策、およびセルフホスト型ランナーの導入により、実用性とセキュリティの両面が大きく強化されました。
