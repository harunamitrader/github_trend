Gemini CLI: v0.52.0-nightly.20260718

LLM 割り振り・トリアージとコンテナビルド（caretaker-triage）の実装や、macOS の Seatbelt サンドボックス制限の厳格化、ReAct 無限ループ防止などを導入した nightly リリース

リリース日 2026-07-19
バージョン v0.52.0-nightly.20260718
ツール Gemini CLI

主な変更点

Google の Gemini CLI が v0.52.0-nightly.20260718 (gacae7124b) にアップデートされ、タスク管理のためのインフレ機能およびサンドボックス環境のセキュリティ強化が行われました。主な変更点は以下の通りです。

  • Caretaker Triage の追加: LLM を用いたタスクの自動仕分け・トリアージを行うオーケストレーターと、それに伴うコンテナビルドフローを実装しました。
  • macOS Seatbelt プロファイル制限の厳格化: macOS における permissive（許可的）な Seatbelt サンドボックス設定を、標準の deny-default（デフォルト拒否）モデルへ統合・制限しました。
  • 無限ループ軽減対策: 自律エージェントが誤った ReAct プロセスや同一プロンプトの挿入を繰り返して無限ループに陥る現象を検知・緩和する防止ロジックを追加しました。

影響や使いどころ

新規タスクの割り振りやコンテナでの実行処理が自動化されるため、CLI 経由での大規模な自動テストやタスク実行の安定性が向上します。また、macOS での実行時セキュリティがより厳格になりました。

まとめ

Gemini CLI v0.52.0-nightly は、自律型開発タスクの実行基盤としての堅牢性を高めるため、セキュリティプロファイルと自動化ロジックの両面から強化を施したバージョンです。
