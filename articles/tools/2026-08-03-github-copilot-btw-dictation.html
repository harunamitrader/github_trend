GitHub Copilot / Product Update

GitHub Copilot /btw Command & Local Dictation

サイドチャット用の/btwコマンド、多言語対応のローカル音声入力、隔離ワークスペース用の実験的/worktreeコマンド、およびモデル廃止スケジュールの発表

リリース日 2026-08-03
アップデート August 2026 Update
ツール GitHub Copilot

主な変更点

GitHub Copilotの2026年8月第1週のアップデート（VS Code拡張機能 1.132など）が公開されました。作業中のサイドチャットを分離する機能や音声入力の強化、さらに一部モデルの非推奨化が公表されています。主な変更点は以下の通りです。

  • サイドチャット用の「/btw」コマンド: 現在の作業コンテキストに直接影響を与えることなく、ちょっとした疑問や調査タスクを別枠で進めるためのサイドチャットコマンドが導入されました。
  • ローカルオンデバイス音声入力: 多言語に対応したオンデバイス音声認識（Local Dictation）が実装され、インターネットを介さない高速でプライベートな音声指示に対応しました。
  • 実験的「/worktree」コマンドの追加: Copilot CLIにおいて、メインの作業コピーを汚さずに隔離されたGit Worktree内でエージェントに変更タスクを実行させる実験的なコマンドがサポートされました。
  • モデルの非推奨・廃止スケジュール: 2026年9月1日をもって、Gemini 3.1 Proや一部の旧Claude Opus/Sonnetモデルを含む計6種類のAIモデルを廃止することがアナウンスされました。

影響や使いどころ

本番用コードに影響させずに別の調査や一時的な変更を /btw や /worktree で安全に行えるほか、9月のモデル移行に向けて早めの切り替え確認が必要です。

まとめ

対話と開発を整理する便利なコマンドの追加やローカルでの音声指示など、UXを高める改善と、9月に予定されているモデル整理に向けたインフラ更新を含んでいます。
