AI Coding Tools Update (2026-05-15)

Claude Code の agents コマンド強化、GitHub Copilot の専用アプリ技術プレビュー開始、Gemini CLI のナイトリー更新等の最新情報をまとめました。

リリース日 2026-05-15
カテゴリー Coding
ツール Multiple Tools

主な変更点

本日のアップデートでは、エージェントの自律性と専用インターフェースの拡充が目立ちます。

  • Claude Code (v2.1.141): claude agents コマンドに --cwd オプションが追加され、特定ディレクトリでのエージェント起動が可能になりました。また、セッション要約機能が改善されています。
  • GitHub Copilot: デスクトップ専用アプリの「Technical Preview」が一部ユーザー向けに開始。IDEを介さず直接エージェントと対話できる環境が整備されつつあります。
  • Gemini CLI (v0.44.0-nightly): スキルベースのリファクタリング機能が統合され、複数のスキルを跨いだコード変換の安定性が向上しました。

影響や使いどころ

GitHub Copilot の専用アプリ化は、開発者がIDEの枠を超えてAIを活用する「AI-Native な OS 利用」への大きな一歩です。また、Claude Code の微細なコマンド改善は、マルチリポジトリ構成での自動化をより容易にします。

まとめ

エージェントが「IDE内の機能」から「OS上の独立した作業主体」へと進化する兆しが見えるアップデートとなりました。各ツールのナイトリー版やプレビュー版の動きが加速しています。
