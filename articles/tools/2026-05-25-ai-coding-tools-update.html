2026-05-25 AIコーディングツール アップデート

Google Antigravity 2.0 / CLI / SDK の公開と GitHub Copilot for Eclipse のオープンソース化をまとめた 2026-05-25 の AIコーディングツール監視ログです。

リリース日 2026-05-25
カテゴリ Coding
ツール Antigravity, GitHub Copilot

主な変更点

2026年5月25日に確認した主要なAIコーディングツールの更新は、次の2件です。

  • Antigravity: Google I/O 2026 に合わせて 2.0 を公開し、スタンドアロンのデスクトップアプリ、CLI、SDK をそろえました。Gemini 3.5 Flash を前提にした実行環境や、Scheduled Tasks、成果物ベースのフィードバック導線が強化されています。
  • GitHub Copilot: Eclipse 向けプラグインが MIT ライセンスでオープンソース化され、チャット、コード補完、エージェント機能、Skills、MCP 連携、BYOK などの実装を公開しました。

影響や使いどころ

Antigravity は、IDE 内の AI 補助にとどまらず、CLI と SDK まで含めた「実行基盤」として使える形に広がりました。対して GitHub Copilot for Eclipse は、実装の透明性が上がったことで、Eclipse ユーザーや拡張機能の開発者が挙動を追いやすくなっています。どちらも、単なる機能追加より「運用と拡張のしやすさ」を押し上げる更新です。

まとめ

今回の2件は、AI コーディングツールが閉じた製品から、CLI・SDK・OSS を含む拡張可能なプラットフォームへ移っている流れをよく表しています。実務で使うなら、機能だけでなく公開形態や拡張性もあわせて見ておく価値があります。
