AI Coding Tools Update: Claude Code v2.1.131, Cursor 3.3, and Windsurf 2.2.17

2026年5月7日のAIコーディングツールの主要アップデートをまとめました。Claude Code の Windows 環境での修正や Cursor のコンテキスト使用量可視化、Windsurf の新レビュー機能など、利便性を高める更新が続いています。

リリース日 2026-05-07
カテゴリ Coding
ツール Claude Code, Cursor, Windsurf, Gemini CLI

主な変更点

主要なツールの最新リリースにおける変更点は以下の通りです。

  • Claude Code v2.1.131: Windows 環境における VS Code 拡張機能の有効化プロセスを修正。Mantle エンドポイントの認証エラーを解消。
  • Cursor 3.3: 「Context usage breakdown」機能を追加。どのファイルや履歴がコンテキストを消費しているかを詳細に把握可能に。
  • Windsurf v2.2.17: 「Devin Review & Quick Review」を導入。エージェントによるコードレビューの質と速度を向上。
  • Gemini CLI v0.42.0-preview.2: ナイトリービルドおよびプレビュー版の安定性向上。

影響や使いどころ

今回のアップデートでは、特に「可視化」と「安定性」が重視されています。Cursor のコンテキスト内訳機能は、トークン制限が厳しいモデルを利用する際の最適化に大きく寄与します。また、Claude Code の Windows 関連の修正により、多くのユーザーで VS Code との連携がスムーズになることが期待されます。

まとめ

主要な AI コーディングツールが着実に進化を遂げています。特に開発者の「使い心地」に直結する機能追加やバグ修正が目立ち、より実用的なフェーズへと移行していることが伺えます。
