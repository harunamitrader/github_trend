AI Tool Log

2026-05-22 AI一般ツール アップデート

ChatGPT の Codex 更新、Claude の企業向け連続発表、Grok Skills の公開を横断して確認します。

リリース日 2026-05-22
カテゴリ Others
ツール ChatGPT, Claude, Grok

主な変更点

直近の公式アナウンスでは、汎用 AI ツールが「個人向けの使い勝手改善」だけでなく、「業務導入先の拡大」と「生成物の種類拡張」を同時に進めています。

  • ChatGPT: 5/21 の release notes で Codex 関連の更新を公開。Appshots、Goal mode の一般提供、in-app browser の注釈強化、locked computer use、browser use improvements など、長時間タスクの実行と確認を支える機能がまとまって追加されました。
  • Claude: Anthropic は 5/14 の PwC 連携拡張、5/18 の Stainless 買収、5/19 の KPMG との戦略提携を続けて発表。Claude を企業の中核業務に入り込ませる動きと、SDK/MCP 周辺の開発基盤強化が同時に進んでいます。
  • Grok: 5/18 に Skills を公開し、web / iOS / Android でドキュメント、プレゼン、表計算、PDF を直接生成できるようにしました。自作スキルの共有にも対応し、会話型アシスタントから作業実行基盤へ踏み込みました。

影響や使いどころ

ChatGPT は「対話の中で作業を進める」方向に、Claude は「企業システムと接続される」方向に、Grok は「成果物をそのまま作る」方向に伸びています。用途が重なる部分はあっても、各社の強化点はかなり明確に分かれてきました。実務では、長いタスクを任せるなら ChatGPT、組織導入やデータ連携を重視するなら Claude、文書や資料の即時生成を求めるなら Grok という使い分けがしやすくなっています。

まとめ

今回の更新は、一般向け AI ツールが「便利なチャット」から「具体的な業務装置」へ移行していることを示しています。最新の差分を追うだけでも、各社が狙っている価値が明確に見える週でした。
