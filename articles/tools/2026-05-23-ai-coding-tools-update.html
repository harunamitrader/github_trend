AI Tool Log

2026-05-23 AIコーディングツール アップデート

Claude Code v2.1.148、Cline CLI v3.0.10、Gemini CLI v0.43.0 の3件をまとめた 2026-05-23 の AIコーディングツール監視ログです。

リリース日 2026-05-23
カテゴリ Coding
ツール Claude Code, Cline, Gemini CLI

主な変更点

2026年5月22日に確認された、主要なAIコーディングツールの更新は以下の3件です。

  • Claude Code (v2.1.148): 一部環境で Bash tool が exit code 127 を返し続ける回帰を修正しました。
  • Cline CLI (v3.0.10): file:// 経由のプラグイン導入、アイドル中のセッション維持、Bedrock の profile 認証復元などをまとめて改善しました。
  • Gemini CLI (v0.43.0): edit tool の使い分け、/resume の復帰、非対話セッションの出力、モデルルーティング周りを広く修正しました。

影響や使いどころ

今回は新機能の大幅追加というより、既存の自動化や長時間セッションを壊さないための安定化が中心です。Claude Code は実行系の回帰修正、Cline はプラグインとセッション運用の改善、Gemini CLI は編集精度と復帰性の改善がそれぞれ効いています。

まとめ

3つとも「実務で止まりやすい場所」を埋める更新でした。細部の修正ですが、日々の開発フローではこうした安定化が最も効きます。
