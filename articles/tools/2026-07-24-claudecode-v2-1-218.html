Claude Code: v2.1.218

/code-review コマンドのバックグラウンドサブエージェント化、スクリーンリーダー用アクセシビリティ向上、MCP接続エラー報告の強化

リリース日 2026-07-24
バージョン v2.1.218
ツール Claude Code

主な変更点

Claude Code が v2.1.218 にアップデートされ、コードレビュー機能のバックグラウンド化、ターミナル操作のアクセシビリティ改善、Model Context Protocol (MCP) のデバッグ機能の強化が行われました。主な変更点は以下の通りです。

  • /code-review のバックグラウンド化: 従来メインセッションの対話履歴を汚しがちだった /code-review コマンドが、バックグラウンドのサブエージェント（サブタスク）として実行されるようになりました。これにより会話履歴が整理され、後続の指示がシームレスに適用可能です。
  • ターミナルアクセシビリティの向上: Option+Delete や Ctrl+W などの単語/行削除コマンドを実行した際、スクリーンリーダー向けに削除されたテキストを音声アナウンスするアクセシビリティ機能が追加されました。
  • MCP 接続エラー報告の強化: MCP サーバーへの接続失敗時、単に失敗を告げるだけでなく、詳細な HTTP ステータスコードやエラー内容が表示されるようになりました。また、設定値に不可視の余分な空白文字が含まれている場合の警告も追加されました。

影響や使いどころ

レビュー実行時のチャットログが大幅に簡素化され、コードの改善作業により集中できるようになります。また、MCP周りの設定エラーを突き止めるデバッグ作業が容易になりました。

まとめ

Claude Code v2.1.218 は、コードレビューコマンドのサブタスク化によるセッション履歴のクリーン化、スクリーンリーダーへの対応強化、およびMCP接続トラブルシューティングの利便性向上を含むマイナーアップデートです。
