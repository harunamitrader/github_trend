Grok / Product Update

Grok Voice Think Fast 2.0

書き起こし精度1.4倍向上、低遅延化、より自然な発話スタイルを実現した音声対話モデルの最新アップデート

リリース日 2026-08-01
バージョン Think Fast 2.0
ツール Grok

主な変更点

xAIは、Grok向けの次世代リアルタイム音声対話モデルである「Grok Voice Think Fast 2.0」をリリースしました。主な変更点は以下の通りです。

  • 音声書き起こし精度の向上: 音声認識（Speech-to-Text）の精度が従来モデル（1.0）と比較して1.4倍向上し、誤認識が大幅に減少。
  • 低遅延と自然な発話: 応答遅延がさらに改善され、ユーザーの発話に対する即時のリアクションや、イントネーション・会話のテンポがより自然な発話スタイルへと進化。
  • APIエイリアスの自動移行: 開発者向けの API エイリアス「grok-voice-latest」が、2026年8月5日をもって自動的に 1.0 から 2.0 へ切り替わります。
  • 料金体系: 新モデルの音声利用料は、1分あたり 0.08ドルで提供されます。

影響や使いどころ

モバイルアプリ等でのリアルタイムな英会話練習や音声アシスタントとしての体験が極めてスムーズになります。APIを使用する開発者は、8月5日にエイリアスが自動的にバージョン2.0へと移行するため、テスト環境での動作検証が推奨されます。

まとめ

リアルタイム会話の音声認識と遅延速度に磨きをかけ、自動移行による開発者のスムーズな導入をサポートする強力な音声モデルアップデートです。
