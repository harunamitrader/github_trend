Antigravity: v1.2.4

プロジェクト検出処理をローカルの .antigravitycli フォルダから分離し、中央キャッシュでの一元管理や Windows 環境での自動リトライ動作バグを修正した安定化アップデート

リリース日 2026-07-19
バージョン v1.2.4
ツール Antigravity

主な変更点

Google の CLI コーディングエージェント Antigravity (agy) が v1.2.4（および v1.2.3）にアップデートされ、ワークスペース構成の簡素化と Windows 環境での互換性向上、およびブラウザ制御のパフォーマンス改善が施されました。主な変更点は以下の通りです。

  • プロジェクト検出のデカップリング: ローカルの .antigravitycli ディレクトリへの依存をなくし、プロジェクト情報のマッピングを中央キャッシュ（~/.gemini/antigravity-cli/cache/projects）に一元管理化しました。
  • Windows 互換性向上: 自動リトライ拡張機能（Auto-Retry Extensions）の動作時における Windows 環境特有の不具合を解消しました。
  • fire-and-forget 型 CDP の導入 (v1.2.3): Chrome DevTools Protocol (CDP) のインジェクションを永続接続から非同期実行方式へ刷新し、リトライ動作と処理速度を最適化しました。
  • フォーカス管理の改善 (v1.2.3): 新しいエージェントタブを開く際に、既存の古いタブがフォーカスを奪い返してしまう競合バグを修正しました。

影響や使いどころ

ワークスペースごとに .antigravitycli 構成ファイルを生成・配置する必要がなくなり、複数のプロジェクト間での移動やセットアップがシンプルになります。また、Windows での開発セッションや、ブラウザ TUI の反応速度が大きく向上します。

まとめ

Antigravity v1.2.4 は、マルチプラットフォームでの開発体験を安定させ、プロジェクト管理のオーバーヘッドを取り除く堅実なリファクタリングアップデートとなっています。
