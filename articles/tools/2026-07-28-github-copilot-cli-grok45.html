GitHub Copilot: CLI Grok-4.5 & OAuth Update

GitHub Copilot CLIがアップデート。Grok-4.5モデルの対応追加、プラグイン制御機能の拡張、SessionsサイドバーおよびWebベースOAuthフローの導入

更新日 2026-07-28
対象ツール GitHub Copilot
バージョン CLI Update

新機能・追加点

  • Grok-4.5 モデルサポートの追加: Copilot CLIにおいて、xAIの最新かつ非常に高い推論能力を持つ「Grok-4.5」モデルが利用モデルの選択肢に追加されました。
  • プラグイン・フックの詳細な制御オプション: コマンドライン実行時に、適用するプラグイン（Plugins）、カスタム指示ファイル（Instructions）、自動化エージェント（Agents）、LSP診断（LSP servers）、およびGitフック（Hooks）を個別に有効化・無効化できる柔軟なパラメータが追加されました。
  • Sessions サイドバーの新規導入: 過去に実行した対話セッションの履歴や作業コンテキストを素早く確認・再開できる「Sessions」サイドバーがCLI管理機能に統合されました。
  • Webベースの OAuth ログインフローのサポート: ローカルターミナル上での認証を円滑にするため、ブラウザを自動的に開いてOAuth認証を行う仕組みが導入され、従来の手動トークン貼り付けなどの煩わしさが解消されました。

バグ修正・改善点

  • オートパイロット（Autopilot）処理の改善: バックグラウンドでのタスク自動進行時における、不要な待機プロセスの最適化と、プロンプト解釈の整合性が高められました。

開発者への影響

Grok-4.5の追加により、複雑なアルゴリズムの選定や複数ファイルをまたぐ高度なリファクタリングにおいて、さらに高い適合率でのコード生成が期待できます。また、ブラウザ経由のOAuthログインの導入や各種診断機能の細かなON/OFF設定が整備されたことで、組織のポリシーやローカルリソースの状況に合わせた快適なCLI運用が可能になりました。
