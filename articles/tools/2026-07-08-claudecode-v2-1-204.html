Claude Code v2.1.204: Headless セッション中の SessionStart フックストリーミングとアイドル切断の修正

ヘッドセッション中の SessionStart フックイベントのストリーミング不具合を修正し、リモートワーカーの意図しない刈り取りを防止するパッチ。

リリース日 2026-07-08
バージョン v2.1.204
ツール Claude Code

主な変更点

Claude Code v2.1.204 では、バックグラウンドやヘッドレス（Headless）モードでの動作時におけるフックイベント処理の安定性を向上させる修正が行われました。主な変更点は以下の通りです。

  • SessionStart フックイベントストリーミングの修正: ヘッドレスセッション中に SessionStart フックを実行する際、内部フックイベントが正しくストリーミングされないバグを修正しました。
  • リモートワーカーのアイドル刈り取り防止: 上記のストリーミング不具合に伴い、実行途中のフックタスクがあるにもかかわらず、リモートの作業用インスタンス（ワーカー）が「アイドル状態」と誤認されて途中で強制終了（刈り取り）されてしまう問題を解決しました。

影響や使いどころ

この修正は、特に CI/CD パイプライン内での自動テストの実行や、画面を持たない（Headless）リモートサーバー上で Claude Code に長期の自律ワークフローを実行させる運用において極めて重要です。フックの起動直後にセッションが切断されてしまう不安定さが解消され、サーバーサイド運用の信頼性が大幅に向上します。

まとめ

ヘッドレス環境およびサーバーサイドの長期ワークフロー実行時におけるフック処理のバグを確実に解消するパッチアップデートです。
