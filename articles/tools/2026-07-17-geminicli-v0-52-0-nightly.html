Coding Tool Log

Gemini CLI: v0.52.0-nightly.20260716

キャンセルされたツールレスポンスのグループ化と連続ロール合体による API 400 Bad Request エラーの解消を含む nightly アップデート

リリース日 2026-07-17
バージョン v0.52.0-nightly.20260716
ツール Gemini CLI

主な変更点

Google の Gemini CLI (gemini-cli) が最新のナイトリービルド v0.52.0-nightly.20260716.g3ff5ba20f にアップデートされました。主な変更点は以下の通りです。

  • API 400エラーの防止 (キャンセルレスポンス改善): キャンセルされたツールのレスポンスをグループ化し、連続するメッセージロールを結合して送信するように修正。これにより、Gemini API 側で「400 Bad Request」が返される問題を未然に防ぎます。
  • 計画モードの相対パス書き込みポリシーの簡素化: 計画（Plan）モードで相対パスを使用したファイル書き込み制限ポリシーをよりシンプルな形に簡素化し、動作の安定性を向上させました。
  • 自己修正バイパス機能の追加: write_file や replace による JSON/IPYNB ファイル編集時に、LLM による不必要な自己修正ループをスキップして正確に書き換えを行う挙動を追加しました。
  • タスクキャンセルの挙動修復: バックグラウンドタスクがキャンセルされた際に、実行ループが確実に強制終了（アボート）されるよう修正しました。
  • ライブラリの引き上げ: 内部の google-auth-library のバージョンを 10.9.0 にアップデートし、認証プロセスの安定性を向上させました。

影響や使いどころ

大規模な編集や非同期実行のキャンセル時に時折発生していた API レベルの 400 エラーが修正されたため、複雑なワークフローを CLI で実行する際の堅牢性が向上しています。

まとめ

キャンセル応答時のメッセージ構造最適化による API エラー対策や、JSON/Notebook 編集時の LLM 自己修正のバイパスなど、実用上のエッジケースでのクラッシュと無駄なループを防ぐパッチが施されたビルドです。
