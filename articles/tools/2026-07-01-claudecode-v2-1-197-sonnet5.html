Claude Code v2.1.197: デフォルトモデルに「Claude Sonnet 5」を採用、組織モデル対応とセキュリティ・Windows 互換性の向上

Claude Code のデフォルトモデルとして最新の「Claude Sonnet 5」(1Mトークン窓) が導入されたほか、セキュリティ強化やUI上の添付ファイルリンク、組織デフォルトモデルのサポートを含む大型アップデート。

リリース日 2026-07-01
バージョン v2.1.197 / v2.1.196
ツール Claude Code

主な変更点

今回のアップデートでは、新世代モデルである「Claude Sonnet 5」がデフォルトとして全面採用されたほか、チーム開発を意識した組織デフォルト設定の追加やセキュリティ境界の厳格化など、多面的な機能向上とバグ修正が行われています。主な変更点は以下の通りです。

  • Claude Sonnet 5 のデフォルト採用 (v2.1.197): デフォルトモデルが Claude Sonnet 5 に変更され、1Mトークンの超巨大コンテキストにネイティブ対応しました。2026年8月31日まで特別プロモーション価格（Input $2 / Output $10 per Mtok）で利用可能です。
  • 組織/ロールのデフォルトモデル (v2.1.196): 管理者が Org Console で指定したモデルが未選択時のデフォルト（Org default / Role default）として機能するようになりました。
  • セキュリティ強化 (v2.1.196): コミットされた設定ファイル（.claude/settings.json）を利用してリポジトリが自己承認した .mcp.json の自動生成・起動を無効化。未承認は Pending approval 状態となります。
  • ファイル連携とバックグラウンド処理のバグ修正: チャット内に添付されたファイル名を Cmd/Ctrl+クリックで Finder/Explorer で開けるようになったほか、バックグラウンド会話再開時のトランスクリプト消失などのバグが解消。
  • PowerShell 互換性の向上 (v2.1.196): Windows PowerShell 環境で git diff やパイプ文字 | を含むコマンドが失敗扱いになっていた不具合が解消されました。

影響や使いどころ

これにより、開発者は 1M トークンのコンテキストを活かした大規模プロジェクトのコード生成や修正を Claude Code 上で直接、極めて高速かつ安価に実行できるようになります。また、セキュリティ面や Windows/PowerShell 上での動作の安定性が飛躍的に向上したため、実用ツールとしての実効性が大きく高まりました。

まとめ

Claude Code v2.1.197 は、Claude Sonnet 5 の力をフルに活かす基盤アップデートであり、インフラ・セキュリティ・環境互換性の三拍子が揃った、チームおよび大規模プロジェクト開発にとって極めて重要なマイルストーンです。
