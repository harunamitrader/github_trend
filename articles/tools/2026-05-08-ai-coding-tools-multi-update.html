AI Tool Log #467

AI Coding Tools Update: Claude Code v2.1.133, Cline v3.83.0, and Gemini CLI v0.42.0-p3

2026年5月8日のAIコーディングツールの主要アップデート。Claude Code のリモートプラグイン対応や Cline のメモリ不足修正(8GB heap)、GitHub Copilot CLI の無料枠開放など、実用性を高める更新が続いています。

リリース日 2026-05-08
カテゴリ AIコーディング (CLI本体・拡張機能)
ツール Claude Code, Cline, Gemini CLI, Codex, GitHub Copilot CLI

主な変更点

本日のアップデートでは、大規模なコードベースを扱うエージェントの安定性向上や、プラグインエコシステムの拡張が目立ちます。主な変更点は以下の通りです。

  • Claude Code v2.1.133: --plugin-url によるリモートアーカイブからのプラグイン読み込みに対応。また、Homebrew/WinGet での自動アップデート管理機能（CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE）が追加されました。
  • Cline v3.83.0: メモリ不足（OOM）によるクラッシュを回避するため、ヒープサイズを 8GB に拡大。また、要望の多かった VS Code フォアグラウンドターミナルでの実行オプションが復旧しました。
  • Gemini CLI v0.42.0-preview.3: 自動メモリ管理のための「canonical-patch」コントラクトを導入。/exit --delete によるセッション削除や /bug-memory コマンドが追加されています。
  • Codex v0.129.0: ワークスペース間でのプラグイン共有 API を実装。大規模な MCP 出力の切り詰め処理により、安定性が向上しました。
  • GitHub Copilot CLI v1.1.0: Copilot Free ユーザーへの開放が開始されました。また、--hostname フラグによるマルチアカウント運用がサポートされています。

影響や使いどころ

Cline の 8GB ヒープ対応により、巨大なプロジェクトでの長時間作業がより安定します。また、Claude Code のリモートプラグイン対応は、チーム間でのツール共有を劇的に容易にする可能性があります。GitHub Copilot CLI の無料枠開放は、より幅広いユーザー層が AI 駆動の開発フローを試す機会となるでしょう。

まとめ

エージェントの「タフさ（安定性）」と「拡張性（プラグイン）」の両面が強化された、非常に実用的なアップデート群です。
