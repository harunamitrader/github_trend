AI Coding Tools Update: Claude Code v2.1.138, Cursor v3.3, and Gemini CLI v0.42.0-nightly

2026年5月9日のAIコーディングツールの主要アップデートをまとめました。Claude Code のエージェント安定性向上、Cursor の PR レビュー・並列ビルド機能、Gemini CLI の nightly 更新など、開発効率を底上げする改善が続いています。

リリース日 2026-05-09
カテゴリ Coding
ツール Claude Code, Cursor, Gemini CLI, Codex, GitHub Copilot

主な変更点

本日のアップデートでは、エージェントの「実務適応能力」と「並列処理」に焦点が当てられています。

  • Claude Code v2.1.138: エージェントの安定性と観測性が向上しました。Mantle 認証の修正に加え、特定モデルでの推論効率が改善されています。
  • Cursor v3.3: PR レビュー体験が刷新されました。また、プランから複数のタスクを並列に実行する「Build in Parallel」や、大きな変更を小さな PR に分割する機能が追加されました。
  • Gemini CLI v0.42.0-nightly.20260507: エージェント停止（AgentExecutionStopped）時の JSON 出力に対応。MCP ツールとの連携の信頼性が向上しています。
  • Codex (oh-my-codex) v0.16.3: Native-hook 設定の信頼性が向上し、Team/Ralph ワークフローでのエージェントの引き継ぎがより堅牢になりました。
  • GitHub Copilot: コードレビュー使用統計 API が拡充され、組織内での Copilot 活用状況の可視化が進みました。

影響や使いどころ

特に Cursor の「Build in Parallel」は、複雑な計画を立てた後に一気にコードを生成・テストさせる際に威力を発揮します。また、Claude Code や Gemini CLI の安定性向上により、長時間にわたる複雑なリファクタリング作業での「エージェントの脱落」が減少することが期待されます。

まとめ

エージェントが単なる「コード生成機」から、PR 作成や並列ビルドまでこなす「自律的なチームメンバー」へと進化しています。特に PR 周りの機能強化は、チーム開発での AI 活用を一歩前進させるものです。
