主な変更点

2026年6月3日 JST の再監視では、Coding 対象の公式更新が 3 件ありました。実行前の安全確認、nightly の追従、Codex の利用先拡張が中心です。

  • Claude Code v2.1.160: shell startup files や acceptEdits の対象ファイルに書き込む前の確認が増え、workflow トリガーは ultracode に切り替わりました。Windows のクリップボードや background session まわりの不具合もまとめて修正されています。
  • Gemini CLI v0.45.0-nightly.20260602: experiment flag が有効な環境で flash GA model に切り替える変更が入り、nightly の追従が進みました。
  • Codex: Codex app で Sites が preview になり、Amazon Bedrock 経由でも Codex を使えるようになりました。モバイル側の Codex 連携も合わせて進んでいます。

影響や使いどころ

今回は、モデルそのものよりも「どこに書き込むか」「どの実行環境につなぐか」が更新の焦点でした。Claude Code と Codex は実行の安全性と接続先、Gemini CLI は nightly 追従をそれぞれ確認しておくと運用差分を追いやすいです。

まとめ

今回の更新は、派手な新機能よりも、実行の安全性と運用の境界線を整えるものが中心でした。日常的に AI コーディングツールを使うなら、CLI の許可設定と Codex の接続先を先に見直す価値があります。
