Claude Code v2.1.206: ディレクトリ補完と CLAUDE.md 整理機能の導入

/cd でのディレクトリ補完、/doctor による CLAUDE.md Trimming 提案、本体更新時のバックグラウンドエージェント即時自動更新、複数のハング・タイムアウトバグの修正などを実施。

リリース日 2026-07-10
バージョン v2.1.206
ツール Claude Code

主な変更点

Claude Code v2.1.206 では、ターミナル操作や自律エージェントの運用を円滑にする新機能の追加に加え、キーボードハングやタイムアウト、バックグラウンドでのアップデート同期といった多くの利便性向上・バグ修正が行われました。主な変更点は以下の通りです。

  • /cd でのディレクトリ候補補完の追加: /cd コマンドの入力時に、/add-dir と同様にローカルのディレクトリ構造を元にしたパスの推薦候補が表示されるようになり、移動の操作性が向上しました。
  • /doctor による CLAUDE.md 最適化提案: プロジェクト用の指示書である CLAUDE.md を分析し、コードベースから自動推測可能な不要部分を切り落としてスリム化（Trimming）することを提案するチェック項目が追加されました。
  • バックグラウンドエージェントの自動更新の改善: Claude Code 本体の更新があった際、バックグラウンドエージェントがバックグラウンドで即座に新バージョンへ更新されるようになりました。これにより、後からエージェントを attach する際のバージョン違いによるラグが解消されました。
  • commit-push-pr での自動 git push 範囲の拡張: origin だけでなく、レポジトリに設定された push 専用のデフォルトリモート（remote.pushDefault など）への git push も自動で許可されるようになりました。
  • 多数のハング・不具合修正: claude --resume または --continue 実行時の起動時キーボード入力ハング、MCP コマンドの request_timeout_ms 設定無視によるタイムアウト、OAuth MCP サーバでの再認証不具合などが修正されました。

影響や使いどころ

/cd の補完や CLAUDE.md 最適化機能により、日々のコーディングセッションがスムーズに進むようになります。また、本体のアップデート時にバックグラウンドジョブが即座に同期される仕組みや、--resume 時のキーボードハング修正により、長期の自律ワークフローをバックグラウンドに逃がし、適宜アタッチして状況を確認する開発フローが非常に安定します。

まとめ

ディレクトリ補完や CLAUDE.md 整理機能などのUX改善に加え、バックグラウンドエージェントの更新同期やキーボードハングといった運用の問題を解消するマイナーリリースです。
