Claude Code v2.1.183 リリース

auto-mode 実行時の安全性を強化し、意図しない破壊的な git コマンド実行をブロックする更新。

リリース日 2026-06-20
バージョン v2.1.183
ツール Claude Code

主な変更点

今回のアップデートでは、AIが自律的に実行する自動実行（auto-mode）時の安全ガードレールが強化されました。

  • 破壊的 git コマンドの自動実行ブロック: ユーザーから明示的な指示や承認がない限り、ワークスペースを大きく損なう可能性のある git コマンド（git reset --hard、git checkout -- .、git clean -fd、git stash drop など）の自律実行を自動的に拒否・ブロックする保護メカニズムを導入。

影響や使いどころ

エージェントに自律的なタスク解決を任せる auto-mode 時において、AIの判断ミスや予期しない動作による未コミットファイルの完全消失や、意図しない状態の破壊が防止され、より安心してバックグラウンド実行を任せられるようになります。

まとめ

開発ワークスペースのデータを保護し、自律実行時の深刻なリスクを未然に防ぐための重要なセキュリティ・安全性強化アップデートです。
