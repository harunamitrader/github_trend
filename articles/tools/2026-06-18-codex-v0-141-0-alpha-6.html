OpenAI Codex v0.141.0-alpha.6 リリース

Windows sandbox 実行ポリシーと /usage コマンドの表示バグを整理したアルファ版アップデートです。

リリース日 2026-06-18
バージョン v0.141.0-alpha.6
ツール Codex

主な変更点

OpenAI Codex v0.141.0-alpha.6 では、Windows サンドボックス内の実行フローおよび使用統計コマンドの安定化が行われました。

  • Windows sandbox の実行ポリシー整理: サンドボックス内で一部のシェルコマンドが失敗する問題を解決。
  • /usage コマンドの表示修正: 使用メトリクスが正しく整形出力されないバグを修正。

影響や使いどころ

Windows 環境での自律実行（computer use）や、コスト管理の確認がさらにスムーズに行えるようになります。

まとめ

アルファ段階のマイナーフィックスですが、環境固有の問題に対処する着実な前進です。
