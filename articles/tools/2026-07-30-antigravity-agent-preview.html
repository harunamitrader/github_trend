Antigravity: Managed Agent Public Preview

サンドボックス環境内で自律的な計画・コード実行・ファイル管理・ブラウジングが可能な『Antigravity Agent』のパブリックプレビューが開始

更新日 2026-07-30
対象ツール Antigravity
バージョン Agent Preview

新機能・追加点

  • Antigravity Agentのパブリックプレビュー公開: サンドボックス化された隔離コンテナ内で動作する一般目的の自律型エージェントモデル（`antigravity-preview-05-2026`）が公開されました。これにより、開発者が詳細な手順を与えなくても、大まかな目標に対して自律的に「計画立案」「推論」「コード実行」「ファイル生成・修正」「Webブラウジング」を行い、課題解決までループを実行し続けます。
  • Gemini 3.5 APIファミリー連携の強化: バックグラウンドの推論モデルとして Gemini 3.5 Flash / Pro との連携がさらに深化され、トークン消費効率と推論スピードの双方が高次元で最適化されました。
  • 開発ガイドの更新と多言語化: エージェント開発を推進する「Gemini 3.5 + Antigravity 移行ガイド」や各種プロンプトテンプレートがアップデートされ、より幅広い環境で導入しやすくなりました。

開発者への影響

Managed Agentのプレビュー公開により、従来の単純なコード補完や対話型アシスタントの枠を超え、隔離されたセキュアな環境でリサーチからパッチの適用・検証までをAIに自律操作させる「Agentic Workflow」の体験が可能になります。特にコンテナ化による安全なサンドボックスにより、ローカル環境への影響を心配せずに複雑なコード探索タスクを任せられます。
