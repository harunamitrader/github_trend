Grok CLI / Product Update

Grok CLI 2026-08-03 Update

プロジェクトディレクトリ選択の整理、および外部認証切れ時のエラー挙動改善などを導入したモノレポ同期アップデート

リリース日 2026-08-03
バージョン Commit: e5478ef
ツール Grok CLI

主な変更点

xai-org/grok-build の最新モノレポ同期アップデートが公開されました。主な変更点は以下の通りです。

  • プロジェクトディレクトリ選択UIの整理: ツール起動時にディレクトリ選択を省略する調整を行いました。
  • 外部バイナリ認証フローの修正: 資格情報切れが発生した際、401無限ループに陥るのを防ぎ、適切に新規ログインフロー（Sign-in flow）へユーザーを誘導するよう修正。
  • ファイル監視の安定化: ファイル監視時に入れ子になった（nested）チェックアウトの監視処理をスキップし、不要なIOイベントのループを防止しました。
  • TUI表示の利便性向上: 出力画面上のナビゲーションアイコン「▲」をクリックすることで、レスポンスの先頭まで瞬時にスクロール（ジャンプ）できる機能を追加。

影響や使いどころ

資格情報切れでのハングアップやファイル監視起因の負荷上昇が抑えられるため、CLI対話型開発環境のレスポンスが改善されます。

まとめ

認証無限ループの防止やファイル監視ループの抑止、スクロール利便性向上など、TUI開発での安定性と操作性を向上させるモノレポ同期アップデートです。
