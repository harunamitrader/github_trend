Claude Code v2.1.148: Bash ツールの exit code 127 回帰を修正

Claude Code v2.1.148 は、Bash ツールが一部環境で exit code 127 を返し続ける回帰を修正した小規模パッチです。

リリース日 2026-05-22
バージョン v2.1.148
ツール Claude Code

主な変更点

2.1.147 で入った Bash tool の回帰を修正するメンテナンス更新です。

  • Bash ツールの回帰修正: 一部ユーザー環境で Bash tool がすべてのコマンドで exit code 127 を返し続ける不具合を修正しました。
  • 修正範囲: 2.1.147 で導入された回帰への対処で、機能追加よりも安定性回復を優先したパッチです。

影響や使いどころ

Claude Code で Bash tool を使ったコマンド実行を自動化している場合、誤って失敗扱いになるケースを減らせます。小さな修正ですが、実行系の信頼性には直接効く内容です。

まとめ

v2.1.148 は、Bash tool の回帰だけを素早く潰した安定化パッチです。新機能よりも、既存のワークフローを止めないことに価値があります。
