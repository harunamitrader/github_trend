Gemini CLI: v0.52.0

LLMトリアージオーケストレータの追加、無限ReActループの抑制、A2Aサーバーにおけるリモートコード実行（RCE）防止やセキュリティサンドボックスの強化

リリース日 2026-07-24
バージョン v0.52.0
ツール Gemini CLI

主な変更点

Google公式のCLIツール @google/gemini-cli が v0.52.0 にメジャーアップデートされました。これまでのプレビューやnightlyビルドの機能が集約された安定版リリースです。主な変更点は以下の通りです。

  • LLMトリアージオーケストレータ: エージェントによる意思決定やエラー検出を統合制御する caretaker-triage オーケストレータシステムが実装されました。
  • セキュリティと実行分離の強制: A2A (Agent-to-Agent) サーバーにおいて、信頼境界の検証とタスク分離が厳格化され、リモートコード実行 (RCE) の脆弱性が防止されました。macOS では Seatbelt サンドボックスプロファイルが default-deny（初期拒否）へと移行しました。
  • 安定性の向上と無限ループ対策: エージェントの自律実行時の無限 ReAct ループやプロンプトインジェクションに対する防御策が強化されました。
  • 400 Bad Request 等のバグ修正: 連続する同一ロールの統合処理などにより API 連携のエラーを修正。また GOOGLE_APPLICATION_CREDENTIALS 環境変数のキャッシュ検証を改善しました。

影響や使いどころ

自律的にコード生成やコマンド実行を行う際のエージェントの暴走や、不審なリポジトリ操作による不正コード実行（RCE）のリスクを大幅に削減し、セキュアなローカル実行を実現します。

まとめ

Gemini CLI v0.52.0 は、トリアージコントロールの統合、実行分離やサンドボックス規制の厳格化によるRCE対策など、安全性と堅牢性を劇的に向上させた安定版アップデートです。
