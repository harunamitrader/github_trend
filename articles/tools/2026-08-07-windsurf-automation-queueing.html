Devin Desktop / Product Update

Devin Desktop (Windsurf) Automations API v3

オートメーションのキューイングサポート、Automations API v3の正式公開、GitLabサポートの追加、および自社ホスト型Devin Outpostsの導入

リリース日 2026-08-07
アップデート August 2026 Release
ツール Devin Desktop

主な変更点

旧Windsurfからリブランディングされた「Devin Desktop」の最新アップデートが公開されました。オートメーション機能の大幅な強化や、外部連携の拡充、独自のインフラ上で動かせる機能などが導入されています。主な変更点は以下の通りです。

  • オートメーションのキューイング対応: 実行するオートメーションタスクをキューイングして順番に処理できるようになり、バッチタスクや順序に依存するビルドパイプラインなどを効果的に管理可能になりました。
  • Automations API v3の正式リリース: APIがv3にアップデートされ、生産環境での安定稼働をサポートするプロダクション仕様になりました。
  • GitLabとの統合: GitHubに加えて、GitLabリポジトリをベースにしたオートメーションや、GitLab上のイベントトリガーに対応しました。
  • Devin Outpostsの導入: ユーザー独自のインフラやローカルPC上の隔離環境で、Devinのエージェントタスクやワークロードを安全に実行できる機能が公開されました。
  • VNCビューワーのフルスクリーン対応: 画面上でエージェントの挙動を監視するVNC viewerがネイティブで全画面表示できるようになりました。

影響や使いどころ

GitLabを用いた開発フローにおける自動実行や、セキュリティが要求される環境で独自のOutpostsを介した自己完結型の開発自動化パイプラインが構築できます。

まとめ

今回のアップデートにより、Automations APIの安定化とGitLab・Outpostsといった外部/独自インフラ連携が追加され、大規模な自律型ワークフローを実用化する準備が整いました。
