GitHub Copilot: Auto mode in Chat 一般提供

Copilot Chat 内の「Auto mode」（エージェント自律モード）が全ユーザーに開放され、専用デスクトップアプリも GA（一般提供）に到達しました。

リリース日 2026-06-18
アナウンス 一般提供 (GA)
ツール GitHub Copilot

主な変更点

GitHub Copilot の自律型開発能力が大きく進展し、全ユーザー向けに正式開放されました。

  • Auto mode in Copilot Chat: チャット上でエージェントが自律的に複数ファイルを変更するモードが全ユーザー向けに提供開始。
  • GitHub Copilot Dedicated App: デスクトップ専用アプリ（Technical Preview だったもの）が一般提供 (GA) に移行。
  • 使用統計の集計対象拡大: Copilot usage metrics の集計ルールが改善され、アクティブユーザーのカウント精度が向上。

影響や使いどころ

ブラウザやエディタ拡張の枠を超え、自律エージェントとしての実用性が飛躍的に高まります。

まとめ

Copilot のエージェント機能の普及において節目となるメジャーリリースです。
