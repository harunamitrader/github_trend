2026-05-28 AIコーディングツール アップデート

Claude Code v2.1.152、Cline v3.85.0、Gemini CLI v0.45.0-nightly.20260527、GitHub Copilot の 5/26 更新をまとめた 2026-05-28 の監視ログです。

リリース日 2026-05-28
カテゴリ Coding
ツール Claude Code, Cline, Gemini CLI, GitHub Copilot

主な変更点

2026年5月28日に確認した Coding 対象の公式更新は、次の 4 件です。

  • Claude Code v2.1.152: /code-review --fix の自動反映、スキルの disallowed-tools 指定、/reload-skills、SessionStart hooks の再読込、fallback-model 切り替えなど、長時間セッション向けの制御を広く強化。
  • Cline v3.85.0: SAP AI Core での GPT-5.5 対応、DeepSeek V4 Flash / Pro、Gemini 3.5 Flash の追加、/lg-task URI webhook 連携を追加し、Vertex AI と Poolside Laguna の周辺を修正。
  • Gemini CLI v0.45.0-nightly.20260527: ACP セッションの deadlock 回避、ripgrep パス解決の安定化、セッション削除の分離、Alpine 互換性改善、MCP 準拠修正、Windows のキー操作修正など、実行系の不具合を細かく潰した nightly。
  • GitHub Copilot: 5月26日の changelog で、Copilot Memory の削除・範囲制御と Copilot CLI まわりの扱いを整理し、さらに model rules で組織単位のモデル指定を行えるようにした。

影響や使いどころ

今回は新機能の派手さよりも、セッション制御、権限の明示化、モデル選択の組織管理、実行環境の安定化が目立ちます。Claude Code と Gemini CLI は長時間運用の土台を固め、Cline は対応モデルを広げ、GitHub Copilot は組織内運用のガードレールを強めた形です。

まとめ

AI コーディングツールは、単なる対話 UI から「権限を持った実行基盤」へ寄っています。今回の更新群は、その変化を支える細部の改善が中心でした。
