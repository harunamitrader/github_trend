Claude Code: Native Installer Migration

npmによるインストール方法を非推奨とし、Node.js不要で自動アップデートに対応したネイティブインストーラー方式への移行

リリース日 2026-07-28
アップデート Native Installer
ツール Claude Code

主な変更点

今回のアップデートでは、開発用CLIツールとしての信頼性と配布プロセスの合理化を目的として、以下の極めて重要なインストール方式の変更が行われました。

  • npm インストール非推奨化: これまで標準だった `@anthropic-ai/claude-code` パッケージを用いた npm 経由のグローバルインストール方式が正式に非推奨（deprecated）となりました。
  • ネイティブインストーラーの導入: 代替として、Mac/Linux/WSL向けのシェルスクリプト、およびWindows（PowerShell）向けの専用インストーラーが導入され、Node.jsに依存しない独立したバイナリとして配信が開始されました。
  • 自動バックグラウンド更新: 新しいネイティブ実行ファイル方式に移行したことで、ツール自体が自動的にバックグラウンドで最新バージョンを検出しアップデートを適用する仕組みが有効化されました。
  • 外部パッケージマネージャーの対応: macOSでは Homebrew (`brew install --cask claude-code`)、Windowsでは WinGet (`winget install Anthropic.ClaudeCode`) を通じたOS標準のパッケージ管理をサポートしました。

影響や使いどころ

従来のnpm経由のインストールでは、Node.jsのバージョン競合や、権限まわりの問題によるパスの不整合が発生しやすくなっていましたが、ネイティブインストーラーへの移行によりそれらの問題が完全に解消されます。既存ユーザーは既存の npm 版をアンインストール (`npm uninstall -g @anthropic-ai/claude-code`) し、ネイティブスクリプト等を用いてインストールし直すことが強く推奨されます。

まとめ

Claude Code の今回のアップデートは、Web開発者以外の層や、Node.jsを持たない環境でもCLIツールをスムーズに導入・自動更新できる道を開くものです。配布プラットフォームの刷新として非常に大きな節目となります。
