AI Tool Log

Claude Code: v2.1.215

Agent Skills (/verify, /code-review) の自動実行停止と明示的コマンド呼び出し化による制御性の向上

リリース日 2026-07-20
バージョン v2.1.215
ツール Claude Code

主な変更点

Claude Code が v2.1.215 にアップデートされ、AI エージェントのスキル実行に関する制御ルールが更新されました。主な変更点は以下の通りです。

  • Agent Skills の自動実行停止: バックグラウンドで自動的に実行されていた `/verify` および `/code-review` スキルが、デフォルトで自動起動しないよう仕様変更されました。
  • 明示的な手動呼び出し化: ユーザーがターミナル上で直接 `/verify` や `/code-review` コマンドを入力した場合のみ実行されるようになり、トークン消費と実行タイミングのコントロールが容易になりました。

影響や使いどころ

意図しない自動検証や自動コードレビューによるセッション遅延・トークン消費を防ぎ、必要なタイミングでのみ手動でスキルを実行できるようになります。

まとめ

Claude Code v2.1.215 は、エージェント機能の過剰な自動実行を抑制し、開発者の明示的な指示に基づく動作へシフトさせた制御性重視のマイナーアップデートです。
