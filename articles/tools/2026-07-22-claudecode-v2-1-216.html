AI Tool Log

Claude Code: v2.1.216

バックグラウンドセッション復元時の制限引き継ぎの正確性向上、ファイルシステム隔離無効化オプション of 追加、長時間稼働時のパフォーマンス改善

リリース日 2026-07-22
バージョン v2.1.216
ツール Claude Code

主な変更点

ターミナル向け AI アシスタント CLI ツール Claude Code が v2.1.216 にアップデートされ、セッション復元の正確性向上と安定性の改善が行われました。主な変更点は以下の通りです。

  • バックグラウンドセッション復元時の権限保持: 再開されたバックグラウンドエージェントセッションが、デフォルト設定にフォールバックすることなく、開始時のプロンプトとツール制限を正確に復元するようになりました。
  • 新しい構成設定: ネットワーク送信制御は維持しつつ、ファイルシステムの分離を無効化できるオプション設定 sandbox.filesystem.disabled が追加されました。
  • 長時間稼働時のパフォーマンス改善: 長時間のセッションにおいてメッセージ正規化コストが二次関数的に増大し、セッション再開や応答が数秒間 stalls（失速）する問題を修正しました。
  • 自動実行（Auto Mode）の誤判定修正: HTTP 401 分類エラーが原因で、オートモードでのコマンド実行が不必要に拒否される問題が解消されました。

影響や使いどころ

バックグラウンドでの長時間に及ぶ処理の安定性とレスポンス速度が向上し、開発現場での自律型タスク遂行能力がさらに堅牢になります。

まとめ

Claude Code v2.1.216 は、バックグラウンドセッションの信頼性向上とファイルシステム分離無効化設定の追加、ならびに実行パフォーマンスのボトルネックを解消した重要なマイナーアップデートです。
