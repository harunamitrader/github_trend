Gemini CLI v0.43.0: edit ツール誘導と /resume 周りを修正

Gemini CLI v0.43.0 は、編集ツールの使い分け、/resume の挙動、セッション入出力、モデルルーティングを広く修正した安定化リリースです。

リリース日 2026-05-22
バージョン v0.43.0
ツール Gemini CLI

主な変更点

このリリースは、編集精度とセッションの復帰性を中心に、実務で気になる細部をまとめて整えています。

  • 編集ツールの誘導: モデルが surgical edit の場面で edit tool を使うように steering が追加されました。
  • Auto Memory の説明改善: memory updates と skills の提案がどう扱われるかを明確化しました。
  • セッションと /resume の修正: AgentExecutionStopped の JSON 出力、session の export/import、legacy session の resume 復元、chat corruption の修正が入っています。
  • モデル選択とルーティング: Flash quota 枯渇後の明示的なモデル選択、adaptive token calculator、NumericalRouter の有効化などが改善されました。
  • 実行と安全性: YOLO / AUTO_EDIT での redirection 許可、numeric project ID の拒否、invalid custom plans の扱い改善、macOS 向け unsigned binary の添付などが含まれます。

影響や使いどころ

Gemini CLI を非対話の自動化や長時間セッションで使う場合、途中復帰と出力の安定性が上がるのが実用的です。編集ツールの使い分けも改善されているので、単純な実行 CLI から少し複雑なエージェント基盤へ寄せたいときに効きます。

まとめ

v0.43.0 は、派手な機能追加よりも、編集・復帰・ルーティングの修正を積み上げた安定化リリースです。
