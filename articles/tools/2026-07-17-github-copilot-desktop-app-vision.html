GitHub Copilot: 2026-07-16 Update

デスクトップ専用 Copilot App の全ユーザー（無料プラン含む）開放や、プロンプトへの画像・PDF直接添付が可能な Copilot Vision の一般提供開始などを実施

リリース日 2026-07-17
バージョン 2026-07-16 Update
ツール GitHub Copilot

主な変更点

GitHub Copilot において、エージェント機能の利用シーンを広げる大型のアップデートが発表されました。主な変更点は以下の通りです。

  • GitHub Copilot App の全プラン開放: デスクトップ専用の Copilot App（エージェント駆動の開発環境）が Free および Education プランを含む全ユーザーに対して開放され、macOS, Windows, Linux 上で直接自律開発セッションを開始できるようになりました。
  • Copilot Vision の一般提供 (GA) 開始: 画像や PDF ファイルを直接チャットプロンプトに添付し、モックアップからのコード生成やドキュメント解析を行える「Copilot Vision」が VS Code, github.com, Copilot CLI 等で正式に利用可能となりました。
  • Visual Studio でのリアルタイム制限・監査強化: リアルタイムでの使用量トラッキング機能と予算アラートが追加されたほか、独自の MCP サーバー接続時の信頼性検証プロトコルが強化されました。
  • VS Code での並行エージェントセッション対応: 複数の自律エージェントを同時に別々のコンテキストで実行し、タスクを並行処理する「並行エージェントセッション」のサポートが強化されました。

影響や使いどころ

画像やドキュメントを直接 Copilot に投げて解釈させられる Vision の GA により、仕様書やレイアウト設計図をもとにしたコード生成が格段に便利になりました。また、Free ユーザーでもデスクトップアプリからエージェントを動かせるようになったため、より多くの開発者がエージェントの力を試すことができます。

まとめ

エージェント駆動開発を行うデスクトップ専用アプリの全プラン開放や、ドキュメント・画像の直接入力に対応した Copilot Vision の GA など、製品全体のインターフェースを刷新する重要なアップデートです。
