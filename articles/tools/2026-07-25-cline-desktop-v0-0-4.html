Cline: Desktop App v0.0.4

フォルダ選択不要のチャット開始機能、エージェント用コンテキスト圧縮のデフォルト有効化、オンボーディングやファイルのドラッグ＆ドロップ機能追加

リリース日 2026-07-25
バージョン Desktop v0.0.4
ツール Cline

主な変更点

Cline Desktop App の一般テスト向けプレビュー版が v0.0.4 にアップデートされました。ワークスペースに縛られない自由な対話機能やコンテキストの自動圧縮など、デスクトップ環境における操作性と安定性が劇的に向上しました。主な変更点は以下の通りです。

  • ワークスペースフリーでのチャット開始: プロジェクトフォルダを選択・展開していなくても、その場ですぐにエージェントとの対話セッションを開始できるようになりました。
  • エージェント自動圧縮（Agentic Compaction）の標準化: 会話の長さに応じて、文脈の要点を押さえたままインテリジェントに対話履歴を圧縮する「Agentic Compaction」がデフォルトで有効になり、コンテキストウィンドウの上限に達しにくくなりました。
  • ドラッグ＆ドロップによる添付: チャットエリアへファイルを直接ドラッグ＆ドロップして添付できるようになり、添付画像はチャットログ上にインライン展開されます。
  • ログインシェルの PATH 解決: 実行時にログインシェルの環境変数 PATH を正しく解決するようになり、エージェントが gh などの各種 CLI 開発ツールを見失う問題が解消されました。
  • 単発ルーチンの実行とその他のUI刷新: 1回限りのオンデマンドルーチンの予定に対応し、実行履歴へのナビゲーションを追加。さらに、折りたたみカード化されたチャンネル設定や新しいインアプリナビ付きカスタムタイトルバーなどが導入されました。

影響や使いどころ

フォルダを開く手間なく疑問を解消できるようになり、画像やファイルの受け渡し、ローカルの開発 CLI ツールへのアクセスもシームレス化され、デスクトップ単体でエージェント機能がより直感的に扱えるようになります。

まとめ

Cline Desktop v0.0.4 は、ワークスペースなしチャットのサポート、エージェント圧縮の標準有効化、ドラッグ＆ドロップ、シェルのPATH解決、および新規のオンボーディングとタイトルバーUIの刷新を含むメジャーテストアップデートです。
