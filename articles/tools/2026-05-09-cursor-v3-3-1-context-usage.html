Cursor 3.3.1: Context usage UI改善とバグ修正

v3.3での新機能の使い勝手を向上させるマイナーアップデート。コンテキスト管理機能のUI改善が含まれます。

リリース日 2026-05-09
バージョン 3.3.1
ツール Cursor

主な変更点

3.3で導入された機能の洗練とバグ修正が行われました。

  • UI改善: Context usage breakdownの視認性が向上し、より詳細な情報が確認しやすくなりました。
  • バグ修正: エディタ内の特定の操作で発生していた軽微な不具合を修正。

影響や使いどころ

コンテキストの使用量をより正確に把握できるようになったことで、不要なコンテキストの削減やプロンプトの最適化がさらに容易になります。

まとめ

Cursor 3.3.1は、新機能の使い勝手を向上させるマイナーアップデートです。日々のコーディングの効率化に貢献します。
