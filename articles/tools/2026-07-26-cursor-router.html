Cursor: Cursor Router リリース

タスクの複雑さに応じて最適なモデルを自動選択する「Cursor Router」の導入

リリース日 2026-07-26
アップデート Cursor Router
ツール Cursor

主な変更点

Cursor にインテリジェントなモデルルーティングシステム「Cursor Router」が追加されました。タスクの複雑さを解析し、最適なLLMへリクエストを自動で振り分けることで、生産性とコストのバランスを最適化します。

  • インテリジェントルーティング: タスクに応じて Frontierモデル、Balancedモデル、または Cost-optimizedモデルへ自動的にリクエストを振り分ける Cursor Router を搭載。
  • 3つの最適化モード: ユーザーの好みに合わせて「Intelligence（最高品質）」「Balanced（バランス重視）」「Cost（トークン消費量節約）」のモードを選択可能。
  • 管理者制御 (Teams): 管理者がグループごとにルーターのON/OFF、使用可能モードの制限、およびモデルの許可/禁止リストを設定できる高度なガバナンス機能を実装。
  • Grok 4.5 統合: コスト効率の高い選択肢として Grok 4.5 をルーティングオプションとして利用可能に。

影響や使いどころ

複雑な設計や難解なバグ修正には最高性能のモデルを割り当て、簡単なコード生成やドキュメント整理には軽量で安価なモデルを割り当てるといった判断を、ツール側で自動で行ってくれます。ユーザーはモデルの切り替えを意識することなく、コストを抑えつつ最高の開発体験を得られます。特にチーム開発において無駄なAPIトークン消費を抑制するのに役立ちます。

まとめ

Cursor に最適なモデル自動選択機能「Cursor Router」が実装。生産性の最大化とコスト最適化を自動で両立し、Teams向けの管理者権限での制御にも対応しました。
