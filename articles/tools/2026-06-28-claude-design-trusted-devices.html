Claude: 「Claude Design」デスクトップ専用ホームの追加およびリモート認証強化

デスクトップアプリのサイドバーに「Claude Design」の専用ホームが追加され、プロジェクトとの連携が強化されました。あわせて管理者がリモートセッションでデバイス制限を行える「Trusted Devices」機能がリリースされました。

リリース日 2026-06-28
アップデート区分 UX改善・セキュリティ
ツール Claude

主な変更点

2026年6月25日、Anthropicはデスクトップ版Claudeおよびエンタープライズ管理者向けに、UIとセキュリティに関する重要なアップデートをリリースしました。

  • Claude Design のサイドバー追加: デスクトップアプリのサイドバーに「Claude Design」専用のナビゲーションホームが追加されました。作成中のプロジェクトや外部デザインシステムとの連携をシームレスに行うことができます。
  • デバイス制限「Trusted Devices」の導入: チームおよびエンタープライズの管理者向けに、リモートの Claude Code セッションを接続する際、事前に管理者が承認した信頼済みデバイス（Trusted Devices）からの接続のみに制限できる機能が導入されました。
  • インタラクティブ課金の分離（先週の更新補足）: 6月中旬より、Web対話（claude.ai）や通常のターミナル利用と、 headless Agent（Claude Code 等の自動実行）のAPI課金プールが完全に切り分けられ、管理画面での明細把握が容易になりました。

影響や使いどころ

デスクトップアプリでの「Claude Design」へのアクセス性向上により、モックアップやUIのプロトタイプ作成が非常に効率化されます。また、「Trusted Devices」は、企業内で自律型エージェントを使用する際のセキュリティ要件（接続端末制限）を満たすために必須の機能となります。

まとめ

Anthropicは、エージェント環境（Claude Code）が普及する中で、デスクトップアプリのUXを高めると同時に、企業向け管理機能（Trusted Devices）や課金体系の明確化を行い、実用性を盤石にしています。
