2026-06-05 AIコーディングツール アップデート

Cline v3.0.17、GitHub Copilot の app / CLI 更新、Codex v0.137.0 をまとめた 2026-06-05 の監視ログです。

リリース日 2026-06-05
カテゴリ Coding
ツール Cline, GitHub Copilot, Codex

主な変更点

2026年6月5日 JST の監視では、Coding 対象の公式更新が 3 系統ありました。Cline はセッション再開の安定化、GitHub Copilot は app と CLI の体験拡張、Codex は v0.137.0 で TUI と multi-agent 周りの整備が中心です。

  • Cline v3.0.17: Cline Hub の停止・再起動後に Escape でキャンセルすると固まる回帰を修正し、stale session の検出、pending message の復旧、`Ctrl+C` と Hub shutdown の race 修正、Telegram connector の `--allowed-user-id` 追加が入っています。
  • GitHub Copilot app / CLI: Copilot app の technical preview が既存の有料ユーザー全体に広がり、Canvases、voice conversations、cloud sessions、cloud automations、Copilot CLI sessions の集約、agentic browsing、Rubber duck、`/chronicle` が追加されました。Copilot CLI 側も、新しい terminal UI、rubber duck、`/every` と `/after` の prompt scheduling、voice input をまとめて強化しています。
  • Codex v0.137.0: F13-F24 のキーバインド、検索可能メニューへの paste、月次クレジット上限と cloud-managed config bundles、remote-control の pair/list/revoke、`codex plugin list --json`、hosted web/image tools、multi-agent v2 の runtime metadata など、操作性と運用面の機能が広がりました。

影響や使いどころ

Cline は再起動後のセッション復旧が安定し、GitHub Copilot は app/CLI をまたいだ agent-native 作業導線が広がり、Codex はエンタープライズ運用とマルチエージェント制御の見通しが良くなりました。日常利用では、新機能そのものよりも、セッション継続と権限・配布設定の扱いやすさが効く更新です。

まとめ

今回は派手な新機能だけでなく、再開時の安定性、チーム運用、マルチエージェント制御がそろって前進しました。Cline、GitHub Copilot、Codex を並行して使うなら、各ツールの session / automation / permission 周りを見直す価値があります。
