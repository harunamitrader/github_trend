カテゴリ Coding
ツール Claude Code, Cline, Gemini CLI

主な変更点

2026年5月29日 JST の確認で、Coding 対象の公式更新は 3 件でした。いずれも 2026年5月28日 UTC に公開されたリリースで、Claude Code と Cline は機能追加、Gemini CLI はパッチ更新です。

  • Claude Code v2.1.154: Opus 4.8 を高努力モードのデフォルトに寄せ、/workflows で複数エージェントを背景実行できるようにするなど、大きめの作業を回しやすくする更新でした。
  • Cline v3.86.0: Claude Opus 4.8 と Moonshot Kimi K2.6 を追加し、VS Code 拡張の配置整理とプロバイダ周りの修正をまとめたリリースです。
  • Gemini CLI v0.44.1: v0.44.0 系の修正を反映したパッチ版で、内容は小規模な hotfix でした。

影響や使いどころ

Claude Code は大きめのワークフロー処理、Cline は対応モデルの広さ、Gemini CLI は安定性の底上げが中心です。今回の監視では Cursor、Codex、Antigravity、Windsurf、GitHub Copilot に新規更新はありませんでした。

まとめ

3 件とも派手な新機能より、実運用で効くモデル追加と安定化が中心でした。Coding 監視は引き続き、Claude Code と Cline の大型更新、Gemini CLI のパッチを優先して追うのが妥当です。
