Claude Code v2.1.179 リリース

fallbackModel の解決動作の安定化と、nested skills の名前空間バグ修正を含むバグフィックスリリースです。

リリース日 2026-06-18
バージョン v2.1.179
ツール Claude Code

主な変更点

Claude Code v2.1.179 では、実行時のフォールバック動作の堅牢性とスキル解決の安定性が改善されました。

  • fallbackModel 解決の安定化: プライマリモデルがタイムアウトした際、代替モデルへのフォールバック解決プロセスが正常に完了するよう安定化。
  • nested skills のバグ修正: スキルが別のスキルを入れ子で呼び出す際に発生していた名前空間の競合バグを修正。

影響や使いどころ

長期実行タスクや複雑なマルチタスクでネストされたスキルを使用する際、実行時エラーが発生しづらくなりました。

まとめ

安定性を向上させるマイナーアップデートですが、エラー頻度を低減させる重要な修正が含まれます。
