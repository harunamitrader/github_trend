2026-05-21 AIコーディングツール アップデート

Claude Code (v2.1.145), Cline (v3.84.0), Gemini CLI (v0.44.1-nightly) などの主要AIコーディングツールの新バージョンリリース情報と、GitHub Copilot のモデル自動選択機能の発表をまとめてお届けします。

カテゴリ AIコーディングツール

主な変更点

2026年5月21日現在の主要なAIコーディングツールのアップデート情報は以下の通りです。

  • Claude Code (v2.1.145): 実行中のセッションをJSON出力する agents --json コマンドが追加。OTELトレースのネスト修正や、Windows (PowerShell) 環境での安定性が向上しました。
  • Cline (v3.84.0): SAP AI Core の追加モデルをサポート。MCPサーバーがオフの際に「Restart Server」ボタンを無効化する制御が導入されました。
  • Gemini CLI (v0.44.1-nightly): 2026年6月の Antigravity CLI への統合が発表。RAGスニペットのデバッグ露出や、NO_PROXY 設定の尊重など安定性向上のパッチが含まれています。
  • GitHub Copilot: VS Code においてタスクに応じたモデルの自動選択機能が導入。自動選択を利用するとトークン倍率が10%割引される特典も発表されました。
  • Windsurf (v2.3.10): エディタ本体の最新マイナーパッチがリリース。
  • Antigravity (v4.3.5): スキルやルールの追加時に README 等を自動更新する統計トラッキング機能が強化。
  • OpenAI Codex (v0.18.0): ローカル生成フロー用の omx api 公開や、SparkShell の可観測性向上が行われました。

影響や使いどころ

今回のアップデートでは、特に Claude Code や Gemini CLI のように「ツール間の連携」や「外部スクリプトからの制御」を意識した機能強化が目立ちます。GitHub Copilot のモデル自動選択は、ユーザーが最適なモデルを悩む手間を減らしつつ、コスト効率も高める実用的な更新です。Gemini CLI ユーザーは、来月の Antigravity CLI への完全移行に向けた準備が必要となります。

まとめ

エージェント型ツールの主流化に伴い、セッション管理の自動化や、モデルの動的切り替えといった「運用の高度化」が進んでいます。各ツールの最新バージョンを適用し、より安定した開発環境を構築しましょう。
