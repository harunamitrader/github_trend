AI Others Tools Update: ChatGPT GPT-5.5 Instant Default, Claude Usage Limit Increase, and Gemini File Generation

2026年5月10日の汎用AIツールの主要アップデートをまとめました。ChatGPT の GPT-5.5 Instant デフォルト化、Claude の使用制限大幅緩和と Microsoft 365 連携、Gemini のファイル生成・エクスポート対応など、利便性を高める更新が続いています。

リリース日 2026-05-10
カテゴリ Others
ツール ChatGPT, Claude, Gemini, Perplexity, Grok, NotebookLM, Obsidian

主な変更点

本日のアップデートでは、主要プラットフォームによる「エコシステムの深化」と「実務ツールの統合」が目立ちます。

  • ChatGPT: GPT-5.5 Instant が全ユーザーの標準モデルとなりました。また、特定の回答にどの記憶が使われたかを確認できる「Memory Sources」機能が追加されています。
  • Claude: 有料プラン（Pro/Max/Team）における Claude Code および API の使用制限が従来の 2 倍に緩和されました。また、Word や Excel 上で直接 Claude を利用できる Microsoft 365 アドインが一般公開されています。
  • Gemini: チャットで作成したコンテンツを Docs や Sheets、PDF として直接エクスポートできるようになりました。API 面では、File Search が画像や動画を含むマルチモーダル検索に対応しています。
  • Perplexity: macOS 版デスクトップアプリ「Personal Computer」が全 Pro ユーザーに開放。市場調査や監査などの定型作業を自動化する「Workflows」機能も導入されました。
  • Grok: 100万トークンのコンテキストを誇る Grok 4.3 の展開が進む一方、旧世代モデル（grok-3 等）の 5/15 での廃止が発表されました。
  • NotebookLM: Gemini アプリとのノート双方向同期に対応。インフォグラフィックやレポート作成を支援する「Studio」機能の強化も行われています。
  • Obsidian: CLI のパフォーマンスが向上し、ターミナル上でのコマンド補完機能が追加されました。

影響や使いどころ

ChatGPT のデフォルトモデル更新により、無料ユーザーでもより高度な推論が利用可能になります。また、Claude の制限緩和は、大規模なコードベースを扱う開発者にとって極めて大きなメリットとなります。Gemini のエクスポート機能は、AI との対話をそのままドキュメント化するワークフローを劇的に効率化するでしょう。

まとめ

汎用 AI は単なる「チャット」の枠を完全に超え、ドキュメント作成、アプリ操作、そして広大なコンテキストの管理をシームレスに行う「OS 的な存在」へと急速に進化しています。
