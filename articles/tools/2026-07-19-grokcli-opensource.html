Grok CLI (Grok Build): Open Source

ターミナルから自律開発を可能にする xAI の開発エージェント Grok Build CLI のコードベースが Apache 2.0 で完全オープンソース化され、併せてデフォルトデータ保持ポリシーも廃止

リリース日 2026-07-19
トピック オープンソース化 (Apache 2.0)
ツール Grok CLI

主な変更点

xAI の CLI 開発エージェント Grok Build (Grok CLI) が大幅にアップデートされ、コミュニティ主導の開発とセキュリティ面での配慮が盛り込まれた重要な移行が行われました。主な変更点は以下の通りです。

  • Apache 2.0 ライセンスで完全オープンソース化: ターミナルから自律的に動き、ファイル編集やコマンド実行を行う Grok Build CLI の全ソースコードが GitHub（xai-org/grok-build）で公開されました。
  • デフォルトデータ保持ポリシー of 無効化: 以前のコード情報アップロードに関する懸念に対応し、ユーザー設定に関わらずデータ保持をデフォルトでオフ（無効化）とし、保存されていた過去データも削除することをコミットしました。

影響や使いどころ

エージェントが裏でどのようなコマンドを実行し、ファイルを操作しているかの実装を誰でも確認・検証可能になり、エンタープライズや機密性の高いコードベースでも安全に使用できるようになります。

まとめ

Grok CLI のオープンソース化は、AI 開発ツール市場において透明性を高め、透明なデータ保護指針とともに開発者の信頼を勝ち取るための大きな転換点となります。
