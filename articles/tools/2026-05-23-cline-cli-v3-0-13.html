Cline CLI v3.0.13: セッション復帰表示と /clear 高速化

Cline CLI v3.0.13 は、履歴からのセッション復帰と /clear の待ち時間を改善した小規模更新です。

リリース日 2026-05-23
バージョン CLI v3.0.13
ツール Cline

主な変更点

TUI の待機感とクリア操作の引っかかりを減らす、実用寄りの小更新です。

  • セッション復帰の可視化: 履歴からセッションを復元するときに読み込みダイアログを表示し、TUI が固まったように見える状態を避けるようになりました。
  • /clear の高速化: セッションの新規作成を次のプロンプト送信まで遅らせることで、/clear 実行時の待ち時間を短縮しました。

影響や使いどころ

長時間の対話を続ける使い方や、/clear を頻繁に挟むワークフローでは、体感の引っかかりが減ります。機能の追加というより、既存の操作を滑らかにする改善です。

まとめ

v3.0.13 は小さな修正ですが、セッション復帰とクリア操作の体験を素直に良くしています。常用するほど効いてくるタイプのメンテナンス更新です。
