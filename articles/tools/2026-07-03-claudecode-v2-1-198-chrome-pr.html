Claude Code v2.1.198: 「Claude in Chrome」の一般公開と、自律的ドラフト PR 作成・通知機能の追加

Chrome 連携の一般公開や、自律的なコミット・プッシュ・ドラフトPR作成、エージェント完了/入力待ち通知、新デザインスキル `/dataviz` の追加など、開発自動化が劇的に強化されたメジャーアップデート。

リリース日 2026-07-03
バージョン v2.1.198 / v2.1.199
ツール Claude Code

主な変更点

今回のリリースでは、Chromeブラウザ統合が正式リリースされたほか、バックグラウンドでの作業完了時にドラフトPull Request（PR）の起票までエージェントが自律的に実行するなど、ワークフロー自動化の完了範囲が大きく拡大されました。主な変更点は以下の通りです。

  • Claude in Chrome が一般公開 (GA) 到達: Chrome ブラウザとの深い統合機能がすべてのユーザー向けに一般公開されました。
  • 自律的なコミット・PR起票: claude agents から起動されたバックグラウンドエージェントが、コード作業完了時に手動確認を挟まず自律的に commit、push、さらにドラフトPRの作成まで実行します。
  • エージェント通知機能の追加: エージェントがユーザーの入力を必要とする際（needs_input）や完了時（completed）に通知用フックを発火します。
  • 新スキル /dataviz の追加: チャートやダッシュボードの配色とデザインガイダンスを提供する、カラーバリデータ付きの新スキルを搭載。
  • ネットワーク耐性の向上とバグ修正: 一時的なネットワーク切断（ECONNRESET等）での即時失敗を防ぐ自動バックオフ再試行や、ブランチ切り替え時の /diff 更新バグが修正されました。

影響や使いどころ

これにより、開発者はコードの修正やデバッグのタスクをエージェントに投げた後、手動でコミットやPR作成をすることなく、自動的に用意されたドラフトPRをレビューするだけで済むようになります。また、通知サポートにより並行作業時の介入タイミングが把握しやすくなり、自律エージェントの価値がさらに高まりました。

まとめ

Claude Code v2.1.198 は、エージェントを「ただのアシスタント」から「自律して成果物をチームにマージする開発者」へと昇華させるための重要な進化版アップデートです。
