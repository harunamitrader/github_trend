AI Others Tools Update (2026-05-13)

OpenClaw v2026.5.12-beta.1 のリリース、サブエージェントのネスト表示 UI、OpenAI CLI 認証の改善、および Gemini 3.1 Pro Preview 対応についての技術アップデートログ。

リリース日 2026-05-13
種別 Update Log
ツール OpenClaw

主な変更点

本日の調査で確認された汎用 AI ツールのアップデートは以下の通りです。

  • OpenClaw v2026.5.12-beta.1:
    • Nested Sub-agent UI: セッションピッカーにて、サブエージェントを親セッションの下にツリー形式（└─ プレフィックス）で表示できるようになりました。
    • OpenAI CLI Auth: openclaw models auth login --provider openai にて、ChatGPT/Codex アカウントへのログインフローがデフォルト化されました。
    • Gemini 3.1 Pro Preview: Google SDK 内での ID 正規化により、google/gemini-3.1-pro-preview がテスト利用可能になりました。
    • Security Fixes: memory-wiki 取り込み時の管理者権限要求の厳格化。

影響や使いどころ

OpenClaw の UI 改善により、複雑なマルチエージェント・セッションの親子関係がひと目で把握可能になりました。また、Gemini 3.1 系の早期サポートにより、最新モデルの性能評価をいち早くセルフホスト環境で行えるようになっています。

まとめ

OpenClaw は、マルチエージェント運用の視認性と、最新モデルへの追従速度において、オープンソースの自律基盤としての完成度をさらに高めています。
