Gemini CLI / Security Update

Gemini CLI v0.54.4 (CVE-2026-12537 Patch)

権限のないGitHub IssueトリガーからCIランナー上で任意のコード実行を引き起こすOSコマンドインジェクション脆弱性（CVE-2026-12537）の修正パッチリリース

リリース日 2026-08-07
バージョン v0.54.4
ツール Gemini CLI

主な変更点

Gemini CLI（@google/gemini-cli）の最新安定版「v0.54.4」および対応ツール群がリリースされました。深刻な影響を及ぼす脆弱性の修正を含んでおり、即時アップデートが推奨されています。主な変更点は以下の通りです。

  • OSコマンドインジェクション脆弱性（CVE-2026-12537）の修正: 権限のない悪意あるGitHub Issueをトリガーとして、CIランナー上で任意のシェルコマンドが実行されたり、環境変数や機密情報が窃取されたりする深刻なセキュリティ脆弱性を修正しました。本パッチは gemini-cli 本体および run-gemini-cli プラグインに対して適用されています。
  • リブランディング（Antigravity CLIへの移行準備）の推進: Google Antigravityプラットフォームへの統合と改名に備えた内部コード、およびパッケージ構成の整理を引き続き進めています。
  • 開発連携プロセスのロバスト性向上: 以前のバージョン（v0.54.0）で追加されたFirestore二重ロック制御に加え、エラーハンドリングのバグやシグナル制御に関する細かい修正をマージしました。

影響や使いどころ

GitHub ActionsやCI/CD環境でGemini CLIを用いてPR生成や自動トリアージを運用している全プロジェクトにおいて、悪意ある外部入力を遮断するために直ちに変数をアップデートして最新版に同期する必要があります。

まとめ

GitHub CI上で環境変数やコマンド権限を奪取されかねない深刻なOSコマンドインジェクション脆弱性（CVE-2026-12537）を修正し、安定化を加えた重要セキュリティアップデートです。
