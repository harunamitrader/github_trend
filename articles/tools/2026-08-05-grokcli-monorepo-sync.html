Grok CLI / Product Update

Grok CLI 2026-08-05 Update

Cloudflare 52x等のエラー自動リトライ、非200系APIエラーのTUIバナー表示、およびサンドボックス機能の拡張を施したモノレポ同期アップデート

リリース日 2026-08-05
バージョン Commit: a5589e9
ツール Grok CLI

主な変更点

xai-org/grok-build の最新モノレポ同期アップデートが公開されました。主な変更点は以下の通りです。

  • ネットワークエラーの自動再試行: Cloudflareの52x系エラーや、その他の5xx系一時的サーバーエラー発生時に、リクエストを自動リトライする機能を追加しました。
  • APIエラーの視認性向上: API呼び出し時に発生した非200（エラー）ステータスを、TUI（ターミナルUI）画面上にすっきりとしたバナーとして分かりやすく表示するよう改善しました。
  • サンドボックスプロビジョニングの拡張: 安全な実行環境であるサンドボックス側で、検討プランや永続化メタデータ（durable metadata）等を適切に認識・配置するよう機能調整を行いました。

影響や使いどころ

ネットワークの一時的瞬断による対話セッションの切断率が大幅に低下するほか、エラー発生時の原因特定が画面上で容易になります。

まとめ

サーバー瞬断耐性の向上、エラーUIの可読化、およびサンドボックス機構のプロビジョニング調整を含む、TUI対話開発のロバスト性を強化するアップデートです。
