Grok: Grok 4.5 の正式ローンチ (GA) および Grok Build CLI (v0.2.98) へのアップデート

xAIは、コーディングや自律型タスクに特化したスマートモデル「Grok 4.5」をAPI上で正式に一般公開（GA）し、あわせて開発向けターミナルインターフェース「Grok Build CLI」をv0.2.98へアップデートしました。

リリース日 2026-07-16
バージョン 2026-07-16 Update
ツール Grok

主な変更点

今回の正式ローンチにより、API 経由で開発環境に最先端の推論能力を持つ Grok 4.5 を安全にデプロイ可能になりました。

  • Grok 4.5 の正式GA: コーディングや多段階エージェントタスクのために特別にトレーニングされた xAI の最新スマートモデルが一般公開。Cursor などのエディタとも親和性が高く、ソフトウェア開発の生産性を大きく引き上げます。
  • Grok Build CLI (v0.2.98) のアップデート: 開発セッション管理の改善、より強固な認証ロジックの実装、キュー制御のバグ修正に加え、ターミナル上での実行スピナー（インジケータ）の描画の乱れを解消し、インタラクティブ操作性を高めました。

影響や使いどころ

Grok 4.5 が正式に一般公開されたことで、開発チームは自律型のテスト記述やコードベース修正のパイプラインに Grok を直接組み込めるようになりました。特に Grok Build CLI のアップデートにより、ターミナル操作時に発生していたコマンドラインのハングアップやセッション切断エラーが著しく減少し、長時間の実行もストレスフリーになっています。

まとめ

Grok 4.5 の一般リリースと開発 CLI ツールの改善は、開発ファーストを掲げる xAI の姿勢を示すものです。高度なベンチマーク成績を残す推論エンジンが、より安定した統合ツールとともに利用可能になった意義は大きいです。
