Grok: 2026-07-23 Update

Microsoft Outlook & Excel へのアドイン機能の提供開始と、Google Workspace および Grok Build CLI 連携の強化

リリース日 2026-07-26
アップデート Office & Workspace Integration
ツール Grok

主な変更点

Grok がアップデート。Microsoft Office や Google Workspace とのシームレスな統合のほか、自律 CLI「Grok Build」における自動化連携がサポートされました。

  • Grok for Outlook: Outlook内に直接統合され、長文スレッドの自動要約、個人の声質・トーンに合わせた返信の自動生成、インボックス整理に対応。
  • Grok for Excel: Excel内で直接数式作成や自然言語によるデータ質問、複雑なシナリオの自動実行を支援。
  • Google Workspace / Interactive Brokers 連携: Google ドキュメント内での執筆補助、Interactive Brokers上での金融分析や自動データ構築をサポート。
  • Grok Build 自動化トリガー: スケジュールやメール受信を契機とする自律実行（/goal）タスクの作成、実行結果の自動報告に対応。

影響や使いどころ

メール処理やデータ分析といった日常業務に Grok がネイティブに食い込むため、ブラウザを切り替える必要がなくなります。さらに Grok Build によるスケジュール自律実行とメールトリガーにより、簡易的な業務バッチ処理の自律化が可能になります。

まとめ

Grok に Outlook や Excel の直接連携機能が搭載。Google Workspace や金融分析ツールへの統合、および Grok Build CLI におけるメール受信トリガー自動化機能もサポートされました。
