Cline / Product Update

Cline Desktop v0.0.10

MCP OAuth認可のサポート、エラー表示の局所化、実行エラー時の原因明示などのUX向上とVertex AI等のADC接続改善

リリース日 2026-08-07
バージョン v0.0.10 (Desktop)
ツール Cline

主な変更点

Cline Desktopのマイナーバージョン「v0.0.10」がリリースされました。MCP連携の認証強化や、UX・エラー検知に関する多くのバグ修正が含まれています。主な変更点は以下の通りです。

  • MCPのOAuth認可対応: 設定画面（Settings → MCP）からリモートMCPサーバーのOAuth認可ができるようになりました。認可ステータスの確認や保留中のキャンセル・再試行をサポートするほか、事前登録済みのクライアント情報（クライアントID・シークレット）による認証にも対応しました。
  • MCPエラーの個別表示化: ページ全体でのエラーではなく、問題の発生した個別のMCPサーバーごとにエラーを可視化するように改善されました。設定が無効なサーバーが一覧からサイレントに消えてしまう問題も解決しています。
  • 実行エラーの明確なフィードバック: 認証情報が設定されていないモデルの呼び出しや、キューに入れられた実行の失敗時に、トランスクリプト内に原因と設定画面へのリンクを明示するようになりました。
  • Vertex AI認証プロキシ対応: Vertex AIでの認証トークン更新時に、設定済みのカスタムfetchを適用し、プロキシ環境や特殊なネットワーク環境におけるADC（Application Default Credentials）認証の不具合を解消しました。
  • UI・ショートカットの追加: Welcome画面にモデル接続案内を表示。また、Cmd/Ctrl+Nで新規セッション、Cmd/Ctrl+,で設定画面を開くショートカットキーを追加しました。

影響や使いどころ

エンタープライズ環境やプロキシ背後の開発環境において、MCPサーバーやVertex AIとの連携を安全かつスムーズに構築できます。

まとめ

OAuth認可を用いたセキュアなMCP連携、エラーハンドリングの細分化、およびプロキシ背後でのVertex AI認証問題の解消など、使い勝手と安全性を高めるアップデートです。
