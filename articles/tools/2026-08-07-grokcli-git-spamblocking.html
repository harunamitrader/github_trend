Grok CLI / Product Update

Grok CLI 2026-08-07 Update

クライアントからのGit Status/Diffポーリングスパム防止、エクスポートへの自己改善メモリのバンドル、およびディスク使用量コマンドの追加

リリース日 2026-08-07
コミット afbc0fb7
ツール Grok CLI

主な変更点

Grok CLI の最新の monorepo 同期アップデートがリリースされました。対話型インターフェースおよびエージェント実行プロセスの最適化が行われています。主な変更点は以下の通りです。

  • Gitポーリングスパムの防止: 実行中にクライアントが連続してGitの status や diff コマンドを叩く「ポーリングスパム」からプロセスを守るためのガードロジックを導入し、動作の軽量化を図りました。
  • トレースエクスポート時の自己改善メモリバンドル: セッショントレースをエクスポートする際、エージェントの自己改善メモリの軌跡（memory traces）を一緒にアーカイブにバンドルするよう統合しました。
  • ディスク使用量コマンド「grok du」の追加: CLIのローカルディレクトリ ~/.grok が使用しているディスク容量を簡単に確認できる grok du コマンドを新規実装しました。
  • 複数シェルインスタンス起動時のロック解消: 多くのシェルインスタンスを並行して起動した際に、共通のセッション検索インデックスがロックされてフリーズする不具合を修正しました。
  • その他のバグ修正: プラグイン呼び出しボタン（CTA）のデバウンス処理を500msに調整し、ボタンの二重クリックを防止。

影響や使いどころ

複数のエージェントをローカルで動かしたり、Git管理下の巨大なプロジェクトで作業したりする際、インデックスの競合や無駄なGit通信による遅延を防ぎます。

まとめ

Gitポーリング防御による実行の安定化、セッションエクスポートのメモリ情報追加、およびマルチシェル実行時のロック回避を含む開発インフラの改善です。
