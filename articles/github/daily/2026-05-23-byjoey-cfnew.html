これは何か

cfnew は、Cloudflare Workers / Pages 上で動かすプロキシ管理インターフェースで、VLESS、Trojan、xhttp などの複数プロトコルをまとめて扱えるようにしたリポジトリです。配布、設定、クライアント向けの出し分けを 1 つの Worker に寄せています。

何ができるか

自動的なクライアント判定、地区別の返し分け、延長線上の延滞テスト、API ベースのノード管理、GUI での KV 設定などをまとめて提供します。Cloudflare のランタイムに載せることで、デプロイ後にそのまま設定変更へ進める運用を狙っています。

目立つポイント

多言語対応、ALPN 指定、ECH 対応、自動優選、Cloudflare Pages / Workers の両対応が目立ちます。README がかなり詳細で、導入から運用までをそのまま手順化しているのも強みです。

セットアップや使い方の流れ

Cloudflare 側で Pages か Worker を作成し、compatibility date を README 指定値に合わせてからデプロイします。次に KV をバインドし、UUID や path、各種フラグを設定して、GUI から優選やクライアント配布の条件を調整します。

どんな人向けか

Cloudflare 上で自前のプロキシ配布やノード管理をしたい人、複数クライアントを一括で扱いたい人、運用を GUI と API で切り替えたい人に向いています。

注意点

Cloudflare の runtime と compatibility date に依存するため、設定の違いで挙動が変わりやすいです。README の分量が多いので、最初から全部を入れず、必要な機能だけ段階的に有効化した方が事故を減らせます。

まとめ

cfnew は、Cloudflare 上で複数プロトコルの配布と管理をまとめる実務寄りの基盤です。KV と GUI を使った運用がしやすいのが特徴です。
