これは何か

Meta社内で8年間にわたり開発・利用され、13,000以上の内製アプリケーションを支えてきた、StyleX ベースの完全カスタマイズ可能でアクセシブルなオープンソース・デザインシステムです。人間だけでなく、AI エージェントにとっても理解しやすくコード生成しやすいように API やドキュメントが共同設計されています。

何ができるか

150以上のアクセシブルな Web コンポーネント、ダークモードサポート、標準テーマ（Neutral 等）、すぐに本番デプロイできるテンプレート、および専用 CLI を一元提供します。内部スタイルは StyleX で記述されていますが、ユーザー側は純粋な CSS カスタムプロパティや TailwindCSS、CSS モジュール、通常の CSS などを介して外側から自由にクラスやスタイルをオーバーライドできます。

目立つポイント

「AI エージェントフレンドリー（Agent Ready）」を設計哲学の核に据えています。AI アシスタントが迷わずにコンポーネントを配置・編集できるように、整然とした型定義（TypeScript）、曖昧さを排除した明確なプロパティ定義、そして API と同期したドキュメントスキーマが用意されています。また、必要に応じてコンポーネントのソースコードを自身のプロジェクトへ eject（書き出し）できる「swizzle」機能を CLI に標準装備しています。

セットアップや使い方の流れ

npm/pnpm/yarn から @astryxdesign/core とテーマパッケージ、および CLI 開発ツールをインストールします。その後、CLI を通じて初期構成ファイルを出力し、インポートした React コンポーネントを使用し始めます。

どんな人向けか

本環境でのアクセシビリティ要件を満たした強固なデザインシステムを構築したい React 開発者、および AI コーディングエージェント（Claude Code 等）を日常的に動員してフロントエンド開発のコード生成効率を最大化したいプロジェクトチームに適しています。

注意点

現在ベータ版として開発が進められており、一部の低レイヤー API やテーマ構成は今後のリリースで変更される可能性があります。また、基本の実装には React と StyleX が深く結びついています。

まとめ

Meta社における超大規模な実運用ノウハウを抽出し、人間と AI アシスタントが同じ参照情報（仕様）に基づいて共同開発することを最優先に捉えた、次世代のフロントエンドUIフレームワークです。
