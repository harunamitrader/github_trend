これは何か

Windows Terminalは、Command Prompt、PowerShell、WSL（Windows Subsystem for Linux）などのコマンドラインツールを一元管理・実行するためにMicrosoftが開発する公式オープンソースターミナルアプリケーションです。

何ができるか

マルチタブ表示、ペイン分割、DirectWriteベースの高速なGPUアクセラレーションテキスト描画、UTF-8などの各種文字コード対応、Cascadia Codeフォントのサポート、高度なテーマ・ショートカットカスタマイズ機能を提供します。

目立つポイント

旧来のコンソールホスト（conhost.exe）に代わる最新のモダンアーキテクチャ、JSONまたは設定UIによる自由な見た目・操作性の調整、並びにCanary/Preview版を通じた迅速な新機能開発フィードバックサイクルが魅力です。

セットアップや使い方の流れ

Microsoft Storeから「Windows Terminal」をインストールするか、GitHub Releasesページから `.msixbundle` パッケージをダウンロードしてダブルクリック（またはPowerShellの `Add-AppxPackage`）でインストールします。

どんな人向けか

Windows環境でPowerShell、Cmd、Linux CLI（WSL）などを常用しており、ターミナル作業の効率や視認性・操作性を格段に向上させたいすべての開発者やシステム管理者に向いています。

注意点

動作にはWindows 10 2004 (build 19041) 以降が必要です。ソースコードから自前でビルドする場合は、Visual StudioのC++デスクトップ開発環境と各種SDKの事前セットアップが必要になります。

まとめ

Windows Terminalは、Windowsにおけるコマンドライン体験を現代的かつ高機能に生まれ変わらせた必携ツールです。オープンソースとして絶えず進化を続けており、開発作業に欠かせないインフラとなっています。
