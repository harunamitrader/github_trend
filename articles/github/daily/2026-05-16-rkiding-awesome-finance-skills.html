これは何か

AIエージェントに対して、プロフェッショナルな金融分析能力を即座に付与するためのスキル（ツール）コレクションです。LLMを単なるチャットボットから、リアルタイムデータと専門的な分析ロジックを備えた「AIアナリスト」へと拡張します。

注目のポイント

  • マルチソース・ニュース集約: WSJ、Weibo、Polymarketなど10以上の信頼できるソースからリアルタイムに情報を収集。
  • ロジックの可視化: ニュースが市場に与える影響の伝達チェーンを自動生成し、分析プロセスの透明性を確保。
  • 高度なセンチメント分析: FinBERT等のモデルを用い、文脈に即したセンチメント数値を算出。
  • 市場予測（Kronos）: ニュースの文脈と価格データを統合し、AIによる市場動向の予測を実施。

導入・活用シーン

npx skills install <skill-name> という極めてシンプルなコマンドで、既存のAIエージェント（MCP対応ツール等）に導入可能です。特定の銘柄に関するニュースの要約だけでなく、そのニュースがなぜ市場を動かすのかという「ロジック」をAIに理解させたい場合に最適です。
