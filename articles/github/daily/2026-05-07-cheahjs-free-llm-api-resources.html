これは何か

主要な LLM プロバイダー（OpenAI, Anthropic, Google, Groq, Mistral 等）が提供している無料の API アクセス枠や、特定のプラットフォーム経由で利用可能な無料推論リソースをまとめたキュレーション・リポジトリです。

何ができるか

開発者がコストを抑えて LLM アプリケーションを構築・実験できるよう、永続的な無料枠や初回トライアルクレジットを提供する API プロバイダーを網羅的に把握できます。テキスト生成から埋め込み、マルチモーダル API までカテゴリ別に整理されています。

目立つポイント

永続的な無料枠を持つサービスと、初回限定クレジットを提供するサービスを明確に区別して掲載。コミュニティ駆動で頻繁に更新されており、最新の提供状況が反映されます。

セットアップや使い方の流れ

リポジトリの README を閲覧し、目的のカテゴリからプロバイダーを選択。リンク先の公式サイトで API キーを取得して利用を開始します。

どんな人向けか

コストを抑えて LLM アプリを開発したい個人開発者、学生、プロトタイプ作成中のエンジニア。

注意点

各プロバイダーの利用規約や制限（Rate Limit 等）は随時変更される可能性があるため、利用前に必ず公式サイトを確認してください。

まとめ

LLM 市場の競争激化に伴い、各社が提供する無料枠は変化していますが、このリポジトリはそうした流動的なリソース状況を把握するための標準的なリファレンスとして非常に有用です。
