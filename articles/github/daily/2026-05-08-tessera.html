これは何か

AIコーディングエージェント（Claude Code, Codex, OpenCodeなど）を統合して一元管理できる、オープンソースのビジュアルワークスペースです。Webブラウザおよびデスクトップ（macOS/Windows）で動作し、複数のエージェントによる並列ワークフローをGUI上で可視化・操作できます。

何ができるか

複数のチャットや実装タスクをパネル分割で同時に実行し、各エージェントの推論プロセス、ツール呼び出し、Gitのワークツリー状態（ブランチ、差分、PR状況）をリアルタイムで追跡できます。カンバンボード形式でのタスク管理や、ドラッグ＆ドロップによる直感的なワークスペース構築が可能です。

目立つポイント

1. マルチエージェント並列実行: Claude CodeとCodexを隣り合わせで動かし、出力を比較・同期可能。 2. Gitワークフローの統合: エージェントの作業を独立したワークツリーとして管理し、UIからコミットやPR作成まで完結。 3. リッチなコンポーザー: ファイル参照（@）、画像添付、音声入力、推論設定の微調整などを一箇所で実行。

セットアップや使い方の流れ

デスクトップ版（Releasesからダウンロード）またはnpm版（npm install -g @horang-labs/tessera）を使用します。起動後、ローカルにインストール済みの claude や codex などのCLIを認識して、ビジュアルな操作画面を提供します。

どんな人向けか

複数のAIコーディングツールを使い分けている開発者、ターミナルの文字だけでは把握しにくい複雑な並列作業を視覚化したいエンジニア、チーム全体でのエージェント活用を検討している組織に適しています。

注意点

Tessera自体はエージェントではなく「器（UI）」であり、別途 claude などのCLIツールがローカルにインストール・認証されている必要があります。また、ベータ版のため、デスクトップ版の実行時にはOSのセキュリティ警告が出る場合があります。

まとめ

散らばりがちなAIエージェントの作業を一つの「司令塔（コマンドセンター）」に集約し、開発の全体像を常に把握可能にする、次世代のAIワークスペースです。
