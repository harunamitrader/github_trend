これは何か

notebooklm-mcp-cli は、Google NotebookLM を CLI と MCP Server の両方から扱うための Python パッケージです。README では、旧 NotebookLM-MCP と NotebookLM-CLI を 1 つにまとめ、`nlm` と `notebooklm-mcp` を同時に提供する再編が強調されています。

何ができるか

NotebookLM をコマンドラインから操作したり、Claude Desktop や Cursor、Gemini CLI などの AI ツールから接続したりできます。ノートブック管理、質問応答、周辺の運用をまとめて扱えるので、手作業の往復を減らしやすい構成です。

目立つポイント

単なる接続用ラッパーではなく、CLI、MCP、デスクトップ拡張をひとまとめにした統合版である点が特徴です。README には 35 個の MCP ツール、認証、アップグレード、旧パッケージからの移行までまとまっていて、実運用向けの情報が揃っています。

セットアップや使い方の流れ

まずは `uv tool install notebooklm-mcp-cli` などで導入し、必要に応じて `pip` や `pipx` を選びます。その後は NotebookLM にログインし、`docs/CLI_GUIDE.md` と `docs/MCP_GUIDE.md` を参照しながら、AI アシスタント側の接続やコマンド確認を進める流れです。

どんな人向けか

NotebookLM を日常の調査や資料整理に使っていて、同じ知識ベースを CLI からも AI アシスタントからも呼び出したい人向けです。複数の NotebookLM 関連パッケージをまとめて管理したい人にも向いています。

注意点

この repo は内部 API に依存しているため、仕様変更の影響を受けやすいです。認証や cookie 抽出、アカウント種別の制約もあるので、最初の導入では README の手順を順番に追う必要があります。

まとめ

notebooklm-mcp-cli は、NotebookLM を手動操作だけでなくプログラムからも扱える形に整理した実用的な配布版です。NotebookLM を AI ツールの背後に置いて使いたいなら、まず確認したい repo です。
