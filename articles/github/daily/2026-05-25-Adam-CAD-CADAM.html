これは何か

CADAM は、自然言語や画像から3Dモデルを生成するオープンソースの text-to-CAD Web アプリです。OpenSCAD を WASM で動かし、ブラウザ上で CAD の生成とプレビューを完結させる設計になっています。

何ができるか

テキスト指示からモデルを起こし、寸法はスライダーで後から調整できます。出力は STL、SCAD、DXF に対応しており、3D プリンタ向けの試作や parametric design の検証に使いやすい構成です。

目立つポイント

リアルタイムプレビュー、画像参照入力、カスタムフォント対応、BOSL/BOSL2/MCAD のライブラリ利用がまとまっている点が強みです。単なる生成デモではなく、モデルの再調整と再出力までを同じ画面で扱えるのが実務向きです。

セットアップや使い方の流れ

README の手順どおりにクローンし、npm install の後に Supabase を立ち上げ、ローカル開発サーバーを起動します。サーバー側には OpenAI、Anthropic、OpenRouter、Google、FAL などのキー設定が必要なので、先に環境変数を揃えるのが前提です。

どんな人向けか

3D プリント用の試作、パラメトリック CAD の検証、AI による形状生成を Web で回したい人向けです。GUI ベースで CAD を触りたいが、ローカルアプリより軽い導線を求める用途にも合います。

注意点

ブラウザだけで完結する一方、実際の運用には Supabase CLI や外部 API キーが必要です。生成品質は指示の書き方に左右されるので、最初は単純な形状から試して寸法調整を詰める方が安定します。

まとめ

CADAM は、text-to-CAD を「試す」だけでなく、調整して書き出すところまで繋いだ実用寄りの Web アプリです。生成 UI と parametric control の両方を見たい人に向いています。
