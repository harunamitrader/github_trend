これは何か

Presenton は、Gamma や Beautiful AI の代替を狙う AI プレゼン生成器です。Web の self-hosted 実行、デスクトップアプリ、API をまとめて持っています。

何ができるか

プロンプトや文書からスライドを作り、PPTX と PDF に出力できます。OpenAI、Gemini、Azure OpenAI、 Anthropic、Ollama など複数プロバイダに対応し、自前モデルでも動かせます。

目立つポイント

テンプレートとテーマを自分で持てること、Docker と Electron の両方で配布できること、 さらに MCP Server 経由でも扱えることが強みです。プレゼン生成を SaaS 依存にしない設計になっています。

セットアップや使い方の流れ

README では、Quickstart からデスクトップアプリを試すか、Docker でローカル起動する流れが案内されています。 まずはモデルと出力先を決めて、必要に応じて独自テンプレートを追加するのが現実的です。

どんな人向けか

営業資料や社内説明資料を素早く作りたい人、プレゼン生成を自前運用したいチーム、 資料の生成・編集・配布を一つの基盤にまとめたい人に向いています。

注意点

モデル選択やテンプレート設計で出力品質が大きく変わります。まずは少数のテンプレートで試し、 自分の資料スタイルに合わせて調整していくのがよさそうです。

まとめ

Presenton は、プレゼン生成をローカルで握りたいときの実用的な土台です。 自分のモデルとテンプレートで回せる点に価値があります。
