これは何か

9Router は、Claude Code, Cursor, Cline, Copilot といった主要な AI コーディング CLI ツールと、各社の AI API の間に位置するプロキシ・ルーターです。コスト削減、安定性の向上、そしてプロバイダーの多様化を支援するために設計されています。

何ができるか

「RTK Token Saver」機能により、git diff や grep の出力などの冗長なツール結果を自動圧縮し、トークン消費量を劇的に減らします。また、サブスクリプションの枠が切れた際に安価なモデルや無料モデルへ自動で切り替えるフォールバック機能も備えています。

目立つポイント

40 以上の AI プロバイダー、100 以上のモデルを一つのエンドポイントで統合管理できる点が魅力です。さらに、Gemini の TTS（読み上げ）機能の統合や、システムプロンプトを短縮してトークンを節約する「Caveman」モードなど、ユニークな最適化機能も搭載されています。

セットアップや使い方の流れ

ローカルでバイナリまたは node 経由で実行し、既存のコーディングツールの API エンドポイントを 9Router のローカルアドレスに向けるだけで導入可能です。設定ファイルでプロバイダーの優先順位やコスト制限を細かく定義できます。

どんな人向けか

AI コーディングツールの利用コストを抑えたい個人開発者、API のレート制限やダウンタイムに悩まされているチーム、最新のマイナーモデルも柔軟に試したいエンジニアに最適です。

注意点

プロキシを介するため、わずかなレイテンシが発生する可能性があります。また、出力の圧縮（Token Saver）により、稀にモデルの理解度に影響が出るケースも考えられます。

まとめ

AI 駆動開発における「コスト」と「安定性」という現実的な課題を、高度なルーティングと圧縮技術で解決する、非常に実用性の高いツールです。
