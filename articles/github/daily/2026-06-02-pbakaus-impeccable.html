これは何か

Impeccable は、Claude などの AI に frontend design をより意図的に書かせるためのスキルバンドルです。7つの参照ファイル、23のコマンド、27の deterministic anti-pattern rules、12ルールの LLM critique pass で構成されています。

何ができるか

デザインの polish、audit、critique、animate、bolder、quieter などをコマンドとして扱えます。タイポグラフィ、色、motion、余白、UX writing をまとめて調整しやすく、AI の出力を一段引き締められます。

目立つポイント

Anthropic の frontend-design から着想を得ており、CLI と browser extension で deterministic な anti-pattern チェックを API キーなしで回せるのが特徴です。`impeccable.style` からすぐ使える点も導入しやすいです。

セットアップや使い方の流れ

まずはサイトから bundle を入れるか、リポジトリのコピーを用意します。そのうえで skill を読み込み、必要に応じて `polish` や `audit` を適用し、最後に critique pass で見落としを洗います。

どんな人向けか

AI で UI を作ることが多いフロントエンド開発者、デザインシステムを維持したい人、モデルの出力が毎回似てしまうことに困っている人向けです。生成物の質を言語化して揃えたいときに相性が良いです。

注意点

意図が強いぶん、ブランドやプロダクトの文脈に合わせてチューニングしないと、別の型にはまり込むことがあります。ルールは便利ですが、すべてを機械的に通せばよいわけではありません。

まとめ

impeccable は、AI の frontend design を標準化しつつ、ありがちな見た目を避けるための実践資産です。プロンプトとレビューの両方を整えたい人には、かなり使いどころがあります。
