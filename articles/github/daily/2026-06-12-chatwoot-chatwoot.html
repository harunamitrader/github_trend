これは何か

Chatwoot は open-source live-chat と email support を束ねる omnichannel desk です。README では Captain、Help center portal、Documentation が中心に並び、サポート運用の土台としての役割が分かりやすく整理されています。

何ができるか

Web チャット、メール、ヘルプセンターを一つの画面で扱い、問い合わせ対応の導線をまとめられます。Support desk としてチームで共有しやすく、顧客対応の履歴も追いやすい構成です。

目立つポイント

Captain AI Agent for Support、omnichannel support desk、help center portal が大きな柱です。単なるチャット部品ではなく、サポート組織の運用単位ごとまとめて使えるのが特徴です。

セットアップや使い方の流れ

README の Documentation と導入手順に沿って環境を立て、チャンネルとヘルプセンターを接続していきます。Docker ベースの立ち上げや本番向け構成の情報がまとまっているので、セルフホストでも導入しやすいです。

どんな人向けか

SaaS のサポート担当、CS チーム、社内ヘルプデスクを自前運用したい組織に向いています。

注意点

業務アプリとしては規模が大きく、権限設計や外部チャネル連携を先に整理しておく必要があります。運用前にデータ保存方針と通知設計を確認しておくと安定します。

まとめ

顧客対応をセルフホストでまとめたいときに、チャットとメールとヘルプセンターを一体で持てるのが強みです。
