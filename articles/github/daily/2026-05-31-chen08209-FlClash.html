これは何か

FlClash は、ClashMeta ベースのクロスプラットフォーム proxy client です。Android、Windows、macOS、Linux を横断して使えるように設計され、広告なしの軽い運用を目指しています。

何ができるか

プロキシサブスクリプションの管理、ダークモード、複数テーマ、WebDAV によるデータ同期など、日常の接続管理に必要な機能をまとめています。F-Droid と GitHub Releases の両方から導線があるのも扱いやすい点です。

目立つポイント

Material You ベースの UI と、モバイル・デスクトップをまたいだ構成が目を引きます。UI の見た目だけでなく、同期や配布の導線まで含めて実用寄りにまとまっているのが特徴です。

セットアップや使い方の流れ

README に従って submodules を更新し、Flutter と Golang の環境を用意します。Linux では追加ライブラリが必要で、Android では START / STOP / TOGGLE の intent ベース操作にも対応しています。

どんな人向けか

複数 OS で同じ proxy client を使いたい人、WebDAV で設定を同期したい人、見た目と使い勝手の両方を重視する人向けです。家庭用から個人運用まで、広く使いやすいタイプです。

注意点

ビルド時の依存関係がやや重く、各 OS ごとの準備が必要です。proxy クライアントなので、使うネットワーク環境や提供元のルールも含めて事前確認が必要になります。

まとめ

FlClash は、クロスプラットフォームで使える proxy client を、見た目と実用性の両方から詰めたリポジトリです。接続管理を日常的に扱う人には、かなり相性が良い構成です。
