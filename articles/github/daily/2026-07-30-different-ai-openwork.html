これは何か

openworkは、自律的にコーディングタスクを解決するオープンソースのローカルファーストAIエージェントです。Claude Coworkなどの商用エージェントツールのオープン代替品として開発され、強力なオートメーション環境「OpenCode」を搭載しています。

何ができるか

ファイルシステム操作、端末コマンド実行、ブラウジング、およびコードの読込・編集・検証を含む開発ワークフロー全体を自律実行できます。ユーザーの指示に基づいてコードを記述し、テストを走らせてエラーを自己修復するReActループを回します。

目立つポイント

「ローカルファースト」かつ「プロバイダー非依存（自由選択）」である点です。APIキーを設定することで、Anthropic、OpenAI、Google、またはOllamaなどを介したローカルLLMを自由に切り替えてエージェントの脳として利用できます。

セットアップや使い方の流れ

パッケージマネージャを通じてコマンドラインツール（例: `npm install -g @different-ai/openwork` または pip）を導入し、利用したいLLMのAPIキー環境変数を設定した上で、`openwork` コマンドを叩いてタスク指示を入力します。

どんな人向けか

有料の商用AIコーディングエージェントの枠制限やコストを回避したい、ソースコードのプライバシーを守るためにローカルLLMでエージェントを動かしたい、あるいはエージェントの実行コンテキストやツールを詳細に制御したいエンジニアに最適です。

注意点

自律的にコマンドを実行するため、安全なサンドボックス（Dockerコンテナや仮想マシン内など）で実行しないと、エージェントの誤操作やバグによってローカルのシステムファイルが削除・破壊されたり、不要な変更がコミットされるリスクがあります。

まとめ

different-ai/openworkは、プロバイダーを自分で選んで完全制御できる「自作AIエンジニア」を構築するための優れたオープン基盤です。ローカルAIエージェントによる開発の民主化を加速する最右翼となるでしょう。
