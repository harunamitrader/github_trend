これは何か

Hyper-Extractは、LLMを利用したインテリジェントな知識抽出・進化フレームワークです。大量の非構造化テキストドキュメントから、強固に型定義された predictable な『ナレッジ・アブストラクト（知識要約）』を抽出します。

何ができるか

PDFやMarkdownなどのテキストを入力し、単純なリストやPydanticモデルから、複雑なナレッジグラフ、ハイパーグラフ、さらには時空間（Spatio-Temporal）グラフなど、8種類の高度な知識構造に自動でマッピング・抽出します。GraphRAG、LightRAG、Hyper-RAGなどの多様な抽出エンジンを切り替え可能です。

目立つポイント

金融、法律、医療、業界標準、一般の各ドメインを網羅する80種類以上の即実行可能なYAMLテンプレートを同梱。新しく追加されたドキュメントを取り込んで知識ベースを段階的に発展させる『増分進化』をサポートしており、OpenAI等の商用APIからローカルのvLLM（Qwen3.5-9B等）によるローカル完結型RAGまで対応します。

セットアップや使い方の流れ

`uv tool install hyperextract` でインストール後、`he config init` でAPIキーを設定します。`he parse document.pdf -t general/academic_graph -o ./kb/` を実行すれば、ドキュメントから簡単に知識グラフが抽出され、`he show ./kb/` で確認できます。

どんな人向けか

論文や決算書、契約書などの大量のドキュメントから、重要なエンティティや関係性を高速かつ自動的に抽出して整理し、社内RAGシステムや独自知識データベースを構築したいリサーチャーやアナリスト向けです。

注意点

正確な構造化出力を得るために、LLM側がStructured Outputs（json_schemaやFunction Calling）に対応している必要があります。また、グラフ抽出はプロンプトの往復やコンテキスト長を多く消費するため、実行コストやローカル環境のvLLMの負荷に注意が必要です。

まとめ

多様な知識構造と最先端のGraphRAGエンジン、精度を高めるドメインテンプレートを1つのCLIに凝縮し、LLMによる高度な情報整理を驚くほどシンプルにした優れた知識抽出ツールです。
