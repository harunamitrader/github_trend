これは何か

Ghostty ベースの macOS ターミナルに、AI coding agent 向けの通知とワークスペース管理を足したアプリです。

何ができるか

縦横タブ、通知リング、内蔵ブラウザ、SSH ワークスペース、カスタムコマンド、Claude Code Teams などを使えます。

目立つポイント

Electron ではなく Swift / AppKit で作られたネイティブアプリで、GPU も使いながら AI 作業中の状態変化を見やすくしている点が特徴です。

セットアップや使い方の流れ

macOS では DMG を入れるか、`brew tap manaflow-ai/cmux` と `brew install --cask cmux` で導入します。起動後は `cmux.json` でカスタムコマンドを足し、必要なら `cmux claude-teams` でチームモードを使います。

どんな人向けか

Claude Code、Cursor、Codex、Gemini CLI などを macOS で日常的に回す人に向いています。

注意点

macOS 専用で、ターミナル UI とブラウザ管理を一体化する分だけ初期設定は少し重めです。

まとめ

AI コーディングの作業台を macOS ネイティブでまとめたい人に刺さる、かなり用途特化のターミナルです。
