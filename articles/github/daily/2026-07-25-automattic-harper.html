これは何か

harper は、WordPressの運営会社としても知られる Automattic 社によって開発されている、プライバシー第一のオフラインで動作する超高速・オープンソースの英文校正（グラマーチェッカー）エンジンです。

何ができるか

Grammarly などの従来型校正ツールは、執筆データをすべて外部クラウドサーバーに送信し処理するためプライバシー上の問題がありました。harper は Rust で実装された高性能な言語パーサーを用いて、ローカルPCのCPUのみで極めて高速かつ正確に文法エラー、スペルミス、タイポ、および文脈の矛盾などを検出・修正できます。

目立つポイント

単なるCLIツールにとどまらず、エディタ用の Language Server (harper-ls) や JavaScript ライブラリ (harper.js)、さらには Obsidian プラグインなど、多様な実行バイナリと拡張機能が統合提供されており、あらゆるテキスト入力環境に組み込み可能です。

セットアップや使い方の流れ

各種OS（Mac、Windows、Linux）向けのバイナリパッケージが GitHub Releases で配布されています。また、VS Code ユーザーであれば harper-ls を利用した拡張機能をマーケットプレイスから導入し、ファイル保存時に自動的にオフラインで英文をチェックさせる設定が可能です。

どんな人向けか

英語でドキュメント、ソースコードのコメント、コミットメッセージ、またはブログなどを執筆するエンジニアで、ソースコードや機密テキストを外部のAI学習サーバーやサードパーティのクラウドに送信されたくないセキュリティ意識の高いユーザー向けです。

注意点

現在は「英語（English）」の校正に特化して最適化されており、多言語（日本語など）の直接的な校正サポートについてはカバーされていません。

まとめ

harper は、ローカル＆オフラインの高速実行によってプライバシーと生産性を高める、現代のエンジニアと執筆者にとって最も安全なグラマーチェッカーです。
