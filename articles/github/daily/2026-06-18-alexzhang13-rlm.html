これは何か

Recursive Language Models (RLMs)は、大規模言語モデルが自身の入力をPythonコード環境を介してプログラム的に分割・走査し、自分自身を再帰的に呼び出すことで、実質的に無限のコンテキストを処理できるようにするタスク非依存の推論エンジンおよび学習環境です。

何ができるか

LLMにREPL実行環境を与え、コンテキストをコード内の変数やオブジェクトとして扱わせます。LLMはコードを実行してコンテキストの特定の範囲を抽出し、そこに対してさらにサブLM（自分自身）を再帰呼び出しして結果を集約します。これにより、従来のJSONベースのツール呼び出しや長文処理のコンテキスト制限を突破できます。

目立つポイント

MIT OASYS labによる論文（arXiv:2512.24601）に基づく信頼性の高い設計。APIベースの商用モデルからローカルモデルまで幅広く対応し、Prime Intellectの強化学習フレームワークを利用したRLMの自己学習コード（`training/`）も同梱されています。

セットアップや使い方の流れ

Python 3.11以降が必要です。`pip install rlms` でインストール後、`from rlm import RLM` をインポートし、使用するLLMのバックエンドを指定して `rlm.completion(...)` を実行するだけで、自動でREPLを介した再帰的処理が開始されます。

どんな人向けか

長大なドキュメントや大規模なコードベースをLLMで要約・検索させたい開発者や、JSONに縛られない自律型AIエージェントの新たな制御アーキテクチャを研究したいエンジニア向けです。

注意点

デフォルトの動作では、ホスト側のPython環境で `exec` による直接実行を行うため、信頼できないソースやプロンプトを処理する際はセキュリティ上のリスクがあります。本番運用ではDocker等のサンドボックスで実行することが推奨されます。

まとめ

LLMにコード実行と自己再帰を許可することで、コンテキストの壁を壊しつつより自律的な判断を行わせる、非常に先進的で興味深いアプローチの推論ライブラリです。
