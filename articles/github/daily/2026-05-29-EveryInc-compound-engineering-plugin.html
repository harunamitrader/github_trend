これは何か

Claude Code、Codex、Cursor などで使う公式の Compound Engineering plugin です。README では、計画・レビュー・学習の蓄積を回しながら、後続の作業を楽にする開発スタイルを前提にしています。

何ができるか

`/ce-brainstorm`、`/ce-plan`、`/ce-code-review`、`/ce-compound` などのコマンドで、アイデア出しからレビュー、知見の定着までをつなげられます。単発のタスク処理ではなく、次の作業を軽くするためのワークフローを作るのが中心です。

目立つポイント

37 skills と 51 agents を同梱し、戦略・ブレインストーム・計画・作業・レビュー・総括が一続きになっています。`STRATEGY.md` を軸にした durable anchor の考え方が明確で、プロジェクト全体の文脈を維持しやすいです。

セットアップや使い方の流れ

インストール後は `/ce-setup` で環境を整え、必要に応じて `/ce-strategy` から始めます。大きめの課題では `/ce-ideate` → `/ce-brainstorm` → `/ce-plan` → `/ce-work` → `/ce-code-review` の順で回すのが README の典型です。

どんな人向けか

AI エージェントを使いながらも、作業の再現性とレビュー精度を上げたい人向けです。複数の開発タスクを同じ流れで運用したいチームにも向いています。

注意点

手順が増えるぶん、雑に使うと ceremony に見えやすいです。効果を出すには、最初の戦略とレビューを省略しない前提で使う必要があります。

まとめ

Compound Engineering plugin は、AI 開発を一度きりの実行で終わらせず、次の作業を楽にするためのワークフロー化ツールです。レビューと知見の蓄積を重視する現場で価値が出ます。
