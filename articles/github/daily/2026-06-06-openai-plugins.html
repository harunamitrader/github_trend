これは何か

openai/plugins は、Codex プラグインのサンプルを集めたキュレーション型リポジトリです。単一アプリではなく、プラグインの構成例と周辺ファイルの置き方を学ぶための教材として見るのが正確です。

何ができるか

Figma、Notion、iOS/macOS/Web アプリ、Expo、Netlify、Remotion、Google Slides など、用途別のプラグイン例を横断できます。`.codex-plugin/plugin.json` を中心に、skills や commands、hooks などの周辺サーフェスの組み合わせも確認できます。

目立つポイント

各プラグインが `plugins//` 配下にまとまっていて、どの例も manifest を起点に読み解けます。README で highlighted examples が整理されているので、構成差分を比較しながら自分の用途に近い雛形を選びやすいです。

セットアップや使い方の流れ

まず `plugins//` を開いて `plugin.json` と companion ファイルを確認し、必要な surface だけを取り込みます。実運用では、ひとつの例をそのまま使うより、manifest の書き方とファイル配置を自分の Codex plugin に移植する流れが自然です。

どんな人向けか

Codex プラグインを新規に作る人、既存の例から構成を学びたい人、スキルや MCP を含む周辺設計を比較したい人に向いています。

注意点

これは完成アプリではなく例の集合なので、各サンプルの前提や依存関係はばらばらです。README をそのまま自動化の手順書として読むより、構造の辞書として使う方が失敗しにくいです。

まとめ

Codex プラグインの雛形と周辺ファイルの組み方を、実例ベースで確認するための参照庫です。
