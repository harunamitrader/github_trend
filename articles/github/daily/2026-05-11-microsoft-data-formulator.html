これは何か

Data Formulator は、Microsoft Research が開発した、大規模言語モデル（LLM）と従来のビジュアル分析 UI を高度に融合させたデータ探索・可視化ツールです。単なるチャット形式の AI アシスタントではなく、ユーザーの直感的な UI 操作と自然言語による意図を組み合わせることで、複雑なデータの形成（Data Wrangling）と可視化を同時に、かつ正確に行うことができます。

何ができるか

CSV や Excel データの読み込みはもちろん、スクリーンショットや生テキストからデータを抽出して分析対象にすることも可能です。ユーザーが「どのデータをどの軸に割り当てるか」を UI で示すと、AI がその背後で必要なデータ加工（集計やピボットなど）を自動で行い、即座にグラフ（Vega-Lite ベース）を生成します。また、探索の履歴をツリー形式で管理し、異なる分析ルートを簡単に行き来できる機能も備えています。

目立つポイント

最大の特徴は、「ブレンディッド・インタラクション（Blended Interaction）」という独自の操作モデルです。完全に AI 任せにするのではなく、ユーザーが UI で大枠の意図（軸の指定など）を示し、AI が詳細な実装（データ変換コードの生成）を担うことで、従来のチャット型 AI では難しかった「正確なコントロール」と「高度な自動化」を両立させています。これにより、Python や SQL を書かずに、プロフェッショナルレベルのデータ分析が可能になります。

セットアップや使い方の流れ

Python 環境（3.9以上）にて、uvx data-formulator（推奨）または pip install data-formulator でインストールできます。OpenAI や Azure、Anthropic、Ollama などの API キーを設定して起動すると、ブラウザ上で直感的な分析画面が開きます。データのロード、ドラッグ＆ドロップによる軸の指定、自然言語による補足、というスムーズなフローで可視化を構築できます。

どんな人向けか

データの準備や加工に時間を取られているデータアナリスト、コードを書かずに高度な可視化を行いたいビジネスユーザー、そして AI と人間の新しい協調インターフェースに関心のある研究者に最適です。Microsoft Research の成果ということもあり、非常に実戦的で洗練されたツールとなっています。

注意点

現在は v0.7 のアルファ版であり、研究プロトタイプとしての性質を持っています。そのため、本番環境での利用には注意が必要であり、AI が生成したコードの安全性（サンドボックス実行など）を考慮した運用が推奨されます。また、LLM の API コストが発生する点にも留意してください。

まとめ

Data Formulator は、AI を「外部の相談相手」ではなく「システムの中核」に据えることで、データ分析のワークフローを根本から変えようとする野心的なプロジェクトです。データの準備という最も泥臭いプロセスを AI が肩代わりしてくれるこの体験は、データ活用の未来を予感させてくれます。
