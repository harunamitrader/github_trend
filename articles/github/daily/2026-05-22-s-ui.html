これは何か

SagerNetおよびSing-Boxプロキシサーバーを管理するための高度なWebパネルインターフェースです。

何ができるか

ブラウザからGUIベースでプロキシノードの追加・削除・ルーティングルールの設定、トラフィックのモニタリングなどが直感的に行えます。

目立つポイント

  • 直感的なUI: 複雑なJSON設定を意識することなく操作可能。
  • Sing-Box対応: 最新の強力なプロキシコアであるSing-Boxをネイティブサポート。
  • リアルタイム監視: トラフィック状況や接続クライアント数を可視化。

セットアップや使い方の流れ

インストールスクリプト（bashコマンド）を実行するだけで、必要なパッケージやDockerコンテナが自動的にセットアップされます。その後、ブラウザで指定ポートにアクセスして初期設定を行います。

どんな人向けか

VPSなどでSagerNetやSing-Boxベースのプロキシサーバーを構築・運用しており、ターミナルでの設定ファイル編集から解放されたいサーバー管理者。

注意点

プロキシサーバーの運用にはセキュリティ（ポート開放やパスワード設定）に十分注意する必要があります。

まとめ

s-uiは、Sing-Boxという強力だが設定が複雑なコアを、誰でも簡単に扱えるようにする画期的なWeb管理パネルです。
