これは何か

flue は、Astro フレームワークの開発チームが公開した、ヘッドレスでプログラム可能な 「サンドボックス・エージェント・フレームワーク」 です。AI エージェントが安全にコードを実行したり、外部ツールを操作したりするための隔離環境（サンドボックス）を抽象化し、信頼性の高い自律型システムの構築を可能にします。

何ができるか

ローカル、仮想（just-bash）、リモート（Docker/Daytona）といった多様な実行環境を使い分け、エージェントにタスクを実行させることができます。具体的には、GitHub Issue の自動仕分け（Triage）、ドキュメントベースのカスタマーサポート、複雑なバグ修正エージェントなどの開発が可能です。また、MCP (Model Context Protocol) を標準サポートしており、既存の MCP ツール群を即座にエージェントのスキルとして統合できます。

目立つポイント

最大の特徴は、エージェントの「Role（役割）」や「Skill（スキル）」、文脈となる「Context」を Markdown ファイルで定義できる 点です。これにより、開発者は使い慣れたテキスト形式でエージェントの振る舞いを記述・管理できます。また、Cloudflare エコシステム（R2 や Durable Objects）との統合が深く、エッジ環境での状態管理やファイル保存を効率的に行える設計になっています。

セットアップや使い方の流れ

プロジェクト内に .flue/agents/ などのディレクトリを作成し、エージェントの定義ファイルを配置します。flue dev でローカル開発、flue run でタスク実行が可能です。また、提供されている SDK (@flue/sdk/client) を使用することで、Node.js アプリケーションの中から直接エージェントを呼び出し、対話やタスク実行を制御できます。

どんな人向けか

AI を活用した高度な自動化パイプラインを構築したいエンジニアや、自社プロダクトに特化した独自のコーディングアシスタントを開発したいチーム、そして Cloudflare Workers などのサーバーレス環境でエージェントを動かしたい開発者に最適です。

注意点

現在は「Experimental（実験的）」なフェーズにあり、API の破壊的変更が含まれる可能性があります。ドキュメントも整備の途上であるため、詳細な実装にはリポジトリ内の examples/ フォルダを参照しながら進める必要があります。

まとめ

flue は、Astro チームの「開発体験（DX）」に対する深い知見を、AI エージェントの世界へと持ち込んだ意欲的なプロジェクトです。サンドボックスの隔離性とプログラムによる制御を高い次元で両立しており、次世代のエージェント駆動型アプリケーションの基盤として大きな可能性を秘めています。
