これは何か

Stitch Skills は、Google Labsが公開したオープンソースの「Agent Skills」ライブラリです。AIコーディングエージェント（Claude Code、Cursor、Gemini CLIなど）が、Stitch MCPサーバーと連携して設計意図を解釈し、高品質なコードへと自動変換するためのスキルを提供します。

何ができるか

UIデザインの生成・編集、プロジェクトを解析してインフラコードやReactコンポーネントを組み立てる機能、デザインシステムの「情報源」となる DESIGN.md の自動抽出、曖昧な指示を詳細なプロンプトへ変換する機能など、多様なエージェントスキルを実行できます。

目立つポイント

すべてのスキルが「Agent Skills」というオープン規格に準拠してポータブルに設計されており、異なるAIアシスタントでも同じ体験で動作します。GoogleのLLMやインフラと連動した、自律的かつ連続的なビルドループ（Autonomy Loop）を実現可能です。

セットアップや使い方の流れ

対応するAIエージェントのプラグイン管理コマンドを使って追加します。例えば、Claude Codeでは npx plugins add google-labs-code/stitch-skills を実行することで、デザイン連携やプロンプト最適化などの高度なスキルを自律実行させることが可能になります。

どんな人向けか

AIエージェントを駆使して高速にプロトタイピングを行いたい開発者、Figmaやデザイン定義を自動的にフロントエンドコードへ反映させたいUI/UXエンジニア、またはエージェント向けのシステム構築に関心のあるアーキテクトに向いています。

注意点

Stitch Skillsが提供する高度なデザイン変換機能は、プロジェクト内のデザインシステム（スタイル定義）が明文化されていない場合、出力品質が低下することがあります。あらかじめ DESIGN.md などを整備し、エージェントにコンテキストを与えることが大切です。

まとめ

Stitch Skills は、AIエージェントによるコード生成をデザインレベルから一貫して制御するための画期的なスキル集です。手作業でのマークアップやデザイン調整をAIへスムーズに委託できるため、エージェント開発ワークフローを大きく加速させます。
