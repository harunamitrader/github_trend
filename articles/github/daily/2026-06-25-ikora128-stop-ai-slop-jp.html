これは何か

stop-ai-slop-jp は、AI が下書きした日本語文章から「AI臭」や AI Slop を減らすための Claude Skill です。英語版 hardikpandya/stop-slop の発想を踏まえつつ、日本語で起きやすい大げさな見出し、一般論への飛躍、均一すぎる文体などに焦点を当てています。

何ができるか

Claude Code に入れるか、Claude Projects や API のシステム指示へ組み込むことで、日本語テキストの公開前レビューや書き換えに使えます。命題型 H2、false agency、「AではなくBだ」の反復、全段落が同じ温度で着地する構成、装飾記号の残骸などをまとめて検査し、どこが AI っぽいのかを指摘できます。

目立つポイント

特徴は、単なる禁止語句集ではなく「立場」「リズム」「主体性」「具体性」「削減」の 5 軸で採点するところです。加えて、references/phrases.md、references/structures.md、examples.md が付属し、臭い語彙だけでなく構造上の癖や修正前後の差まで見られるため、レビュー観点をそのまま再利用しやすくなっています。

セットアップや使い方の流れ

導入は簡単で、Claude Code なら ~/.claude/skills/ へ clone するだけです。プロジェクト単位で入れる方法や、Claude Projects に SKILL.md と references/ を載せる使い方、API のシステムプロンプトへ組み込む使い方も README にまとまっています。実運用では「まずレビューだけ」「必要なら書き換え」「公開前チェックだけ」と段階的に使い分けられます。

どんな人向けか

ブログ、技術文書、メール、note などを LLM で下書きしている人に向いています。特に、速く書きたいが AI が書いたとすぐ分かる平坦な文にはしたくない人、自分の主張や主体性を文章に残したい人には実用的です。

注意点

README でも明記されているとおり、この Skill は「書き手の不在」そのものまでは直せません。表現や構造の修正はできても、独自の体験や主張が元原稿に入っていなければ限界があるため、入力側の具体性は別途必要です。

まとめ

stop-ai-slop-jp は、日本語で AI 執筆を使うときのレビュー基準を具体的な Skill と参照ファイルに落とし込んだ実用品です。Claude Code 周辺で文章の自然さを底上げしたい人にとって、軽量で導入しやすい品質ゲートとして機能します。
