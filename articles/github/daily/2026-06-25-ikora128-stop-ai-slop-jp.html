これは何か

stop-ai-slop-jp は、AIコーディングCLIツールである Claude Code などの環境において、生成された日本語文章からAI特有の不自然な表現や「AI臭」を取り除くための Claude Skill（カスタムコマンドおよびシステム指示集）です。英語圏の hardikpandya/stop-slop に着想を得て、日本語の文章特有のAIのクセ（過剰な装飾や定型表現、単調な文章構造など）をレビュー・修正できるように最適化されています。

何ができるか

本 Skill を Claude Code にインストールするか、Claude Projects などのシステム指示に組み込むことで、AIで下書きした日本語テキストの「公開前レビュー」や「AI臭を排除した書き換え」を自動で実行させることができます。具体的には、大げさな見出し（命題型H2）の検知、体験を「真理」や「美学」へ急激に一般化するパターン、単調な「AではなくBだ」という構文の多用、絵文字や不要な括弧の残骸などの記号レベルのノイズから、文章構造自体の平坦さまで多角的にチェックします。

目立つポイント

単なる表記揺れやNGワードの修正ではなく、「立場（主張）」「リズム」「主体性」「具体性」「削減」の5軸で文章を評価する点が特徴的です。「誰が何をしたか」が曖昧な文章（false agency）を検出したり、あえて文章の熱量や長さに「ムラ」を持たせることで、機械的で均一な文章（AI Slop）から人間らしい躍動感のあるテキストへと修正します。避けるべき語彙をまとめた references/phrases.md や、避けるべき構成パターンを網羅した references/structures.md が付属しており、修正の対比（Before/After）も分かりやすくまとめられています。

セットアップや使い方の流れ

Claude Code を個人利用している場合、以下のコマンドで ~/.claude/skills/ 配下に直接リポジトリを clone するだけでインストールできます：
git clone https://github.com/iKora128/stop-ai-slop-jp ~/.claude/skills/stop-ai-slop-jp

インストール後は、Claude に「この文章を stop-ai-slop-jp の基準でレビューして」または「この文章のAI臭を落として」と指示するだけで機能します。API 経由で使う場合は SKILL.md の内容をシステムプロンプトに含めて使用します。

どんな人向けか

LLM を使用してブログ記事、技術ドキュメント、メール、note などのコンテンツを作成しているライターや開発者に最適です。AIでの執筆作業をスピードアップさせつつも、「AIが書いたと一目でわかるような陳腐な文章にしたくない」「自分の言葉や主体性をしっかりと残したい」と考えるすべてのコンテンツ作成者に向いています。

注意点

本 Skill はあくまで表現の修正や構造チェックを行うためのアシスタントであり、文章の根本にある「書き手の不在（独自の体験や主張がないこと）」自体は解決できません。AI臭を真に取り除くためには、ベースとなるインプットに自分自身の体験や独自の観点を豊富に盛り込んでおく必要があります。

まとめ

stop-ai-slop-jp は、AIによる執筆の利便性を享受しながらも、コンテンツの質を落とさないための頼もしいゲートキーパー（検閲官）です。Claude Code などのエージェント開発環境において、ドキュメントの自然さをワンランク引き上げたいときに欠かせない実用的かつスマートなツールと言えます。
