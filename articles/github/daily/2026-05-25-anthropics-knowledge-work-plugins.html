これは何か

Claude Cowork と Claude Code に役割別の仕事の進め方を配るための plugin コレクションです。

何ができるか

プラグインごとに skills、connectors、slash commands、sub-agents を束ねて、営業、法務、財務、データ分析、採用などの作業導線をまとめられます。

目立つポイント

11 個のプラグインを公開しており、単なるサンプルではなく、実際の業務フローを Claude に寄せるための雛形として使える点が強みです。

セットアップや使い方の流れ

まず `claude plugin marketplace add anthropics/knowledge-work-plugins` で marketplace を追加し、必要なプラグインを `claude plugin install sales@knowledge-work-plugins` のように入れます。導入後は `.mcp.json`、skills、commands を自社のツールや用語に合わせて調整します。

どんな人向けか

Claude Cowork や Claude Code を、個人の補助ではなくチームの作業標準として使いたい組織に向いています。

注意点

connectors は自社の Slack、Notion、Jira などに合わせて差し替える前提です。最初から全部を入れるより、1 つの職種から試す方が運用しやすいです。

まとめ

Claude を役割別に調整するための実用的な土台で、会社の業務フローをそのまま agent に寄せたいときに強いです。
