これは何か

ag-kit（Antigravity Kit）は、CursorやWindsurf、VS Code ExtensionなどのAI支援エディタ環境において、開発効率を劇的に向上させるために設計されたオープンソースのツールキットです。プロジェクト内で定型化されたタスクや複雑なマルチステップのコーディング指示を、「エージェント・スキル」として定義し、再利用可能な自律ワークフローとして実行できる仕組みを提供します。

何ができるか

開発者は、独自のカスタムAIアシスタントを構成したり、特定のライブラリや規約に準拠したボイラープレートの自動生成、ソースコードの品質検証、エラー診断といったワークフローを構築できます。エディタのチャットインターフェースでスラッシュコマンドを入力することで、これらの自律フローを瞬時にトリガーすることが可能です。

目立つポイント

エディタの枠を超えて、プロジェクトディレクトリ内の `.ai/` フォルダ下に yaml または markdown 形式でエージェントやワークフローの振る舞いを完全にコード化（Config as Code）して管理できる点です。これにより、チームメンバー間で全く同じAIアシスタント設定をGit経由で共有可能になります。

セットアップや使い方の流れ

npmを通じてグローバルにインストールします（`npm install -g @vudovn/ag-kit`）。その後、開発プロジェクトのルートディレクトリで `ag-kit init` を実行すると、設定ファイル群が初期化され、必要とするエージェントプロファイルや追加スキルのファイルを生成・編集してカスタマイズを開始できます。

どんな人向けか

CursorやWindsurfといったAIエディタを日常的に使いこなしており、AIへの指示や指示フロー（プロンプト等）をプロジェクト専用に体系化して自動化したい、またはその設定をチーム内で共有したいフロントエンド・バックエンドエンジニアに最適です。

注意点

本ツールキットはAIエディタの背後で動作し補助するものですが、最終的なコードの正確性を担保するためには開発者（人間）のレビュー（Human-in-the-loop）が前提となっています。全自動で予期せぬ破壊的変更が行われないよう、実行時のプロンプト確認設定などに注意を払う必要があります。

まとめ

ag-kitは、AIエディタ時代における「プロンプトエンジニアリングと自律ワークフローのコード管理」を実現する先進的なキットです。AIへの指示をチームの共同資産に変えることで、コーディングの標準化と高速化に貢献します。
