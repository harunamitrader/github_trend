これは何か

Kilo Codeは、VS Code、JetBrains、そしてCLIなど、あらゆる作業環境に統合可能なオープンソースの自律型AIコーディングエージェントです。ユーザー自身の開発フローのスピードと精度をAIの自律的な編集・検証機能で最大化します。

何ができるか

ユーザーの曖昧な指示プロンプトからリサーチ、ファイル操作、ターミナルコマンド実行をエージェントが自律的に繰り返し行い、コードを構築してテストします。VS CodeやJetBrainsの拡張機能としてUI上で対話的に使えるほか、CLIで `kilo` を実行してターミナルから直接開発を開始することも可能です。

目立つポイント

オープンな価格体系と500以上のLLMモデルへの対応。GPT-5.5、Claude Opus 4.7、Claude Sonnet 4.6、Gemini 3.1 Proなど、好みのモデルをタスク中に切り替えて利用でき、モデルプロバイダーの原価レートでmarkupなしで支払いが可能です。Web上のクラウド環境（app.kilo.ai/cloud）から直接試すこともできます。

セットアップや使い方の流れ

VS Codeの場合は拡張機能マーケットプレイスから『Kilo Code』をインストールするか、CLIから `npm install -g @kilocode/cli` や `brew install Kilo-Org/tap/kilo` でCLI版をインストールし、プロジェクトディレクトリで `kilo` を起動するだけで即座に使えます。

どんな人向けか

普段使いのIDE（VS CodeやJetBrains等）やCLIの環境をそのまま維持しつつ、自律型のAIコーディングアシスタントを活用してコードの記述、リファクタリング、テスト自動化を高速化したい開発者向けです。

注意点

エージェントがターミナルで実行するコマンドや編集ファイルの許可プロンプトを適切に承認・監視する必要があります。また、使用するモデルに応じたAPIトークンの料金体系やプロバイダーの接続設定を確認する必要があります。

まとめ

優れた拡張性、豊富なモデル対応、そして透過的なプロバイダー原価での課金システムを武器に、AI開発を身近にするオープンソースコーディングエージェントプラットフォームの注目株です。
