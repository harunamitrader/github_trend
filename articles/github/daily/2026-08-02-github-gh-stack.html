gh-stack

GitHub公式による、Stacked PRs（連鎖的プルリクエスト）の管理と同期を自動化するGitHub CLI拡張機能

これは何か

GitHub公式が提供する、Stacked PRs（連鎖的・多層的なプルリクエスト）を効率的に管理するためのGitHub CLI（gh）用の拡張機能ツール。

何ができるか

巨大な開発ブランチを「相互に依存する複数の小さなコミット・PR」へ階層的に分割（スタック化）し、ローカルブランチの自動作成、追従リベース、依存PRの自動ベースブランチ設定、および一括PushとPR提出（gh stack submit）を行います。

目立つポイント

CLIからの直感的な操作（init, add, push, view, submit）による自動化。さらに、AIエージェントに stacked PRs の概念とCLIコマンドを解釈・実行させるための連携拡張モジュール「gh skill install github/gh-stack」を内包している点。

セットアップや使い方の流れ

GitHub CLI（v2.0以上）が導入されている環境で、ターミナルから「gh extension install github/gh-stack」を実行してインストールします。「gh stack init」でスタック化を初期化し、その後「gh stack add [branch]」でブランチを積み重ねていきます。

どんな人向けか

大規模な機能開発やコードリファクタリングをレビューしやすい小さなPRに小分けにして提出したい開発者、またはCursorやClaude Code等のAIコーディングエージェントに連鎖的PRの積み上げ作業を自律実行させたい開発者。

注意点

スタック（ブランチ順序の依存関係）データはローカルの「.git/gh-stack」に非コミットJSONファイルとして保存されるため、別PCやチーム間でローカルのスタック構造自体をGit経由で共有することはできません。

まとめ

多層的な差分管理というGit手動運用で最も破綻しやすい作業を完全に自動化し、AIエージェントとの親和性も高い、モダンな開発フローを支える必携のCLIツールです。
