これは何か

MemPalace は、会話履歴やプロジェクト文脈を逐語で保存し、ローカルの意味検索で再利用するための AI メモリ基盤です。要約や抽出に寄せず、元のテキストをそのまま残す方針がはっきりしています。

何ができるか

プロジェクトファイルや Claude Code のセッションを `mempalace mine` で取り込み、`mempalace search` で必要な断片を引けます。さらに `mempalace wake-up` で次のセッションに文脈を戻し、MCP サーバーやエージェント連携にもつなげられます。

目立つポイント

デフォルトは ChromaDB を使うプラガブルな検索層で、People / Projects / Topics を wings, rooms, drawers に整理する構造が特徴です。ベンチマークも公開されており、Raw の R@5 96.6% など再現手順まで README にまとまっています。

セットアップや使い方の流れ

まず `uv tool install mempalace` か `pipx install mempalace` で CLI を分離インストールし、`mempalace init` で palace を作ります。あとは `mempalace mine ` で記録対象を取り込み、`mempalace search` と `mempalace wake-up` を日常の流れに組み込みます。

どんな人向けか

長い作業セッションの文脈をローカルで保持したい人、Claude Code や MCP を使う人、クラウド送信を避けつつ検索性を上げたい人に向いています。

注意点

Python 3.9+ とローカルのベクトルストア、埋め込みモデルの容量が必要で、グローバル環境に雑に入れると依存関係で詰まりやすいです。README でも公式サイトと PyPI のみを正規ソースと明示しているので、導入先は必ず公式導線で確認した方が安全です。

まとめ

ローカルに閉じたまま、会話とプロジェクトの文脈をそのまま再利用できる AI メモリ層として使うのが本筋です。
