これは何か

自身で所有するレトロゲームの ROM ファイルやディスクイメージをセルフホスト環境で一元管理し、Webブラウザ上で直接プレイできる、美しく高機能なゲームライブラリマネージャーです。

何ができるか

手元のゲームコレクションをスキャンし、IGDBやScreenscraper、MobyGamesなどの外部データベースからカバーアート、発売日、概要などのメタデータを自動取得してライブラリを豊かに構築します。さらに、ブラウザ統合エミュレータ（EmulatorJS）や Flash プレイヤー（Ruffle）を搭載しており、ブラウザからワンクリックで即座にゲームを遊ぶことができます。

目立つポイント

400以上のゲームプラットフォームに対応し、マルチディスクゲーム、DLC、ゲームハック（パッチ）、攻略マニュアルなどを一元的に管理できる点が強みです。また、詳細なユーザー管理権限機能を持ち、ライブラリの一部のみを家族や友人と共有することもできます。Retroachievements APIを介してゲームの実績を表示する機能もサポートされています。

セットアップや使い方の流れ

Docker または Docker Compose を使用して、自身のサーバーやローカルPC上にコンテナとしてデプロイします。WebUIにアクセスし、ライブラリフォルダを指定してスキャンを開始するだけで自動的にゲーム情報の収集が行われます。Playnite（デスクトップアプリ）や Android ランチャー向けの公式連携プラグインも用意されています。

どんな人向けか

レトロゲームのバックアップROMコレクションを大量に所有しており、整理された美しいビジュアルのライブラリを作成して、デバイスを問わず（PC、スマートフォン、タブレットなど）ブラウザ経由で遊びたいゲームコレクターに適しています。

注意点

本ソフトウェアにはゲームの ROM ファイルや BIOS イメージは同梱されていません。著作権に基づき、ユーザー自身で適切にバックアップを取得したデータを用意する必要があります。

まとめ

優れたメタデータ自動取得性能とブラウザ上でのシームレスなプレイ環境を両立し、セルフホストによるレトロゲーム管理の決定版とも言える完成度を誇るメディア管理プラットフォームです。
