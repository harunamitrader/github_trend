これは何か

pi-subagents は、Pi から子エージェントへ作業を委譲しやすくする拡張です。レビュー、調査、実装、並列確認のような役割を切り分けて回す前提で作られています。

何ができるか

コードレビューやスカウト、実装、並列監査、背景ジョブの振り分けを、短い指示で別エージェントに渡せます。大きいタスクを小さく分解して、戻り値をまとめやすくする使い方に向いています。

目立つポイント

truncate、artifacts、session sharing を組み合わせて、子エージェントとのやり取りを扱いやすくしているのが特徴です。`pi install npm:pi-subagents` で導入でき、レビュー担当や scout などの役割例もREADMEで示されています。

セットアップや使い方の流れ

まず Pi に拡張を入れ、次に仕事の役割を明示して委譲します。並列で動かしたい確認作業や、結果を切り分けたい実装タスクから試すと、効果が見えやすいです。

どんな人向けか

Pi を使っていて、1つの指示を複数の視点に分けて処理したい人向けです。レビュー品質を上げたい人、調査と実装を分けたい人、並列で安全確認したい人に向いています。

注意点

子エージェントを増やせば自動的に良くなるわけではなく、役割定義が曖昧だとむしろ混乱します。結果の統合と最終レビューは、利用側で明示的に設計しておく必要があります。

まとめ

pi-subagents は、Pi ベースの作業を分担型に寄せたいときに効く拡張です。複雑な仕事を並列化しつつ、後でまとめ直すワークフローを作りたい人に向いています。
