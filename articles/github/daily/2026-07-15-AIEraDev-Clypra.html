これは何か

「Clypra」は、Tauri v2、React 19、およびRustを使用して開発されている、オープンソースのマルチプラットフォーム（デスクトップ・モバイル対応）動画編集アプリケーションです。商用の高機能な動画編集ソフト（CapCutなど）で有償提供されているような各種高度な機能（自動テロップ生成、AIスマートカット、エフェクト適用など）を、完全無料で永久に使い続けられる環境を提供することを目指しています。

何ができるか

現在開発が進められている主要な機能は以下の通りです。

  • マルチトラック・ノンリニア編集: タイムライン上に複数の動画、音声、テキストトラックを配置し、プレビューを確認しながら直感的にトリミング、カット、移動が可能です。
  • ハードウェアアクセラレーションとRust処理系: Rustで記述された高性能バックエンドエンジンとFFmpegのハードウェアデコード/エンコード連携を活用し、4K解像度の映像処理もCPU/GPUリソースを効率的に使用して高速処理します。
  • ローカルAIによる支援機能: 音声のテキスト文字起こし（自動字幕/テロップ付け）や、無音区間の自動カットなどをローカル環境で（クラウド送信なしに）動作する軽量AIエンジンで実行可能です。

目立つポイント

Tauri v2を採用したハイブリッド構成を取っている点です。UI層はReact 19とTailwind CSSによる美しく滑らかでインタラクティブなモダンWebスタックで構築され、重いエンコード処理やファイルIO、システムリソース制御はRustが直接ハンドルします。これにより、クライアント全体のインストールフットプリントが非常に小さく、起動も高速です。

セットアップや使い方の流れ

各プラットフォーム向けにプリビルドされたインストーラーがリリース予定ですが、ローカルでソースコードからビルドする場合は、RustツールチェーンとNode.js、およびFFmpegライブラリが必要です。

# 依存パッケージのインストールと起動
git clone https://github.com/AIEraDev/Clypra.git
cd Clypra
npm install

# 開発サーバーおよびTauriデスクトップの起動
npm run tauri dev

どんな人向けか

手軽に短尺動画やYouTube、TikTok向けの動画制作を行いたいクリエイターや、サブスクリプション型の有償動画編集ソフトに代わる軽量なツールを求めているユーザーに適しています。また、Tauri v2とRustを用いた大規模デスクトップアプリケーションの実装パターンを学びたい開発者にとっても非常に参考になる構成です。

注意点

プロジェクトはアクティブに開発中であり、一部の高度なエフェクトやトランジション、複雑なマルチカメラ編集機能は現在順次実装されている段階です。プロダクションレベルでの大規模かつ緊急の編集作業に投入する際は、定期的なプロジェクト保存を行うなど、ベータ段階のツールとしての配慮が必要です。

まとめ

「Clypra」は、Tauri v2＋Rust＋React 19という最先端の技術スタックを融合させ、ユーザーファーストかつ完全無料で高度なクリエイティブ作業を実現しようとする野心的な動画エディタです。AIアシストによる省力化とハードウェアに寄り添うハイパフォーマンスを兼ね備え、今後の進化が非常に期待されるオープンソースプロダクトです。
