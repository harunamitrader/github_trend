これは何か

Neural Networks: Zero to Hero は、神経ネットワークを基礎から段階的に学ぶための講義ノートと Jupyter Notebook をまとめた学習用リポジトリです。YouTube 講義と連動しており、micrograd、makemore、GPT、Tokenizer まで順番に進める構成になっています。

何ができるか

動画を見ながら手を動かし、各レクチャーの Notebook で backprop、language modeling、activation、BatchNorm、tokenization までを実装ベースで追えます。単なる資料集ではなく、学習の順番が明確なので、最初の一歩から Transformer の入口まで一気通貫で進めやすいです。

目立つポイント

micrograd から始まり、makemore の各段階、GPT の自作、Tokenizer の理解までが一直線につながっている点が強みです。講義映像と Notebook、演習問題がセットになっているため、座学と実装を同時に進めやすくなっています。

セットアップや使い方の流れ

README では YouTube 講義を見ながら、対応する Notebook を Jupyter や Colab で開いて進める流れが想定されています。まずは Lecture 1 の micrograd から入り、ノートブックを自分の環境で実行しながら、必要に応じて演習を解くのが素直です。

どんな人向けか

Python と高校レベルの微積分を少し触ったことがある学習者、ML の仕組みを実装で理解したい人、LLM の土台を体系的に学びたい人に向いています。

注意点

これは学習教材であって、即戦力の推論基盤やライブラリ集ではありません。内容は順番に積み上げる前提なので、飛ばし読みよりも手を動かす時間を確保した方が価値を取りやすいです。

まとめ

Karpathy の Neural Networks: Zero to Hero は、基礎から GPT までを Notebook で追える学習リポジトリです。動画と実装が揃っていて、LLM の土台を順番に理解したい人に向いています。
