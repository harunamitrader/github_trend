これは何か

OpenReel Video は、CapCut の代替を目指して開発されている、完全クライアントサイド（ブラウザ上）で動作するオープンソースのビデオ編集ツールです。WebGPU や WebCodecs といった最新のウェブ標準技術を駆使しており、インストール不要かつ 100% ローカル環境での編集を可能にしています。

何ができるか

マルチトラックのタイムライン編集（ビデオ、オーディオ、画像、テキストを無制限に追加可能）、トリミング、分割、リップル削除などの精密なカット編集、キーフレームによるアニメーション設定、そして GPU 加速によるスムーズなリアルタイムプレビューと 4K 解像度での書き出しが可能です。

目立つポイント

最大の特徴は「100% ブラウザ完結」である点です。ファイルはデバイス外に送信されず、透かし（ウォーターマーク）もありません。また、ブレンドモード、速度制御（ピッチ維持）、カラーグレーディング（LUT 対応）、クロマキー合成など、プロ仕様のエフェクトやツールも備えています。

セットアップや使い方の流れ

セットアップは非常に簡単で、GitHub Pages 等で公開されている URL にブラウザでアクセスするだけですぐに利用できます。開発者はリポジトリをクローンしてローカルの node 環境でビルドすることで、自分専用の編集環境を構築することも可能です。

どんな人向けか

プライバシーを重視する動画クリエイター、インストール制限のある環境で動画編集を行いたいユーザー、WebGPU を活用した次世代の Web アプリケーション開発に関心のあるエンジニアに最適です。

注意点

現在はアクティブに開発中のプロジェクトであるため、複雑なプロジェクトではパフォーマンスや安定性に制限が出る可能性があります。重要なプロジェクトではこまめなバックアップが推奨されます。

まとめ

WebGPU の力を引き出し、ブラウザを本格的な動画編集スタジオに変える意欲的なプロジェクトです。プライバシーと使い勝手を両立させた CapCut の有力なオープンソース対抗馬と言えるでしょう。
