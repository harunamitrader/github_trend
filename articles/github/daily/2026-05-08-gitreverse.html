GitHub Watcher

gitreverse

GitHubリポジトリを「AIへの開発指示プロンプト」に逆変換。既存プロジェクトの設計をCursorやClaude Codeで再利用可能にするツール。

これは何か

公開されているGitHubリポジトリを解析し、そのプロジェクトをゼロから再現するために必要な「単一のユーザープロンプト」を生成するリバースエンジニアリングツールです。CursorやClaude CodeなどのAIエディタにそのまま貼り付けられるような、文脈を捉えた会話形式のプロンプトを抽出します。

何ができるか

リポジトリのURLを入力するだけで、メタデータ、ファイルツリー、READMEなどを解析し、そのプロジェクトの本質（何を作るのか、技術スタックは何か、主要な機能は何か）を凝縮した1つの合成プロンプトを出力します。生成されたプロンプトは共有可能なリンクとしても保存できます。

目立つポイント

1. プロンプトへの変換: 複雑なコードベースを、人間がAIに依頼する際の「最初の指示」へと逆変換。 2. マルチLLM対応: Grok 3, Gemini 2.5 Pro, GPT-4.1など、最新のLLMを活用した高速な解析。 3. 共有とキャッシュ: 解析結果をキャッシュし、他のユーザーが生成したプロンプトのライブラリを閲覧することも可能です。

セットアップや使い方の流れ

公開されているWebサイトでリポジトリのURLを入力するか、セルフホストする場合はリポジトリをクローンし、環境変数にLLMのAPIキー（OpenAI, Google等）を設定してNext.jsアプリとして起動します。

どんな人向けか

他のプロジェクトの優れた設計思想を自分のコードに取り入れたい開発者、既存のアプリをベースに新しいツールを「Vibe Coding（AIとの対話による開発）」で迅速に作り上げたいエンジニアに適しています。

注意点

現時点ではリポジトリ全体の文脈を使用して1つのプロンプトを生成します。特定のサブフォルダやファイルに絞った詳細な解析については、今後のアップデートでの対応が予定されています。

まとめ

優れたコードベースを「AIへのプロンプト」という形で再利用可能にする、AI時代の新しいソースコード活用ツールです。
