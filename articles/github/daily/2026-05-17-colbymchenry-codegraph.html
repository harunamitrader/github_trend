これは何か

CodeGraph は、Claude Code、Codex、Cursor、OpenCode などの AI コーディングエージェント向けに、コードベースを事前解析してローカルの知識グラフへ落とし込む CLI です。関数、クラス、呼び出し関係、ルート定義までを SQLite ベースのインデックスとして保持し、エージェントが毎回ファイル探索から始めなくても全体像をつかめるようにします。

何ができるか

エージェントは `grep` や全文読みに何度も頼らず、シンボル検索、call graph、影響範囲、関連コードの即時取得を行えます。README のベンチマークでは、7 つの実コードベースで中央値比較した結果として平均 35% 安価、59% 少ないトークン、49% 高速、70% 少ないツールコールをうたっており、特に大規模リポジトリほど効果が出やすい設計です。

目立つポイント

100% ローカル動作で、外部サービスや API キーを前提にしない点がまず大きい特徴です。さらに、自己完結したランタイム付きインストーラで Node.js なしでも導入でき、Claude Code、Cursor、Codex CLI、opencode、Hermes Agent の設定まで自動化します。対応言語は 19 以上あり、直近のリリースでは Hermes Agent 対応と Drupal のルート・フック解析が追加され、Web フレームワークの経路把握も強化されています。

セットアップや使い方の流れ

導入は `npx @colbymchenry/codegraph`、または OS 別のインストールスクリプトから始めます。セットアップ後に対象プロジェクトで `codegraph init -i` を実行すると `.codegraph` 配下にインデックスが生成され、以後はエージェント再起動後に MCP ツールとして参照できます。ファイル変更はウォッチャーで追従するため、初回インデックス後は継続運用しやすい構成です。

どんな人向けか

Claude Code や Codex CLI を日常的に使っていて、巨大なリポジトリで探索コストやトークン消費が膨らむことに悩んでいる開発者向けです。コードレビュー、影響調査、既存構造の理解を AI に任せたいが、外部送信は避けたいチームにも相性があります。

注意点

前提は静的解析なので、強い動的メタプログラミングや実行時生成コードでは取りこぼしがありえます。また、恩恵を得るには最初にインデックス生成が必要です。最近の変更で除外対象は `.gitignore` ベースへ寄ったため、コミット済みの `vendor` や `dist` を解析させたくない場合は `.gitignore` の整備も必要です。

まとめ

CodeGraph は、AI エージェントにコードベースの地図を先に渡しておくための基盤です。大規模開発での探索回数とトークン浪費を減らしつつ、ローカル完結のまま理解精度を上げたい場合、かなり実務寄りの選択肢です。
