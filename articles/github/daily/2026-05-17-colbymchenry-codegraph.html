これは何か

Codegraph は、Anthropic の CLI ツール「Claude Code」などの AI コーディングエージェントをよりスマートにするための補助ツールです。プロジェクトのソースコードを解析し、関数やクラスの依存関係を「知識グラフ」として事前インデックス化することで、AI がコードの構造を即座に把握できるようにします。

何ができるか

大規模なコードベースにおいて、AI が「どのファイルがどの関数を参照しているか」といった複雑な関係性を、トークンを浪費する大規模な全ファイル読み込みなしで理解できるようになります。これにより、より正確な修正案の提示や、バグの原因特定が高速化されます。

目立つポイント

100% ローカルで動作し、インデックス作成プロセスも透過的である点です。AI エージェントが個別のツールを呼び出す手間（ツールコール）を減らし、コンテキストウィンドウの利用効率を最大化するように設計されています。また、TypeScript や Python など主要な言語の解析をサポートしています。

セットアップや使い方の流れ

npm などのパッケージマネージャを通じてインストール可能です。プロジェクトのルートディレクトリでコマンドを実行すると、コードの静的解析が始まり、エージェントが読み取り可能な形式のインデックスファイルが生成されます。その後は、Claude Code 等からこのインデックスを参照させることで、強力なコンテキスト補助が受けられます。

どんな人向けか

Claude Code などの AI IDE をヘビーに活用しており、大規模なプロジェクトで AI が「迷子」になることに不満を感じている開発者、あるいは API コストを抑えつつ AI の推論精度を向上させたいエンジニアに最適です。

注意点

コードの静的解析に基づいているため、動的なメタプログラミングを多用しているコードベースでは、一部の依存関係が正確にグラフ化されない場合があります。また、大規模プロジェクトでは初期インデックス作成に一定の時間がかかります。

まとめ

Codegraph は、AI エージェントと人間のエンジニアをつなぐ「地図」のような存在です。AI がコードの全体像を正確に把握するためのインフラを提供することで、AI による開発体験を次のレベルへと引き上げてくれるでしょう。
