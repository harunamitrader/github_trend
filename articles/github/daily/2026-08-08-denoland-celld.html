S3互換バケットを用いて自律的に同期・永続化する、セルフホスト可能な分散Durable Objects（SQLiteベースの分離実行セル）

調査日 2026-08-08

シリアル番号 #938

リポジトリ概要

celldは、Cloudflare WorkersやDurable Objectsを自分のサーバー上で動かし、S3互換オブジェクトストレージをバックエンドとして分散状態を共有する、オープンソースのバックエンドデーモンです。

注目のポイント

  • セル単位でのデータベース sharding: Durable Objectごとに独立した SQLite データベースが構築・マウントされます。単一の巨大な共有DBに依存しないため、アクセス競合や単一障害点（blast radius）が設計上排除されています。
  • S3経由でのデータ同期と ownership 制御: コンセンサスプロトコルや制御プレーンを必要とせず、S3 bucket へのSQLite差分レプリケーションおよび compare-and-swap 操作によってノード間でデータ所有権を排他的に制御・移行します。
  • V8エンジン内蔵と Wrangler 連携: Wranglerでビルドした Worker 資産をそのまま celld deploy でデプロイし、組み込まれたV8ランタイムによってローカルで高速に動作します。

開発におけるインパクトや使いどころ

Cloudflareのマネージドサービスと同等の分散ステートフル処理（チャットセッションやマルチユーザー共同編集など）を、インフラ利用料を抑えながらS3互換ストレージを用いてオンプレミスや安価なVPSにデプロイして運用できます。

まとめ

SQLiteとS3を利用した、コンセンサスなしの分散所有権制御を備えたステートフルWorker用の軽量で強力な分散Durable Objectsランタイムです。
