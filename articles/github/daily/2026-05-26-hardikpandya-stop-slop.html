これは何か

Stop Slop は、AI が書きがちな「それっぽいけれど中身が薄い文章」を見つけて直すための skill file です。生成そのものではなく、仕上げ工程に置く前提で作られています。

何ができるか

曖昧な前置き、過剰に整った構文、同じ意味の言い換えの連発といった AI の癖を捕まえ、より自然で読みやすい prose に寄せるための指示を与えます。Claude だけでなく、他の LLM にも転用しやすい構造です。

目立つポイント

Skill Structure がはっきりしていて、`SKILL.md` に加えて `references/phrases.md`、`references/structures.md`、`references/examples.md` を分けて持っています。Quick start と Scoring もあり、修正前後を機械的に比較しやすいのが実用的です。

セットアップや使い方の流れ

リポジトリを skill として配置し、`SKILL.md` から参照資料を読ませます。そのうえで、下書きや生成文を通して「AI らしさの除去」を依頼する流れです。最初から完璧な文章を狙うというより、粗い草案を最後に磨く用途に向きます。

どんな人向けか

AI で文章を書く機会が多く、見た目の整いすぎを減らしたい人向けです。プロンプト設計、編集支援、社内文章の整形など、文体を一定以上に保ちたい場面で役に立ちます。

注意点

文体を均す力が強い分、個性のあるトーンまで削りすぎる可能性があります。自動整形の結果をそのまま採用せず、最終的には人間の読みで温度感を戻すほうが安全です。

まとめ

Stop Slop は、生成よりも編集に価値を置いた skill file です。AI の癖を薄めて、読み手が自然に読める文章へ寄せたいときに、そのまま組み込める小さな実務ツールです。
