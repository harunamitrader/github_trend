WrenAI

これは何か

WrenAIは、AIエージェントが自然言語による質問から信頼性の高いSQLを自動生成し、ブラウザ上で共有可能なダッシュボードを生成・デプロイ・ガバナンス管理するためのオープンソースGenerative BI（GenBI）エンジンです。

何ができるか

BigQuery、Snowflake、PostgreSQL、ClickHouseなど20種類以上の多様なデータベースと接続し、スキーマ定義だけでなくビジネス意味論や社内ドキュメントを統合したコンテキストレイヤーを形成。人間が検証可能な正確なSQLとグラフを描画します。

目立つポイント

スキーマ検索・MDLプランニング・DRY実行検証による「ハルシネーションの抑制」、ワンコマンドでCloudflare PagesやVercelへ共有可能なWebダッシュボードを自動デプロイする機能、WebAssembly技術（wren-core-wasm）による高速なクライアントサイド描画が大きな特徴です。

セットアップや使い方の流れ

Dockerベースの導入またはPython (`pip install wrenai`) / CLIツールを用いてセットアップを行います。データベース接続を設定後、自然言語で問い合わせを行うか、各種AIエージェントの背景コンテキストとして統合して使用します。

どんな人向けか

社内データベースに対する問い合わせ対応を自動化したいデータエンジニアやBIアナリスト、または自作のAIエージェントに信頼できるText-to-SQL機能とダッシュボード出力能力を持たせたい開発者に向いています。

注意点

2026年5月のリファクタリングにより、コアエンジン（wren-engine）が同リポジトリの core/ ディレクトリ以下へ統合されています。旧レガシー構成（v1）とは設定形式やコマンド体系が異なるため、公式ドキュメントを参照してください。

まとめ

WrenAIは、単なるText-to-SQLにとどまらず、コンテキスト管理とダッシュボード共有までを一貫して提供する頼もしいGenBIプラットフォームです。AIエージェントとビジネスデータの架け橋として強力な威力を発揮します。
