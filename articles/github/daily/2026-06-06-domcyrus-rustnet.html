これは何か

RustNet は、端末上で TCP / UDP / QUIC の接続をリアルタイムに観察するためのネットワーク監視ツールです。単なる netstat 置き換えではなく、どのプロセスがどの通信を持っているかまで追えるのが大きな特徴です。

何ができるか

ライブ接続の一覧に加えて、深いパケット解析、DNS や HTTP/SNI の識別、接続状態の可視化、インターフェース統計の監視まで扱えます。フィルタやソートも TUI から素早く使えるので、気になる通信だけを絞って確認できます。

目立つポイント

Linux では eBPF、macOS では PKTAP、Windows と FreeBSD では各 OS の API を使って、クロスプラットフォームで接続の主体を見分けます。さらに Landlock、Seatbelt、権限低下などのサンドボックス設計が入っているので、観測ツールとしての安全性も意識されています。

セットアップや使い方の流れ

macOS と Linux は Homebrew、Ubuntu や Fedora、Arch などは各ディストリのパッケージ、Windows は Chocolatey で入れられます。Packet capture が必要なため権限調整が要り、Linux では `setcap`、Windows では Npcap の事前導入が前提になります。

どんな人向けか

ローカルや SSH 越しに「誰がどこへつないでいるか」を即座に見たい人、Wireshark ほど重くなくプロセス視点で通信を追いたい人、運用・調査・セキュリティ確認を端末で完結させたい人に向いています。

注意点

deep packet inspection や packet capture を使うので、OS ごとの権限設定を飛ばすとすぐにつまずきます。eBPF も環境によっては使えないことがあるため、README の権限とトラブルシュートを先に見ておくのが安全です。

まとめ

RustNet は、接続の主体と通信内容を同時に把握したいときに強い、端末向けの監視基盤です。netstat と Wireshark の間を埋めるツールとして、常備しておく価値があります。
