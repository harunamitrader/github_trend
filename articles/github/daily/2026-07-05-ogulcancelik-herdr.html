これは何か

ターミナル（CUI）上で動作する、AIコーディングエージェント管理に特化したRust製のマルチプレクサ（エージェント専用 tmux）です。複数のエージェントをローカル、または SSH 経由のリモートサーバー上で同時に実行し、進行状況を管理します。

何ができるか

各エージェントに「本物のターミナル（TTY）」を割り当て、エージェントが内部で実行するフルスクリーンTUIも正しく描画・処理します。また、サイドバーにエージェントのステータス（🔴 待機中/Blocked、🟡 動作中/Working、🔵 完了/Done、🟢 アイドル/Idle）をリアルタイムで要約表示し、複数のエージェントの作業状況を一覧監視できます。

目立つポイント

tmux のように「デタッチ/アタッチ」に対応しており、PCのフタを閉じて作業を中断してもバックグラウンドサーバーでエージェントは動き続けます。別のPCやスマートフォンから SSH 接続して再度アタッチすることが可能です。GUI（Electron等）を一切排除し、非常に軽量な単一の Rust バイナリで動作するためテレメトリーもなくプライバシーも担保されています。

セットアップや使い方の流れ

Rust製バイナリとしてビルド、またはインストールし、herdr コマンドから起動します。マウス操作にもネイティブで対応しており、ペインのドラッグ＆ドロップ、クリックによるタブやワークスペースの分割がコマンドライン上で直感的に操作できます。

どんな人向けか

日常的に Claude Code や Cline などの自律コーディングエージェントを並行稼働させて開発を行っているパワーユーザーや、複数の自律タスクを並列処理させるエージェントエンジニアに適しています。

注意点

エージェントを起動・監視するためのシステムであり、独自のAIモデルやLLM推論ロジックは内包していません。また、エージェントから送信される状態シグナルを正しく解釈するためには、ターミナル上で適切な連携設定が必要です。

まとめ

AIエージェントの大量実行時代を見据え、CUI（CLI）開発環境の利便性を損なうことなく複数エージェントを多重管理・監視できるようにした極めて実用的で硬派なシステム開発支援ツールです。
