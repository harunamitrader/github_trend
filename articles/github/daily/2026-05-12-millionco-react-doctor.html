React Doctor

AIエージェントが書いた「質の低いReactコード」を検出し、健康診断スコアと改善策を提示する自動レビューツール。

記事作成日 2026-05-12
種別 GitHub Trending (Rank 8)
対象 repo millionco/react-doctor
Star数 7,900

これは何か

AIエージェント（Claude CodeやCursorなど）が生成したReactコードの品質を担保するための診断ツールです。静的解析によってパフォーマンスやアーキテクチャのアンチパターンを特定します。

何ができるか

コードベースをスキャンして0〜100の「健康スコア」を算出し、状態管理、副作用（Effects）、パフォーマンス、セキュリティ、アクセシビリティなどの観点から具体的な問題を指摘します。

目立つポイント

診断だけでなく、AIエージェント自体にベストプラクティスを「教える」インストール機能（npx react-doctor install）を備えています。これにより、エージェントが最初から質の高いコードを書くように誘導できます。

セットアップや使い方の流れ

プロジェクトのルートディレクトリで`npx -y react-doctor@latest .`を実行するだけです。CI/CD（GitHub Actions）への組み込みもサポートされており、プルリクエストごとに自動で品質チェックを行えます。

どんな人向けか

AIを開発にフル活用しているフロントエンドエンジニア、Reactプロジェクトのコード品質を維持したいチームリーダー。

注意点

現時点ではReactに特化しており、VueやSvelteなどの他のフレームワークには対応していません。また、既存のESLint設定との競合を避けるための微調整が必要な場合があります。

まとめ

AI時代の開発ワークフローにおいて、人間が行っていたコードレビューの一部を自動化し、品質の低下を未然に防ぐための重要なガードレールとなるツールです。
