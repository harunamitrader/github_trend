これは何か

ai-agent-book は、元マイクロソフトのAI研究者である李博杰（Li Bojie）氏による専門書『深入理解AI Agent：设计原理与工程実践』（AIエージェントの深い理解：設計原理とエンジニアリング実践）の原稿PDFや、各章に紐づく60以上のサンプルプログラムを惜しみなく無料公開しているオープンソース・リポジトリです。

何ができるか

AIエージェントの基本設計公式「Agent = LLM + Context + Tools」の考え方に沿って、プロンプトエンジニアリング、RAG（検索拡張生成）、ツール使用（Tool Call）、制約付き推論、コード生成支援、そしてマルチエージェントシステムの協調動作までを体系的に学ぶことができます。

目立つポイント

理論書の側面を持ちつつ、実際に動かせる豊富なサンプル（Pythonコードなど）が網羅されており、本番環境でのAIエージェント構築に必要なエンジニアリングの実践的ノウハウが凝縮されている点が極めて高い価値を持っています。

セットアップや使い方の流れ

リポジトリを git clone して手元に置き、公開されているPDFドキュメントを読みながら、対応する各フォルダの実験コードを実行環境（PythonやDocker等）で起動させて学習・検証を進めます。

どんな人向けか

LLMのAPIを使った簡単なチャットアプリ開発から一歩進み、自律的にタスクを解決する高度なAIエージェントや、複雑なマルチエージェントシステムを自作・設計したいソフトウェアエンジニアやAI開発者向けです。

注意点

原本は中国語で執筆されていますが、リポジトリの人気に伴い有志による英語訳やその他の多言語翻訳、コードのドキュメント化が進められています。

まとめ

ai-agent-book は、AIエージェントの概念設計から本番運用の設計パターンまでを理論と大量の動くコードで網羅した、AIエンジニアにとっての最高峰のバイブル的オープンソース教材です。
