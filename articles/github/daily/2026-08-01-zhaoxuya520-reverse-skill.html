これは何か

reverse-skillは、AIコーディングアシスタントやエージェント（Claude Code、Cursor、Cline、Kiro等）がリバースエンジニアリングや脆弱性検査などの高度なセキュリティ作業を行う際に、推測による誤ったコマンド入力を防ぎ、正確な手順と最適なツール（jadx、Frida、Ghidra等）を自動的に選定・実行させるための技能ルール（Skill）および自動化スクリプトの統合パックです。

何ができるか

AIエージェントがAPKやELFバイナリ、難読化JSコードなどの解析タスクを受け取った際に、このリポジトリのルールを読み込ませることで、自動的に検証フェーズ（権限やネットワーク状況の確認など）を立ち上げ、対象に合わせた「Evidences → Findings → Action Paths」のワークフローを自律構築してコマンド実行させることができます。

目立つポイント

AIエージェントに対する指示追従性を高めるための専用マークダウン構造（README_AI.mdなど）と、ローカル環境のツールをインデックス化するスクリプト群が整備されている点です。AIが当てずっぽうで破壊的なコマンドを実行するのを防止し、ゼロトラスト前提の堅実な検証フローを自律的に展開させることができます。

セットアップや使い方の流れ

リポジトリを「git clone」で取得した後、WindowsやLinux/macOSそれぞれの環境向けに提供されているツールインデックス更新スクリプトを実行して、ローカルで利用可能な解析ツールをAIに登録します。以降、AIエージェントへのプロンプトでこのパッケージのMASTER-ROUTINGファイルをロードさせます。

どんな人向けか

AIエージェントをアシスタントとして活用してバイナリ逆向やペネトレーションテスト、CTF攻略、セキュリティ研究を行いたい開発者やアナリストに向いています。

注意点

安全で認可された環境における検証目的（Authorized Pentesting）を前提としており、実際のターゲットへの行動前に権限確認スコープ（scope.md）などを定義してAIを制御する仕組みになっているため、設計段階での正しい制約定義が必要です。

まとめ

AIエージェントの誤動作を防ぎつつ、逆向や脆弱性解析という極めてエラーの起こりやすい高度なタスクを、自律的かつ正確に処理させるための知的な運用ルールセットです。
