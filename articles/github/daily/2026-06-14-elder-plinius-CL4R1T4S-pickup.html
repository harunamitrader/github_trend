これは何か

CL4R1T4S は、Claude、ChatGPT、Gemini、Grok、Perplexity など複数の AI 製品に関する system prompt やガイドラインを集めた公開アーカイブです。指定ファイルの ANTHROPIC/CLAUDE-FABLE-5.md では、Claude Fable 5 の振る舞い方針や安全面の指示が整理されています。

何ができるか

モデルごとの方針差や制約の入り方を比較しやすくなり、AI がどう振る舞うよう設計されているかを確認できます。プロンプト設計や安全性の調査、挙動比較の参考資料として使いやすい構成です。

目立つポイント

単独のモデル資料ではなく、複数ベンダーの内部指示を横断して集めている点が特徴です。透明性や観測を前面に出した編集方針なので、実装よりも「何が前提になっているか」を把握したいときに向いています。

セットアップや使い方の流れ

まず README で収録対象と更新方針を確認し、次に目的のモデル別ファイルを開いて内容を読み比べます。今回のソースのように個別ファイルを起点にすると、必要な範囲だけ素早く追えます。

どんな人向けか

AI の挙動設計を調べたい人、system prompt の違いを比較したい人、プロンプトや安全ポリシーの研究素材を探している人に向いています。

注意点

収録されている内容は、見つけた時点の断面です。実際の製品挙動や公開ポリシーは更新されるため、研究や比較では必ず元の公式情報も合わせて確認する必要があります。

まとめ

AI の内部指示を横断的に読み比べたいときに役立つ、参照性の高い透明性アーカイブです。
