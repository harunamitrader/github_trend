リポジトリ概要

SwarmForgeは、複数のAIエージェントに異なる役割を与え、競合することなくGit Worktreesやtmuxセッションを横断して協調開発させるためのオーケストレーションフレームワークです。

注目のポイント

  • Worktree分離による安全な共同開発: 異なるエージェント（設計・実装・リファクタリング・QAなど）がそれぞれ別々の Git Worktree にアサインされます。並行作業時のコードの衝突や上書きバグを防ぎます。
  • tmuxを用いたセッション管理: エージェントごとのバックグラウンドプロセスを tmux ターミナルセッションで管理し、自動手番制御やメッセージパッシングを行うことで、一貫性のある作業フロー（憲章・規約に基づく）を構築します。
  • 分岐プリセット（パック）の提供: two-pack（実装者＋リファクタラー）、four-pack（仕様化＋実装＋リファクタ＋アーキテクト）など、プロジェクト規模に応じた協調体制のブランチを選択できます。

開発におけるインパクトや使いどころ

AIによる自律コーディングにおいて、1つのエージェントにすべてを任せるのではなく、「仕様検証」「リファクタリング」「単体テスト記述」「アーキテクチャ監査」など、専門エージェントに分割して厳格な品質管理を行いたい高度なチーム開発に有用です。

まとめ

tmuxとGitのインフラをフルに活かし、AIエージェント同士の権限境界と協調シーケンスを管理することで、高品質なコードベース構築を自律化するターミナルベースのオーケストレーターです。
