これは何か

AIコーディングエージェント（特に Claude Code などの Opus 4.7 等のモデル）を利用して、既存のウェブサイトのレイアウトやコンポーネントを分析し、現代的な Next.js アプリケーションコードへと完全に自動再構築・複製するためのスターターテンプレートおよび自動化スキル集です。

何ができるか

コマンド /clone-website <対象URL> を実行するだけで、指定したウェブサイトのビジュアルやスタイル、インタラクションを解析し、Next.js 16 (React 19) + Tailwind CSS v4 + TypeScript + shadcn/ui を用いたクリーンなコードベースを生成します。並列で複数のビルドエージェントを走らせるため、大規模なサイトも高速に複製できます。

目立つポイント

既存のビジュアルテーマやアセットを分析・取得する「Reconnaissance (偵察)」、取得データに基づく「Component Specs (詳細設計仕様書)」の自動生成、Git Worktreeを用いた「Parallel Build (並列ビルド)」、さらに最終成果物と元のサイトのビジュアルテスト（QA）まで含む、一連の全自動リバースエンジニアリングパイプラインをパッケージ化している点がユニークです。

セットアップや使い方の流れ

GitHub上でこのテンプレートから自身のリポジトリを作成し、ローカルにクローンして npm install を実行します。その後、Claude Code 等の AI エージェントを起動（例: claude --chrome）し、エージェントへ向けて /clone-website <複製したいURL> とコマンド入力することで自動パイプラインが開始されます。

どんな人向けか

WordPressやWebflow等のレガシー/ノーコードで作成された既存サイトを Next.js へ移行させたい開発者、ソースコードを紛失した実稼働サイトを復元したい管理者、実際のフロントエンド実装やアニメーションの構築手法を動くコードを通して学びたい学習者に適しています。

注意点

他者のデザインやロゴ、商標などのコンテンツを複製・利用する場合は、著作権や各ウェブサイトの利用規約（スクレイピング禁止ポリシー等）を十分に確認してください。フィッシングサイト構築やなりすましなどの不正な目的での使用は固く禁じされています。

まとめ

ai-website-cloner-template は、AIエージェントの自律的な分析・コーディング能力を最大限に引き出す設計が特徴的です。設計書の自動生成とエージェントへの詳細なコンテキスト指示を並行して行う画期的なシステムにより、Web開発におけるマイグレーション作業やプロトタイプ作成の手場を大幅に削減します。
