これは何か

NGINX は、世界で広く使われているオープンソースの Web サーバーです。同時に、リバースプロキシ、ロードバランサー、API Gateway、キャッシュの役割も担えるため、インフラの前面に置かれることが多いです。

何ができるか

HTTP 配信、TLS 終端、リクエストの振り分け、キャッシュ制御、HTTP/2 や HTTP/3 関連の運用をまとめて扱えます。大きな Web サービスの入口を安定させるための制御面として使いやすいです。

目立つポイント

C 実装の本体を追えるので、高負荷環境での振る舞いをソースから理解できます。README のバッジや topics からも、quic や security を含む周辺機能まで広くカバーしていることが分かります。

セットアップや使い方の流れ

通常は配布パッケージで入れ、設定ファイルで振る舞いを調整します。ソースを読む場合は、ビルドオプションとモジュール構成を先に見ておくと、どの機能がどこで効いているか追いやすくなります。

どんな人向けか

Web インフラを運用する人、負荷分散やリバースプロキシの実装を見たい人、Edge 側の性能や安全性を調整したい人に向いています。バックエンドの入口を作る立場なら、今も価値が高いです。

注意点

本体は堅実ですが、設定やモジュールの組み合わせで挙動が大きく変わります。公式ソースを読むときは、設定例と実装の両方を見ないと、実運用の理解が浅くなりやすいです。

まとめ

NGINX は、Web 配信の前面を支える定番中の定番です。いまでも、インフラの基礎体力を作るために読んでおく価値があります。
