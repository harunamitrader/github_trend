これは何か

Nuclei は、高速で高度にカスタマイズ可能な脆弱性スキャナーです。セキュリティコミュニティが作成・公開している数千もの YAML 形式テンプレートを活用し、Web アプリケーション、ネットワーク、DNS、クラウド設定など、あらゆる対象のセキュリティ上の欠陥を自動的に検出します。

何ができるか

最新の CVE（脆弱性情報）に基づいたスキャン、設定ミス、デフォルトパスワード、情報の漏えいなどを瞬時に特定できます。Go 言語で記述されており、数千ものホストに対して並列で非常に高速にリクエストを送信することが可能です。

目立つポイント

テンプレート駆動型であるため、新しい脆弱性が発見されると即座にコミュニティからテンプレートが供給される点です。また、スキャンの挙動を完全に制御できるため、偽陽性（誤検知）を最小限に抑えつつ、ターゲットに合わせた緻密なテストが行えます。

セットアップや使い方の流れ

Go がインストールされていれば go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest でインストールできます。あとは nuclei -u https://example.com のようにコマンドを実行するだけで、自動的に最新のテンプレートがダウンロードされスキャンが開始されます。

どんな人向けか

セキュリティエンジニア、バグバウンティハンター（脆弱性報奨金制度の参加者）、そして自社の IT インフラを定期的に自己診断したい企業のシステム管理者に最適です。

注意点

強力なツールであるため、必ず自分が管理している、あるいは許可を得たターゲットに対してのみ使用してください。無許可でのスキャンは攻撃とみなされる可能性があります。また、実行パラメータの設定によってはターゲットに高い負荷をかける場合もあります。

まとめ

Nuclei は、モダンなセキュリティ診断においてデファクトスタンダードとなりつつあるツールです。コミュニティの知恵が結集されたテンプレートを活用することで、常に最新の脅威に対抗できる強力な武器となるでしょう。
