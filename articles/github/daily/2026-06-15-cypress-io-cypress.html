これは何か

Cypress は、ブラウザで動くアプリケーションを対象にしたテスト基盤です。実際の操作に近い形で、画面遷移や UI の反応を検証しやすくします。

何ができるか

JavaScript / TypeScript でテストを書き、クリック、入力、ネットワーク制御、アサーションをまとめて扱えます。ローカルでも CI でも同じ感覚で回しやすいのが強みです。

目立つポイント

Interactive runner で失敗箇所を追いやすく、ブラウザに寄ったデバッグ体験が整っています。Web アプリの回帰テストを短いサイクルで回したい現場に向いています。

セットアップや使い方の流れ

npm で導入して、npx cypress open で試し、spec を追加して CI に載せます。画面の待ち合わせや API のスタブを含めて、フレークしにくい書き方に寄せると安定します。

どんな人向けか

フロントエンド開発者、QA、Web サービスの回帰テストを早く整えたいチーム向けです。

注意点

ブラウザ依存のため、待機条件や非同期処理を雑に書くと不安定になります。万能ではないので、単体テストや API テストと役割分担すると扱いやすいです。

まとめ

ブラウザ操作を含む回帰テストを、実務レベルで回しやすい定番の E2E 基盤です。
