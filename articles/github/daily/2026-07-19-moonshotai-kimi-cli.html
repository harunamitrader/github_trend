これは何か

Kimi CLIは、ターミナル上で対話しながらファイル操作、コードの読み書き、シェルコマンド実行、ウェブ検索などを自律的に計画して実行するAIコーディング＆オペレーションエージェントです。Moonshot AIの強力なコード生成モデルを背景に、単なる対話チャットにとどまらない「実行型」のサポートを提供します。

何ができるか

ファイル内のコードを読み取り、自律的に編集して保存することや、必要に応じてシェルコマンドを直接実行することができます。さらに外部ウェブページの検索・取得（スクレイピング）を行い、ネット上の最新情報を含めた計画立案やコード修正が可能です。

目立つポイント

Ctrl-Xキーを押すだけで通常のシェルとエージェントモードを切り替えることができるシェル統合機能や、Agent Client Protocol (ACP) を介したZedやJetBrainsなどの主要なIDE連携が組み込まれています。またOh My Zshなどのzshプラグイン連携により、既存のシェル開発環境の使い勝手を損なわずにAIのアシストを受けられます。

セットアップや使い方の流れ

Node.js（バージョン20以上）が稼働する環境で、`npx` コマンドからログインを実行したあと、ACP設定やZshプラグインを有効にすることでセットアップできます。IDEで利用する場合は、IDE側の設定ファイル（`settings.json`など）に `kimi acp` コマンドを追加することでエージェントパネルから呼び出せるようになります。

どんな人向けか

ターミナル作業やコマンドラインでの開発が多く、シェル環境を離れずにコーディングアシストやシステム構築作業を自律的かつ並行して行いたいエンジニアや、Zed / JetBrainsなどのエディタを使用している開発者に向いています。

注意点

開発チームによる公式アナウンスにより、本プロジェクトは次世代AIエージェントである「Kimi Code CLI (MoonshotAI/kimi-code)」へ開発が引き継がれ、kimi-cliプロジェクト自体は徐々に縮小（ドキュメント等は維持）されていく予定です。新規に導入する場合は、移行先となるkimi-codeも視野に入れる必要があります。

まとめ

Kimi CLIは、ZshやIDEに組み込んでシームレスに使用できるターミナル特化型AIエージェントです。将来的にkimi-codeへの移行が推奨されているものの、ACPやMCPをサポートした完成度の高いCLIエージェントとしての設計は健在です。
