これは何か

swc は、JavaScript と TypeScript を高速に解析・変換・圧縮する Rust 製の基盤です。Babel や TypeScript compiler の一部を置き換える用途で比較されることが多いプロジェクトです。

何ができるか

ビルドパイプラインに組み込み、トランスパイル、minify、コード変換、パーサー処理をまとめて高速化できます。大きなフロントエンド資産を抱えるほど、効きやすいタイプの基盤です。

目立つポイント

Rust 実装であることと、npm / crates.io の両方に導線があることが強みです。README の「Web 開発を速くする」というメッセージが、そのまま用途を示しています。

セットアップや使い方の流れ

まず @swc/core などのパッケージを入れて、既存の Babel や tsc の置き換えから試します。その後、エッジケースやプラグイン互換を確認しながら適用範囲を広げます。

どんな人向けか

フロントエンド基盤を改善したい人、大きな TypeScript リポジトリを抱えるチーム、ビルド時間を詰めたい人向けです。

注意点

Babel と完全互換ではないため、変換結果やプラグインの差分確認が必要です。移行時は既存テストを使って回帰を潰すのが前提になります。

まとめ

Rust ベースで JS/TS の変換パイプラインを高速化する、定番の開発基盤です。
