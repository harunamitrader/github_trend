これは何か

Anthropic が公式に提供する、金融サービス業界向けの参照エージェント、ツール、およびデータ連携用のテンプレート集です。Claude Code や Claude Cowork での利用を想定しています。

何ができるか

投資銀行業務、株式リサーチ、プライベート・エクイティ等の専門的なワークフローを AI で支援。DCF モデリング、LBO 分析、ディールトラッキング、コンプライアンスチェックなどを効率化できます。

目立つポイント

Markdown と JSON で構成された柔軟なテンプレート。公式推奨のデータコネクタ構成例が含まれており、安全な社内データ連携の指針となります。

セットアップや使い方の流れ

Claude Code 等の環境に、提供されているスキルやプロンプトをインポート。必要に応じて自社の財務データや内部プロセスに合わせてカスタマイズして実行します。

どんな人向けか

金融業界のアナリスト、アソシエイト、AI 導入を推進する IT 部門。

注意点

生成された財務モデルや分析結果は必ず人間が検証する必要があります。また、機密データの取り扱いには十分注意してください。
