これは何か

ppf-contact-solver は、ZOZO が公開している接触ソルバです。README では、shells、solids、rods を含む物理シミュレーション向けの solver として位置づけられており、Blender から扱えることが大きな特徴です。

何ができるか

布やロープ、剛体を含む 3D シーンの接触計算を高精度に扱えます。Blender add-on から遠隔実行したり、JupyterLab で Python から試したり、Windows の単体実行ファイルや Docker 経由で動かしたりできます。

目立つポイント

README では、penetration-free、180M 以上の接触まで見据えたスケール、GPU 上での並列実行、Blender 連携、MCP サポートなどが前面に出ています。ドキュメントやデモも豊富で、研究用途と実務寄りの運用をまたいで使いやすい構成です。

セットアップや使い方の流れ

まずは Windows native か Docker のどちらかで solver 本体を起動します。NVIDIA driver を入れたうえで、Windows なら `start.bat`、Docker なら README の手順に従って起動し、JupyterLab は `http://localhost:8080` で開きます。その後、Blender add-on か Python API からシミュレーションを流します。

どんな人向けか

3D アーティスト、テクニカルアーティスト、シミュレーション研究者、GPU を使う物理ベース表現の開発者に向いています。特に Blender を中心にした制作フローと相性が良いです。

注意点

高機能ですが、NVIDIA GPU 前提の運用が基本で、arm64 は対象外です。README でも `warmup.py` をローカルで実行しないよう注意があり、環境構築は手順どおりに進める必要があります。

まとめ

ppf-contact-solver は、視覚的な制作フローにそのまま接続できる高精度接触ソルバです。Blender と Python の両方から扱えるので、研究と制作の間をつなぐ土台としてかなり実用的です。
