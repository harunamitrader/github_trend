これは何か

Y Combinator の Garry Tan 氏が、自身の開発ワークフローで使用している Claude Code 向けの設定と、23 種類の専門的なツール（エージェントスキルのセット）を公開したものです。CEO、デザイナー、エンジニアマネージャーなど、複数の役割をエージェントに担わせるためのツール構成が含まれています。

何ができるか

Claude Code にインポートすることで、エージェントがプロジェクトの設計、リリースマネージャーとしての判断、ドキュメント作成、QAテスト、さらにはエンジニアリングマネージャーとしての進捗管理などを自律的に行えるようになります。開発の全工程をエージェントが「役割」を持って補佐する環境を構築できます。

目立つポイント

単なるツールの集合ではなく、YC 流の「意思決定」や「品質管理」の観点をエージェントに持たせるための「意見のある（opinionated）」ツール群である点が特徴です。各ツールが CEO や Designer などの役割に紐付けられており、対話の質が劇的に向上します。

セットアップや使い方の流れ

リポジトリ内の設定ファイルを自身の ~/.claude ディレクトリに反映させることで利用可能です。Claude Code の起動時にこれらのツールが読み込まれ、エージェントが状況に応じて最適なツール（役割）を選択して実行するようになります。

どんな人向けか

Claude Code を既に使いこなしており、さらに高度な自律性をエージェントに持たせたい開発者や、プロフェッショナルな開発チームのワークフローを AI で再現したいリーダー層に非常に適しています。

注意点

23 種類ものツールを統合するため、各ツールの動作原理や Claude Code の基本操作を理解していることが推奨されます。また、一部の設定は Garry Tan 氏独自のワークフローに最適化されています。

まとめ

著名な投資家でありエンジニアでもある Garry Tan 氏の「秘密兵器」とも言える設定群の公開です。エージェントを単なるコーダーとしてではなく、プロダクト開発のパートナーへと進化させるための最良のリファレンスとなるでしょう。
