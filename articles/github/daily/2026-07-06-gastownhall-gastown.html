gastown

これは何か

Claude Code や GitHub Copilot、Codex などの複数の AI コーディングエージェントを同時並行で動作させ、タスクの手渡しや作業状態を安全に集中管理するためのオープンソースのマルチエージェントオーケストレーション・ワークスペースマネージャです。

何ができるか

複数のエージェント（Polecats）を異なるタスクやプロジェクト（Rigs）に分散実行させ、エージェント間のメールボックス、アイデンティティ管理、およびハンドオフ（タスク引き継ぎ）を可能にします。また、エージェントが再起動した際に失われがちなコンテキストや作業状態を、Git をベースとしたフックと「Beads」と呼ぶ共有台帳（Ledger）に保存・永続化することで、20〜30体のエージェントを破綻なく多重コントロールします。

目立つポイント

全体を統率するマスターAI「The Mayor（市長）」を最上流に配置する設計が特徴です。ユーザーはまず The Mayor（Claude Code 実装）に全体の目標を指示するだけで、市長がバックグラウンドの各プロジェクトフォルダ（Town）に配置されたエージェントたちに適切な役割を振り分け、並行処理を開始させます。

セットアップや使い方の流れ

リポジトリをクローンしたのち、設定ファイルでワークスペースディレクトリ（例：~/gt/）を定義して起動します。The Mayor セッションを開始し、「〇〇というアプリを構築したい」といった指示を与えることで、Mayor が必要な Rigs（作業区画）を作成してエージェントたちに指示を投げ始めます。

どんな人向けか

単一の AI エージェントで作業するだけではパワー不足を感じており、多数のエージェントを並行して別々のプロジェクトやファイル領域に動員し、長時間の自動開発を管理したい開発者やエージェントエンジニアに最適です。

注意点

多数のエージェントが自律的に動き回り、ファイルの書き換えや Git コミット・操作を行うため、テスト用のクリーンな環境や適切なサンドボックス内で動作させることが強く推奨されます。また、多重の LLM API コールによるコスト管理が必要です。

まとめ

AI エージェント同士がメールボックスや共有台帳を介して自律的に協調し合い、開発フローの永続的な引き継ぎを可能にした、マルチエージェント開発環境の先駆的なオーケストレーションフレームワークです。
