これは何か

プライバシーを最優先に設計された、100%ローカル（オフライン）で動作する Rust 製の AI 会議アシスタント・自動議事録作成アプリです。Mac および Windows 向けにデスクトップクライアントが提供されています。

何ができるか

会議の音声を検出し、Parakeet や Whisper の高速ローカルエンジンを用いて、クラウドを経由せず4倍速でリアルタイム文字起こしを実行します。さらに、複数人の会話から誰が発言したかを特定する話者識別（speaker diarization）機能、およびローカル LLM 実行基盤である Ollama を用いた会議全体の自動要約・ネクストアクション抽出に対応しています。

目立つポイント

会議の録音データや文字起こしテキスト、まとめメモのすべてがユーザー自身のデバイス内にのみ保存され、一切クラウドへ送信されません。セキュリティ要件が極めて厳しい企業の会議や機密性の高い商談であっても、データ漏洩のリスクなく最先端の AI 会議書き起こし・整理サポートを利用できる点が最大の強みです。

セットアップや使い方の流れ

デスクトップアプリをダウンロードしてインストールします。ローカルで動作する Ollama のセットアップを完了させたのち、音声入力デバイスを選択して会議の文字起こしボタンを押すだけでスタートします。直感的でモダンなダッシュボードから、書き起こし履歴の閲覧や再度の要約実行が可能です。

どんな人向けか

日常的にオンライン/オフライン会議が多く、議事録やネクストアクションの作成を効率化したいビジネスパーソンや、情報セキュリティ規約の観点からクラウド型 AI 議事録サービス（Notion AI や Otter 等）を利用できない大手企業・金融・医療・官公庁のエンジニアや実務家に適しています。

注意点

ローカルのCPU/GPUリソースを利用して音声文字起こしや大規模モデル要約を実行するため、安定して処理を行うにはある程度のスペック（特に GPU や Apple Silicon Mシリーズ）を備えた PC 環境が推奨されます。

まとめ

Rust の高速なパフォーマンスを活かし、クラウドサービスに依存せず完全に自身の管理下（ローカル）で高品質な会議ノートを自動構築できる、まさにプライバシー重視時代の決定版 AI アシスタントアプリです。
