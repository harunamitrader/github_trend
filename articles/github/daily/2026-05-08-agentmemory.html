これは何か

AIコーディングエージェント（Claude Code, Cursorなど）に永続的な記憶を与えるための共有メモリレイヤーです。Andrejs Karpathy氏が提唱した「LLM Wiki」パターンを拡張し、実務レベルのベンチマークに基づいて設計されています。

何ができるか

複数のエージェント間で知識を共有し、以前の指示や修正内容を「忘れさせない」ことができます。MCP (Model Context Protocol) サーバーとして動作し、ハイブリッド検索、ナレッジグラフ、確信度スコアリングなどの機能を備えています。

目立つポイント

1. 永続的共有メモリ: 異なるエージェント（Claude CodeとCursorなど）が同じ記憶を参照可能。 2. 高度な検索技術: ハイブリッド検索とナレッジグラフを組み合わせ、関連情報を的確に抽出。 3. リアルタイム可視化: 記憶の操作や依存関係をGUIダッシュボード（iii Console）で確認・追跡可能。

セットアップや使い方の流れ

MCPサーバーとしてインストールするか、HTTP API経由で接続します。各エージェントの設定ファイルにMCPサーバーの情報を追加するだけで、エージェントが記憶にアクセスできるようになります。

どんな人向けか

複数のAIコーディングツールを併用している開発者、大規模なプロジェクトでAIに文脈を保持させたいエンジニア、エージェントの思考プロセスを可視化・デバッグしたいユーザーに適しています。

注意点

記憶の精度はスコアリングに基づきますが、古い情報や矛盾する情報が蓄積される可能性があるため、定期的なクリーンアップや確信度の調整が必要になる場合があります。

まとめ

AIエージェントに「一度教えたことは二度と言わせない」永続性と共有性をもたらし、開発効率を劇的に向上させるインフラツールです。
