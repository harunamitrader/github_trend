これは何か

Node.jsの創始者Ryan Dahlが開発した、安全なセキュリティデフォルトと優れた開発者体験を備えたJavaScript/TypeScript/WebAssemblyランタイム。

何ができるか

デフォルトでファイルアクセスやネットワークなどのパーミッションを制限して実行するため、安全なコード動作を保証します。TypeScriptのネイティブ実行、パッケージ管理プラットフォーム「JSR」との連携、ES Modulesベースの外部インポート、テスト、Linter、Formatter、ドキュメント生成などの標準開発ツールを組み込みで提供します。

目立つポイント

V8エンジン、Rust、およびTokioによる非同期IOを基盤とした高性能動作に加え、パッケージのインストールや設定ファイル（package.jsonなど）のセットアップをすることなく、URLの直指定だけでモジュールをロードして即座に動かせる手軽さ。

セットアップや使い方の流れ

OSごとに用意されたインストーラーを実行（Mac/Linuxではcurlシェルコマンド、WindowsではPowerShellなど）し、「deno」コマンドを使用できるようにします。プログラムは「deno run --allow-net server.ts」のようにアクセス制限を明示して動かします。

どんな人向けか

Node.jsの設定の多さやパッケージディレクトリの重さに不満を感じているJavaScript/TypeScript開発者、およびセキュリティ保護が施されたサンドボックス実行環境を必要とするサーバーサイドエンジニア。

注意点

Node.jsとはインポート文の解決（npmパッケージ指定）や実行APIに差異があるため、歴史的なNode.js用ライブラリを移行する際には一部互換レイヤー（npm:プレフィックスやdeno.jsonの設定）を活用する工夫が必要です。

まとめ

セキュリティ、開発速度、TypeScriptサポートを極限まで高め、未来のJavaScript開発を提案する極めて洗練された次世代ランタイムです。
