これは何か

Orca は、複数の CLI ベース AI コーディングエージェントを 1 つの画面で束ねて扱うための ADE（Agent Development Environment）です。Codex、Claude Code、OpenCode、Pi などをそれぞれ独立した Git worktree 上で走らせ、結果比較からレビュー、マージまでをひと続きで扱えます。

何ができるか

1 つの指示を最大 5 つのエージェントへ同時に投げ、並列 worktree で生成された差分を比較して勝者を選べます。加えて、WebGL ベースの高速ターミナル分割、iOS/Android のモバイルコンパニオンによる進捗監視と追加入力、GitHub や Linear をアプリ内で見ながらのタスク起点レビュー、CLI からの自動操作まで揃っています。

目立つポイント

特に強いのは、実 Chromium ウィンドウ上の要素をクリックして HTML/CSS と切り抜き画像をそのままプロンプトへ渡せる Design Mode と、AI が作った diff の任意行へコメントを返して再修正させるレビュー機能です。単なるターミナル集約ではなく、UI 修正とコードレビューの往復まで Orca 内で閉じられます。

セットアップや使い方の流れ

導入はシンプルで、公式サイトまたは GitHub Releases から macOS・Windows・Linux 向けデスクトップアプリを入れれば開始できます。必要に応じて iOS アプリや Android APK をペアリングし、CLI エージェントのアカウントを接続したうえで、タスクごとに worktree を切って並列実行する流れです。Homebrew や AUR での導入経路も用意されています。

どんな人向けか

複数の AI エージェントをすでに実務へ組み込み、同じ課題に対する出力を並列比較したい開発者に向いています。あわせて、長時間走るエージェントの状態をスマートフォンから追いかけたい人や、レビューとマージを 1 つのワークフローに寄せたいチームにも相性が良いです。

注意点

複数エージェントを並列に動かす設計上、CPU・メモリ・ディスク I/O に加え、各エージェント側の API 使用量や契約プランも重くなりがちです。また、仕事の進め方が Git worktree と CLI エージェント中心になるため、単一エージェントで十分な用途にはややオーバースペックです。

まとめ

Orca は、CLI エージェントを 1 体ずつ使う段階から、複数のエージェントを並列運用して選別・修正・統合する段階へ進みたい人向けの実践的なオーケストレーション環境です。モバイル監視、Design Mode、差分レビューまで含めて、エージェント運用の周辺作業をまとめて吸収している点が魅力です。
