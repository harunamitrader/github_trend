これは何か

Orca は、ヘビーなエンジニア（100x builder）向けに開発された、AI コーディングエージェントのためのデスクトップ・モバイル統合型オーレーションツールです。複数のエージェントを並行して実行し、それぞれの成果を視覚的に比較・管理することを目的にしています。

何ができるか

ひとつのプロンプトから最大 5 つの異なる AI エージェント（Claude Code、Codex、Pi 等）を並行して別々の isolated Git worktree（隔離されたワークツリー）上で動作させることができます。各エージェントが作成したコードの diff を視覚的に比較し、最も優れた結果を選択してメインブランチにマージできます。また、WeblGLレンダリング対応の高速な分割ターミナルや、モバイルコンパニオンアプリ（iOS/Android）を介した進捗監視と指示送信も可能です。

目立つポイント

Chromium ウィンドウが内蔵されており、クリックした UI 要素の HTML/CSS や切り抜いたスクリーンショットを直接エージェントのプロンプトへドラッグ＆ドロップできる「Design Mode」や、エージェントによって生成された diff 行にコメントを追加してエージェントに修正指示をフィードバックする機能が強力です。

セットアップや使い方の流れ

公式ウェブサイト（onorca.dev）またはリポジトリのリリース一覧から macOS、Windows、Linux 用のデスクトップアプリをダウンロードしてインストールします。コンパニオンアプリは App Store や APK から導入します。

どんな人向けか

複数の AI エージェントを日常の開発ワークフローに組み込んでおり、タスクに応じて最適なエージェントの提案を並行比較したいエンジニア、あるいは長時間のタスク実行中にスマートフォンからリモートでエージェントを制御・確認したい開発者に最適です。

注意点

複数のワークツリーを同時に立ち上げてヘビーな CLI エージェントを走らせるため、マシンパワーと API クォータ（またはプロバイダのアカウント管理）を多く消費する点に注意が必要です。

まとめ

Orca は、AI エージェントをただのチャットツールとして使うのではなく、複数のエージェントが自律的に並行して成果物を競い合う「エージェントファクトリー」としての新しい統合開発体験を提供する先進的なプラットフォームです。
