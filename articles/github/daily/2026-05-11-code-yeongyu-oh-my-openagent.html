これは何か

oh-my-openagent (omo) は、複数の専門特化したAIエージェントを「開発チーム」のようにオーケストレート（調整）し、高度な自律性を実現するターミナル専用の開発ハーネスです。「知能は個々のエージェントではなく、システム（ハーネス）に宿る」という哲学のもと、Claude CodeやCursorを凌駕する複雑な課題解決能力を目指して設計されています。

何ができるか

ultraworkコマンド一つで、リポジトリの全容把握から計画立案、コードの実装、そして独立した検証ステップまでをAIチームが自律的に実行します。複数のファイルを跨ぐ大規模なリファクタリングや、複雑な依存関係の解決など、単一のエージェントでは困難だった高度なソフトウェアエンジニアリングタスクを完遂可能です。

目立つポイント

最大の特徴は、**「計画（Planner）」と「実行（Executor）」の完全な分離**です。戦略を練る『Prometheus』と、実作業を指揮する『Atlas』、そしてコード検索の『Librarian』やデバッグ専門の『Oracle』といったエージェント群が連携します。また、**「Team Mode」**ではこれらのサブエージェントが並列でタスクを処理し、その様子をtmux上でリアルタイムに監視できるという、圧倒的な「プロ仕様」の機能群を備えています。

セットアップや使い方の流れ

Bunがインストールされた環境で bunx oh-my-openagent install を実行することで導入できます。AnthropicやOpenAIなどのAPIキーを設定後、プロジェクトディレクトリで ulw (ultrawork) コマンドを叩くと、AIチームとの共同作業が始まります。最初にPlannerがタスクの詳細をインタビューし、承認された計画に基づいて実行が開始される流れとなります。

どんな人向けか

既存のAIコーディングツールの自律性に物足りなさを感じているパワーユーザーや、大規模なコードベースの変更をAIに高い信頼度で任せたいエンジニアに最適です。複数のLLMを適材適所で使い分け、AIのポテンシャルを極限まで引き出したい層にとって、現在最も野心的な選択肢の一つと言えるでしょう。

注意点

動作にはBunが必要であることや、高度な機能を使いこなすには適切なモデル選択（Opus 4.7 Maxなど）や設定の知識が求められる点に注意が必要です。また、デフォルトで匿名テレメトリが有効になっているため、必要に応じて設定でオフにする必要があります。

まとめ

oh-my-openagentは、単なるチャットUIの延長ではなく、「AIチームの司令塔」としての開発体験を提供する次世代のフレームワークです。その高度なオーケストレーション機能は、AIによるソフトウェア開発が次のフェーズ（完全自律）に入ったことを強く予感させます。
