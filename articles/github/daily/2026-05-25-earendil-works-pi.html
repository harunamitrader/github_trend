これは何か

自分で拡張できる coding agent ハーネスをまとめた mono repo です。

何ができるか

coding agent CLI、agent runtime、unified multi-provider LLM API、TUI ライブラリを同じリポジトリで扱えます。

目立つポイント

OSS の作業セッション共有や、依存関係の固定・shrinkwrap まで含めた supply-chain hardening が入っている点が特徴です。

セットアップや使い方の流れ

README では `npm install --ignore-scripts`、`npm run build`、`npm run check`、`./test.sh`、`./pi-test.sh` の順が案内されています。まず build と check を通してから、CLI をソースから試す流れが分かりやすいです。

どんな人向けか

coding agent を自作したい人、LLM API とエージェント実行基盤をまとめて触りたい人に向いています。

注意点

LLM 依存テストや外部 API が必要な部分があるため、完全にローカルだけで完結する前提ではありません。lockfile 管理も厳しめです。

まとめ

単なる CLI ではなく、agent 基盤と配布・検証の考え方まで含めた実装用の土台です。
