これは何か

container は、Mac 上で Linux コンテナを軽量 VM として動かすための Swift 製ツールです。Apple silicon 向けに最適化されていて、OCI 互換イメージをそのまま扱えます。

何ができるか

イメージの pull、run、push に対応し、system start と system stop でバックグラウンドサービスを管理できます。署名済み installer と更新・削除用スクリプトがそろっているので、ローカル実行環境を手早く整えられます。

目立つポイント

Mac の仮想化とネットワーク機能を使って、コンテナをネイティブに近い形で動かせる点が大きな特徴です。README では導入、更新、削除、技術概要までが一続きで案内されていて、使い方の導線が明快です。

セットアップや使い方の流れ

GitHub Releases から最新の signed installer を入れて、セットアップ後に container system start を実行します。更新は update-container.sh、停止は container system stop、削除は uninstall-container.sh という流れです。

どんな人向けか

Mac で Linux コンテナを動かしたい開発者、Apple silicon でローカル検証をしたい人、Docker 以外の選択肢を試したい人に向いています。

注意点

macOS 26 以降が前提で、古い macOS は非対応です。README でも 1.0.0 前は minor release に破壊的変更が入りうると明記されているため、実運用ではバージョン固定が必要です。

まとめ

Mac 向けのコンテナ実行基盤として、ローカル検証や小規模な配布環境に使いやすい実装です。
