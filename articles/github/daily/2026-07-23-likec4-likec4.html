これは何か

likec4 は、独自の人間可読なドメイン固有言語 (DSL) を使用して、ソフトウェアシステム全体の構成要素や関係性をテキストコードとして定義し、それに基づいた双方向・動的なシステム設計図面を自動レンダリングしてくれる「Architecture-as-Code (AaC)」のオープンソース・ツールキットです。

何ができるか

プレーンテキスト (.c4 または .likec4 ファイル) でシステム構造や境界を記述し、Vite プラグインや React コンポーネントを介して、自身のアプリケーションにインタラクティブなシステム設計図を埋め込めます。また、CLI を用いたローカルプレビュー (likec4 start) や、Mermaid、Draw.io、D2、Dot、PNG、JSON 等の様々なフォーマットへの書き出しが可能です。

目立つポイント

従来の硬直した作図ツールとは異なり、ネストレベル（階層）を自由に増やせる柔軟なモデリング機能が特徴的です。VS Code 拡張機能が公式提供されており、エディタ内でオートコンプリートやシンタックスハイライト、図面のライブプレビューを見ながら快適に設計ドキュメントの記述を進められます。

セットアップや使い方の流れ

プロジェクト内で npm install --save-dev likec4 で導入するか、npx likec4 start コマンドをファイルのあるフォルダで直接走らせるだけで、ホットリロードが効いたローカル開発サーバーが立ち上がります。

どんな人向けか

システムの規模が大きくなるにつれて図面の保守（アップデートの追従）が難しくなりがちなソフトウェアアーキテクトや、インフラ・アプリの設計ドキュメントを Git でのコード管理やバージョン管理に乗せたいと考えている開発チーム向けです。

注意点

DSL の構文を新しく学習する必要がある点や、巨大な設計モデルを扱う場合の自動レンダリング結果のレイアウト微調整には、DSL側のスタイリング定義をある程度理解しておく必要があります。

まとめ

likec4 は、テキストコードで記述したアーキテクチャ定義から常に正確で美しい作図を自動構築し、システムの進化と設計ドキュメントの完全な同期を約束してくれる、極めて実用的な設計支援ツールです。
