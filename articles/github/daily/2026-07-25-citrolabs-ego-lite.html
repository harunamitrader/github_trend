これは何か

ego-lite は、Codex や Claude Code などの AI コーディングエージェントが、あなたの PC 上で Web オートメーション（ブラウザ操作）を最も高速かつ安全に実行できるように開発された、オープンソースの専用ブラウザ基盤です。

何ができるか

通常、AIエージェントにブラウザを操作させる（Computer Use）には、ヘッドレスブラウザで複雑なセッション管理を行うか、ユーザーのブラウザセッション全体を露出させる必要がありました。ego-lite は、ユーザーがログインしている各種Webサービスのクッキーやセッション状態を、メインブラウザでの作業を一切邪魔することなく、エージェントへ限定的に橋渡しして動作します。

目立つポイント

「ゼロ構成・ゼロコスト」を掲げており、セットアップが極めて簡単です。エージェント向けに最適化された超軽量構造であるため、動作速度が他のブラウザ自動化フレームワークと比べて圧倒的に速く、不要なリソース消費を抑えられます。

セットアップや使い方の流れ

macOS 用のビルド（DMG形式）が提供されており、ダウンロードしてインストールすることで利用を開始できます。導入後は、エージェントを実行する CLI 環境から ego-lite を経由して接続させる設定を行うことで、GitHub や Slack、クラウドコンソールなどログインが必要なサイトに対する自律操作をエージェントに委託できます。

どんな人向けか

AIエージェントを用いたブラウザ自動化やスクレイピング、Webサービス横断の自律ワークフロー構築を行いたい開発者で、パスワード再入力や二要素認証（MFA）の突破などの面倒なログイン手順を省略しつつ、セキュアにエージェントにタスクを実行させたいユーザー向けです。

注意点

現時点では macOS ビルド（Apple Silicon / Intel）が先行して提供されており、Windows や Linux 向けの対応やサポート状況については進捗を確認する必要があります。

まとめ

ego-lite は、ユーザーのログイン状態をエージェントにシームレスに明け渡すことで、AIによる「Computer Use」の実用性と実行速度を飛躍的に向上させるインフラブラウザです。
