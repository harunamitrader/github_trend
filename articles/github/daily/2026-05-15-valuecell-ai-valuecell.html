これは何か

金融領域に特化した、コミュニティ駆動のオープンソース・マルチエージェントプラットフォームです。株式市場（米国、香港、中国）や暗号資産（Binance, OKX 等）の膨大なデータを扱い、それらを解析・実行する複数の専門 AI エージェントを統括・運用するためのインフラを提供します。

何ができるか

複数の LLM（Claude, GPT, Gemini, DeepSeek 等）やフレームワーク（LangChain, Agno 等）を自在に組み合わせ、複雑な金融タスクを自動化できます。例えば、財務書類の深層リサーチ、ニュースのリアルタイム監視、複数の取引所を跨いだ自動トレーディング戦略の実行などが可能です。各エージェントは「A2A (Agent-to-Agent) プロトコル」により、互いにセキュアに連携します。

目立つポイント

「Super Agent」を司令塔とし、必要に応じて専門エージェントを呼び出す高度なオーケストレーション機能が特徴です。また、金融というリスクの伴う分野を考慮し、エージェントが実行計画を立てる際や取引を行う前に人間の承認を求める「HITL (Human-In-The-Loop)」の仕組みが標準で組み込まれています。

セットアップや使い方の流れ

Python ベースの環境で導入可能です。提供されている a2a-sdk を活用して、独自の金融エージェントを定義したり、既存のリサーチエージェントや戦略エージェントを組み合わせて自分専用の「金融 AI チーム」を構築できます。各エージェントの会話履歴は SQLite で永続化され、監査や文脈の再利用も容易です。

どんな人向けか

独自の金融分析ツールや自動取引ボットを構築したいエンジニア、AI エージェントを実務レベルの金融業務（リサーチ、ポートフォリオ管理）に投入したい金融プロフェッショナル、そしてマルチエージェントによる高度な意思決定システムに関心のある開発者に最適です。

注意点

実際の取引を行う場合、取引所 API の適切な管理と、エージェントが提示する戦略の慎重な検証が不可欠です。プラットフォーム側でガードレール機能は提供されていますが、最終的な投資判断はユーザーの責任となります。

まとめ

AI エージェントが個別に動作する段階から、複数のエージェントが「チーム」として金融市場に立ち向かう段階へと進化させるプロジェクトです。金融ドメイン特化の Agent-Native な基盤として、AI による資産運用の未来を占う重要なプラットフォームとなるでしょう。
