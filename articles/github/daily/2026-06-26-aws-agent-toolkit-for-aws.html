これは何か

AIコーディングエージェント（Claude Code、Codex、Cursor、Kiroなど）がAWS上のリソースを安全かつ効率的に構築、デプロイ、管理するためのAWS公式ツールキットです。

何ができるか

AWSコアサービス（CDK/CloudFormation、サーバーレス、コンテナ、ストレージ等）の自動プロビジョニング、Amazon Bedrockを用いたAIエージェントの作成、AWS GlueやAthenaを使ったデータ分析ワークフローの構築、DevSecOpsエージェントによる脆弱性スキャンやインシデント調査が可能です。

目立つポイント

主要なAIコーディングエージェントへのプラグイン（Claudeの公式マーケットプレイス経由など）やMCPサーバーとしてのネイティブ統合、AWS操作に関する知識ライブラリ、および不正なリソース作成やセキュリティポリシー違反を防ぐためのガードレール機能が含まれています。

セットアップや使い方の流れ

Claude Codeの場合は /plugin install aws-core@claude-plugins-official でインストールします。CursorではリポジトリをTeam Marketplaceとして追加しプラグインを導入します。ローカルにはAWSの適切な認証情報が設定されている必要があります。

どんな人向けか

Claude CodeやCursorなどのAIエージェントを利用して、AWS上でのインフラ定義（CDKやCloudFormation）やデプロイ、アプリケーション開発を迅速に進めたいソフトウェアエンジニアやインフラ管理者。

注意点

エージェントが自律的にインフラを作成・変更するため、誤って高額な課金リソースを立ち上げないようガードレールの適切な設定が必須です。また、ローカルで動作する uv やAWSの適切な権限設定が前提となります。

まとめ

AIエージェントが「AWSインフラを組み立てる」ための強力な公式パーツであり、ローカル開発環境からAWSクラウド上の実デプロイ・運用までの距離を極限まで縮めるツールキットです。
