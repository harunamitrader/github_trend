これは何か

3D Gaussian Splatting (3DGS) の点群データをブラウザ上で直接編集、クリーニング、最適化できるオープンソースツールです。

何ができるか

不要なガウス分布の削除、セグメンテーション、位置・回転・スケールの調整、データサイズ削減のための最適化が可能です。

目立つポイント

インストール不要のブラウザ動作、WebGPU/WebGL による高速プレビュー、直感的な UI ツールセット、Ply ファイルのインポート/エクスポート。

セットアップや使い方の流れ

公式サイト（superspl.at）にアクセスするか、リポジトリをローカルにクローンして npm install 後、npm run develop で起動します。

どんな人向けか

3DGS を活用するクリエイター、Web3D 開発者、研究者。

注意点

大容量の Ply ファイルを扱う場合、ブラウザのメモリ制限に注意が必要です。

まとめ

3DGS の仕上げに欠かせない「Photoshop 的存在」。Web ベースでありながらプロ仕様の編集機能を備えた傑作ツールです。
