MediaCrawler

これは何か

Playwright ブラウザ自動化を利用して、小紅書（RedNote）、抖音（Douyin）、快手（Kuaishou）、Bilibili、微博（Weibo）などの中国主要プラットフォームからデータを高速収集するオープンソースのセルフメディア・データ収集ツールです。

何ができるか

各プラットフォームのキーワード検索結果、投稿（動画・ノート）詳細データ、ユーザーからのコメント（返信コメント含む）、クリエイターのプロフィール情報などを自動的に取得し、CSVやデータベース（SQLite/MySQL）に出力できます。

目立つポイント

Playwright を用いてブラウザのログインセッションを管理するため、署名パラメータの生成や難解なJavaScriptコードの難読化解除（リバースエンジニアリング）を行う必要がなく、安定した収集動作を実現している点が最大の強みです。

セットアップや使い方の流れ

Python環境で pip install -r requirements.txt を実行し、Playwright のブラウザバイナリをインストール後、設定ファイル（config.py）に対象プラットフォームやログイン用のCookieなどを指定してメインスクリプトを起動します。

どんな人向けか

中国主要SNSにおける競合分析、ユーザーフィードバックやコメントのトレンド解析、セルフメディアのマーケティングリサーチを行いたい開発者やデータアナリストに適しています。

まとめ

難解な署名アルゴリズムを回避し、Playwrightでブラウザ挙動を模倣することで高い収集成功率を誇る、実用的なSNSクローラープロジェクトです。
