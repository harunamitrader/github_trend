BMAD-METHOD

AIを「高度な専門職エージェント」として活用し、アジャイル開発のライフサイクル全体を革新する次世代開発フレームワーク。

これは何か

AIとの協業を「ロール（役職）」ベースで構造化し、単なるコード生成を超えた「意思決定」と「設計」の品質を極限まで高めるための、エンジニアリング規律に基づいた開発手法（メソッド）です。

何ができるか

PM、アーキテクト、UXデザイナーなど、12種類以上の専門スキルを持つAIエージェントを使い分け、要件定義からシステム設計、実装、テストまでの全工程をガイドします。特に「敵対的レビュー」により、AIの妥協を許さない品質担保が可能です。

目立つポイント

「敵対的レビュー（Adversarial Review）」という独自の品質管理機構。レビュアー役に「必ず欠陥を見つける」という役割を与えることで、AI特有の曖昧な肯定を排除し、堅牢なシステム構築を強力に支援する点が最大の特徴です。

セットアップや使い方の流れ

GitHub上のプロンプト集やドキュメントをベースに、ChatGPTやClaudeなどのLLM環境、あるいはCursor等のエージェント型IDEに組み込んで使用します。「パーティーモード」により、複数のエージェントを一つのコンテキストに呼び出す使い方が推奨されています。

どんな人向けか

AIを活用して開発スピードを上げつつ、アーキテクチャの品質や設計の妥当性を疎かにしたくない開発チームやリードエンジニア。大規模なシステム開発をAIと共に主導したいプロフェッショナル向けです。

注意点

AIに丸投げするのではなく、人間が「意思決定者」として各エージェントの議論を統制する必要があります。また、メソッドの真価を発揮するには、アジャイル開発の基本的な知識が前提となります。

まとめ

AIを「書記」から「専門家チーム」へと昇華させる、ソフトウェアエンジニアリングの本質を突いた意欲的な開発フレームワークです。
