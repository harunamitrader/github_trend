これは何か

Trivy は、Aqua Security が公開している総合セキュリティスキャナです。コンテナイメージ、ファイルシステム、Git リポジトリ、仮想マシンイメージ、Kubernetes を対象に、脆弱性や設定不備をまとめて確認できます。

何ができるか

OS パッケージや依存関係の SBOM、既知の CVE、IaC の設定ミス、秘密情報、ライセンスを一つの流れで見つけられます。セキュリティの入口をバラさずに、開発中の資産を横断的に点検できるのが強みです。

目立つポイント

導入経路が広く、brew、Docker、バイナリ配布のどれでも始めやすいです。GitHub Actions、Kubernetes operator、VS Code plugin などとの統合も用意されていて、最新の release は v0.71.0 です。main 追従の canary build もありますが、README でも production では推奨されていません。

セットアップや使い方の流れ

まずは `brew install trivy` か `docker run aquasec/trivy` で入れます。その後、`trivy image python:3.4-alpine` でイメージを、`trivy fs --scanners vuln,secret,misconfig myproject/` でローカルファイルを、`trivy k8s --report summary cluster` で Kubernetes を点検する流れがわかりやすいです。

どんな人向けか

DevSecOps を前提にしたチーム、CI でのセキュリティゲートを整えたい人、コンテナや IaC を扱う開発者に向いています。スキャン対象が広いので、単発の脆弱性確認だけでなく、継続運用の土台として使いやすいです。

注意点

canary build は毎回 main の push から生成されるため、安定運用では release 版を優先した方が安全です。また、スキャン対象が広いぶん検出結果も多くなりやすいので、CI に入れるならアラートの扱い方を先に決めておく必要があります。

まとめ

Trivy は、開発の早い段階に置きやすい実務向けのセキュリティスキャナです。コンテナ、Kubernetes、コード、設定ファイルを一つにまとめて見たいなら、まず候補に入る repo です。
