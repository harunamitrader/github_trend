これは何か

no-mistakes は、リモートリポジトリへ直接 push する前に、AI 駆動の検証パイプライン（レビュー、テスト、ドキュメント、lint 等）を使い捨ての worktree 上で実行するためのローカル Git プロキシです。開発者の作業環境に影響を与えることなく、コードの健全性を検証した上で自動的に PR を作成する役割を果たします。

何ができるか

ローカルから git push no-mistakes を実行するだけで、裏側で隔離された Git worktree が立ち上がり、テスト実行や linter、AI によるコードレビュー、ドキュメントの更新確認が自動的に走ります。すべてのチェックをパスした場合のみ、本物のリモート（origin等）へブランチが転送され、GitHub 上で PR が作成されます。エラーが発生した場合は、内蔵の TUI（Terminal User Interface）を起動して findings（検出事項）を確認・修正・承認することができます。

目立つポイント

開発者の日常的な Git フロー（git push）にシームレスに介入する点、Claude Code 等のコーディングエージェントに /no-mistakes というスキルとして組み込める点、そして検出された些細なフォーマットエラーなどを自動修正（auto-fix）して PR に含める機能が挙げられます。

セットアップや使い方の流れ

curl スクリプト経由でインストール後、対象の Git リポジトリ内で no-mistakes init を実行するだけで初期化され、専用のリモートゲートが追加されます。その後は git push no-mistakes を実行することで検証が開始されます。

どんな人向けか

PR を常にクリーンな状態に維持したい個人開発者や、チーム開発において CI の失敗を未然にローカルで防ぎたいエンジニア、また Claude Code などの自律エージェントに安全なガードレールを設置したい開発支援ツール愛好者に最適です。

注意点

ローカルで隔離された worktree 内でテストやビルドを実行するため、テストランタイムやビルド環境がローカルに正しくセットアップされている必要があります。また、AI レビュー機能を利用するためには、バックエンドの LLM（Ollama や Gemini API）への接続が必要です。

まとめ

no-mistakes は、手動での Git プッシュ作業に AI 駆動の自動ガードレールを付与し、ローカルでの検証を強力にサポートすることで、壊れたコードが共有されるのを防ぐ非常に実用的でユニークな Git プロキシツールです。
