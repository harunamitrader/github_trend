これは何か

このリポジトリは、複数の AI ツールに関する system prompt、内部メモ、モデル情報をまとめたコレクションです。README の時点で、単一ツールの実装というより、各プロダクトの挙動や内部設定を横断的に見るための資料置き場になっています。

何ができるか

ツールごとの prompt 構造やモデル選定の違いを比較しやすくなり、別のエージェント実装を作るときの参考にもなります。新しいツールを触る前に、どのような指示系が使われているかを確認したい場面で有用です。

目立つポイント

対応対象が多く、Augment Code、Claude Code、Cursor、Windsurf などの情報をひとつの場所で追える点が強みです。README も更新案内やロードマップがあり、単なる貼り集めではなく継続的な整理資料として使える構成です。

セットアップや使い方の流れ

基本は clone して README から対象ツールの項目へ進み、必要な prompt やモデル情報を読む形です。実行環境を作るより、調査対象ごとに目次をたどって情報を比較する使い方が中心になります。

どんな人向けか

AI ツールの挙動を分析したい人、プロンプト設計を学びたい人、自前のエージェント実装で既存ツールの考え方を参照したい人に向いています。

注意点

内容は網羅的に見えても、各ツールの公式仕様を代替するものではありません。モデルや prompt は更新されやすいので、古い情報を前提に流用しない方が安全です。

まとめ

実装よりも参照価値が高いリポジトリで、AI ツールの設計思想を比較したいときの起点になります。
