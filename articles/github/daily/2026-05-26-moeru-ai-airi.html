これは何か

airi は、X の Grok Companion を自分で動かすためのオープンソースプロジェクトです。README では「re-creating Neuro-sama」とも説明されていて、会話型のキャラクターを動かす基盤として設計されています。

何ができるか

リアルタイム音声会話に対応し、Minecraft や Factorio のようなゲームとも連携できます。Web、desktop、mobile の3方向で展開し、ブラウザだけでなくローカル環境でも使えるのが特徴です。

目立つポイント

最初から Web 技術を活用している一方で、desktop 版では NVIDIA CUDA や Apple Metal を使う native 経路も用意されています。Stage Web、Stage Tamagotchi、Stage Pocket という段階的な開発構成もわかりやすいです。

セットアップや使い方の流れ

Web 版は `pnpm i` のあと `pnpm dev` で起動します。Desktop 版は `pnpm dev:tamagotchi`、mobile 版は `pnpm dev:pocket:ios` で進める流れです。ドキュメントサイトもあり、開発・公開の導線が分かれています。

どんな人向けか

AI キャラクター、VTuber 風の対話体験、音声付き companion を自前で組みたい人向けです。Web / native / mobile を横断した実装を試したい人にも向いています。

注意点

README では early stage の開発段階であることが明示されており、協力者やデザイナーも募集しています。主要機能は WIP が多く、実運用前提なら状態をよく確認する必要があります。

まとめ

airi は、単なるチャット UI ではなく、音声・表現・ゲーム連携まで含めた伴走型キャラクターの土台です。野心は大きいですが、そのぶん遊べる範囲も広いプロジェクトです。
