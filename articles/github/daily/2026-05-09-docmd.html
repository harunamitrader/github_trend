docmd

Markdownから本番環境レベルのドキュメントサイトを高速に構築できる軽量ツールです。

これは何か

Markdownファイルを含むフォルダでコマンドを実行するだけで、即座にプロダクション品質のドキュメントサイトを生成・公開できるNode.jsベースの軽量ツールです。

何ができるか

npx @docmd/core dev を実行するだけでローカルサーバーが立ち上がり、ファイル構造に基づいたナビゲーションが自動生成されます。また、ビルドコマンドにより静的なHTMLサイトを出力でき、SEO最適化も標準で行われます。

目立つポイント

最大の特徴は「ゼロコンフィグ（設定不要）」である点です。Reactなどの重いフレームワークを使用せず、JavaScriptのペイロードを最小限（約18kb）に抑えているため、表示速度が極めて高速です。i18n、バージョニング、オフライン検索などの高度な機能も標準搭載されています。

セットアップや使い方の流れ

既存のMarkdownプロジェクトで npx @docmd/core dev を実行するか、npm install -g @docmd/core でグローバルにインストールして使用します。必要に応じて docmd.config.js を作成し、タイトルやURLをカスタマイズできます。

どんな人向けか

ドキュメントツールの設定に時間をかけたくない開発者や、高速で軽量なドキュメントサイトを求めているOSSプロジェクトのメンテナーに最適です。

注意点

極限までシンプルさを追求しているため、Docusaurusのような高度にカスタマイズされたUIコンポーネントを多用するニーズには不向きな場合があります。

まとめ

「ドキュメントツールは目立たない存在であるべき」という哲学の下、執筆に専念できる環境を提供する、次世代のドキュメント生成ツールです。
