リポジトリ概要

Scientific Agent Skillsは、K-Denseによって作成された、AIエージェント（Cursor, Claude Code, Codexなど）のための包括的なスキルセットです。ゲノミクス、分子動力学、気候科学、金融、複雑なデータ分析など、多岐にわたる科学ドメインにおいて、AIエージェントが専門的なツールやデータベースを使いこなせるように最適化された135のスキルを提供します。

主な特徴

  • 135の研究用スキル: バイオインフォマティクス、創薬、臨床研究、物理学など、主要な科学分野を広くカバーしています。
  • 100以上の科学データベースへのアクセス: PubChem, UniProt, ClinicalTrials.gov, FREDなどのデータベースと直接連携可能です。
  • 主要AIエージェントに対応: Cursor, Claude Code, Codex, Gemini CLIなど、Agent Skills標準をサポートするすべてのプラットフォームで動作します。
  • 最適化されたPythonパッケージ連携: RDKit, Scanpy, PyTorch Lightningなどの科学系ライブラリをAIが正確に操作できるようドキュメント化されています。

活用シーン

創薬パイプラインの自動化

特定のタンパク質に対する阻害剤の検索から、RDKitによる構造活性相関の分析、DiffDockによるドッキングシミュレーションまでを一貫してAIに実行させることができます。

マルチオミクス解析

RNA-seqデータ、プロテオミクス、メタボロミクスデータを統合し、疾患のバイオマーカー発見を加速させます。

文献調査とレポート作成

PubMedなどのデータベースから最新の知見を収集し、専門的な科学レポートや図表を自動生成します。

このスキルセットを導入することで、開発用AIエージェントを、専門知識を持った「AI共同研究者」へと進化させることが可能になります。
