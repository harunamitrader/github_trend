Pake

Webページをわずか5MBのRust (Tauri) 製軽量デスクトップアプリへ、コマンド1つで高速パッケージングするパッケージツール

これは何か

コマンドラインから1つのコマンドを実行するだけで、任意のWebサイトやWebアプリケーションをデスクトップアプリ（macOS、Windows、Linux）に変換できるRust製の軽量パッケージングツールです。

何ができるか

指定したURL（ChatGPT、YouTube、または自作のWebアプリなど）をデスクトップアプリ化し、OSネイティブなウィンドウで直接実行できるようにします。デスクトップ用の各種ショートカットキーの有効化、没入型ウィンドウ（フレームなし表示）、ファイルドラッグ＆ドロップへの対応、独自のカスタムCSS/JSの挿入、Web内の不要な広告要素の非表示フィルターなどを設定可能です。

目立つポイント

従来のWebアプリデスクトップ化の代名詞であった「Electron」と比較して、パッケージサイズが約20分の1（通常5MB前後）という驚異的な軽さを誇ります。これはRustおよびTauriフレームワーク上に構築され、OSに最初から備わっているWebViewエンジン（Webkit/WebView2）を利用する設計になっているためです。起動時間が極めて短く、動作時のメモリ消費量もごく僅かに抑えられているため、動作環境を選びません。

セットアップや使い方の流れ

Node.js環境があれば、npm install -g pake-cli でコマンドラインツールをグローバルインストールします。その後、pake https://chatgpt.com --name ChatGPT と実行するだけで、OSに応じた実行ファイル（.appや.exeなど）がカレントディレクトリに一瞬で出力されます。ローカルに環境を作りたくない一般ユーザー向けには、GitHub Actionsを利用してオンライン上でビルドし、バイナリをダウンロードする手順も提供されています。

どんな人向けか

よく使うWebアプリをブラウザのタブから独立させてデスクトップ上で常駐実行させたい人、作成したWebアプリを数メガバイトのサイズでクライアントに配布したい開発者、Electronアプリの重さやサイズにストレスを感じている開発者に適しています。

注意点

OSネイティブのWebView機能を利用するため、ビルドされた環境と動作する環境でOSバージョンやWebViewコンポーネント（WindowsにおけるEdge WebView2ランタイム等）の有無が動作影響を及ぼすことがあります。また、一部のサイトではセキュリティの制約（OAuthのポップアップログインなど）により、一部の動的遷移が正常に動かない場合があるため、動作確認を行う必要があります。

まとめ

RustとTauriのメリットを最大限に活かし、極めて軽量かつ実用的なデスクトップアプリをコマンド1つで誰でも即座に作り出せる、画期的な高速アプリ化ツールです。
