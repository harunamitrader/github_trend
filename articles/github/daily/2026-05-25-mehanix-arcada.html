これは何か

React と Pixi.js で作られた、部屋や家全体の間取りをブラウザ上で描けるオープンソースのフロアプラン作成ソフトです。

何ができるか

壁の追加・編集、家具の配置、ドアや窓の追加、寸法測定、複数階の扱い、保存と読み込み、印刷までをひと通りカバーします。

目立つポイント

図面を描くだけでなく、編集と表示の流れが実務向けにまとまっていて、住宅設計で必要な操作を一画面で追いやすい構成です。UI は Mantine、サーバー側は Express.js と MongoDB を使っています。

セットアップや使い方の流れ

README では Docker 構成が最短ルートとして案内されており、ローカルで動かす場合は本体リポジトリに加えて backend 側も用意して依存を入れ、フロントエンドとサーバーを順に起動します。

どんな人向けか

内装のたたき台を素早く作りたい人、リノベーションやDIYの間取り確認をしたい人、ブラウザベースの図面ツールを試したい人に向いています。

注意点

単体のフロントエンドだけでは完結しないため、動作確認には README にある backend の手順も必要です。まずはドキュメントの流れをそのまま追うのが安全です。

まとめ

部屋の配置や家具の配置を視覚的に組み立てたい場面で、実用性のある OSS フロアプラン作成ツールとして把握しやすいリポジトリです。
