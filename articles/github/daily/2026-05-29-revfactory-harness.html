これは何か

Claude Code 向けに、ドメイン説明から agent team と skills を生成するプラグインです。README では、6 つの事前定義パターンを使って `.claude/agents/` と `.claude/skills/` をまとめて作る流れが示されています。

何ができるか

プロジェクトの要約を渡すだけで、Pipeline や Fan-out/Fan-in などの構成に沿ったエージェント群を組み立てられます。技能生成とオーケストレーション、検証までを一つの流れで扱えるのが中心です。

目立つポイント

6 つのチームアーキテクチャ、Progressive Disclosure による skill 生成、検証用のドライランや比較テストが大きな特徴です。英語・韓国語・日本語の導線があるので、導入の入口が分かりやすいです。

セットアップや使い方の流れ

README の案内では Marketplace から導入し、プロジェクトの説明を入力して harness を生成します。その後は生成された agent と skill を `.claude` 配下で使い、必要に応じて検証フローを回します。

どんな人向けか

Claude Code で複数エージェントを組みたい人、役割分担のある AI チームを素早く用意したい人、エージェント構成を再利用可能な形で整理したい人向けです。

注意点

設計ファクトリー寄りのツールなので、単なるテンプレート集よりも抽象度が高いです。ドメインの説明が曖昧だと生成結果もぶれやすいので、最初の入力は具体的にしたほうが良いです。

まとめ

Harness は、Claude Code 向けのエージェントチーム設計を言語化して自動生成までつなげる基盤です。複雑な開発タスクを、役割の分かれたチームで扱いたいときに効きます。
