これは何か

social-auto-upload は、動画コンテンツを複数の SNS へまとめて投稿するための自動化ツールです。抖音、Bilibili、小紅書、快手、動画号、百家号、TikTok、YouTube などを対象にしています。

何ができるか

動画のアップロード、予約配信、プラットフォーム別の uploader 切り替えをまとめて扱えます。運用の入口を CLI とブラウザ自動化の両方に寄せられるので、投稿作業の繰り返しを減らしやすい構成です。

目立つポイント

README の機能表が明確で、どのプラットフォームに何が対応しているかを一目で確認できます。AI Agent と Skill の導線もあり、単なるスクリプト集ではなく、運用手順まで含めて再利用しやすいのが強みです。

セットアップや使い方の流れ

まずは依存関係を入れ、対象プラットフォームのログインや投稿先設定を整えます。そのうえで CLI か browser automation を使ってアップロードを実行し、必要なら定時実行の形に載せます。

どんな人向けか

動画を複数 SNS に配るクリエイター、運用担当、コンテンツの再投稿を定型化したいチーム向けです。手作業の投稿回数が多いほど、効果が出やすいリポジトリです。

注意点

各プラットフォームの UI 変更や認証仕様の変更に影響を受けやすいので、長期運用では定期確認が必要です。アカウント管理や投稿ポリシーも、使う先ごとに個別確認しておくのが安全です。

まとめ

social-auto-upload は、動画配信の最後のひと手間をまとめて吸収する自動化基盤です。コンテンツ制作そのものより、配信と定時運用を軽くしたい人に向いています。
