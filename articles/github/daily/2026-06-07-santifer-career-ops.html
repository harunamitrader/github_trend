これは何か

Career-Ops は、AI を使って求人探索と応募準備を自動化するマルチエージェント型のシステムです。README では「候補者自身に AI を持たせる」という発想が前面に出ていて、単なる応募テンプレート集ではありません。

何ができるか

求人検索、履歴書の最適化、PDF 出力、バッチ処理、Go 製ダッシュボードなどを一連の流れで扱えます。14 個の skill mode が用意されているので、調査から文章生成までの役割を切り分けて運用しやすいです。

目立つポイント

Claude Code、OpenCode、Gemini CLI など複数の AI コーディングツールと相性が良い構成で、就職活動をひとつのワークフローとして扱っている点が特徴です。求人を探すだけでなく、応募先ごとに材料を組み替えるところまで意識されています。

セットアップや使い方の流れ

まず README から自分の言語版を選び、必要な CLI と環境変数を整えます。そのうえで、検索・評価・履歴書調整・PDF 出力を順に回すと、手作業の多い応募作業をかなり圧縮できます。

どんな人向けか

求人応募を大量にこなしたい人、AI でパーソナルなジョブサーチを組みたい人、Claude Code を実務ワークフローに落とし込みたい人に向いています。採用活動のオペレーションをコードで管理したい人にも合います。

注意点

外部サービスや入力品質に依存する部分が多く、レジュメの自動調整はそのまま万能にはなりません。出力結果を鵜呑みにせず、応募先ごとの文脈に合わせて最後は人が見る前提が必要です。

まとめ

Career-Ops は、AI を使って求人探索と応募文書の作成を一体化する実験として面白いリポジトリです。AI エージェントを業務オペレーションに寄せたい人には特に参考になります。
