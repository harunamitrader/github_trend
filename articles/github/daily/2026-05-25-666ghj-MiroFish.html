これは何か

複数エージェントで仮想世界を作り、未来シナリオを推演する予測エンジンです。

何ができるか

ニュースや政策案などの種データを取り込み、GraphRAG、人格生成、シミュレーション、レポート生成、対話型の深掘りまで一気通貫で回せます。

目立つポイント

単に予測文を返すのではなく、仮想世界を作って何度もシミュレーションする設計なので、議論や意思決定の試行錯誤に寄せやすいです。

セットアップや使い方の流れ

ソースデプロイでは Node.js 18 以上、Python 3.11-3.12、uv を前提にし、`.env.example` を `.env` にコピーして API キーを入れます。準備後は `npm run setup:all` か `docker compose up -d` で立ち上げます。

どんな人向けか

世論分析、企画の事前検証、創作の分岐シミュレーションをやりたい人に向いています。

注意点

API キー前提で、構成も重めです。予測の精度は入力データとシミュレーション設定に強く依存します。

まとめ

かなり実験色は強いですが、マルチエージェントで予測を回すという方向性ははっきりしていて、研究や企画の sandbox として面白いです。
