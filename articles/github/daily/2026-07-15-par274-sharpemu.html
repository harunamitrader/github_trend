これは何か

「SharpEmu」は、ソニー・インタラクティブエンタテインメントの家庭用ゲーム機「PlayStation 5」（PS5）の挙動を再現することを目指す、実験的なオープンソースのエミュレータプロジェクトです。モダンなC#（.NET 9）をベースに構築されており、Windows、Linux、およびmacOSのクロスプラットフォームで動作するように設計されています。

何ができるか

現時点では「実験的（experimental）」なフェーズであり、市販のPS5用3Dゲームソフトを滑らかにプレイできる段階ではありませんが、以下のような低レベル/高レベルエミュレーション機能の開発と実験が進行しています。

  • CPU・命令セットのトランスレーション: x86-64アーキテクチャの命令デコードや、JIT（Just-In-Time）コンパイルによる動的バイナリ変換エンジンのテスト。
  • システムコールのエミュレーション: PS5のカスタムOS（BSDベース）が提供するファイルシステム、メモリ管理、マルチスレッド制御に関するシステムコールのモックおよびエミュレーション層の構成。
  • グラフィックスパイプラインの解析: Vulkan等のモダンなグラフィックスAPIへのシェーダトランスレーションの設計検証。

目立つポイント

エミュレータ開発において伝統的に用いられてきたC/C++ではなく、近年パフォーマンスとメモリ安全性、および高効率な開発体験を高い次元で両立しているC#（.NET 9）を選択して開発されている点が大きな特徴です。.NET 9で強化されたハードウェア組み込み関数（Intrinsics）や、メモリ空間の直接操作（Span型やunsafeコード）を駆使し、高水準言語でありながら低レイテンシで動くトランスレータの構築に挑んでいます。

セットアップや使い方の流れ

プロジェクトをビルドまたは開発に参加するためには、最新の.NET 9 SDKが必要です。現段階ではユーザー向けのインストーラーはなく、ソースコードからコンパイルを行います。

# リポジトリのクローンとビルド
git clone https://github.com/par274/sharpemu.git
cd sharpemu
dotnet build -c Release

# 実験的ランナーの実行 (詳細はプロジェクトドキュメント参照)
dotnet run --project src/SharpEmu.CLI -- [path_to_elf_or_pkg]

どんな人向けか

ゲーム機のエミュレータ開発やコンパイラ・動的翻訳（JIT）の設計に深い興味がある開発者、BSD/UNIXライクなOSの低レイヤー構造を学びたいプログラマ、およびC#/.NET 9の極限パフォーマンスチューニングを実践・研究したいエンジニアに向いています。

注意点

本プロジェクトはまだ最初期の研究・実験段階であり、商業用ゲームタイトルを快適に動作させることはできません。ゲームを遊ぶためのツールではなく、エミュレーション技術の実現可能性を検証する「技術デモ・研究プロジェクト」として捉える必要があります。また、エミュレータを使用する際は著作権法や各国の知的財産ポリシーに十分配慮してください。

まとめ

「SharpEmu」は、C#（.NET 9）のポテンシャルをフルに発揮してPS5エミュレーションの難題に挑む、技術的好奇心にあふれた野心的なオープンソースプロジェクトです。最新テクノロジーを活用したシステム変換ロジックの追求により、エミュレータ開発コミュニティに新たなアプローチを提示しています。
