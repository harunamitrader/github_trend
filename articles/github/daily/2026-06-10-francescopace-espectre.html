これは何か

ESPectre は、Wi-Fi の電波変化を解析して動きを検知するプロジェクトです。README では CSI 解析を軸にしていて、Home Assistant との連携まで含めたスマートホーム向け構成になっています。

何ができるか

ESP32 上で動作させながら、電波の揺らぎから人の動きや在室の変化を推定できます。Home Assistant 側に接続すれば、照明や通知などの自動化のトリガーとして使えます。

目立つポイント

ESPHome コンポーネント、Home Assistant 統合、ML ベースの検知オプション、サンプルや FAQ の充実が目立ちます。センサー配線を増やさずに空間の変化を取りたいときに、かなりユニークなアプローチです。

セットアップや使い方の流れ

まずは ESP32 と ESPHome の構成を用意し、README の Quick Start に沿ってデバイスと Home Assistant をつなぎます。その後、検知アルゴリズムや ML ディテクタの設定を調整して、環境ごとの感度を詰める流れになります。

どんな人向けか

スマートホームを細かく自動化したい人、Wi-Fi CSI を試したい人、ESPHome と Home Assistant を組み合わせたい人に向いています。

注意点

Wi-Fi ベースの検知は環境依存が大きく、壁や設置位置で結果が変わります。実用に入れるなら、初期調整と誤検知の観察を前提に考えるべきです。

まとめ

センサー追加なしで空間の変化を拾いたい場合に、かなり面白い実験リポジトリです。
