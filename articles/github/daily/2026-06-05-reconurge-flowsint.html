これは何か

flowsint は、reconurge が公開している graph-based investigation tool です。README では reconnaissance と OSINT に焦点を当てていて、対象同士の関係をグラフでたどりながら調査を進める前提がはっきりしています。

何ができるか

ドメイン、IP、ASN を起点にして、Reverse DNS、WHOIS、Subdomain Discovery、IP 情報、履歴データなどを段階的に enrich できます。調査対象の断片をつなぎ直して、見落としやすい関連を視覚的に確認できるのが強みです。

目立つポイント

単なる情報収集ツールではなく、Domain / IP / ASN / Email / Organization といったデータ型をモジュール分割して扱える設計です。ETHICS.md を前面に出している点も特徴で、技術的な調査と責任ある利用を同時に意識した repo になっています。

セットアップや使い方の流れ

まずは Docker と Make を用意して、Linux / macOS なら `make prod` か `make dev`、Windows なら Docker Compose ベースで起動する流れです。初回は `.env` の準備とログインを済ませ、必要な enrichers を使える状態にしてから、対象をグラフに追加していくのが自然です。

どんな人向けか

OSINT やインシデント対応を扱うアナリスト、ネットワーク由来の関係性を追いたい調査担当、グラフベースで検証を進めたいセキュリティ寄りのエンジニアに向いています。対象を一枚の図にまとめたい人ほど恩恵が大きいです。

注意点

調査対象の性質上、倫理面と許可範囲の確認は必須です。実行には Docker やデータベース系の構成が絡むため、軽量な単体 CLI というより、調査環境を一式整えるタイプのツールとして見た方が扱いやすいです。

まとめ

flowsint は、OSINT をグラフ化して追跡するための実務寄りの基盤です。対象の関係性を整理しながら調べたいなら、調査プロセスの中心に置ける repo です。
