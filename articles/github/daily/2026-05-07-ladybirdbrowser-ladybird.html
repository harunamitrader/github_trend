ladybird

これは何か

非営利団体によって開発されている、完全に独立した新しいウェブブラウザです。既存のブラウザエンジンを一切流用せず、ゼロから C++ で構築されています。

何ができるか

モダンで標準準拠なブラウジング体験を提供。企業の利益や広告ビジネスに左右されない、純粋にオープンで透明性の高いウェブブラウザとしての機能を目指しています。

目立つポイント

独自レンダリングエンジン（LibWeb）と JavaScript エンジン（LibJS）。マルチプロセスアーキテクチャによる堅牢なセキュリティ設計。

セットアップや使い方の流れ

現在は開発者向けのプレアルファ段階であり、リポジトリからソースコードを取得してビルドすることで試用可能です。2026 年以降にアルファ版のリリースが予定されています。

どんな人向けか

ブラウザ技術に関心のある開発者、プライバシーと透明性を重視するユーザー、ウェブの多様性を支持する層。

注意点

現在は開発の初期段階であるため、日常的なメインブラウザとしての利用には適していません。レンダリングの不完全さやクラッシュが含まれる可能性があります。

まとめ

ブラウザの寡占化が進む中で、独立した実装が存在することはウェブの健全な発展に不可欠です。自由なウェブの砦としての成長が期待されるプロジェクトです。
