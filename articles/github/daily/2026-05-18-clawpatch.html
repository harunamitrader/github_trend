これは何か

リポジトリ内のソースコードをセマンティックな「機能スライス（Feature Slices）」に分解し、ローカルのAIエージェント（Codexや各種ACP対応AIなど）と連携して自動コードレビューやバグの修正、最終的なプルリクエスト（PR）の作成までを一貫して行うことができる自律型開発CLIツールです。

何ができるか

clawpatchを実行すると、プロジェクトのビルド設定やコード構造を静的にマッピングし、AIを使って安全にコードを検証（レビュー）します。発見された問題点（Finding）に対しては、専用のコマンドを使ってAIが自動で修正パッチを当て、ローカルの検証コマンドをパスした後にGitHubへ直接下書きPRを作成することができます。

目立つポイント

  • マルチ言語・マルチフレームワーク対応: TypeScript/Node.js、Go、Rust、Python、Java、Kotlin、C#、Ruby、PHPなど、極めて広範な言語に対応したマッピングエンジンを搭載。
  • 安全な自律修正（Fix Loop）: レビュー自体はファイルの変更を行わず、明示的に指定した問題に対してのみAIが修正を実行。検証コマンド（テストなど）を実行して正常動作を確認する安全志向の設計。
  • 多様なAIプロバイダー対応: ローカルのCodex CLIをはじめ、ACP（Agent Connection Protocol）互換のAIエージェント、Grok、OpenCodeなど、多様なローカル/リモートプロバイダーをバックエンドに選択可能。

セットアップや使い方の流れ

pnpm add -g clawpatch でインストールできます。その後、対象のプロジェクトルートで clawpatch init を実行して初期化し、clawpatch map で構造を解析させ、clawpatch review でAIレビューを開始します。発見された不具合は clawpatch fix --finding <id> で自動修正を試行します。

どんな人向けか

AIエージェントを活用してリポジトリ全体の自律的なバグハントやコード品質維持を行いたい開発者、またはローカルLLMを用いたセキュアな静的解析と自動修正のパイプラインを構築したいプラットフォームエンジニア。

注意点

現在は早期のCLIフェーズであり、自動修正（fix）コマンドの適用後はワークツリーの変更点やテスト結果を手動でダブルチェックすることが推奨されます。また、デフォルトではローカルのCodex CLIなどの外部エージェントプロバイダーがセットアップされている必要があります。

まとめ

clawpatchは、開発者が日常的に行う「コードレビュー、バグ修正、テスト検証、PR作成」という一連のサイクルを、AIエージェントを使って完全に自動化・構造化することを目指す意欲的なプロジェクトです。ローカルかつ安全性を重視した設計となっており、AI時代のCI/CDや個人開発の強力な相棒になる可能性を秘めています。
