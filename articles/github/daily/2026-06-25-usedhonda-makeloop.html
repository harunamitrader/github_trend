これは何か

makeloop は、AIコーディングCLIツールである Claude Code のプラグインです。Claude Codeには、与えられたゴールを達成するまでループ処理で自律的に開発や修正を繰り返す /loop コマンドがありますが、最適なループを実行するためには高品質なプロンプトの記述が必要です。makeloop は、現在のプロジェクトの状況やこれまでの会話履歴を読み込み、ゴールを達成するために必要な「検証ゲート（テスト）」「状態追跡」「停止条件」を網羅した、コピペしてすぐに使える /loop 用のプロンプトを自動生成してくれます（※プロンプトの生成のみを行い、ループ自体は自動実行しません）。

何ができるか

現在の作業ディレクトリで /makeloop [ゴールのヒント] を実行するだけで、Claude Code がリポジトリの構成やソースコードのコンテキストをスキャンします。その後、ゴールの特定、厳格な成功基準、検証のためのコマンド（ビルド・テスト・lint）、状態を保存するファイル（.loop/state.md）の設計、および無限ループを防ぐための停止条件（最大反復回数など）を含んだ完全なプロンプトを作成します。作成されたプロンプトはチャット上に表示されるほか、.loop/loop-prompt.md ファイルに自動保存されます。

目立つポイント

単なる定型文の生成ではなく、プロジェクトの「成熟度」や「種類」を動的に評価する点が非常に優れています。例えば、まだ何もない空のリポジトリ（グリーンフィールド）であれば、まずテストを書いてそれをパスさせる TDD 的なループを自動で提案し、すでにテスト環境が構築された成熟したプロジェクトであれば既存のテストランナーを再利用するよう指示します。また、一方向で完了を目指す「クローズドループ」だけでなく、監視や変更検知を行ってトリガー起動する「オープンループ」も判別し、ループが適さないタスク（自動検証が不可能なもの）には「ループを使うべきではない」と警告を出すなど、非常に実践的な「ループ・エンジニアリング」の知見が詰まっています。

セットアップや使い方の流れ

Claude Code のプラグインマーケットプレイスを利用して、以下のコマンドで簡単に導入できます：
/plugin marketplace add usedhonda/makeloop
/plugin install makeloop

インストール完了後、任意のプロジェクトで /makeloop、または目標を付け加えて /makeloop finish the auth refactor のように実行します。質問にいくつか答えるだけで、カスタマイズされたループプロンプトが出力されます。

どんな人向けか

Claude Code の /loop 機能を日常的に活用し、自律エージェントに大きなタスクを任せたい開発者に最適です。特に、ループ中にAIがテストを勝手にスキップして自己評価だけで「完了した」と判断してしまう問題（Ralph Wiggum loop）や、トークンの浪費に悩まされている人にとって、確実な検証ガードレールを簡単に敷くための強力なツールとなります。

注意点

本プラグインはあくまで「/loop に入力するための最適なプロンプトを設計・生成する」ためのツールであり、自動でループ実行を開始するわけではありません。生成されたプロンプトを確認し、手動でコピペして実行する必要があります。また、ローカルでテストやビルドの検証を走らせるため、それらの検証コマンドが正しくローカルにセットアップされている必要があります。

まとめ

makeloop は、AIによる自律開発における「プロンプトエンジニアリング」を自動化し、Claude Code のポテンシャルを最大限に引き出す実用的なユーティリティです。効率的かつ安全にAIエージェントを駆動したい開発者にとって、必携のプラグインと言えます。
