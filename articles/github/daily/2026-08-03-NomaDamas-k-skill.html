k-skill

韓国の高速鉄道予約や行政・交通・生活特化 of APIをAIエージェントに統合するNode.js製カスタムスキル集

これは何か

韓国のローカル環境向けに、高速鉄道（SRT/KTX）の予約や大衆交通案内、行政サービス、生活情報などの各種ローカルAPIをAIエージェントに統合・実行させるための、自律エージェント向けカスタムスキルコレクション。

何ができるか

SRTやKTX列車の空席確認・予約・キャンセル、地下鉄の到着情報、ソウル主要地域の混雑度、大衆交通の最適なルート検索、カカオトーク（macOS版）のローカルログ検索、韓国の法律や判例の検索、気象庁の局所予報や微小粒子の監視など、20以上の韓国特化型スキルをAIに提供します。

目立つポイント

Claude CodeやCodex、OpenClawなどの多様なエージェントクライアントへの容易なツール統合。特別なクライアントAPIを必要とせず、「npx --yes skills add ...」によるシンプルなコマンド実行だけで手軽にエージェントへ機能拡張を施せる仕組み。

セットアップや使い方の流れ

Node.js 18以上がインストールされた環境で、エージェントを介して「npx --yes skills add NomaDamas/k-skill --all -g」を実行することでセットアップが行えます。特定のスキルのみを個別にインストールして利用することも可能です。

どんな人向けか

韓国在住の開発者で、移動の予約や書類手続き、ローカルメッセージや法律の検索など、日常的なルーティン作業をAIエージェントに自律実行・自動処理させたいと考えているユーザー。

注意点

SRT/KTXの予約や登記簿謄本の取得などのいくつかの高度な自動化アクションにおいては、ユーザー自身が対象サービスの公式アカウントやログイン情報（シークレットキー等）を所持している必要があります。

まとめ

AIエージェントの適用領域を「一般コーディング」から「韓国ローカルの日常実務・予約手続き」へ拡張し、生活の自律支援ツールへと昇華させる実用的なカスタムスキルハブです。
