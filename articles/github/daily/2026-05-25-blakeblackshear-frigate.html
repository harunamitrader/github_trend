これは何か

IP カメラ向けのローカル NVR と AI 物体検出をまとめた監視基盤です。

何ができるか

Home Assistant 連携、ローカル物体検出、24/7 録画、RTSP 再配信、WebRTC / MSE のライブ表示、MQTT 連携ができます。

目立つポイント

クラウド依存を避けつつ、必要な箇所だけ物体検出を回す設計なので、常時録画と低遅延ライブ表示の両立を狙いやすいです。

セットアップや使い方の流れ

README は docs.frigate.video を案内しており、GPU か AI accelerator を使う構成が推奨です。まずはドキュメントの手順に沿ってカメラ、検出器、Home Assistant 連携を組みます。

どんな人向けか

自宅や小規模拠点の映像監視をローカルで完結させたい人に向いています。

注意点

GPU 推奨で、検出器設定や保存ポリシーも事前設計が必要です。商標とライセンスの扱いも README を確認した方が安全です。

まとめ

ローカル NVR と AI 検出をきちんとやりたい人には強い選択肢ですが、インフラ側の手間はそれなりにあります。
