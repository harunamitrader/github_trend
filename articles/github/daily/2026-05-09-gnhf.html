これは何か

「Good Night, Have Fun（おやすみ、楽しんで）」という名前の通り、人間が寝ている間にAIエージェント（Claude Code, Codex, GitHub Copilot CLIなど）を自律的にループ稼働させ、タスクを完遂させるためのオーケストレーターです。

何ができるか

指示（プロンプト）を与えると、AIエージェントが「1回のイテレーションごとに1つの小さなコミットを行う」というサイクルを繰り返し、目標を達成するまで自律的に動作します。朝起きたときには、綺麗に整理されたプルリクエストや作業ログが出来上がっている状態を目指しています。

目立つポイント

最大の特徴は「自律ループの堅牢性」です。各イテレーションでの変更を自動でコミットし、失敗した場合はロールバックまたは修復を試みます。また、Git worktree を利用して、複数のエージェントを異なるブランチで同時に走らせることも可能です。

セットアップや使い方の流れ

npm経由で npm install -g gnhf でインストールできます。使い方は非常にシンプルで、gnhf "コードベースの複雑さを軽減して" のようにコマンドを実行するだけで、自律ループが開始されます。

どんな人向けか

大規模なリファクタリングやテストの追加など、時間がかかる作業をAIに任せて放置したい開発者や、複数のAIエージェントを同時に並列稼働させて開発を加速させたい人に最適です。

注意点

AIが自律的にコマンドを実行するため、信頼できる環境での使用が推奨されます。また、トークン使用量の制限（--max-tokens）などを適切に設定しておくことが重要です。

まとめ

「寝ている間に開発が進む」という夢を実現する、自律型開発エージェントのための強力な実行エンジンです。
