これは何か

codebase-memory-mcpは、AIコーディングエージェントが大規模なコードベースを瞬時に把握するための超高速・高効率なコード理解エンジンです。Model Context Protocol (MCP) を介して動作し、コードベース全体をナレッジグラフ化して管理します。

何ができるか

Tree-sitterを活用したAST解析によって158の言語をサポートし、主要9言語ではLSP相当のセマンティック型解析も同時に行います。関数、クラス、呼び出し関係、HTTPルート等の依存関係をグラフとして永続化し、AIに与えるコンテキストを最小限に絞ることで、トークン消費を最大99%削減します。

目立つポイント

C言語で実装された、依存関係ゼロのシングルスタティックバイナリ。SQLiteのインメモリ処理やAho-Corasickパターンマッチにより、Linuxカーネル（2800万行）をわずか3分でインデックス化し、構造クエリには1ms未満で応答します。3Dグラフ表示用のWeb UI（ポート9749）も搭載しています。

セットアップや使い方の流れ

各OSに対応するバイナリをダウンロードし、`install` コマンドを実行してCursorやClaude Codeなどの対応AIエージェントに登録します。あとはAIに対してコードベースに関する質問や指示を行うだけで、本サーバーが裏で適切なコンテキストをエージェントに提供します。

どんな人向けか

大規模なソースコードを読み解きながら、AIコーディングアシスタント（Claude Code、Cursor、Gemini CLIなど）をフル活用して高速に開発やリファクタリングを進めたいソフトウェア開発者向けです。

注意点

エージェントの設定ファイルやコードベース全体をローカルで読み書きするためパーミッションに注意が必要です。ただし、すべての処理は100%ローカル（オフライン）で実行され、外部にソースコードが送信されることはありません。

まとめ

膨大なコードベースの構造をナレッジグラフとして整理し、AIへ超効率的に渡すことで、AIによるソフトウェア開発の生産性と精度を劇的に向上させる極めて優れたMCPサーバーです。
