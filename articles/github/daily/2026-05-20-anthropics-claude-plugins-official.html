これは何か

Anthropicが管理する、Claude Code向けの公式プラグインディレクトリです。内部プラグインと、パートナーやコミュニティが提供する外部プラグインをまとめて扱います。

何ができるか

Claude Code内で /plugin install {plugin-name}@claude-plugins-official を実行して導入でき、/plugin > Discover から一覧を探せます。READMEでは内部プラグイン用の /plugins と外部プラグイン用の /external_plugins が分かれています。

目立つポイント

各プラグインは .claude-plugin/plugin.json、.mcp.json、commands/、agents/、skills/、README.md という標準構成でまとまっています。スラッシュコマンド、エージェント、スキル、MCPサーバー設定をひとつの形で配布できるのが特徴です。

セットアップや使い方の流れ

まずは公式ドキュメント code.claude.com/docs/en/plugins を確認し、必要なプラグインを /plugin install で入れます。外部プラグインを公開したい場合は、READMEにある提出フォームから申請できます。

どんな人向けか

Claude Codeを特定のワークフローやフレームワークに合わせて拡張したい開発者、またはMCPやスキルを配布・利用したいチームに向いています。

注意点

READMEでも、プラグインに含まれるMCPサーバーやファイルについてAnthropicが内容を完全には管理できないと明記されています。導入前に、各プラグインのホームページや内容を確認してから使うのが前提です。

まとめ

claude-plugins-officialは、Claude Codeの拡張を配布・発見・導入するための公式基盤です。標準化された構造で、Claude Code周辺の拡張を整理して扱えるのが強みです。
