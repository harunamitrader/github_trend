これは何か

SQLiteの使いやすさと高い互換性を維持しながら、グローバルな分散レプリケーションやエッジ/サーバーレス環境での高速動作を実現するために開発された、オープンソースかつモダンなSQLデータベースシステム（および関連SDK）です。

何ができるか

エッジコンピューティング環境やサーバーレス環境（Vercel、Cloudflare Workers、Fly.ioなど）と非常に親和性が高く、ユーザーに近いリージョンで超低レイテンシでの読み書き処理を実行できます。データベースのコアには SQLite のオープンソース・フォークである「libSQL」を採用しており、分散レプリカ同士の高速なデータ同期や、Rust、JavaScript、TypeScript、Python、Go、Javaなどの主要言語によるデータベースアクセスをサポートします。

目立つポイント

SQLite は「ローカルの単一ファイルデータベース」として有名ですが、サーバーレス環境ではデータの永続化やサーバー間のデータ共有が困難でした。Turso は、SQLite のコードベースの軽快さを保ちつつ、インターネット越しに分散配置されたエッジロケーション間でレプリカを同期・運用できるようにした点が画期的です。インプロセスデータベースの持つ「高速なクエリ応答」というメリットをクラウド上でシームレスに享受できます。

セットアップや使い方の流れ

ローカル開発では Rust の Cargo などで crates.io/crates/turso などのSDKを利用するか、npmから @tursodatabase/database をインストールします。本家サービスと連携する場合は専用CLIを使ってデータベースを作成し、払い出された接続URLと認証トークンをアプリの環境変数に設定してクエリを発行します。

どんな人向けか

サーバーレス環境でSQLite並みに手軽で起動が速く、かつデータ永続化とスケーラビリティを確保したい開発者、世界中にアクセスが分散するようなSPA（シングルページアプリケーション）やエッジAPIのバックエンドDBを探しているWebエンジニアに適しています。

注意点

SQLite互換ではありますが、完全に同じではなく、libSQL独自の機能拡張や分散処理用の制約があります。また、大規模なデータ分析（OLAP）や、超高頻度かつ複雑なトランザクションが多重に発生するような用途には、PostgreSQLなどのフル機能のリレーショナルデータベースに一日の長があります。

まとめ

インプロセスのSQLiteの軽快さと、グローバル分散エッジデータベースの実用性を融合させ、モダンなWeb・サーバーレス開発におけるデータレイヤーのボトルネックを解消する、非常に優れた次世代のデータベースソリューションです。
