これは何か

厳しいインターネット検閲環境下でも、DNS クエリの中に TCP トラフィックを隠蔽して通信を可能にする DNS トンネリング VPN です。

何ができるか

国際帯域が遮断された環境下でも、DNS 解決が可能であれば外部ネットワークへのアクセスを確保します。

目立つポイント

独自の軽量プロトコル、高遅延・高損失ネットワークでの安定性を高める ARQ 制御、複数の DNS リゾルバへの負荷分散。

セットアップや使い方の流れ

サブドメインの NS レコードをサーバーに設定し、サーバー側でインストールスクリプトを実行。クライアント側で暗号鍵を入力して接続します。

どんな人向けか

通信制限の厳しい地域でのインターネット利用が必要なユーザー、ネットワークセキュリティの研究者。

注意点

DNS トンネリングの特性上、通常の VPN と比較して通信速度は非常に遅くなります。

まとめ

「最後の通信手段」としての信頼性を追求した DNS トンネラー。独自の最適化により、従来のツールよりも高い安定性を実現しています。
