Lark CLI

AI エージェントを Lark/Feishu の「パワーユーザー」に変える、20 以上の AI スキルを統合した公式 CLI 基盤

記事作成日 2026-05-15
種別 Pickup
対象 repo larksuite/cli
Star数 10,392

これは何か

Lark（ラーク）および Feishu（飛書）を操作するための公式 CLI ツールです。最大の特徴は、人間だけでなく AI エージェント（Claude Code, Cursor, MCP サーバー等）が利用することを前提に設計された「Agent-Native」な構造にあります。ビジネスに必要なメッセージ送信からドキュメント作成、データベース操作まで、あらゆる機能をプログラムから自在に操れます。

何ができるか

メッセンジャー、カレンダー、ドキュメント（Docs）、多次元データベース（Base）、タスク、メールなど、Lark のほぼ全てのドメインに対応する 200 以上のコマンドを提供します。特に、AI エージェント向けの「AI Agent Skills」が統合されており、エージェントは提供される構造化ドキュメントを読み取るだけで、正確に Lark 内の情報を取得・加工・共有することができます。

目立つポイント

単なる API ラッパーではなく、AI の推論ミスを最小限に抑えるための「構造化メタデータ（SKILL.md）」が各コマンドに付随している点が画期的です。これにより、AI エージェントは日本語の指示を受けて「特定のグループチャットに今日の予定を要約して投稿し、関連資料を Docs にまとめる」といった複雑な連鎖タスクを、一貫した精度で実行可能になります。

セットアップや使い方の流れ

npm install -g @larksuite/cli でインストール可能です。初回起動時に lark login を実行するとブラウザが開いて認証が完了します。AI エージェントに環境を渡す場合は、エージェントの作業ディレクトリに CLI のバイナリやスキルセットへのパスを教えるだけで、即座に「Lark 操作スキル」を持ったエージェントが誕生します。

どんな人向けか

Lark/Feishu を業務基盤として利用しており、AI エージェントによる業務自動化を一段階進めたい開発者や、複雑な企業内ワークフローを AI に委ねたい組織に最適です。日本語でのコミュニケーションを AI が理解し、それを Lark 上の各種ツールへと正確に橋渡しする基盤を求めている層に強く推奨されます。

注意点

強力な権限を持つため、CLI の認証情報（トークン）の管理には細心の注意が必要です。また、AI エージェントが実行するコマンドの範囲を適切に制限することで、安全な自動化環境を構築することが推奨されます。

まとめ

「ビジネス OS」としての Lark のポテンシャルを、AI エージェントという新しいインターフェースへと開放するミッシングリンクです。24 個の AI スキルを備えたこの公式 CLI は、未来の「AI 協調型オフィス」を実現するための最重要ツールの一つと言えるでしょう。
