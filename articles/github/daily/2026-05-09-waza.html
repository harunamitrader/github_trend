これは何か

AIエージェントが実行する「スキル（Agent Skills）」の品質を評価・向上させるための、Go言語で開発されたCLIツールおよびフレームワークです。Microsoftによって公開されています。

何ができるか

スキルの雛形作成（scaffold）、ベンチマークの実行、そして異なるモデル間での結果の比較が可能です。また、スキルが仕様に準拠しているか、トークン予算内に収まっているかなどをチェックする readiness report も生成できます。

目立つポイント

単なるテストツールではなく、AIエージェントの能力を定量的に「測定」し、改善のサイクルを回すためのエコシステムを提供している点が強力です。LLM-as-a-judge 方式によるグレーディング機能も備えており、人間の判断に近い評価を自動化できます。

セットアップや使い方の流れ

インストールスクリプトや azd 拡張機能として導入できます。waza init でプロジェクトを初期化し、waza new skill で新規スキルを作成、waza run で評価スイートを実行するという流れで利用します。

どんな人向けか

高度なAIエージェントや、再利用可能なAIスキル（スキルの定義ファイルなど）を開発しているエンジニア、プロンプトエンジニアリングの品質を客観的に検証したいチームに向いています。

注意点

内部で LFS（Large File Storage）を使用しているため、ソースからのビルド時には git lfs pull が必要になる場合があります。また、実行には Copilot 等の適切なモデルプロバイダーの設定が必要です。

まとめ

AIの振る舞いを「勘」ではなく「データ」で改善するための、エンジニアリング重視の強力な評価プラットフォームです。
