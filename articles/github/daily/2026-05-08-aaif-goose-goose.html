これは何か

Goose は、Block (aaif) が開発している Rust ベースの拡張可能な AI エージェントです。リサーチ、コーディング、ライティング、各種タスクの自動化を目的としており、デスクトップアプリ、CLI、API の 3 つの形態で提供されています。

何ができるか

Anthropic や OpenAI などの主要な LLM と連携し、ローカルファイルや外部ツールを自律的に操作してタスクを遂行します。複数のサブエージェントを生成して並列処理を行わせたり、ブラウザやデータベースなどの外部ツールと MCP 経由で対話させることが可能です。

目立つポイント

オープン標準の Model Context Protocol (MCP) をフル活用しており、70 以上の既存拡張機能と即座に連携できる点が強力です。また、プロンプトインジェクション対策やツールの権限管理など、セキュリティ機能も Rust で堅牢に実装されています。

セットアップや使い方の流れ

macOS, Linux, Windows 用のネイティブアプリをインストールするか、cargo 経由で CLI をインストールして使用します。設定画面から API キーを入力し、必要な MCP 拡張機能を読み込ませることで、自分専用の強力なエージェントが完成します。

どんな人向けか

日々のルーチンワークを自動化したい開発者、大量の文書やコードベースを横断的に調査したいリサーチャー、MCP エコシステムを活用したエージェント開発に興味があるエンジニア向けです。

注意点

非常に強力な権限（ファイル操作など）をエージェントに与えることになるため、実行環境の分離や権限設定には注意が必要です。また、使用するモデルに応じた API コストが発生します。

まとめ

MCP という強力な武器を携えた、次世代の AI エージェント基盤です。Rust による高速・安全な設計と、圧倒的な拡張性が魅力のプロジェクトです。
