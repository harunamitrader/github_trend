PageIndex

これは何か

PageIndex は、従来のベクトル類似度検索（Vector Search）に依存しない、推論ベースの新しい RAG（検索拡張生成）フレームワークです。文書を単なる「チャンク（断片）」として扱うのではなく、意味のある階層構造としてインデックス化することで、精度の高い情報抽出を実現します。

何ができるか

長大な PDF やドキュメントから、人間が目次や索引を辿るようにして必要な情報を見つけ出します。質問に対して LLM がインデックスのツリー構造を動的に探索し、最も関連性の高いセクションを特定して回答を生成します。ページ番号やセクション名の正確な引用も可能です。

目立つポイント

「ベクトルレス」かつ「チャンク分割不要」な点が最大の特徴です。これにより、文脈の分断を防ぎ、複雑な構造を持つ文書でも正確に理解できます。また、探索のプロセスが可視化されるため、なぜその回答に至ったのかという説明責任（Explainability）が非常に高いのも利点です。

セットアップや使い方の流れ

Python ライブラリとして提供されており、`pip install pageindex` で導入可能です。ドキュメントを読み込ませてツリーインデックスを作成し、クエリを投げることで、高度な推論を伴う RAG システムを構築できます。

どんな人向けか

従来のベクトル RAG の精度に限界を感じている開発者、法務・技術文書などの構造化された長大ドキュメントを扱う企業、根拠（引用）の正確性が求められるシステムを構築したいエンジニア向けです。

注意点

探索に LLM の推論を複数回使用するため、単純なベクトル検索と比較してコストとレスポンスタイムが増加する傾向があります。速度よりも精度を重視するユースケースに適しています。

まとめ

「検索」を「推論による探索」へと進化させた RAG のブレイクスルーです。ベクトル検索の弱点を補い、ドキュメント理解の質を一段階引き上げる強力なフレームワークです。
