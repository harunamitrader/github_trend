これは何か

AI アシスタント（Claude Code、Codex、VS Code、ローカル LLM など）と Unity エディタの間を、Model Context Protocol（MCP）規格を介して双方向で接続するためのオープンソースブリッジツールです。

何ができるか

接続された AI アシスタントに対して、Unity エディタ内のアセット管理、シーンの配置制御、C# スクリプトの編集・検証、テストの実行、ゲームビルドやデプロイプロセスの実行指示といった強力なツール（Tools）を提供します。これにより、AI はテキストチャットを介してゲームオブジェクトを生成したり、シーン内の特定のオブジェクトの配置やプロパティを物理的・自動的に変更可能になります。

目立つポイント

AI にシーン内のアセット情報やインスペクターの値をリアルタイムで解析・フィードバックできる点が最大の特徴です。ゲームエンジンである Unity を AI の「手の届くツール環境」とすることで、自然言語を用いたゲームプロトタイピングや、コードとアセットを跨ぐ複雑なデバッグを AI が代行できるようになります。

セットアップや使い方の流れ

Unity プロジェクト内に MCP Unity パッケージを導入し、AI アシスタント側（Claude デスクトップ等）の mcpServers 設定ファイルにこのブリッジサーバーを登録します。Unity エディタ上の MCP 接続インジケータがアクティブになれば連携完了です。

どんな人向けか

Unity を用いたゲーム開発や 3D アプリケーション構築において、C# コードの自動生成だけでなく、シーン構成、UI レイアウト、アセットのロード＆セットアップなどの反復的な作業を AI に自動化させたいゲームクリエイターやエンジニアに最適です。

注意点

AI エージェントがエディタ操作やシーン内アセットの変更を実行するため、予期せぬオブジェクトの削除や上書きが生じる可能性があります。アセットの破壊を防ぐため、Git や Unity の Version Control 等でバックアップを取りながら使用する必要があります。

まとめ

Model Context Protocol の持つ強力な外部操作ツール機能を Unity エディタに統合し、ゲーム制作に必要な「アセット・シーン・コード」のすべてを AI が直接ハンドリングできるようにした革新的なゲーム開発ブリッジです。
