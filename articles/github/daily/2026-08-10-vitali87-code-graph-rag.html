これは何か

code-graph-ragは、Tree-sitterによる抽象構文木（AST）解析と、インメモリのグラフデータベース「Memgraph」の知識グラフを組み合わせ、巨大なモノレポコードベースをAIエージェントが正確に理解・操作できるようにするオープンソースのRAGシステムです。

何ができるか

従来のベクトル検索による「曖昧な類似度検索」では捉えきれない、コード間の構造的な関係性（関数の呼び出し関係、クラスの継承、モジュールのインポートなど）をグラフ構造で追跡できます。さらに、Model Context Protocol（MCP）サーバーとして動作し、Claude CodeやChatGPTなどのAIアシスタントに自然言語で「この関数の呼び出し箇所を全て見せて」といったグラフクエリを安全かつ正確に実行させることが可能です。

目立つポイント

多言語対応（Python、TS/JS、Rust、Go、C/C++など11言語を統合して単一スキーマで管理可能）と、大規模なマルチ言語モノレポに対応している点です。また、LLMを使用して自然言語からCypher（グラフクエリ言語）を動的に生成し、構造的なデータ検索と更新を実行します。

セットアップや使い方の流れ

MemgraphのDockerコンテナを立ち上げ、リポジトリをインデックス化します。その後、Claude DesktopやMCPクライアントに対応する設定を追加して起動し、AIエージェントに「code-graph-rag ツールを使ってコードベースをクエリして」と指示して会話を開始します。

どんな人向けか

AIコーディングアシスタントのコンテキスト制限に悩んでいる開発者、大規模なモノレポを管理するチーム、またはAIエージェントに正確なコードリファクタリングを自律実行させたいエンジニア向け。

注意点

動作にはMemgraph（グラフデータベース）サーバーの常時起動が必要であり、初回インデックス作成時のパース処理にはある程度の時間とリソースを要します。また、言語ごとにASTの抽出精度に若干のばらつきが生じる場合があります。

まとめ

曖昧なテキスト検索の限界を突破し、構造的なコード理解をAIに与えることで、開発エージェントの自律的なリファクタやナビゲーションを強力に支援する画期的なRAGエンジンです。
