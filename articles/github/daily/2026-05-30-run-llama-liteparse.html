これは何か

run-llama が公開している、文書を速く扱うための open-source document parser です。README では Rust ベースの実装として、解析・OCR・CLI 利用をまとめて案内しています。

何ができるか

PDF や各種文書の解析、バッチ処理、スクリーンショット生成、OCR を含む取り込み前処理に使えます。RAG の前段で、検索しやすい形へ文書を整える用途に向いています。

目立つポイント

高速さを前提にしつつ、CLI と OCR setup、batch parsing、screenshot generation までひとまとめになっているのが強みです。README に Agent Skill の案内があるため、エージェント系ワークフローへ組み込みやすい点も見えます。

セットアップや使い方の流れ

README の Installation に従って Rust 環境または配布バイナリを用意し、CLI で個別解析やバッチ解析を試します。OCR が必要な場合は、先に OCR Setup を確認してから本処理に入ると安定します。

どんな人向けか

RAG の文書取り込みを作る人、PDF から構造化データを抜きたい人、OCR を含む前処理を軽くしたい人向けです。研究用途よりも、実務の ingestion front-end に寄った印象です。

注意点

解析精度は入力品質や OCR の設定にかなり左右されます。大量文書を扱うときは、速度だけでなく失敗時の再実行や出力形式も先に決めておくと扱いやすいです。

まとめ

LiteParse は、文書を壊さず速く吸い上げる前処理層として使うのが向いています。RAG や文書検索の入口を整理したい人には、かなり実用的な候補です。
