これは何か

Lightricks社によって開発された、初のDiffusion Transformer（DiT）ベースのオーディオ・ビデオ融合基盤モデル「LTX-2」を、ローカルで実行するための推論およびLoRA（Low-Rank Adaptation）追加学習用の公式Pythonパッケージです。映像と、その映像内容に完璧に同期した音声を単一のAIモデルで同時生成できることが最大の特徴となっています。

何ができるか

テキストプロンプトや画像、またはその両方から、同期されたオーディオ付きの動画を生成できます。高忠実度な映像表現と、それに違和感なく同期する環境音や効果音を同時に出力可能です。公開されたモデルウェイトを用いて、独自のデータセットによるLoRA学習を実行し、映像のスタイルや特定の被写体をカスタマイズすることができます。複数のパフォーマンスモード（高速・高品質など）をサポートし、APIや専用プレイグラウンドからのアクセスも可能です。

目立つポイント

従来の動画生成モデルは映像のみを生成し、効果音やBGMは別のAIで後付けするものが大半でした。LTX-2は、映像フレームと音声波形を単一のDiT構造内で相互に関連づけながら同時に生成するため、ドアの閉まる音や足音などが映像の動きと完璧なタイミングで連動します。また、LoRA学習スクリプトが公式に同梱されており、開発者が容易に追加学習を始められる点も極めて優れたポイントです。

セットアップや使い方の流れ

Python 3.10以上の環境を用意し、PyTorchおよび依存関係をインストールします。リポジトリをクローンし、pip install -e . でパッケージをインストールします。Hugging Face（Lightricks/LTX-2.3）から事前学習済みモデルをダウンロードします。付属の inference.py を実行してプロンプトからオーディオ付き動画（MP4形式等）を出力するか、train_lora.py で追加学習を開始します。

どんな人向けか

ローカル環境で高度なAI動画生成モデルを実験・調整したい開発者やAI研究者、同期した効果音付きの映像コンテンツを短時間で制作したいクリエイター、特定の画風やキャラクターを学習させて独自の動画生成AIを作りたいエンジニアに向いています。

注意点

DiTモデルのローカル推論およびLoRA学習には、相応に大容量のVRAMを搭載したNVIDIA製GPU（RTX 3090/4090、またはA100など）が必要です。また、生成される音声と映像の品質は入力するプロンプトの記述精度や事前学習モデルのバージョン（2.3など）に依存します。

まとめ

「映像と音声の同時・同調生成」という動画生成AIの長年の課題を解決したLTX-2のローカル動作環境であり、推論からカスタマイズ学習までを一貫して提供する、非常に実用価値と技術的好奇心の高いオープンソースパッケージです。
