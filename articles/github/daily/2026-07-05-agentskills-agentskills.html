これは何か

AIエージェントに新しい能力や専門知識を動的かつ再現可能な方法で追加するための、軽量でオープンな共通規格「Agent Skills」の公式仕様書およびドキュメンテーションプロジェクトです。

何ができるか

エージェント開発者は、この仕様に基づいて「Skill」と呼ばれる自律的動作のパッケージを作成できます。これにより、特定の法務レビュー、データ解析パイプライン、システム監視、コード修正などのタスク実行手順をAIに指示可能となります。また、エージェント側は起動時に必要なスキルのみを動的ロード・実行し、不要なコンテキスト消費を防ぐことができます。

目立つポイント

「progressive disclosure（段階的開示）」と呼ばれる3段階のロード手法（Discovery -> Activation -> Execution）を採用しています。これにより、エージェントは膨大なスキルライブラリから必要なものだけを自動選択してコンテキストに読み込むことができ、トークンコストを最小限に抑えつつ高精度な実行を可能にする点が特徴です。

セットアップや使い方の流れ

Skill は、メタデータとプロンプト手順書を格納した SKILL.md をルートに配置し、任意の executable スクリプト（scripts/）、アセットやリファレンスドキュメントで構成されるフォルダとして定義されます。このフォルダをエージェントにインポートさせるだけで導入が完了します。

どんな人向けか

自律型AIエージェントの能力拡張を行いたいプロダクト開発者、およびチーム固有の業務フローやルールをAIエージェントに忠実に守らせたい社内エンジニアに適しています。

注意点

本プロジェクトは仕様規格の提案・解説書であり、それ単体で動作するAIエージェントそのものではありません。実際にスキルを実行するためには、この仕様に対応した実行エンジン（ランタイム）を開発または利用する必要があります。

まとめ

AIエージェントの能力拡張を統一的なフォーマットで標準化し、ポータブルでバージョン管理可能なアセットとして再利用できるようにするための革新的なエージェント規格です。
