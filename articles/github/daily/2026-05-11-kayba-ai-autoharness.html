これは何か

AIエージェントの開発において、プロンプト、設定、ミドルウェアなどの「ハーネス（構成要素）」を最適化するためのツールです。ベンチマークを実行し、その結果に基づいて自動的に改善案を提案・適用する反復ループを実現します。

何ができるか

pytest や tau2_bench などの既存のベンチマークフレームワークと連携し、エージェントのパフォーマンスを測定します。その後、LLM（CodexやClaude）を使用してプロンプトやコードの修正案を生成し、再度テストを行うことで、最適な構成（チャンピオン）を導き出します。

目立つポイント

改善案の自動生成（Proposal Generation）、最適化キャンペーンの管理、複数のベンチマークアダプターへの対応、そしてローカルでの設定管理（.autoharness/）が特徴です。単なるテストランナーではなく、性能向上のための「自律的な実験プラットフォーム」として機能します。

セットアップや使い方の流れ

pip install autoharness でインストール後、autoharness guide でプロジェクトの初期設定を行います。その後 autoharness optimize を実行することで、ベンチマーク結果に基づいた最適化の反復が開始されます。

どんな人向けか

AIエージェントの開発者や、既存のエージェントの精度・効率をさらに向上させたいと考えているエンジニアに最適です。

注意点

最適化ループ内でLLMのAPIを多用するため、トークンコストに注意が必要です。また、自動生成されたコードやプロンプトが常に期待通りであるとは限らないため、最終的な検証は人間が行うことが推奨されます。

まとめ

autoharness は、勘や経験に頼りがちだったAIエージェントの微調整を、ベンチマークという客観的な指標に基づいて自動化する強力なツールです。開発の反復速度を劇的に向上させる可能性を秘めています。
