これは何か

任意の質問（プロンプト）と、指定したファイル群（glob指定可能）を自動的に1つのコンテキストへとパッキングし、各種LLM（GPT-5.x, Gemini, Claude等）にコマンドラインから即座に問い合わせて回答を得ることができる、エンジニア向けの強力なCLI開発支援アシスタントです。

何ができるか

入力したプロンプトと対象のソースコードをバンドル化してAIに送信できます。APIキーを設定したAPIモードだけでなく、APIキーを必要としない「ブラウザ自動化モード（Browser Mode）」を備えており、ローカルのChromeブラウザのセッションを利用して直接 ChatGPT Pro や Gemini などの高機能なWebモデルへ自動で問い合わせることができます。また、複数モデルへの同時並列問い合わせと結果比較、過去セッションの再生、ChatGPT Projectへのソースコード追加機能なども備えています。

目立つポイント

有料APIキーの従量課金コストを気にせず、ローカルのブラウザセッション経由でAI（GPT-5.5 ProやExtended Thinkingなど）の最新機能を利用できる高度なブラウザオートメーション機構が最大の特徴です。さらに、CLI単体としての動作にとどまらず、CodexスキルやMCP（Model Context Protocol）サーバーとしても機能するため、Claude CodeやCursorといった他の自律型開発環境とも親和性高く連携できます。

セットアップや使い方の流れ

Node 24+ 環境において、グローバルインストール npm install -g @steipete/oracle するか、または npx -y @steipete/oracle を使用してインストール不要で実行できます。APIモードで利用する場合は OPENAI_API_KEY などのキーを設定します。ブラウザモードを利用する場合は、初回のみ oracle --engine browser --browser-manual-login -p "HI" を実行し、開いたChromeウィンドウでChatGPTにログインしてプロファイルを保存させます。以降は oracle -p "リファクタリングして" --file "src/**/*.ts" のように任意のプロンプトとファイル範囲を指定するだけで動作します。

どんな人向けか

手元のソースコードの一部をAIに投げて素早くコードレビューやデバッグを行いたい開発者や、同じソースコードを複数の異なるAIモデルに投げてその出力の質を比較検討したいエンジニアに適しています。また、Cursorなどのエディタ環境に自分のブラウザセッションをMCP経由で統合させたいパワーユーザーにも最適です。

注意点

ブラウザ自動化（Browser Mode）は、ブラウザのアップデートやChatGPT/GeminiのUI変更に伴って動作が不安定になる可能性がある実験的機能です。また、ローカルのソースコードを外部のAIモデルに転送するため、セキュリティ要件の厳しい商用プロジェクトや機密データを扱う際は、送信先モデルの設定や各プロバイダーのデータ学習ポリシーを事前に十分確認する必要があります。

まとめ

oracle は、開発者の「このコードをAIに見せて相談したい」という日常的なタスクの摩擦を極限まで減らしてくれるツールです。CLI、MCP、ブラウザ自動化という3種類のアプローチを柔軟に組み合わせることで、開発環境と最新のシリコンインテリジェンスとの距離を劇的に縮めてくれます。
