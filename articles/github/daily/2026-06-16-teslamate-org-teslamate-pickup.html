これは何か

TeslaMate は、Tesla の走行・充電・位置情報をセルフホストで記録するデータロガーです。自分の環境に置いて、車両データを長く蓄積できます。

何ができるか

充電履歴、走行距離、消費電力、停車や充電のログをまとめて見返せます。データの蓄積先を自分で持てるので、あとから分析しやすいのが利点です。

目立つポイント

Docker ベースで導入しやすく、ダッシュボードで時系列を追いやすい構成です。Tesla 由来のデータを日常的に残したい人に向いた、軽めの運用基盤です。

セットアップや使い方の流れ

まず Docker で起動し、Tesla アカウントと車両接続を済ませます。そのうえでダッシュボードにアクセスし、必要ならバックアップや保持期間を調整します。

どんな人向けか

Tesla オーナーや、車両ログを自分で保管したいセルフホスト派に向いています。

注意点

車両 API や認証まわりは変化しやすいので、導入前に公式手順を確認したほうが安全です。データの保管場所と権限設計も先に決めておくと運用が安定します。

まとめ

Tesla の車両データを自前で蓄積し、後から見返せるようにする実用的なセルフホスト基盤です。
