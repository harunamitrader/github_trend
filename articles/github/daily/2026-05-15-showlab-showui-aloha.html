ShowUI-Aloha

「一度教えれば、あとは任せる」を現実にする、人間指導型の Windows/macOS 自律操作エージェント

これは何か

仮想環境ではなく、実際の Windows 10 以降や macOS のデスクトップ環境を直接操作するために開発された、人間指導型（Human-taught）のコンピュータ操作エージェントです。ユーザーが見せた一回の手本（デモンストレーション）を解析し、類似のタスクを自律的に実行する能力を備えています。

何ができるか

専用のレコーダーでユーザーの操作を記録し、学習器がその「セマンティック（意味的）な操作ログ」を抽出します。実行時には、視覚言語モデル（VLM）が現在の画面状況をリアルタイムで理解し、学習したワークフローを新しい状況に合わせて調整しながら、クリック、ドラッグ、タイピング、スクロール等の操作を OS レベルで再現します。

目立つポイント

単なる「記録・再生」のマクロとは異なり、操作の対象となる UI 要素の意味を抽象化して学習する点が最大の特徴です。これにより、一つの手本を見せるだけで、タスクのバリエーションに対しても柔軟に対応でき、OSWorld ベンチマークにおいても高い成功率を記録しています。

セットアップや使い方の流れ

Windows 用（.exe）または macOS 用（.dmg）のレコーダーを導入し、手本を見せたい操作を実行して記録します。その後、Python ベースの実行器に指示（タスクプロンプト）を与えることで、エージェントが学習した知見に基づき、デスクトップ上の様々なアプリケーションを跨いだ自動化を開始します。

どんな人向けか

複雑な GUI 操作を AI で自動化したい開発者や、プロンプトだけでは説明が難しいワークフローを「手本で見せて」教えたいユーザー、さらには RPA（ロボティック・プロセス・オートメーション）を次世代の AI エージェント技術で置き換えたい企業エンジニアに最適です。

注意点

実際のデスクトップを操作するため、プライバシーやセキュリティの観点から動作環境の適切な管理が求められます。また、現在は VLM を活用した推論プロセスが含まれるため、一定の計算リソースが必要です。

まとめ

「Teach once（一度教える）」という直感的なインターフェースにより、AI エージェントと人間の協調を一段階進めるプロジェクトです。ブラウザ内に閉じない、真の意味での「コンピュータ・ユース」を加速させる基盤技術として、大きな可能性を秘めています。
