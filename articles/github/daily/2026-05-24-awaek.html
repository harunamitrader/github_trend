これは何か

Awaek は、保存済みの X ブックマークを使って質問に答えたり、要約や下書きを作ったりするローカル前提の AI ツールです。Hermes Agent の中で動き、保存した投稿をそのまま知識源として扱います。

何ができるか

ブックマークを SQLite に保持し、検索しやすい evidence chunks に分割して、質問応答や文章生成に使えます。 たとえば、保存した投稿からテーマを要約したり、ローンチ計画や X 投稿の下書きを作ったりできます。

さらに、長文ポストの中から重要なリンクや主張を拾い、複数の保存済み投稿をまたいで「何を繰り返し見ているか」を 把握しやすくしています。

目立つポイント

一番の強みは、X の保存済み投稿を「あとで読む」状態から「今すぐ使える材料」に変える点です。 単純なブックマーク一覧ではなく、回答や下書きの根拠として再利用できるように設計されています。

もう一つは、データがローカルに閉じることです。No hosted backend の方針なので、保存したリンクや検索対象を 自分の環境の中で完結させやすいです。

セットアップや使い方の流れ

README では、Hermes に Awaek の skill を入れ、`xurl` の認証を済ませてから `Awaek sync` でブックマークを 取り込みます。取り込み後は `Awaek status` や通常の対話で、保存済み投稿を材料に質問できます。

先にブックマークを同期し、その後に「自分の保存履歴は何に偏っているか」「この保存群から何が言えるか」を 聞く流れがわかりやすいです。読み返しではなく、分析用の入口として使うのが自然です。

どんな人向けか

X の保存機能を情報収集の本棚として使っている人、保存した投稿から文章や企画を起こしたい人、 ローカルに閉じた知識ベースを持ちたい人に向いています。

注意点

Hermes Agent と `xurl` のセットアップが前提なので、単体の軽量ツールとしては始めにくいです。 また、X の利用規約や認証まわりの運用条件は確認しておく必要があります。

まとめ

Awaek は、X の保存済みブックマークを単なる保存箱ではなく、質問・要約・下書きの材料に変えるための基盤です。 ブックマークを知識資産として使いたい人に向いたリポジトリです。
