これは何か

Google Antigravity と Gemini を土台に、Python から AI エージェントを組み立てるための SDK です。`Agent` を中心に、実行ループや状態管理、ツール連携をまとめて扱えるようにしています。

何ができるか

ストリーミング応答の受信、`Conversation` による状態保持、Python 関数のツール登録、MCP サーバー接続、画像・音声・文書を含むマルチモーダル入力に対応します。

目立つポイント

既定では read-only モードで、安全側に寄せた設計です。書き込み系の機能は `CapabilitiesConfig()` で明示的に有効化します。また、実行に必要な compiled runtime binary は PyPI の platform-specific wheel に含まれるため、リポジトリを clone しただけでは動きません。

セットアップや使い方の流れ

まず `pip install google-antigravity` を入れ、`GEMINI_API_KEY` を設定します。そのうえで `examples/getting_started/hello_world.py` を動かすか、README の `Agent` 例を起点に自分のツールやプロンプトを差し替えるのが最短です。

どんな人向けか

Python で自律エージェントや社内アシスタントを作りたい人、MCP 連携や状態付き会話を前提にした実装を組みたい人向けです。小さな試作品よりも、実運用を見据えた構成に向いています。

注意点

リポジトリのソースだけでは実行できず、PyPI の配布 wheel が前提です。README でもこの点が強調されているので、ビルドや配布の導線は先に確認しておくべきです。

まとめ

antigravity-sdk-python は、Antigravity を Python から使うための実用的な入口です。`Agent`、`Conversation`、MCP、ストリーミングを一通り押さえられるので、エージェント実装の土台をまとめて整えたい場合に向いています。
