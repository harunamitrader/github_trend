これは何か

Chrome拡張機能ベースのMCP (Model Context Protocol) サーバーです。ClaudeなどのAIアシスタントからブラウザを直接操作・制御できるようにし、日常的に使用しているChromeのログイン状態や設定を引き継いだままブラウザ自動化やコンテンツ分析を可能にします。

何ができるか

20種類以上のツールを提供。スクリーンショット撮影、ネットワーク監視、インタラクティブな操作（クリック、入力）、ブックマーク管理、閲覧履歴の検索、さらにはセマンティック検索によるタブ内容の発見などが可能です。

目立つポイント

1. 既存ブラウザの活用: Playwright等とは異なり、ユーザーが普段使いしているChrome環境をそのまま制御。 2. セマンティック検索: ベクトルDBを内蔵し、タブの内容を意味的に検索可能。 3. 視覚的エディタ: Claude CodeやCodex向けのビジュアルエディタ機能を搭載。

セットアップや使い方の流れ

GitHubから拡張機能をダウンロードして読み込み、npm install -g mcp-chrome-bridge でブリッジをインストールします。MCPクライアント（Claude Desktop等）の設定にHTTPまたはSTDIO接続の情報を追加して使用します。

どんな人向けか

AIを使ってブラウザ作業を自動化したいユーザー、特定のウェブサイトの情報をAIにリアルタイムで分析させたい開発者、複雑なウェブ操作をAIエージェントに任せたいエンジニアに適しています。

注意点

拡張機能を「デベロッパーモード」で読み込む必要があり、環境構築にはNode.jsの知識が多少必要です。また、ブラウザの完全な制御権をAIに与えるため、信頼できる環境での使用が推奨されます。

まとめ

普段のブラウザをそのままAIの「手」に変え、ウェブ閲覧・操作を極限まで効率化する強力なMCPツールです。
