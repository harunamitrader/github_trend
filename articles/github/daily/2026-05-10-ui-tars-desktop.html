これは何か

画面の視覚情報（スクリーンショット）から UI 要素を認識し、人間のようにマウスやキーボードを操作してタスクを完遂するデスクトップ AI エージェントです。

何ができるか

ブラウザでの航空券予約、ローカルファイルの整理、複雑な GUI 操作を自然言語の指示だけで自動実行します。

目立つポイント

強力な視覚言語モデル UI-TARS 搭載、マルチプラットフォーム（Win/Mac）対応、MCP (Model Context Protocol) 連携による外部ツール拡張。

セットアップや使い方の流れ

公式インストーラーまたは npx コマンドで起動し、使用する AI モデル（Doubao, Claude, GPT 等）の API キーを設定して使用します。

どんな人向けか

ルーチンワークを自動化したいユーザー、次世代の GUI 自動化を研究する開発者。

注意点

AI による自動操作のため、意図しないクリックなどが発生するリスクを理解し、監視下で実行する必要があります。

まとめ

ByteDance チームによる、GUI エージェントの決定版。視覚認識に基づく操作により、API のない古いアプリでも自動化できる圧倒的な汎用性を持ちます。
