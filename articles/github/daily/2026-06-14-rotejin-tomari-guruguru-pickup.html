これは何か

tomari-guruguru は、ブラウザ上で動くトマリ用アバターです。マウスの位置に合わせて 25 方向へ振り向き、トマリトーク側では音声に合わせた口パクやまばたきを扱えます。

何ができるか

トマリぐるぐるでは、カーソルを追うキャラクター表示をシンプルに楽しめます。トマリトークでは、マイク入力や音声ファイルに合わせて口パクするため、配信やデモ、ブラウザ常駐の演出に使いやすいです。

目立つポイント

「ぐるぐる」と「トーク」を分けているので、見せたい動作に応じて使い分けやすいのが特徴です。Node.js 22 LTS 推奨、Vite 8 前提の構成で、Windows では start.bat からそのまま立ち上げられます。

セットアップや使い方の流れ

まず npm install を実行し、Windows なら start.bat、手動なら npm run dev で起動します。トーク版は http://127.0.0.1:5173/talk.html、ぐるぐる版は http://127.0.0.1:5173/guruguru.html で開きます。

どんな人向けか

自分のキャラクターをブラウザで動かしたい人、配信やデモで軽いアバター表示を使いたい人、マウス追従や口パクの挙動を素早く試したい人に向いています。

注意点

マイク入力は localhost または HTTPS でしか使えません。Google Fonts を CDN から読むため、初回表示ではネット接続が必要です。

まとめ

見た目の動きが分かりやすく、導入も軽いブラウザアバターです。トマリの表示を手早く動かしたい用途に合っています。
