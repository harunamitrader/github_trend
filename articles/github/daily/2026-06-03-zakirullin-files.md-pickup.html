これは何か

files.md は、web/index.html から開けるブラウザベースのローカルファーストな Markdown アプリです。README では、メモ、ドキュメント、日記、チェックリストを「端末の上の plain .md ファイル」として扱う設計だと説明されています。

何ができるか

チャット入力から思考をそのまま書き込み、あとで Note、Journal、Tasks、Checklists に振り分けられます。さらに、ローカルフォルダ、iCloud / Dropbox / Google Drive、セルフホストの同期サーバー、ホスト型サーバーという複数の同期方法を選べます。

目立つポイント

インストール不要で、オフラインでも使える点が大きいです。コードベースを小さく保ち、「一人か LLM で全体を把握できる」ことを強く意識しているので、重たい PKM ツールよりも軽い思考補助として使いやすい作りです。

セットアップや使い方の流れ

まず app.files.md を開き、右側の "Install files.md" を押します。次に保存先のローカルフォルダを開き、必要なら同期方式を選びます。入力は Cmd+Enter の chat から始めるのが一番わかりやすいです。

どんな人向けか

データを手元に置いたまま、Markdown で軽く記録したい人に向いています。Second Brain を盛りすぎず、ノート、タスク、日記を最小限の導線で回したい人とは相性が良いです。

注意点

README でも触れられている通り、Chrome 系ブラウザの File System API が一番扱いやすいです。機能はシンプルですが、同期方式やファイルの置き方を理解して使う前提なので、最初から複雑な構成にしすぎない方が運用しやすいです。

まとめ

files.md は、Markdown ファイルを中心に「記録」と「思考」をつなぐための軽い基盤です。データをローカルに置きつつ、必要なら同期や bot 連携も使いたい人に合います。
