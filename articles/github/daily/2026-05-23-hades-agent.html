これは何か

Hades Agent は、Electron と Gemini Live API で作られたデスクトップ AI コンパニオンです。README では 「invisible, ultra-fast desktop companion」と説明されており、画面上に常駐しながら音声、検索、記憶を まとめて扱う用途に寄せられています。

何ができるか

Alt+D で出る Spotlight Command Bar から、リアルタイムのインターネット参照付き回答を呼び出せます。 Alt+B では PC 内部音声を 16 kHz PCM で Gemini Live API に流し、会議や動画の文字起こしをすばやく 行えます。

さらに、Session MiniChat で現在のモデルやトークン消費を見ながら会話でき、バックグラウンドでは Dream Memory Consolidation が会話ログを要約して `learnings.json` に圧縮します。 予定管理も Safe Task Scheduler で分離されているため、UI とバックグラウンド処理の役割分担が明確です。

目立つポイント

一番の特徴は、`setContentProtection` を使った Anti-Recording Shield です。README 上では OBS、 Discord、Teams、Zoom などの画面キャプチャから見えない設計とされており、プライバシー重視の常駐 AI として 独自性があります。

もう一つは、見えている UI を薄く保ちながら、裏側でメモリ整理とタスク予約を進める構成です。 単なるチャットアプリではなく、常駐型の作業補助に寄せている点が分かりやすいです。

セットアップや使い方の流れ

ユーザー向けには Releases から Windows 用インストーラを入れて起動し、Alt+S で API キーを入力する流れが 案内されています。開発者向けには `git clone` の後に `npm install`、`npm run dev` で Electron と Vite を同時に立ち上げます。

使う前提として Google Gemini API Key と Tavily Search API Key が必要です。検索と推論の両方を外部 API に 依存するので、導入時はこの 2 つを先に用意しておくのが前提です。

どんな人向けか

会議音声の文字起こし、画面を見せずに使う AI 補助、常駐型の検索バーをまとめて使いたい人に向いています。 とくに、業務画面の共有中でも見せたくない情報を扱う人には、設計意図がはっきりしています。

注意点

README では Windows 10 での検証のみが案内されており、Windows 11 は未検証、macOS と Linux は非対応です。 また、動作には Gemini と Tavily の API キーが必要で、完全ローカル完結のツールではありません。

まとめ

Hades Agent は、常駐型デスクトップ AI を「見えないこと」と「音声・検索・記憶の分離設計」でまとめた ツールです。画面共有や会議補助を含む実務で、プライバシーを意識しながら使いたい場合に検討しやすい リポジトリです。
