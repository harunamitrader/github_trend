これは何か

croc は、あらゆるコンピュータ間でファイル、フォルダ、またはテキストを直接かつ最も安全に転送するために開発された、Go言語製のオープンソース CLI ユーティリティです。

何ができるか

PAKE (Password-Authenticated Key Exchange) アルゴリズムを用いた強固なエンドツーエンド暗号化により、転送データを保護します。ネットワークのポート開放（ポートフォワーディング）やローカルサーバー構成、複雑な接続設定を行わずに、自動で用意されるパブリックリレーを中継して高速に転送を確立できます。

目立つポイント

通信の切断などで転送が中断された場合でも、その途中から再開できる「レジューム機能」を標準でサポートしています。また、Tor プロキシ経由の通信や、複数ファイル・複数フォルダの一括送信に対応しており、独自の中継（Relay）サーバーをプライベート環境に構築して自己ホストすることも可能です。

セットアップや使い方の流れ

macOS では brew install croc、Windows では winget install croc や scoop install croc、Linux ではインストール用スクリプト (curl https://getcroc.schollz.com | bash) を用いて導入します。送信側が croc send [ファイル名] を実行して発行されたワンタイムフレーズコードを、受信側が croc [コード] と入力するだけで転送が開始されます。

どんな人向けか

異なるOS（Mac、Windows、Linuxなど）の端末間で、USBメモリや外部のクラウドストレージを使わずに素早くセキュアにファイルを移動させたいエンジニアや、社内ネットワークや閉域網でセキュアな転送手段を求めているチーム向けです。

注意点

転送用の共有フレーズコードを何らかの方法で相手に伝える必要があります。また、リレーサーバー経由での接続確立がファイアウォール設定等で阻害される場合は、自己ホストサーバーの構築が必要になることがあります。

まとめ

croc は、暗号化による究極のセキュリティを維持しつつ、「コードを入力するだけ」という最小のアクションでクロスプラットフォーム超高速転送を実現する、コマンドライン時代の傑作転送ツールです。
