これは何か

Hivemind は、複数の AI エージェントにまたがる会話、ツール操作、結果を Deeplake に構造化トレースとして保存し、共有の記憶層として再利用する TypeScript 製の基盤です。README では、個々のエージェントを賢くするだけでなく、チーム全体に学習を波及させる設計を前面に出しています。

何ができるか

セッションを記録し、BM25 と埋め込み検索で探し、そこから得たパターンを SKILL.md に落として別のエージェントへ配布できます。記憶、検索、要約、共有の流れが一体化しているので、エージェント運用の属人化を減らしやすいです。

目立つポイント

Claude Code、OpenClaw、Codex、Cursor、Hermes、pi を横断サポートし、リアルタイムで能力を伝播できるのが強みです。LoCoMo ベンチマークでは、共有記憶なしより 25% 安く、1.7 倍少ないトークンで、31% 少ないターンで回答できたと README にあります。

セットアップや使い方の流れ

npm でグローバルインストールして hivemind install を実行するだけで導入できます。CI や headless 環境ではトークン指定に切り替え、状態確認は hivemind status、特定エージェントだけに入れるなら hivemind codex install などを使います。

どんな人向けか

複数の AI エージェントをチームで運用したい人、過去の成功パターンを再利用したい人、エージェントの記憶を共有資産にしたい人向けです。

注意点

セッション痕跡を扱うので、保存先と権限設計、機密情報の扱いを先に決める必要があります。自動要約や技能化は便利ですが、誤った抽出や過剰一般化が起こりうるため、重要なものは人手で確認した方が安全です。

まとめ

エージェントの記憶を個人用のログではなくチーム資産に変えるための、かなり実戦寄りの共有脳です。
