これは何か

AIのためにゼロから構築された、オープンソースかつSwift製のmacOSネイティブ動画エディタです。ユーザーとAIエージェントが、タイムライン上で協調して映像を編集・生成できる先進的な動画編集ソフトです。

何ができるか

Swift製ならではのネイティブで高速なタイムライン動画編集（ Premiere Pro にインスパイアされたUI）を提供します。Seedance、Kling、Nano Banana Proなどの最先端（SOTA）モデルを用いた動画・画像生成を、タイムライン上で直接実行可能です。アプリ起動時にMCP（Model Context Protocol）サーバー（http://127.0.0.1:19789/mcp）を自動で公開し、外部のAIエージェント（Claude Code、Codex、Cursorなど）に動画の編集命令を送信させることができます。または、アプリ内に統合された専用の対話型AIエージェントを利用して、同じ編集プロジェクトをリアルタイムで共同編集することも可能です。

目立つポイント

最も革新的なのはMCP（Model Context Protocol）サーバー機能です。これにより、Claude CodeなどのターミナルAIから claude mcp add --transport http palmier-pro http://127.0.0.1:19789/mcp という1つのコマンドを叩くだけで、AIがユーザーのタイムラインを読み取ったり、クリップを挿入したりする「AIによるプログラム可能な動画編集」が実現します。

セットアップや使い方の流れ

macOS 26 (Tahoe) 以上の Apple Silicon搭載Macが必要です。リポジトリのReleasesから .dmg ファイルをダウンロードしてインストールするか、ソースコードからビルドします。アプリを起動し、Claude Code、Codex、またはCursorにMCPサーバーを追加します。タイムラインで動画をドラッグ＆ドロップで編集するか、AIに「〇〇秒目のクリップの明るさを調整して」といった指示を出して編集を実行します。

どんな人向けか

AIエージェントを使った自律的な動画制作ワークフロー（動画の自動カット編集や要約動画作成など）をプログラムしたいエンジニアやクリエイター、タイムラインベースのAI映像生成を効率よく行いたいMacユーザーに向いています。

注意点

動作には比較的新しい macOS 26（Tahoe）および Apple Silicon（Mシリーズチップ）が必須となっており、Intel MacやWindows/Linuxはサポートされていません。また、MCP経由での外部接続には、ローカルポート（19789）のバインドが必要となるため、セキュリティ設定や他のプロセスとの競合に注意してください。

まとめ

「AIと人間が対話的・プログラム的に同じタイムラインを触る」という動画編集の新たなパラダイムを、Swiftネイティブな高品質動作とMCPによる高い結合度で実現した、非常に実験的かつ将来性のあるオープンソース動画編集アプリです。
