これは何か

AgentHub は、1 人でソフトウェア会社のように動くためのハーネス型管理アプリです。README では、47 の AI エージェントを 1 つの Electron アプリから運用し、Claude Code を中心に役割分担と制御を行う構成として説明されています。

何ができるか

プロダクト管理、エンジニアリング、デザイン、マーケティング、テスト、プロジェクト管理、スタジオ運用までを、役割ごとの Agent として整理できます。Task Board、Sessions、Projects、Agents の画面があり、進行状況や担当を GUI で追えるのが実務向きです。

目立つポイント

Hooks で危険操作や品質ゲートをブロックし、Skills で手順を標準化し、FileWatcher で Markdown の変更を即時同期する設計が核です。README では 24 の built-in Skills、6 の Hook templates、G0 から G6 までの quality checkpoints が示されていて、AI を自由に暴れさせるのではなく制約で安定化させる思想がはっきりしています。

セットアップや使い方の流れ

導入には Node.js 18 以上、npm、Claude Code、Git、Python、各種ビルドツールが必要です。`git clone` のあと `npm install`、続けて `bash scripts/install-skills.sh` を実行し、最後に `npm run dev` で起動します。README では、Claude Code の認証とネイティブ依存の準備が最初の関門として明示されています。

どんな人向けか

複数の Claude Code セッションを役割分担させたい人、AI の作業をプロジェクト単位で管理したい人、危険なコマンドや手順逸脱を Hook で止めたい人に向いています。単なる AI チャットではなく、運用の型まで含めて整えたい人向けです。

注意点

このプロジェクトは GUI アプリですが、実際の作業は Claude Code CLI に依存します。さらに、Windows では C++ build tools が必要になるなど、初期セットアップのハードルは低くありません。

まとめ

AgentHub は、AI エージェントを「増やす」だけでなく「統制する」ための基盤です。プロンプトの工夫よりも、ルール・検証・同期を先に置きたい運用に合っています。
