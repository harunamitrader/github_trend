これは何か

AIエージェントやLLM（大規模言語モデル）を組み込んだアプリケーションの稼働状況を監視し、予期せぬエラーや挙動を追跡・分析するためのオープンソースのオブザーバビリティ（可観測性）プラットフォームです。一般的なソフトウェア開発における Sentry のような存在であり、AIアプリケーションの品質管理とデバッグを強力にサポートします。

何ができるか

複数ターンにわたる複雑なエージェントセッションや、外部ツール呼び出し、実行トレース（パス）の可視化。失敗したトレースや不適切な挙動を自動的にイシュー（課題）として集約・グループ化し、対応の優先順位付けとステータス追跡を可能にします。また、人間による評価基準を自動で評価器に反映し（Human-aligned evals）、人間とAIの判断のズレ（アライメントスコア）を追跡することができます。

目立つポイント

問題が発生したトレースを自動的に「イシュー」として分類・整理するイシュー中心（Issue-centric）の管理モデル、全トレースの完全インデックスによる意味・完全一致・類似文章によるセマンティック検索機能、Slackやメール、Webhookへのエスカレーションアラート、さらには Claude Code 等のコーディングエージェントから操作可能な MCP（Model Context Protocol）サーバーの提供が特徴です。

セットアップや使い方の流れ

クラウドホスト版（無料枠あり）を利用する場合は、latitude.so にサインアップし、SDK（TypeScript: @latitude-data/telemetry など）をインストールして API キーを設定します。また、Docker Compose や Kubernetes（Helm chart）、Railway などを通じたセルフホストでの構築にも対応しています。さらに Claude Code 用に専用のテレメトリパッケージ（npx -y @latitude-data/claude-code-telemetry install）も提供されています。

どんな人向けか

本番環境でAIエージェントや複雑なRAG、マルチステップのLLMアプリを運用しており、挙動の不安定さやハルシネーション、予期せぬ例外エラーを可視化して迅速にデバッグ・修復したいエンジニアやプロダクト運用チーム。

注意点

動作ログやトレースなどの監視データを大量に記録・保存するため、セルフホストで運用する場合にはデータベース（ClickHouse等）のストレージ容量やインフラの監視負荷に配慮する必要があります。クラウド版でのデータ保存・転送容量については、無料プランおよび有料ライセンス規約を確認してください。

まとめ

latitude-llm は、従来の Web アプリ開発におけるエラーログ監視の手法をAIエージェント向けに昇華させ、複雑な自律エージェントの動向を正確にトラッキングできるように設計された高度なツールです。イシュー起点での直感的UIに加え、開発者向けエージェントとの MCP 連携や Claude Code テレメトリの提供など、エージェント開発ワークフロー全体にシームレスに組み込める点が非常に優れています。
