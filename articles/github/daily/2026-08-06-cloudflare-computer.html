computer

AIエージェントにSQLiteベースの仮想ファイルシステムと分離されたLinux実行環境を提供するサンドボックス

記事作成日 2026-08-06
種別 Trending Rank 1
対象 repo cloudflare/computer
Star数 2,532

これは何か

CloudflareのDurable Objectsを活用し、AIエージェントにSQLiteベースの仮想ファイルシステムと、完全に分離された軽量なプラッガブル実行環境（Linux FUSEコンテナやJavaScriptアイソレートなど）を提供するサーバーレスサンドボックス。

何ができるか

エージェントがアクセスするワークスペースをSQLite上に永続化して管理します。実行環境として、FUSEマウントを用いて実際のLinux環境をコンテナ化して提供する「Container」、Workers RPC経由でBashを動作させる「Isolate shell」、Dynamic Workerで安全にJavaScriptを評価する「Isolate JavaScript」の3つのバックエンドを利用可能です。

目立つポイント

仮想ファイルシステムの変更履歴やエージェントのアクションをSQLiteで一貫してトラッキングでき、必要に応じてファイルシステムのみの起動や別バックエンドへの切り替えをシームレスに行える点。Cloudflareエッジ上でスケーラブルかつセキュアに動作します。

セットアップや使い方の流れ

npmから @cloudflare/computer パッケージをインストール。Durable Objects構成を設定し、Durable Object内の workspace.runtime.exec(source, { backend }) を呼び出すことで、指定されたJavaScriptモジュールやシェルスクリプトを実行環境上で動作させます。

どんな人向けか

Cloudflareのサーバーレスアーキテクチャ上で、セキュアなコード実行環境やAIアシスタント用の作業仮想スペースを低遅延でホストしたいプラットフォーム開発者やSaaSプロバイダー。

注意点

現在はプレビュー版（PREVIEW ONLY）として提供されており、APIの仕様や内部設計は今後大きく変更される可能性があります。本番環境への直接の導入は推奨されておらず、先行技術検証としての利用に留める必要があります。

まとめ

AIエージェントが本番環境でコードやコマンドを安全に実行するための「エッジ上のセキュアな作業PC」をDurable ObjectsとSQLiteの力で実現する、新機軸のサーバーレス開発基盤です。
