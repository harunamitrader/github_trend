これは何か

「graphify」は、プロジェクト内のソースコード、SQLスキーマ定義、各種スクリプト、技術ドキュメント、論文、さらには関連する画像や動画までを解析し、AIコーディングアシスタント（Claude Code、Codex、Cursor、Gemini CLIなど）が構造的に検索・推論できる「開発用知識グラフ」を全自動で構築する開発ナレッジ抽出ツールです。アプリケーションコードからデータベース、インフラ設計までを1つの有向グラフとしてモデル化し、AIの理解力を底上げします。

何ができるか

本リポジトリは、AIによるソフトウェア開発を加速するための以下の強力な機能を備えています。

  • 統合型知識グラフの構築: コード内の呼び出し関係だけでなく、DBスキーマとの関係、インフラ構成、ドキュメントの記述などを連結した1つの統一グラフを自動構築します。
  • マルチソース解析: テキストコードだけでなく、SQL定義、シェルスクリプト、説明ドキュメント、システム構成画像や解説動画などのマルチモーダルアセットも解析対象に含めることができます。
  • AIコーディング用スキルとしての統合: 構築された知識グラフは、Claude CodeやCursorなどのエージェント向けカスタムスキル（MCP経由など）としてバインド可能で、AIからの高精度なセマンティック検索に対応します。

目立つポイント

最大の特徴は、単なるコードシンボルのインデックス（定義位置の抽出）にとどまらず、設計や運用に関わる「コンテキスト（文脈・意図）」をグラフ接続する点にあります。これにより、AIアシスタントが「このAPIを変更した際、どのDBテーブルや関連ドキュメントに影響が出るか」といった、プロジェクト全体を見渡した高度なインパクト分析を瞬時に実行できるようになります。

セットアップや使い方の流れ

CLIツールとして導入し、プロジェクトのルートディレクトリで実行することでナレッジベースを作成します。主要なAIクライアントのMCPサーバー設定ファイルに登録することで、チャットから直接グラフ検索を実行させることができます。

# CLI ツールのインストール
npm install -g @graphify-labs/graphify

# ナレッジグラフの構築
graphify init ./my-project
graphify build

# MCP サーバーとして起動
graphify serve --mcp

どんな人向けか

AIエージェントを本格的に実業務に導入し、開発プロセスの大部分を自動化したいと考えているソフトウェアエンジニアやアーキテクトに最適です。特に、コードベースが巨大でドキュメントやデータベースとの依存関係が複雑化したレガシーシステムのマイグレーションや、大規模な新規機能開発を進めるチームで絶大な効果を発揮します。

注意点

大量のドキュメントや画像・動画ファイルを解析する際、APIキーを介したモデル利用料金（トークン消費量）やインデックス構築の時間が膨らむ可能性があるため、初回構築時は対象フォルダを絞るなどの適切なフィルタリングが推奨されます。

まとめ

「graphify」は、AIエージェントにプロジェクト全体の広大なコンテキストを与えるための、極めて先進的なグラフベースのセマンティック検索システムです。AIコーディング時代の標準インフラとして、今後の開発効率化を強力に牽引する可能性を秘めたツールです。
