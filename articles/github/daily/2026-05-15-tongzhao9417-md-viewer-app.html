これは何か

Tauri v2 を基盤として開発された、Markdown ドキュメントの「閲覧」に特化したデスクトップアプリケーションです。編集機能を省くことで、バイナリサイズ約 8.6MB という驚異的な軽量さと、高速な起動・描画を実現しています。

何ができるか

ローカルの Markdown ファイルやフォルダをドラッグ＆ドロップで即座に表示できます。VS Code 風のサイドバー、マルチタブ管理、目次（アウトライン）表示といった開発者に馴染みのある UI を備えており、HTML、PDF、DOCX へのエクスポート機能も搭載しています。

目立つポイント

Tauri v2 と Rust による最適化により、システムリソースをほとんど消費せずに動作する点が魅力です。また、学術論文風（Academic）や技術ドキュメント風（Technical）など、読書体験を向上させる独自のテーマエンジンを搭載しています。

セットアップや使い方の流れ

リリースエンジンのバイナリをダウンロードして実行するだけで利用可能です。エディタを開くほどではないが、複雑な構造のドキュメントを整理して読みたい場合に、ファイルをアプリへ放り込むだけで閲覧を開始できます。

どんな人向けか

AI エージェントが生成した大量の Markdown ドキュメントを素早く確認したい開発者や、VS Code を「ビューワー」として使うには重すぎると感じているユーザー、軽量な技術文書閲覧環境を求めている研究者に最適です。

注意点

閲覧専用（Pure Reader）であるため、アプリ内での Markdown 編集機能は提供されていません。修正が必要な場合は別途エディタを使用する必要があります。

まとめ

「読むこと」に徹することで、エディタにはない快適さを実現した秀逸なツールです。AI 時代、テキストベースの情報が爆発的に増える中で、こうした「軽快なビューワー」の価値はますます高まっていくでしょう。
