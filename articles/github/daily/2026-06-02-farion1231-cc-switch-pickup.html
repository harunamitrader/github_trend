これは何か

CC Switch は、Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw、Hermes Agent を一元管理するデスクトップアプリです。README では「All-in-One Manager」として案内されており、複数の AI アシスタントを同じ入口で扱えるのが前提になっています。

何ができるか

プロバイダの切り替え、プロキシやフェイルオーバー、MCP / prompts / skills の管理、使用量とコストの追跡、セッションと workspace の整理までまとめて扱えます。複数の CLI を日常的に使う人には、そのまま運用面の差が出やすい構成です。

目立つポイント

単なるランチャーではなく、接続先の選択と運用管理を一体化している点が特徴です。Tauri ベースで Windows / macOS / Linux に対応しており、ローカルで完結する運用と相性が良いです。

セットアップや使い方の流れ

まずは公式サイトか GitHub Releases から入手し、使いたい provider を登録します。その後、セッションや workspace をつなぎ、必要に応じて MCP や prompt、skill の設定を足していく流れが自然です。

どんな人向けか

複数の AI CLI を毎日切り替える人、プロバイダごとの挙動を見比べたい人、セッションやコストを横断して見たい人に向いています。個別のツールをバラバラに管理したくない場合に効きます。

注意点

統合アプリなので便利ですが、実際の認証や各 provider の挙動は元ツール側に依存します。公式サイトは ccswitch.io とされているため、導入時は配布元を確認してから使うのが安全です。

まとめ

cc-switch は、複数の AI コーディング/エージェント CLI をまとめて運用するための実用ハブです。ツールを増やすほど管理が散らかりやすい人に、かなり刺さるタイプの repo です。
