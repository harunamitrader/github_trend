これは何か

claude-videoは、Claude Codeやその他のCLI型AIエージェントが動画アセットを直接理解し分析できるようにするためのオープンソースのスキル・拡張ツールです。通常はテキストと一部画像に制限されているAIエージェントに対して、動画ファイル（またはYouTube等のリンク）を渡すことで、内部で自動処理を行い、視覚（静止画フレーム）と聴覚（音声文字起こし）の両面から動画を「視聴」する機能を提供します。

何ができるか

開発者やAIエージェントが特定の動画について質問を投げると、本スキルが動画ファイルを自動ダウンロードし、フレームレートに応じたキーフレーム（静止画）の抽出と、音声トラックの切り出し・Whisper等による高精度文字起こしを順次実行します。処理されたマルチモーダルデータはAIエージェントのコンテキストに集約され、動画全体の要約、特定シーンの発生タイミング、会話内容の検索と分析が可能になります。

目立つポイント

FFmpegなどの強力なメディア処理ツールとAIエージェントの対話用APIをスムーズに架け橋し、完全に非対話（Headless）またはコマンドラインから一貫して実行できる点です。動画解析のためだけにブラウザや専用のWebインターフェースを開く必要がありません。

セットアップや使い方の流れ

プロジェクトをクローンし、`python -m pip install -r requirements.txt` で依存関係をインストールします（FFmpegがシステムにインストールされている必要があります）。Claudeのカスタムスキル定義フォルダに統合した上で、`claude-video <video_url_or_filepath>` という形でコマンドを実行して使用します。

どんな人向けか

AIエージェント（特にClaude Code）を用いた開発プロセスの自動化を進めており、講義動画、ゲームプレイのキャプチャ、UIテストの動画ログ、プロダクトデモ映像などをコマンドラインから直接AIに要約・テスト・分析させたいエンジニアやクリエイターに向いています。

注意点

動画のサイズや長さによっては、フレーム抽出処理や文字起こしに相応のマシンパワーと実行時間がかかります。また、生成されるコンテキストデータ（大量の抽出画像と長文の文字起こし）が膨大になるため、AIのコンテキスト制限（Token Limit）やAPIの消費コスト管理に注意する必要があります。

まとめ

claude-videoは、コマンドラインAIエージェントの認識限界を「動画メディア」にまで広げる画期的なスキル統合ツールです。動画の目視確認や手作業の書き起こしを自動化し、メディア分析の生産性を極限まで高めてくれます。
