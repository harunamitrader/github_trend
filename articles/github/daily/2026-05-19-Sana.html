Sana

これは何か

NVIDIA LabsとMIT等の研究チームが主導して開発する、極めて効率的かつ高性能な高解像度画像・動画生成のための拡散モデル（Diffusion Models）のコードベースおよびモデルファミリーです。従来の重厚な画像生成AIモデル（FLUXなど）に匹敵する極めて高品質な表現力を維持しながら、モデルサイズを約20分の1に縮小し、最大100倍という圧倒的な超高速推論を実現する画期的なアーキテクチャを備えています。

何ができるか

テキストプロンプトからの超高画質な画像生成（最大4K解像度）に加え、短いアイディアやシナリオからの一貫性のある動画生成、6自由度（6-DoF）のカメラ制御を備えた minute-scale（分単位）のワールドモデル構築（SANA-WM）、および一ステップまたは数ステップの推論で画像を出力する蒸留モデル（SANA-Sprint）など、画像および動画生成に関わる統合的なパイプラインをローカル環境で動かすことができます。

目立つポイント

以下の2大コア技術が圧倒的な高効率を支えています。

  • Linear Attention (線形注意機構): 従来のDiT（Diffusion Transformer）で解像度の二乗比例で計算コストが爆発していた自己注意機構を、解像度に対して線形でスケールする線形アテンションに置き換え、4K画像や長尺動画の推論負荷を大幅に削減。
  • DC-AE (Deep Compression Autoencoder): 従来のVAEの8倍圧縮に対し、空間情報を32倍に超圧縮する独自のオートエンコーダー。これにより潜在トークン数を極限まで減らし、驚異的な処理速度を実現。

セットアップや使い方の流れ

リポジトリをクローン後、付属の `environment_setup.sh` を使用して簡単に依存関係を構築できます。Hugging Face上に公開されているトレーニング済みチェックポイントを読み込み、Pythonの `diffusers` ライブラリ（`SanaPipeline`）経由で数行のコードを記述するだけで、RTX 4090環境では0.3秒以下、ハイエンドのH100環境ではわずか0.1秒で1024pxの高精細画像を生成可能です。また、ComfyUIやSGLangでのサービングも公式サポートされています。

どんな人向けか

ローカル環境のGPUリソース（ノートPC等の8GB VRAMなど）で最先端の高品質な生成AI画像を高速に作成したいクリエイター、推論性能と省メモリ特性を極限まで両立させたいゲーム開発者、動画生成やワールドモデリング（Embodied AI・世界モデリング）の研究を進める学術・産業界の技術者に最適です。

注意点

線形アテンションと極端な空間圧縮（DC-AE 32x）を採用しているため、非常に微細なテキストのスペル描画など、極小領域のディテール再現において標準的なDiTモデルと特性が異なる場合があります。また、4ビットや8ビット量子化による8GB VRAM未満での動作が可能ですが、量子化手法（SVDQuant等）の適切な導入が必要です。

まとめ

NVlabs/Sanaは、「高性能な画像・動画生成には巨大なGPUサーバーと膨大な推論時間が必要である」というこれまでの常識を、アテンションの線形化と画期的なエンコーダー技術によって根本から覆すマイルストーンです。オープンソースとしてApache 2.0ライセンスで提供され、超高速なクリエイティブイテレーションを個人デスクトップ環境で実現できるという点で、画像生成AIの民主化を真に推し進める驚異的なプロジェクトと言えます。
