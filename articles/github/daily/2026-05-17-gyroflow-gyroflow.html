これは何か

Gyroflow は、カメラ内蔵のジャイロスコープ（角速度計）のデータを利用して、後処理で動画の手ぶれを補正するツールです。一般的な画像解析による補正とは異なり、センサーの物理的な動きを元にするため、非常に高い精度で滑らかな映像を作り出すことができます。

何ができるか

FPV ドローン、GoPro、SONY α シリーズなど、ジャイロログを記録できるあらゆるカメラの映像を補正できます。手動での調整はもちろん、レンズプロファイルに基づいた歪み補正や、地平線維持（Horizon Lock）などの高度な機能も備えています。

目立つポイント

完全にオープンソースであり、Windows, macOS, Linux に加えて Android/iOS でも動作するマルチプラットフォーム対応が特徴です。また、GPU 加速による高速なレンダリングが可能で、4K や 5K といった高解像度の動画もストレスなく処理できます。

セットアップや使い方の流れ

公式サイトまたは GitHub の Releases からインストーラーをダウンロードして実行します。使い方はシンプルで、動画ファイルを読み込むと、対応していれば自動的にジャイロデータがロードされます。あとはプレビューを見ながら補正強度を調整し、書き出すだけです。

どんな人向けか

FPV ドローンレーサー、シネマティックな映像を撮りたいクリエイター、そして高価なジンバルを使わずに手持ち撮影のクオリティを上げたいビデオグラファーに最適です。

注意点

補正の精度は、カメラから取得できるジャイロデータの正確性と、レンズプロファイルの適合性に依存します。また、大幅な補正を行う場合は、映像がクロップ（切り抜き）されるため、撮影時に少し広めの画角で撮っておく必要があります。

まとめ

Gyroflow は、センサーデータの活用という物理的なアプローチで動画編集の常識を塗り替えた傑作ツールです。手ぶれ補正の限界に挑戦したいすべてのクリエイターにとって、必携の選択肢となるでしょう。
