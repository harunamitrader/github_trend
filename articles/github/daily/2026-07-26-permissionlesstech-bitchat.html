これは何か

BitChat は、中央集権的なサーバー、電話番号の登録、あるいはインターネット接続すら必要としない、完全分散型のピア・ツー・ピア（P2P）メッセージングアプリケーションです。主に近距離での Bluetooth メッシュネットワークと、長距離インターネット接続時の Nostr プロトコルをハイブリッドで動作させます。

何ができるか

インターネットが遮断された環境や災害地において、近くのデバイス同士が Bluetooth Low Energy（BLE）を介してメッシュ状に繋がり、メッセージをバケツリレー式に中継（マルチホップ）して相手に届けることができます。ネット接続が回復すると、自動的に Nostr リレーを介したグローバルな暗号化チャットへと切り替わります。

目立つポイント

IRC スタイルのコマンドベースインターフェース（/join や /msg など）を搭載しており、電話番号やメールアドレスなどの永続的 ID は一切不要です。通信はエンドツーエンドで暗号化（メッシュ上は Noise Protocol、Nostr 上は NIP-17 を採用）されており、端末のトリプルタップによるローカルデータの完全消去（Emergency Wipe）にも対応しています。

セットアップや使い方の流れ

Android ユーザーは GitHub の Releases ページから提供される APK ファイルをダウンロードして「提供元不明のアプリのインストール」を許可して導入します。iOS/macOS については App Store や TestFlight 経由で展開されています。また、ターミナル上で動作する Rust 製クライアント `bitchat-tui` を Cargo などを通じて導入することも可能です。

どんな人向けか

通信インフラが脆弱な山間部や災害被災地、または大規模な通信障害時のバックアップ連絡手段を求めるユーザーに最適です。また、中央集権的な監視や検閲を回避し、最高レベルの匿名性とオフライン性能を求めるセキュリティ重視のエンジニアやアクティビストにも向いています。

注意点

現時点ではセキュリティ専門家による十分な外部監査が行われていない実験的ソフトウェアです。機密度の極めて高い通信に依存することは推奨されません。また、一部の国や地域においては、インターネット検閲や監視を容易にバイパスする性質から法的な配布規制やリポジトリの削除要請などの対象となるリスクがあります。

まとめ

BitChat は、Bluetooth メッシュによる物理的な近接通信と Nostr によるインターネット通信をシームレスに統合し、インフラのない状況でもメッセージングを維持できる革新的な P2P チャットです。堅牢な検閲耐性を備えたオフラインメッセージングの新たなマイルストーンとなるポテンシャルを秘めています。
