これは何か

odysseus は、ChatGPT や Claude に近い UI 体験を自分のハードウェア上で再現することを目指した self-hosted AI workspace です。README では local-first、privacy-first を前面に出し、手元のデータで動かす前提が明確です。

何ができるか

Chat でローカルモデルや API と会話でき、Agent では MCP、web、files、shell、skills、memory を使って実作業を任せられます。Deep Research は複数ソースを集めて要約し、Compare ではモデル比較もできます。

目立つポイント

Cookbook が付いていて、手元のハードウェアをスキャンしながら VRAM やモデルの適性を見て選びやすいのが特徴です。単なるチャット画面ではなく、モデル選定から実行、比較までをひとつの workspace にまとめています。

セットアップや使い方の流れ

まずは公式サイトと README の install / quick start を見て、対応バックエンドをひとつ選びます。その後、Chat か Agent から始めて、必要に応じて Deep Research や Compare に広げるのが自然です。

どんな人向けか

クラウド依存を減らして AI ワークスペースを自前で持ちたい人、複数のモデルを手元で使い分けたい人、作業の流れを Chat / Agent / Research に分けて整理したい人に向いています。

注意点

self-hosted なので、モデル性能だけでなく GPU、メモリ、接続先の整備がそのまま体験差になります。自由度は高い一方で、安定運用には環境づくりが必要です。

まとめ

odysseus は、ローカル主体で AI workspace を組みたい人にとってかなり分かりやすい入り口です。Chat、Agent、Research を一体で回したいなら、実用候補として強い repo です。
