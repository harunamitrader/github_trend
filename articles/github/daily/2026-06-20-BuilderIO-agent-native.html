これは何か

自律エージェントとリッチなWeb UI（ユーザーインターフェース）を統合した「エージェント・ネイティブ」なアプリケーションを構築するためのオープンソースフレームワークです。人間とAIエージェントが、同一のアプリケーション上で対等な編集者として共同作業できる環境を提供します。

何ができるか

エージェントとUIが同じデータベースおよびState（状態）をリアルタイムで共有し、どちらの変更も即座に画面へ反映されます。CRDT（衝突のない複製データ型）によるマージやライブプレゼンス（カーソル移動、選択リング、他の人がどのコンポーネントを見ているか等）をサポートし、リアルタイムマルチプレイヤーで共同編集できます。ユーザーごとにカスタマイズ可能なSQLバックエンドのワークスペースを提供し、個別のスキル、メモリ、指示、MCP（Model Context Protocol）サーバーを設定可能です。A2A（Agent-to-Agent）でのエージェント間通信をサポートし、異なるアプリ上のエージェントが互いを発見して連携アクションを実行できます。

目立つポイント

最もユニークな特徴は「UI操作とチャットでの指示が等価である」という設計思想です。ボタンをクリックして要素を動かすことも、AIに指示して動かすこともでき、すべてが同一のデータ上で瞬時に同期します。ヘッドレスAPI、リッチチャット、あるいはフルUIアプリといった3つの形態にシームレスに展開できる汎用性の高さも魅力です。

セットアップや使い方の流れ

Node.js環境でプロジェクトを用意します。リポジトリをクローンまたは依存関係をインストールします。Drizzle ORMがサポートするSQLデータベース（SQLite、Postgresなど）と、Nitroがサポートするホスティング環境を設定します。Dispatch構成を記述し、vaultに認証情報を保存してアプリからエージェント実行を開始します。

どんな人向けか

AIエージェントを自社サービスに組み込んで、ユーザーとAIがシームレスに共同編集するリッチなSaaSを作りたいWebエンジニアやプロダクトデザイナー、CursorやClaude Codeのような高度な自律的編集ワークフローを自前のWebアプリとして提供したい開発者に適しています。

注意点

リアルタイム同期やCRDTマージを使用するため、接続するデータベースの設定や接続状態の管理に注意が必要です。また、実運用時にはエージェントの実行コストやAPIのレートリミットを考慮したDispatch管理（vault内のシークレットやクレジット制限）が必須となります。

まとめ

「AIと人間が同じキャンバスで協働する」という未来のWebアプリケーションのあり方を提示する、強力なリアルタイム同期機能と拡張性の高いMCPサポートを兼ね備えた、極めて先進的なエージェント連携フレームワークです。
