dots.ocr

RedNote AI Labが開発した、多言語対応の次世代OCR・レイアウト解析ツール。チャートやグラフィックを直接SVGに変換する強力な機能と、3Bパラメータという軽量ながらSOTAの性能を両立。

これは何か

「小紅書（XiaoHongShu）」のAI Labが開発した、ドキュメント解析と文字認識に特化したVision-Language Model (VLM) です。現在は dots.mocr としても知られており、画像やPDFに含まれるテキストだけでなく、レイアウト構造やグラフィック要素までを高度に理解し、構造化データとして抽出することを得意としています。

何ができるか

人類が使用するほぼ全ての言語体系に対応したOCR機能に加え、特に「dots.mocr-svg」モデルでは、画像内のチャートやダイアグラムを解析し、そのまま編集可能な SVGコード へと変換することができます。また、vLLMなどの高速推論エンジンに対応しており、ドキュメントの大量処理にも適しています。

目立つポイント

3B（30億）パラメータという、現代のVLMとしては比較的軽量なサイズでありながら、ベンチマークにおいて巨大なモデルを凌駕するSOTAの性能を叩き出している点が驚異的です。特にレイアウト解析の精度が高く、単なる文字の羅列ではなく「表」や「図」として情報を再構成できるため、RAG（検索拡張生成）のデータ前処理としても非常に強力です。

セットアップや使い方の流れ

Hugging Faceからモデルの重みをダウンロードし、TransformersライブラリまたはvLLMを使用して起動します。Pythonスクリプトから数行で画像を読み込ませ、JSON や Markdown、あるいは SVG 形式での出力を得ることが可能です。公式リポジトリには推論用のサンプルコードが充実しています。

どんな人向けか

ドキュメントのデジタル化（Digitization）を推進しているエンジニアや、画像ベースの情報をAIに読み込ませるための高精度なパーサーを探している開発者に最適です。また、画像内のグラフをベクターデータとして抽出したいデザイナーやリサーチャーにとっても、唯一無二のツールとなるでしょう。

注意点

モデルはMITライセンスで公開されていますが、商用利用の際は開発元であるRedNoteのガイドラインを適宜確認することをお勧めします。また、日本語の認識精度も高いですが、手書き文字や極端にノイズの多い画像では、適切な前処理が推奨されます。

まとめ

dots.ocr は、OCRの枠を超えて「ドキュメントを構造的に理解する」次世代のスタンダードを予感させるプロジェクトです。特に図表のベクター化（SVG変換）機能は、今後のマルチモーダルAI活用の幅を大きく広げるキーテクノロジーとなるでしょう。
