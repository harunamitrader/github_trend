これは何か

Jellium Desktopは、オープンソースのメディアサーバー「Jellyfin」に接続して各種動画や音楽コンテンツを視聴するための、非公式（サードパーティ製）軽量デスクトップアプリケーションです。

何ができるか

CEF (Chromium Embedded Framework) によるスムーズなWeb UI表示と、強力なオープンソースメディアプレイヤーエンジン「mpv」を統合したハードウェアアクセラレーション再生、高精度な字幕・音声トラック切り替えに対応しています。

目立つポイント

Linux (AppImage, Flatpak, AUR)、macOS (Apple Silicon / Intel)、Windows (x64 / arm64) といった主要デスクトップOSを幅広くサポートし、ブラウザ再生にありがちなトランスコード発生を抑えたネイティブ再生機能が特長です。

セットアップや使い方の流れ

GitHubのReleasesまたはNightlyビルドリンクから自身のOSに合ったインストーラーや実行ファイルをダウンロードして起動します。初回起動時に自身のJellyfinサーバーのURLとログイン情報を設定します。

どんな人向けか

自前でJellyfinメディアサーバーを運用しており、PCやMac上でブラウザを介さずにネイティブな操作感と安定した高画質再生を楽しみたいメディア愛好家やLinux/Macユーザーに向いています。

注意点

Jellyfin公式の公式デスクトップクライアント（Jellyfin Media Player）とは異なる個人開発プロジェクトです。macOS環境では初回起動時に隔離属性（quarantine）の解除コマンド実行が必要になる場合があります。

まとめ

Jellium Desktopは、CEFとmpvの組み合わせによりJellyfinの視聴体験を非常に快適にする期待のデスクトップクライアントです。各種プラットフォーム対応の軽快さが評価されています。
