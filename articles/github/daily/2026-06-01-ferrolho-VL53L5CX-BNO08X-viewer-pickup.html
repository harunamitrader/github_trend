これは何か

VL53L5CX-BNO08X-viewer は、VL53L5CX の 8x8 時間差測距センサーと BNO08X 系 IMU を組み合わせて、周囲の距離情報を 3D 点群として見せるリアルタイムビューアです。README では、センサーの測定値をそのまま眺めるだけでなく、姿勢追跡と合わせて空間の形を把握できる点が前面に出ています。

何ができるか

64 ゾーンの測距結果を 3D の ray として表示し、IMU の向きに合わせて視点を回せます。平面検出、ノイズ平滑化、マッピングモードもあり、単発の可視化だけでなく、環境の形を追いながら記録する用途にも使えます。

目立つポイント

ESP32、VL53L5CX、BNO085 という比較的手に入りやすい構成で、約 30 ドル前後の部品費を想定しているのが実用的です。Python 側の viewer と Arduino ファームウェアが分かれているので、センサー処理と可視化を切り分けて理解しやすいです。

セットアップや使い方の流れ

まず ESP32 側のファームウェアを Arduino CLI でビルドして書き込み、そのあと Python の依存を入れて viewer を起動します。起動後はブラウザでローカルの表示画面を開き、シリアル経由で届く距離データと姿勢情報を確認します。

どんな人向けか

ToF センサーや IMU を使って空間計測を試したい人、3D 可視化のデモを短く作りたい人、ハードウェアと Python をまたいだ最小構成を参考にしたい人向けです。教育用のプロトタイプとしても扱いやすいです。

注意点

ハードウェア前提なので、配線、I2C バス、シリアルポート、書き込み環境の確認が必要です。測距精度や見え方は周囲の反射特性に左右されるため、ソフトだけでなく設置条件も調整しないと結果が安定しません。

まとめ

VL53L5CX-BNO08X-viewer は、安価なセンサー構成で 3D 点群ビューを試せる実用的なサンプルです。距離計測と姿勢追跡を組み合わせて、環境の形をその場で確認したいときに向いています。
