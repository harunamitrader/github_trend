site2cli

Web ページを Markdown に変換してターミナルで読むための、シンプルかつ高速な CLI ツール

これは何か

任意の URL から Web ページのコンテンツを取得し、人間や AI が読みやすい Markdown 形式に変換して標準出力する CLI ツールです。ブラウザを開くことなく、ターミナル上で情報を素早く確認することに特化しています。

何ができるか

HTML をパースして不要なタグを除去し、純粋な記事内容を Markdown として抽出します。site2cli <URL> というワンコマンドで、複雑な Web ページをテキストベースのドキュメントとして取得できます。

目立つポイント

JavaScript を実行しない軽量な設計により、非常に高速に動作します。また、生成される Markdown は構造化されているため、そのままエディタで編集したり、AI エージェントへの知識ソースとしてパイプで渡したりするのに非常に適しています。

セットアップや使い方の流れ

Go 製のツールとして、go install github.com/lonexreb/site2cli@latest でインストール可能です。実行時は site2cli https://example.com のように URL を引数に渡すだけで、Markdown が出力されます。

どんな人向けか

ターミナル中心のワークフローを好む開発者や、AI エージェントに Web の最新情報を効率よく提供したいエンジニアに最適です。

注意点

JavaScript を多用する動的なページ（SPA 等）では、初期ロード時の HTML のみが対象となるため、期待通りの内容が取得できない場合があります。

まとめ

site2cli は、「Web 情報をテキストとして所有する」ための最もシンプルで確実な手段の一つです。AI 時代における情報収集のパイプラインとして重宝するでしょう。
