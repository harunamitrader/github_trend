これは何か

AIエージェント（特に terminal 上で動く Claude Code 等）の出力結果における無駄な挨拶や冗長な接続詞（filler tokens）を極限までカットするためのプロンプトスキル/プラグインです。AIに「洞窟原人（Caveman）」のように極度に要約された簡潔な口調を強制することで、回答のコードやコマンド精度を完璧に保ったまま、出力トークン数を劇的に削減します。

何ができるか

Claude Code, Codex, Gemini CLI, Cursor, Windsurf などの30以上のAIコーディングアシスタントに対応し、出力トークンを平均して65%削減できます。コードブロックやエラー出力、実行コマンドそのものは1バイトも改変されず、それらを説明する「人間のためのお喋り」部分だけが「Brain big. Mouth small.」のような短い英語（または日本語）へ圧縮されます。

目立つポイント

「why use many token when few token do trick（なぜ多くのトークンを使う？少しで足りる）」という原人の思考コンセプトをそのままプロンプトのインストラクションに落とし込んだ点です。無駄な文脈の生成を抑えることで、APIの利用コストを大幅に節約できると同時に、生成スピード（Time to First Token以降の応答完了時間）も体感で大幅に高速化します。

セットアップや使い方の流れ

各エージェントのスキル設定フォルダ（例: Claude Code の場合は .claude/skills/）に、このリポジトリの skill ファイルを配置（またはインポート）します。特別なセットアップは不要で、一度導入すれば、その後のエージェントの返答が自動的に原人の口調になります。

どんな人向けか

Claude Code や Cursor などの商用APIキーを使い、トークン消費による課金コストを限界まで削減したい開発者、またエージェントからの「よろしくお願いします」といった定型句に飽き、素早く結果（コードやコマンド）だけを得たい実用主義的なエンジニア向けです。

注意点

出力される解説テキストが非常にぶっきらぼうで文法的に崩れたもの（例: 「Error fix. Run again.」など）になるため、AIに対して丁寧な解説や初心者向けの分かりやすいドキュメント作成を求めている場合には、このスキルをオフにするか、対話レベルを調整する必要があります。

まとめ

AIの回答品質はそのままに、出力フォーマットを強制要約するだけでコストを6割以上削るという、極めて実用的でウィットに富んだオープンソースハックです。
