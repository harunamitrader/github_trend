これは何か

Super Hermes は、Hermes Agent に「どう考えるか」を教えるための skills 集です。README では、エージェント自身が分析用のプロンプトを組み立てる前提になっていて、受け身の補助ではなく思考手順の拡張に近い設計です。

何ができるか

`/prism-3way` のような複数視点分析や、`/prism-reflect` のような差分を浮かび上がらせる処理を通じて、対象を多角的に見られるようにします。単に文章を出すのではなく、分析の質を揃えるところに価値があります。

目立つポイント

「Proven Prisms」が同梱されていて、すぐ試せるのが強みです。Try it now と Try it with Hermes の両方があるので、実際の Hermes 環境がなくても挙動を確認しやすくなっています。

セットアップや使い方の流れ

まずは同梱された prism を試し、必要なら Hermes 本体に入れて動かします。README の流れは短く、スキルを読み込んでから分析対象を渡すだけなので、導入のハードルは低めです。

どんな人向けか

エージェントに一段深い分析をさせたい人、あるいは自分のプロンプト設計を再利用可能な形にまとめたい人向けです。要件分解や比較検討のような、視点の抜け漏れを減らしたい場面に合います。

注意点

分析を多角化できるぶん、出力が増えすぎることがあります。使う場面を決めずに広く入れると、逆に判断が遅くなるので、対象タスクを絞って使うほうが実用的です。

まとめ

Super Hermes は、エージェントに分析の型を渡すための軽量な skills 集です。複雑なテーマを、複数視点でさばきたいときに効くタイプの拡張です。
