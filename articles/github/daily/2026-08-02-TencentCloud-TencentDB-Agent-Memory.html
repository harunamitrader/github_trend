TencentDB-Agent-Memory

AIエージェントのトークン消費を最大61%削減し、会話・知識を階層的に管理するチーム向けメモリハブ

これは何か

AIエージェントやフレームワーク向けに設計された、チームレベルの統合メモリ管理プラットフォーム。会話履歴やソースコード、ドキュメントを記号的・階層的な再利用可能資産として保持・管理します。

何ができるか

複雑なツールログをMermaid形式等の記号的な短期メモリに圧縮して文脈（コンテキスト）トークンの消費を抑えるとともに、長期メモリを階層化されたペルソナやシーンとしてベクトルストレージ等へ適切に格納します。OpenClawやHermesと容易に統合できます。

目立つポイント

記号的な短期メモリと階層化された長期メモリの協調。検証データにおいて、OpenClaw統合時のコンテキストトークン消費量を最大61.38%削減し、タスク成功率を51.52%（相対値）向上させた高い実用性。

セットアップや使い方の流れ

Node.js 22環境に対応し、@tencentdb-agent-memory/memory-tencentdb をnpm経由等でインストールしてプロジェクト内でインポートして使用。OpenClawなどのエージェントGatewayのプラグインとして設定ファイル（yaml/json）を通じて読み込ませることができます。

どんな人向けか

AIエージェントの運用コスト（APIトークン料）に悩む企業・開発者チーム、または長期会話を継続してもコンテキスト崩壊や指示忘れを起こしたくない高機能エージェント開発者向け。

注意点

Node.js v22以上が推奨環境となっており、既存の動作環境のランタイム更新が必要となる場合があります。また、メモリ記号化の処理によるオーバーヘッドが超短文会話では却って無駄になる可能性があります。

まとめ

トークン枯渇と記憶の散乱というAIエージェントの2大課題に対し、階層ストレージと記号的短期記憶のハイブリッド方式で極めて合理的な回答を示したメモリ統合基盤です。
