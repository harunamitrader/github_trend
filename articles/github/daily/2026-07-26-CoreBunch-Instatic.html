これは何か

Instatic は、Webflow、Framer、および WordPress に代わるオープンソースかつセルフホスト型のビジュアル CMS（コンテンツ・マネジメント・システム）です。特に AI エージェントの連携（Agentic 構造）に最適化されており、クリーンな静的 HTML ページを出力します。

何ができるか

視覚的なインターフェースを通じてドラッグ＆ドロップでサイトをデザイン・編集でき、ユーザー権限の管理や、プラグインによる機能拡張、データベース統合に対応した本格的な Web サイトを構築できます。AI エージェント（Claude Code や Codex など）によるブラウザ操作に最適化された連携機能を備えています。

目立つポイント

独自のエージェント型アーキテクチャが最大の特徴で、Model Context Protocol（MCP）および OAuth 設定を標準サポートしており、AI エージェントが直接 CMS のデータストアとやり取りしてコンテンツの生成や変更を行うことができます。また、高速で軽量な SQLite がデフォルトデータベースとして組み込まれています。

セットアップや使い方の流れ

導入は非常にシンプルで、リポジトリをクローンしたのち `bun install` で依存パッケージをインストールし、`bun run dev` を実行するだけでローカル開発サーバー（localhost:5173）が起動します。初回アクセス時にはセットアップウィザードが開き、サイト構成や管理者アカウントの登録が案内されます。

どんな人向けか

デザインから実装、ホスティングまでをセルフホストで行い、ランニングコストを最小化したい Web デザイナーや個人開発者に最適です。さらに、AI エージェントを活用した自動コンテンツ生成や自動 Web サイト更新システムを構築したい開発者にとっても強力なバックエンドになります。

注意点

Bun ランタイムおよび SQLite に依存した設計となっているため、既存の Node.js 向けホスティングサービスで直接運用する場合には事前に実行環境の確認が必要です。また、開発中の機能も多く、プラグインの安定性などについては注意する必要があります。

まとめ

Instatic は、静的ページ出力とビジュアル編集の良さを維持しつつ、AI エージェント時代のワークフローを組み込んだ極めて先進的な CMS です。Web 制作の自律化や個人開発の現場において、今後の成長が大きく期待されるプロダクトです。
