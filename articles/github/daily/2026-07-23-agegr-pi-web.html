これは何か

pi-web は、拡張可能な次世代の自律AIコーディングエージェント「Pi」のセッションを管理・可視化するための、ローカル環境向けのビジュアル Web UI（ダッシュボード）プロジェクトです。

何ができるか

エージェントが行ったすべての会話や操作ログをプロジェクトごとにブラウズできます。リアルタイムチャットに加え、エージェントが作成・編集した HTML ページや画像、PDF、ドキュメントを side-by-side（左右分割画面）で直接プレビューする機能や、進行中のセッションを複製して別のルートで検証する「Fork」機能を備えています。

目立つポイント

ターミナルベース（CLI）の対話だけでは捉えにくかった、エージェントの内部挙動（トークン消費量、累積利用料金、背後のプロンプト命令）をダッシュボード上でグラフィカルに可視化します。さらに、モデルの選択や API キー、実行権限設定なども Web 画面から直接カスタマイズ可能です。

セットアップや使い方の流れ

Node.js環境から、インストール不要のコマンド npx @agegr/pi-web@latest を実行するか、グローバルにインストール (npm install -g @agegr/pi-web && pi-web) します。起動後、ブラウザで http://localhost:30141 にアクセスして操作します。

どんな人向けか

AIコーディングエージェント「Pi」をフル活用して開発を進めたいプログラマーや、ターミナルでのテキストログ追跡に限界を感じており、視覚的かつ構造化された UI で会話分岐やリソース管理を行いたい効率重視の開発者向けです。

注意点

本ツールは「Pi」エージェントの UI コンポーネントであるため、利用にはローカル環境で動作する「Pi」本体や対応する API キー設定が別途必要になります。

まとめ

pi-web は、ターミナルでのAIエージェント開発に強力なブラウザワークスペースを提供し、セッション管理や成果物のリアルタイムプレビューをシームレスにする、自律開発エージェント運用の必須ユーティリティです。
