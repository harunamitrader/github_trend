これは何か

HY-World-2.0 は、テキスト、単一画像、多視点画像、動画を入力にして、編集可能な 3D world を作る Tencent Hunyuan の world model です。README では、再構成は WorldMirror 2.0、生成は HY-Pano 2.0 と WorldStereo 2.0、移動計画は WorldNav という役割分担で整理されています。

何ができるか

単一画像やテキストからナビゲーション可能な 3D 空間を作り、multi-view / video から depth、normal、camera、point cloud、3DGS をまとめて推定できます。Blender、Unity、Unreal Engine、Isaac Sim に持ち込みやすいのが実用面の強みです。

目立つポイント

動画を生成して終わるのではなく、実際に編集・再利用できる 3D 資産を出力する点が大きいです。公式サイト、Hugging Face モデル、技術レポート、デモが揃っているので、研究用途でも追いやすい構成です。

セットアップや使い方の流れ

まず repo を clone して、README 推奨の CUDA 12.8 / Python 3.11+ で conda 環境を作ります。再構成だけ試すなら pip install -r requirements.txt から python -m hyworld2.worldrecon.pipeline --input_path ...、生成まで試すなら requirements_git.txt、submodule、navmesh などの追加依存を順に入れて traj_generate.py から world_gs_trainer.py まで進めます。

どんな人向けか

3D world generation / reconstruction の研究者、デモを早く作りたい人、3D 生成の実装をそのまま追いたい人向けです。まずは WorldMirror 2.0 で再構成を動かし、その後に worldgen を足すと理解しやすいです。

注意点

worldgen まで含めると依存が重く、GPU とディスク容量が必要です。README でも段階的導入を勧めているので、いきなり全部を入れるより、用途を絞って試す方が安全です。

まとめ

HY-World-2.0 は、3D world を生成・再構成・シミュレートまで一続きで扱えるのが魅力です。まずは WorldMirror 2.0 を動かして、必要に応じて WorldStereo 2.0 と WorldNav に広げるのが取り組みやすいです。
