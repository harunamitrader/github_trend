これは何か

agentsview は、coding agents の session intelligence と analytics を扱う local-first ツールです。README では Claude Code や Codex を含む 20 以上の agent を対象にしていることが示され、利用状況を一元的に見るための基盤として設計されています。

何ができるか

インストール後にセッション情報を集め、使ったエージェントや作業履歴を可視化できます。macOS / Linux / Windows をまたいで導入でき、remote forwarded access の導線も用意されています。

目立つポイント

local-first であること、複数エージェントに対応していること、そして ccusage の 100x faster replacement をうたう速度面が目立ちます。単なるログ閲覧ではなく、実運用の観測基盤として寄っています。

セットアップや使い方の流れ

README の Install と Quick Start に沿って導入し、必要に応じて OS ごとの手順を分けて進めます。遠隔アクセスが必要な場合は forwarded access を使い、ローカルで収集したセッションをそのまま確認できます。

どんな人向けか

Claude Code や Codex など複数の coding agent を日常的に使い、利用状況を可視化したい開発者やチーム向けです。

注意点

local-first の前提なので、収集元やアクセス方法を環境ごとに確認する必要があります。実運用では、どの agent の履歴を取り込むかを先に決めておくと混乱しにくいです。

まとめ

複数の coding agent の利用状況をまとめて見たいときに、軽量な観測レイヤーとして使いやすいリポジトリです。
