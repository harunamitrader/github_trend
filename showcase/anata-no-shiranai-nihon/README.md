# あなたの知らない日本

スマートフォン向けの、47都道府県を対象にした4択・ミサイル防衛ゲームです。

## 世界観

敵国から複数のミサイルが発射され、日本各地の着弾予測地点が防衛管制システムに表示されます。プレイヤーは管制官として、地図の照準を見て都道府県名を4択から指定します。

防衛システムは一度に一都道府県しか迎撃できません。正しい名前を選べば迎撃成功。不正解または時間切れなら、**照準された都道府県だけ**が防衛失敗となります。誤って選んだ選択肢の都道府県は被害を受けません。

## 内容

- 北日本・東日本・中日本・近畿・中国・四国・九州・沖縄の6つの地域別モード
- 各地域でC評価以上を取ると、全国モード（47都道府県）が解放
- 着弾予測地点 → 同じ地域の4択 → 最終確定、という一問30秒の進行
- 地図のパン・ピンチズーム、着弾地点に正確に飛ぶミサイル演出
- 正解は迎撃・防衛済み表示、不正解・時間切れは照準地点だけを防衛失敗表示
- 防衛失敗県数、対象人口・面積、人口防衛率、最大連続成功数を結果表示
- 画像生成で制作した現代日本の防衛管制室ストーリー（スキップ可）
- 東日本の表示では、見やすさのため東京都の伊豆・小笠原など遠方島しょ部を省略（出題・人口・面積は東京都として扱う）

## データ

- 都道府県境界: 地球地図日本（国土地理院）由来の境界を `dataofjapan/land` がTopoJSON化したもの。出典を明記して使用しています。再配布・商用利用時は、配布元が案内する地球地図日本の利用条件を確認してください。
- 人口: 総務省統計局「令和2年国勢調査」の固定値。
- 面積: 国土地理院「全国都道府県市区町村別面積調」の2024年基準値。
- ストーリー画像: OpenAI Image Generationで新規生成。
